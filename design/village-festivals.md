# 村の祭り・季節イベント

`design/yorishiro-moods.md` `plan/quest-board.md` で採用した「端末の日付を
ハッシュして決める」仕組みをもう一段活かし、**周期的に村が賑わう日**を
作る。実在の暦・宗教行事は使わず、この世界独自の行事にする
(`design/world.md` の「名前も設定もすべてオリジナル」という方針を継ぐ)。

## 宵祭り(よいまつり)

### 内容
月に一度(目安: 日付キーの下1桁が特定の値になる日)、ネンネ村が
提灯を灯して**ヨリシロが今夜も穏やかに眠っていることを祝う**祭りを開く。
`design/world.md` の世界観そのもの(村はヨリシロを起こさぬよう暮らして
きた)を、年中行事として形にしたもの。

- 拠点のBGMが宵祭り専用の編成になる(`design/audio-direction.md` の
  「軽いレイヤーを足す」手法を流用)。
- `plan/shops-and-thieves.md` の近道屋の出店とは別に、宵祭り限定で
  村の広場に**普段は出回らない品**(地方限定素材の詰め合わせ等)が並ぶ。
- `design/village-life.md` のNPCが、この日だけ普段と違う一言を話す。
  絆(きずな)を進める特別な会話をここに割り当ててもよい。

### 位置づけ
戦闘・報酬に影響する内容は持たせない。**行っても行かなくても攻略上は
困らない、雰囲気を楽しむための日**とする(`design/balance-philosophy.md`
のパワーバジェット方針)。

## 樽比べ(たるくらべ)

### 内容
宵祭りとは別に、不定期(目安: 週1回相当の頻度)で村はずれに的が
並び、**タルを的に当てる精度を競う簡易ミニゲーム**が遊べるようになる。
コアのダンジョン探索とは独立した、短時間で遊べる寄り道コンテンツ。

- 制限時間内に、遠さ・的の大きさが異なる的をタルで狙う(既存の
  タル投擲操作(Gキー)をそのまま流用できる)。
- 成績に応じてほこら粉・刻印石を報酬にする。`plan/equipment-forging.md`
  の経済を回す、もう1つの供給源にする。
- 自己ベストを記録し、`plan/achievements.md` の実績(「樽比べで満点を出す」
  等)と接続する。

### 位置づけ
ダンジョンに潜らずとも遊べる短時間コンテンツを用意することで、
「今日は少しだけ遊びたい」という遊び方にも応える。`design/balance-philosophy.md`
の「深く潜る以外の目的を常に併存させる」方針の、拠点内で完結する版。

## データ構造

```ts
export function festivalForDate(dateKey: string): "yoimatsuri" | "tarukurabe" | "none" {
  /* moodForDate / questsForDate と同じ日付ハッシュの仕組みを再利用 */
}
```

`design/yorishiro-moods.md` の「今日の気分」表示と同じ場所(拠点の
出発前画面)に、今日開催中の行事も一緒に表示する。

## バランス上の注意

- いずれも**攻略必須にしない**。行事が無い日でも通常のダイブ・依頼
  (`plan/quest-board.md`)だけで問題なく遊び続けられることを前提にする。
- 樽比べの報酬は、`plan/equipment-forging.md` の経済を補う程度に留め、
  依頼板や店より効率の良い稼ぎ方にはしない(既存の収入源と競合させない)。
