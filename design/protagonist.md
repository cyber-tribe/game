# 主人公の個性(モンスターとの違い)

`design/characters.md` でガルドの人物設定は定めたが、ここでは
**ゲームシステム上、ガルドだけがモンスター(仲間含む)と何が違うのか**を
一度整理する。夢あわせ(`plan/monster-fusion.md`)・進化
(`plan/companion-evolution.md`)でモンスター側の個性づけを深掘りしてきた
のに対し、主人公側の掘り下げが手薄だったための補完。以後の
`plan/protagonist-equipment.md`(装備・アイテム)`plan/protagonist-arts.md`
(樽守りの技)は、ここで整理する非対称性を土台にする。

## 現状の実装からすでに確認できる非対称性

- **満腹度を持つのはガルドだけ**(`PlayerState.satiety`)。モンスターも
  仲間も空腹にならない。
- **道具・巻物・杖を使えるのはガルドだけ**(`Inventory` は
  `PlayerState` にしか存在しない)。
- **タルを担いで運ぶ・投げるのはガルドだけ**(`carrying` は
  `PlayerState` にしか存在しない)。
- **経験値を貯めてレベルが上がるのはガルドだけ**(`gainExp` は
  `src/game.ts` でプレイヤーにしか呼ばれていない。仲間は捕まえた時点の
  数値のまま、`plan/monster-fusion.md` の夢あわせでしか成長しない)。
- **所持金を持つのはガルドだけ**(`PlayerState.gold`)。

これらはすべて「作り忘れ」ではなく、**世界観上意味のある非対称性**として
そのまま採用する。

## 世界観上の理由づけ

`design/world.md` の通り、モンスターは夢のかけらそのものであり、
ガルドだけがこの世界で唯一の「現実側の生き物」。

- 空腹になるのは、夢に長居しすぎると現実側の足場が薄れていく存在
  だから(`design/world.md` の満腹度の説明そのもの)。夢のかけらである
  モンスターには、そもそも「現実側の足場」が要らない。
- 道具・タル・お金を扱えるのは、それらが**現実(麓)の物**だから。
  夢のかけらは夢の中でしか完結しない存在で、現実の道具の使い方を知らない。
- 経験値で育つのは、ガルドが**現実の生き物として経験を積んで成長する**
  存在だから。モンスターの成長が夢あわせ(=別の夢と混ざり合うこと)
  でしか起きないのと対照的にしている。

## 非対称設計の方針

**モンスター(仲間)の個性は「種族・特技・特性・進化」で作り、ガルドの
個性は「装備・技・レベル」で作る。** 混ぜないことで、それぞれの強化手段が
何のためにあるのかが分かりやすくなる(`design/balance-philosophy.md` の
「操作の複雑さを大きく崩さない」方針とも合う)。

| | ガルド | モンスター(仲間) |
|---|---|---|
| 成長の軸 | レベル(経験値)+装備+技 | 種族+特技+進化(夢あわせ) |
| 道具の扱い | 使える(杖・巻物・食料) | 使えない |
| タル | 運べる・投げられる | 運べない |
| 満腹度 | ある | ない |
| 全滅時 | 拠点に逃げ帰る(ゲームオーバーではない) | その回のダイブでロスト(道具と同じ扱い) |
| 村の各機能との関わり | すべての起点(依頼を受ける・絆を育む・図鑑を埋める) | 対象・素材になる側 |

## この先の掘り下げ

- `plan/protagonist-equipment.md`: 武器・盾に加えて頭防具・装身具の
  スロットを増やし、樽守りらしい専用装備・道具を追加する。
- `plan/protagonist-arts.md`: レベルや物語の進行で覚える、ガルド専用の
  能動的な技(樽さばき等)を追加する。モンスターのAIによる自動戦闘との
  違いを、プレイヤー自身の判断で繰り出す技として際立たせる。

## 未決事項

- 仲間にも経験値によるレベルアップを許すかどうかは、本文書では
  「許さない」を基本線にしたが、`plan/companion-evolution.md` との
  兼ね合いは実装時に再確認してよい。
- 満腹度・道具・タル・お金のいずれかを将来仲間にも一部開放する場合は、
  本文書の非対称設計の方針を先に見直すこと。
