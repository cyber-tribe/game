# ネンネ村の建物考証 ― 暮らし・生業・タルとの関係・歴史

`design/yorishiro-and-barrels.md`(祠木とタルの考証)を土台に、
村の各建物が「どんな生活と生業の場で、タルとどう関わり、どんな
歴史を背負っているか」を定める。モデリング
(`plan/models/model-village-structures.md`)・画面構成
(`plan/models/village-scene-redesign.md`)・音
(`plan/sound/village-soundscape.md`)の再設計は本書を出典とする。

## 村の全体像

- ネンネ村は**祠木の疎らな林の中に建った村**である。家々は祠木を
  伐り拓いた跡地に建ち、村のどこからでも山(ヨリシロ)の稜線が
  見える。「山に背を向けて建てない」のが村の作法で、**主要な建物は
  すべて入口が山側を向く**。
- 建材は祠木の間伐材。**タルと同じ木でできた村**なので、村全体が
  樽色(飴色の木肌)で統一される。屋根は伏せたタルを思わせる
  緩い丸屋根が基本(「夜ざらしのタルは伏せる」の作法が建築にも
  及んだ、という考証)。
- 村の中心は広場の**囲炉裏火(いろりび)**。夢は火を嫌って近寄らない
  と伝わり、村が夢に呑まれないための「現実側の錨」として一年中
  絶やさない。祭り(宵祭り)もこの火を囲んで行う。

## 各建物の考証

### 洞窟の入口(山の口)
- **歴史**: 初代がはじめて器の世話(`yorishiro-and-barrels.md` の
  「器の時代」)を行った風穴。村はこの穴を中心に拓かれた。
- **暮らし**: 入口の両脇に一対の古い祠木が門柱のように立ち、
  しめ縄ならぬ**タルのたが(箍)を結んだ縄**が渡してある。潜る者は
  ここで一礼して入る。出発の支度(持ち込み・行き先選び)は
  入口脇の**支度小屋**(棚と長机だけの吹きさらしの小屋)で行う。

### モグラ婆の倉庫
- **生業**: 村の共有蔵の番。持ち帰った道具・素材の預かりと帳付け。
- **タルとの関係**: 倉庫の棚は**すべて伏せたタルを転用**したもの。
  古タルは捨てずに蔵の棚・腰掛け・水汲みに降ろすのが村の習い
  (タルの一生: 現役→蔵の棚→薪にはしない=禁忌)。
- **歴史**: 元は樽蔵(できたタルの貯蔵庫)。モグラ婆が目を悪くして
  樽守りを退いたとき、村総出で改装して倉庫番の住まいを継ぎ足した。
  ガルドの育ての親の家でもあり、ガルドはこの倉庫の屋根裏で育った。

### ゲンドの工房
- **生業**: 祠木の伐り出しからタル作りまでの一貫工房。装備の強化・
  刻印(`plan/game/archive/equipment-forging.md`)も、祠木の削り粉
  (ほこら粉)を炉で焼き付ける技の応用として同じ炉で行う。
- **タルとの関係**: 「怒りっぽい木」(ばくはつタルの材)を扱える
  村で唯一の男。工房の裏には材の祠木が寝かせて乾かしてある。
- **歴史**: ゲンドの家系は器の時代から続く樽大工の本家。炉の火は
  広場の囲炉裏火から株分けしたもの、という筋で「村の火はひとつ」の
  信仰につながる。

### ねむり小屋(フク)
- **生業**: 捕らえた夢のかけら(タル入りの仲間)の預かりと
  寝かしつけ。夢あわせ(`plan/game/archive/monster-fusion.md`)の
  立ち会い、改名、夢返し(逃がす)の作法一式。
- **タルとの関係**: 小屋の中は**タルの寝床がずらりと並ぶ**。それぞれ
  薄い掛け布と名札が付く。フクはヨリシロの寝息と同じ拍でタルを
  ゆっくり揺らして回る(`yorishiro-and-barrels.md` の口伝の実践)。
- **歴史**: 元は病人を寝かせる湯治小屋。かけらの世話が生業になった
  「暮らしの時代」に今の役目へ変わった。だから作りが宿に似ている。

### おキヨの図鑑小屋
- **生業**: 夢のかけらの観察記録(図鑑)。旅暮らし時代の標本と
  書物が壁を埋める。
- **タルとの関係**: 記録は**タルの側板に焼き付けた木札**に書く
  (紙より夢気に強い、という考証)。図鑑=木札の束。
- **歴史**: おキヨは外から来た人で、村に「記録する」文化を持ち込んだ
  新参(それでも30年)。イト(記録の間)の師匠でもある。

### 記録の間(イト)
- **生業**: 村の帳場。ダイブの記録・実績・称号、村の歴史の管理。
- **タルとの関係**: 巻物棚の芯棒はタルのたがの再利用。村の年代記
  「ねむりのしおり」は初代からの樽守りの名を連ねた巻物で、
  最後の行にガルドの名がある。
- **歴史**: 帳場としては村で一番新しい建物だが、収めている記録は
  一番古い。おキヨの記録文化とオトネの窓口仕事が合流してできた。

### オトネの依頼板
- **生業**: 村の窓口。困りごとを聞き取り、依頼札にして板に貼る。
- **タルとの関係**: 依頼板そのものが**大タルの底板を並べた板壁**。
  依頼を果たすと札を裏返す(タルの木は裏表で色が違う)。
- **歴史**: うなされ声を聞いた者が祠木の根元に文句を書き置いた
  「祈りの時代」の名残が、窓口仕事に整えられたもの。

### 村の広場(ポチ・おたま)
- **暮らし**: 中心に囲炉裏火。周りにタルの腰掛け。夕方は村人が
  火を囲み、宵祭り(`design/village-festivals.md`)の出店もここに
  立つ。子供(ポチ)の遊び場で、遊びは「タル転がし」(樽比べの
  ミニゲームの原型、という接続)。
- **歴史**: 火を絶やさぬ番は村人の持ち回り。おたまが救出後に
  火の番を買って出る(進行連動の小さな変化の題材)。

### ガルドの家
- **暮らし**: 樽守り本家の小さな家。土間に支度用のタルが一つ、
  壁に歴代の樽守りの手形が押してある(身支度=衣装替えの場)。
- **歴史**: 両親の代の記録は「ねむりのしおり」に空白がある
  (`design/story.md` の含みに接続。ここでは掘らない)。

### 旅の看板
- 村の出入り口の古い立て札。旅人たちの記録が貼り出される予定地
  (みんなの記録)。板はやはりタルの側板の再利用。

## 生業の循環(村の経済の考証)

```
祠木の林 → ゲンドの工房(伐る・作る) → 樽守り(潜る・世話する)
   ↑                                        ↓
 夢返し(森へ帰す) ← ねむり小屋(預かる) ← 持ち帰り(倉庫・記録)
```

村の外との行商が金銭(G)の出どころ: 夢のかけら由来の素材
(ほこら粉・地方素材)は外の職人に高く売れる。ただし生きたかけら・
タルそのものは**決して売らない**(世話の対象を商品にしない、が
村の一線。`design/economy.md` の設定側の裏付け)。
