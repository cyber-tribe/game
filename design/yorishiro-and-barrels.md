# ヨリシロとタル ― 眠る山と、夢のゆりかごの考証

`design/world.md` は「祠木(ほこらぎ)には夢を出し入れする性質が
わずかに残っている」とだけ述べ、**なぜ木の器が巨人の夢に干渉できる
のか**、**タルを使うことはヨリシロにとって何なのか**を掘っていない。
この2つのキー設定の関係を、以後のすべての仕様(タルわざ・村の建物・
祭事)の土台になる深さまで考証する。

## 1. 祠木はなぜ夢を容れられるのか

ヨリシロは眠りながら夢を見て、夢は寝息とともに山の土へ染みる。
祠木はヨリシロのひげの根から生えた木であり、**根がいまもヨリシロに
つながっていて、樹液として夢を吸い上げている**。祠木の年輪が
渦を巻くのは、吸い上げた夢が幹の中でゆっくり回り続けているからだ
――と村では言う。

つまり祠木の幹は、生まれつき**「夢が満ちている容れ物」**である。
くり抜いて空洞を作ると、空洞は「夢の抜けた分だけ、夢を呑もうとする」。
これが空のタルがモンスター(夢のかけら)を吸い込む理由の考証となる。
**タルは道具である前に、祠木の性質そのもの**であり、村人はそれを
器の形に整えているに過ぎない。

- 弱った夢のかけらほど呑まれやすいのは、「形を保つ夢の力」が
  空洞の吸う力に負けるから(`captureChance` がHPで決まることの裏付け)。
- タルの中の夢のかけらが暴れないのは、幹に残る夢の記憶が
  **ヨリシロの寝息と同じ拍**でかけらを揺らし、寝かしつけるから。
  ねむり小屋のフク(`design/village-life.md`)の「よく眠る子はよく育つ」
  は、この拍を人の手で補う技の口伝である。

## 2. タルを使うことは、ヨリシロの世話である

夢のかけらが洞窟に湧きすぎると、ヨリシロの夢は騒がしくなり、
眠りが浅くなる(=`design/yorishiro-moods.md` の「気分」が荒れる)。
村に伝わる理解では、**タルでかけらを捕らえて連れ出すことは
「うなされている夢を間引いて、眠りを深くしてやる」世話**にあたる。

- 樽守り(ガルドの家業)の本義は「タルの番人」ではなく
  **「タルを使って眠りを守る者」**。狩人でも退治屋でもない。
  この解釈が、モンスターを「悪者ではなく寝ぼけた夢の住人」とする
  トーン(`design/world.md`)と、倒すより捕まえることに価値がある
  ゲームデザインの、設定側の根拠になる。
- 仲間を「逃がす」(`plan/game/archive/release-companion.md`)は
  **夢返し**と呼ばれ、行き場を定めてかけらを夢へ帰す作法。
  乱雑に割って捨てるのではなく、村はずれの祠木の根元で行う。

## 3. タルの種類の考証

- **空のタル**: 上記のとおり「夢を吸おうとする空洞」。
- **ばくはつタル**: 脂の多い祠木の個体は、吸った夢を練りすぎて
  幹の中で澱(おり)にする。澱は衝撃で一気にほどけ、夢を破裂させる。
  村では「怒りっぽい木」と呼び、伐るのは職人だけに許される。
- **元素タル(`plan/game/barrel-arts.md` の水・風・光・石・ねむ)**:
  仲間の夢のかけらが**自分の夢気(ゆめけ)をタルへ吹き込んだ**もの。
  かけら自身が夢でできているからこそ、タルの空洞に「自分の性質の
  夢」を満たせる。タルわざが仲間にしかできない(人間にはできない)
  こと、なじみが深いほど濃い夢気を注げること(強力版)の考証になる。
- **あける**(同仕様書)は、満たした夢気を現実の側へこぼす行為。
  夢は現実に触れるとすぐ薄れて消えるため、効果がその場限りなのも
  筋が通る(水びたしの床がやがて乾く、壁がいずれ崩れる等の
  実装都合を設定側から支える)。

## 4. 歴史 ― 村とタルの三つの時代

1. **祈りの時代**: 最初の移住者たちは、山がうなされるたび地滑りや
   霧に苦しみ、祠木の根元に供え物をして祈るだけだった。
2. **器の時代**: あるとき倒れた祠木の洞(うろ)に夢のかけらが
   自分から入り込み、静かになったのを見て、初代の樽守りが
   「器で世話をする」ことを覚えた。タルの原型は自然の洞である。
   ネンネ村はこのとき、祈る村から**世話をする村**へ変わった。
3. **暮らしの時代(現在)**: 樽作り・寝かしつけ・記録・依頼の
   分業が整い、村の生業がすべてタルを軸に回るようになった
   (各建物の生業は `design/village-buildings.md` で詳述)。

## 5. 作法と禁忌

- **タルを火にくべない**(中の夢ごと燃やすのは夢返しの作法に反する。
  ばくはつタルの使用は「洞窟の中=夢の内側」でだけ許される)。
- **空のタルを口を上にして夜ざらしにしない**(夜の夢を勝手に吸う。
  村のタルが全部伏せて積まれている理由。モデリング指針に効く)。
- **めざめの階段の上でタルを抱えたまま降りない**(夢と現実の境で
  中身が迷子になる、と伝わる。`plan/game/archive/
  barrel-stairs-safeguard.md` の制限の設定側の根拠)。

## 6. ゲーム仕様との対応表

| 仕様 | 考証 |
|---|---|
| 捕獲率がHPで決まる | 形を保つ夢の力と空洞の吸う力の綱引き |
| タルわざは仲間にしかできない | 夢気を注げるのは夢のかけらだけ |
| なじみで強力版 | 懐くほど濃い夢気を注げる |
| 元素タルの効果がその場限り | 夢は現実に触れると薄れる |
| 捕獲・連れ出しが推奨される遊び | 眠りの世話=樽守りの本義 |
| ヨリシロの気分 | 夢のかけらの騒がしさ=眠りの浅さ |
