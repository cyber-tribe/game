# 小ネタ・遊び心

数値・システムの設計が積み上がってきたので、ここで一度**細部の手触り**
に焦点を当てる。同じ台詞・同じ説明文を何百回も見ることになるローグ
ライクだからこそ、細部の作り込みが「毎回似たダンジョンの繰り返し」
という反復感(`design/balance-philosophy.md`)を和らげる最後の一押しに
なる。

## アイテムの、もうひとつの説明文

現状のアイテム説明(`ItemDef.description`)は「HPを25回復する。」のような
機能の説明に徹している。これは操作上必要なのでそのまま残しつつ、
**もう1行、味のある一言(`flavorText`)を足す**。

```ts
// ItemDef に追加
flavorText?: string;
```

例:
- いやしの葉 →「かむと青くさいが、傷にはよく効く。ガルドは苦手な顔をする」
- ばくはつタル →「ゲンド曰く『とにかく揺らすな』」
- 鉄のなた →「重い。振り慣れるまでガルドの利き腕が筋肉痛になった」

機能説明とは別枠にすることで、**プレイヤーが読み飛ばしても実害がない**
(遊びに必須の情報は従来通り `description` 側にある)ようにする。

## NPCのせりふプール

`design/village-life.md` のNPCは、毎回同じ一言だと数十回目の来訪で
急に安っぽく感じられる。各NPCに**複数の候補セリフ**を持たせ、来訪の
たびに(直前と同じものは避けて)ランダムに選ぶ。

```ts
export interface DialoguePool {
  npcId: string;
  context: "default" | "afterFestival" | "moodRestless" | "highBond";
  lines: string[];
}
```

`design/yorishiro-moods.md` の気分・`design/village-festivals.md` の
行事・`design/village-life.md` の絆段階を `context` に指定できるようにし、
既存のこれらの仕組みに新しい分岐を増やさず、**テキストデータを差し込む
だけ**で会話のバリエーションが増えるようにする。

## モンスターの小さな仕草

戦闘に関わらない待機時の細かい動き(README記載の`idle`クリップの範囲内)
で個性を足す。新規クリップの追加はコストが高いため、既存の`idle`の
再生速度・タイミングの調整だけで表現できる範囲に留める。

- ぷるんは待機中、ゆっくり上下に揺れる
- ガジリねずみは待機中、きょろきょろと周囲を気にする(臆病な性格
  (`plan/monster-compendium.md`)の裏付け)
- ホネガラミは待機中、ほとんど動かない(古い記憶が積み重なっている
  という設定に合わせ、鈍重さを見せる)

## 隠れた小ネタの例

- `design/village-life.md` の**物知りのおキヨ**に、まだ捕まえていない
  種族について尋ねると、正確な数値は言わず「たしか、湿地のあたりで
  跳ねているのを見た気がするねぇ」のような**うろ覚えのヒント**を返す。
- `design/village-life.md` の**ひよっこのポチ**は、特定の弱いモンスター
  (例: ぷるん)だけを妙に怖がる、という一貫したキャラ付けを台詞の端々に
  仕込む。
- `plan/equipment-forging.md` の**樽転がしのゲンド**は、強化値が+9に
  達した装備を見せると、それ専用の一言(「わしの手を離れた」)を返す。

## 実装コストの抑え方

本文書の内容はすべて**テキストデータ・軽い分岐の追加**で完結し、新しい
システムを作らない。`design/balance-philosophy.md` の「操作の複雑さを
大きく崩さない」方針にも合致する、**投資対効果の良い作り込み**として
優先度を判断してよい。
