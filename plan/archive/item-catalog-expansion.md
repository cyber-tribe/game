# アイテム図鑑の拡充

> **実装済み。** `src/items/catalog.ts`(草2種・巻物2種・杖2種・食料2種の
> 計8アイテム)・`src/items/effects.ts`(`defenseUp`・`senseStairs`・
> `invisibility`・`fearRoom`・`pull`・`sealTarget`)・`src/core/types.ts`
> (`STATUS_INVISIBLE`・`STATUS_FEAR`)・`src/entities/ai.ts`(透明中は新規に
> 気づかない、おびえは最優先で逃走、封じられている間は遠隔攻撃/特技を
> 出さない)・`src/game.ts`(封じられている攻撃者は状態異常の追加付与を
> 出さない)。テストは `tests/item-catalog-expansion.test.ts`。
>
> 実装時の決定:
> - 「かなしばりの杖」で付与する封じ(`STATUS_SEAL`)は、これまで型だけ
>   定義されていてゲームロジック上は何もしていなかった。今回はじめて
>   実際の効果(遠隔攻撃の禁止・攻撃時の状態異常追加付与の禁止)を実装した
> - 各アイテムの出現階層・重み・持続ターン数(とうめいの巻物5ターン、
>   おびえの巻物6ターン等)は未決事項だったため実装時に決定した

現状のアイテム図鑑(`src/items/catalog.ts`)は草3種・巻物3種・杖2種・
食料2種(`plan/status-effects.md` で草2種を追加予定)と、まだ選択の幅が
狭い。既存の効果システム(`src/items/effects.ts` の `applyEffect` の
switch文)に効果を1つずつ足す形で、無理なく種類を増やす。

## 追加する草

| 名前 | 効果 | 備考 |
|---|---|---|
| がんじょうの葉 | defense永続+1 | 既存の「ちからの葉」(attack永続+1)と対になる |
| みちしるべの葉 | 階段の位置と、そこまでの大まかな道筋だけが分かる | 「地図の巻物」(全地形判明)の下位互換・安価版。序盤の手頃な探索補助 |

## 追加する巻物

| 名前 | 効果 | 備考 |
|---|---|---|
| とうめいの巻物 | 数ターンの間、モンスターに発見されなくなる(`aware`にならない) | `plan/combat-mechanics.md` の不意打ち(未発見の相手には確定会心)と直接噛み合う。使ってから畳みかける、という組み立てが生まれる |
| おびえの巻物 | 同じ部屋のモンスターを「眠り」「混乱」ではなく**逃走**させる | 既存の「ねむりの巻物」「混乱の巻物」と並ぶ3つ目の部屋制圧手段。無力化ではなく退避に寄せた選択肢 |

## 追加する杖

| 名前 | 効果 | 備考 |
|---|---|---|
| 引き寄せの杖 | 向いている方向のモンスターを1マス引き寄せる | 「場所替えの杖」(位置を入れ替える)の逆方向版。遠隔モンスターを詰め寄らせて各個撃破する使い方 |
| かなしばりの杖 | 向いている方向のモンスターに「封じ」を付与する | `plan/status-effects.md` で追加した封じ状態を、プレイヤー側からも狙って使えるようにする(現状はヨロイムカデ等から受ける一方だった) |

## 追加する食料

| 名前 | 効果 | 備考 |
|---|---|---|
| 山の幸 | 満腹度を150回復 | 「大きなパン」より上位。深い地方(`design/regions.md`)でのみ出現し、深追い用の備え |
| ほしぼし | 満腹度を15回復 | 効果は小さいが軽くて安価。序盤〜終盤問わず持ち歩きやすい「つなぎ」の食料 |

## 追加する効果ハンドラ

```ts
// src/items/effects.ts の applyEffect に追加
case "defenseUp": ...      // がんじょうの葉
case "senseStairs": ...    // みちしるべの葉
case "invisibility": ...   // とうめいの巻物
case "fearRoom": ...       // おびえの巻物
case "pull": ...           // 引き寄せの杖
case "sealTarget": ...     // かなしばりの杖
```

いずれも既存の `affectRoom` / `targetStatus` / プレイヤーへの直接効果、
という3パターンのいずれかに当てはめられるため、新しい効果の「種類」は
増やすが、効果を適用する仕組みそのものは増やさない。

## バランス上の注意

- とうめいの巻物は`design/balance-philosophy.md`のパワーバジェット対象。
  「確実に不意打ちできる」という強い効果のぶん、持続ターンは短め
  (目安5ターン程度)に抑え、無制限の蹂躙にはしない。
- かなしばりの杖は、モンスターの行動を丸ごと止める`sleepTarget`(既存の
  ねむりの杖)と役割が被らないよう、**道具・特技を封じるだけで通常攻撃は
  封じない**という既存の封じ状態の定義(`plan/monster-compendium.md`の
  ヨロイムカデ)をそのまま踏襲する(行動不能にはしない)。
