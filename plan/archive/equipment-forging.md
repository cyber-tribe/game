`design/characters.md` で設定した拠点NPC **樽転がしのゲンド**(村の樽細工職人)

## 世界観との接続

- **強化値**: ゲンドが祠木の粉(後述)を使って刃や盾を研ぎ・馴染ませる、
  という素朴な鍛冶仕事として説明する。
- **印(いん)**: `plan/monster-fusion.md` の「夢あわせ」で仲間同士が特技を
  引き継ぐのと対になる仕組みにする。倒した夢のかけらが稀に残す
  **刻印石(こくいんいし)** に、その個体の性質のかけらが宿っており、
  それを武器・盾に刻み込むと、性質の一部を装備に移せる――という理屈。
  「モンスターの個性が、仲間としてはスキルに、素材としては装備の印になる」
  という一貫性を持たせる。

## 強化値(+n)

- 武器・盾それぞれに `+0`〜`+9` の強化値を持たせる。
- 強化には **ほこら粉** (新規アイテム、ダンジョン内のドロップ品)を使う。
  ゲンドの工房(拠点)でのみ強化でき、ダンジョン内では行えない。
- 1回の強化で `+1` され、必要な「ほこら粉」の個数は強化値が上がるほど
  増える(例: `必要数 = 2 + plus`)。**失敗して装備が壊れる・強化値が
  下がるといったマイナス方向のランダム性は入れない。** 素朴で温かい
  トーン(`design/world.md`)を壊さないよう、強化は「時間と素材をかければ
  必ず伸びる」安心設計にする。
- 効果: 武器は `+1` ごとに攻撃力 `+2`、盾は `+1` ごとに防御力 `+1`
  (既存の `bonus` 値: ておの(4)/はがねの(9)、木の盾(3)/はがねの盾(7) と
  比べて急激に強くなりすぎない比率にしている。実装時に既存装備の
  バランスと合わせて微調整してよい)。

## 印(刻印)

- 武器・盾は、強化値とは別に **印を1つ**まで持てる(上限は将来2つに
  広げる余地を残す)。
- 印は、対応する刻印石をゲンドの工房に持ち込み、費用(ほこら粉少量+刻印石)
  を払って刻む。既に印がある装備に別の印を刻むと、古い印は上書きされる
  (刻印石も消費される)。
- 印の種類は、既存モンスター5種にそれぞれ対応させ、`plan/monster-fusion.md`
  の特技一覧と対で覚えやすくする。

| 印 | 由来 | 装備部位 | 効果案 |
|---|---|---|---|
| ぷるんの印 | ぷるん | 盾 | 被弾ダメージを確率5割で1割軽減 |
| ガジリねずみの印 | ガジリねずみ | 武器 | そのランの最初の1手を必ず先制できる |
| ツブテガエルの印 | ツブテガエル | 武器 | タルを投げたときのダメージ+2 |
| マドロミダケの印 | マドロミダケ | 武器 | 攻撃時、眠り付与の確率+10%(通常攻撃に眠りが乗る) |
| ホネガラミの印 | ホネガラミ | 盾 | HPが1残っていれば、致死ダメージを1回だけ耐える(1ラン1回) |

`plan/monster-fusion.md` の特技表と効果をほぼ揃えているのは意図的。
「仲間として育てるか、装備の力にするか」という選択をプレイヤーに
持たせるため、同じ性質を2つの手段で得られるようにしている。

## データ構造

```ts
// Item (core/types.ts)
export interface Item {
  uid: number;
  defId: string;
  charges?: number;
  plus?: number;     // 強化値。武器・盾以外は常に undefined
  markId?: MarkId;   // 刻んだ印。未刻印なら undefined
}

export type MarkId = "purun" | "gajiri" | "tsubute" | "madoromi" | "honegarami";
```

`weaponBonus` / `shieldBonus`(`src/items/inventory.ts`)は `plus` を
加味した計算に拡張する。印の効果(先制・眠り付与率upなど)は戦闘計算
(`src/systems`)側で `markId` を見て分岐させる。

新規アイテム:
- `ほこら粉`(`category: "material"` 相当。既存の `ItemCategory` に
  `"material"` を追加するか、専用の非インベントリ資源として扱うかは
  実装時に判断)
- `刻印石`(5種、それぞれ対応モンスターの低確率ドロップ)

## 拠点UI

- ゲンドの工房を拠点メニューに追加。
  - 「強化する」: 持ち物/倉庫の武器・盾を選び、ほこら粉を消費して `+1`
  - 「印を刻む」: 対象装備 + 刻印石を選び、印を刻む(上書き注意の確認あり)
- `src/ui/town.ts` の一覧UIパターンを踏襲する。

## バランス指針

- 強化値・印とも、ダンジョン内では変更できない(拠点限定)ことで、
  「潜る前にどう備えるか」を考える楽しさに寄せる。
- 印を装備に賭けるか、その素材(刻印石)を将来仲間に使う想定の別ルートに
  取っておくか、という選択は本仕様の対象外(刻印石を夢あわせにも使える
  ようにするかは今後の検討課題とし、現時点では別素材として扱う)。
