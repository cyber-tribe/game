# ホネダタミ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第四地方(骨積みの回廊)。

1. **三語コンセプト**: 積み重なった重み・道をふさぐ・動かない
2. **シルエットの記号**: 既存の重なった骨板(`honeda_plate`/
   `honeda_plate2`素材)。丸い骨の輪郭に硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 骨板が積み重なった塊、横に広い1頭身
4. **パレット**: 基色=骨の生成り `(0.86, 0.83, 0.72)` / 従色=骨板の灰
   `(0.60, 0.58, 0.53)` / 差し色=眼窩の光 `(0.68, 0.58, 0.32)`
5. **設定の見せ場**: design/characters.mdの「積み重なった記憶の重み
   そのもの。通路の真ん中に居座り、道をふさいでどかない」設定を、
   隙間なく積み重なった骨板で表す
