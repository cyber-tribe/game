# こだまぐも

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第六地方(こだまの尾根)。

1. **三語コンセプト**: 響きに寄る雲・群れ・音に惹かれる
2. **シルエットの記号**: 既存の岩(`kodamagumo_rock`素材)。丸い
   体表面に唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 雲のような丸い群れ型、1頭身弱
4. **パレット**: 基色=岩の灰 `(0.58, 0.57, 0.56)` / 従色=土の茶
   `(0.60, 0.48, 0.34)` / 差し色=口の暗色 `(0.28, 0.20, 0.15)`
5. **設定の見せ場**: design/characters.mdの「響きに寄ってくる、雲の
   ような群れ。こだまうさぎと同じく、音に惹かれて群がる」設定を、
   響きに寄り集まった岩の塊で表す
