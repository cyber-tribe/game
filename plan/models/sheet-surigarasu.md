# スリガラス

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第一地方(うたたねの参道)。

1. **三語コンセプト**: 他愛のない衝動・光るもの・すぐ逃げる
2. **シルエットの記号**: 既存の角ばったくちばし(`suriga_beak`素材、
   `box`)。丸い羽毛の輪郭にくちばしだけが硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 鳥型、細身で1頭身弱
4. **パレット**: 基色=羽毛の茶 `(0.62, 0.56, 0.46)` / 従色=翼の濃茶
   `(0.50, 0.44, 0.36)` / 差し色=くちばしの山吹 `(0.68, 0.56, 0.32)`
5. **設定の見せ場**: design/characters.mdの「ふと目についたものを
   持っていきたくなる、他愛のない衝動」「悪意ではなく光るものに
   気を取られるだけ」設定を、鋭いくちばしの一点だけに差し色を
   置くことで表す
