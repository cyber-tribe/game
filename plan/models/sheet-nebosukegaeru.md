# ねぼすけがえる

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第三地方(まどろみの茸林)。

1. **三語コンセプト**: より深い眠り・動かない・起こされ反撃
2. **シルエットの記号**: 定位置に居座り続けた証として、背に苔むした
   硬いこぶを新設する(`C.box`+ベベル。
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: ツブテガエルの遠い親戚、どっしり低い姿勢
4. **パレット**: 基色=土の焦茶 `(0.30, 0.22, 0.15)` / 従色=胞子の
   山吹 `(0.80, 0.70, 0.44)` / 差し色=口の中の暗緑 `(0.18, 0.24, 0.14)`
5. **設定の見せ場**: design/characters.mdの「ツブテガエルの遠い親戚で、
   より深く眠っている。ふだんは動かないが、起こされる(攻撃される)と
   跳ねて反撃する」設定を、動かないまま苔むしたこぶで表す
