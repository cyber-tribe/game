# わたあめのおばけ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第七地方(わすれられた祭りの跡)。

1. **三語コンセプト**: 甘い匂い・誘われる夢・煙を残して逃げる
2. **シルエットの記号**: 刺さったままの割り箸(菓子の芯棒)を新設する
   (`C.cylinder`。わたあめが割り箸に巻かれたまま夢になった、という
   見立て。plan/models/archive/
   silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: ふわふわした綿状の塊、1頭身弱
4. **パレット**: 基色=綿の桃 `(0.78, 0.52, 0.56)` / 差し色=きらめき
   `(0.82, 0.66, 0.30)`
5. **設定の見せ場**: design/characters.mdの「甘い匂いに誘われる夢。
   触れると煙のような幻を残してすぐ逃げる」設定を、割り箸に巻かれた
   わたあめそのものの形で表す
