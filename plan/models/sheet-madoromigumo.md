# まどろみぐも

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第三地方(まどろみの茸林)。

1. **三語コンセプト**: 隙間に張る糸・気配なし・不意打ち
2. **シルエットの記号**: 既存の牙(`madoromi_fang`素材)。丸い体表面に
   唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 蜘蛛型、低く構えた姿勢
4. **パレット**: 基色=体の焦茶 `(0.28, 0.21, 0.15)` / 従色=脚の暗色
   `(0.24, 0.18, 0.13)` / 差し色=模様の山吹 `(0.70, 0.60, 0.36)`
5. **設定の見せ場**: design/characters.mdの「まどろみの隙間に糸を張る
   蜘蛛。隣接するまで気配を消し、油断したところに噛みつく」設定を、
   隠れた牙で表す
