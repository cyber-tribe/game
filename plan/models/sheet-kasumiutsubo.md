# かすみウツボ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。配合限定(モヤウツボ×ワスレガニ)。

1. **三語コンセプト**: 薄れる存在感・かすめ避ける・忘却の果て
2. **シルエットの記号**: ワスレガニの甲殻が薄く透けた、面取りの浅い
   小さな殻の欠片を新設する(`C.box`+ベベル。「存在感そのものが
   薄れ」た結果、殻もほとんど残っていない状態を表す。
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: モヤウツボと同じ細長い体、より淡く透けた印象
4. **パレット**: 基色=背の青緑 `(0.56, 0.64, 0.64)` / 従色=腹の
   暗青緑 `(0.34, 0.42, 0.44)` / 差し色=口の暗色
5. **設定の見せ場**: design/characters.mdの「『忘れる』というテーマを
   さらに煮詰めた結果、存在感そのものが薄れ、相手の攻撃をかすめて
   避けやすくなる」設定を、ほとんど残っていない殻の欠片で見せる
