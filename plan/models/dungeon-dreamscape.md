# ダンジョンを「夢の中」の見た目にする ― 地方別タイルセットと夢の演出言語

## 診断

全ダンジョンが「コンクリートブロックの積み上げ」に見える原因は
構造的で単純:**wall/floor/stairsの同一ボックスモデルを全地方で
使い回し、色味だけ変えている**。同一サイズの直方体が整列した絵は、
どんな色でもブロック塀にしかならない。そして何より、ここは
**ヨリシロの夢の中**(`design/world.md`)であり、石造りの遺跡である
必要がそもそも無い。設定を見た目の武器に変える。

盤面のグリッド・生成ロジック・当たり判定は一切変えない。
**変えるのは見た目のレイヤーだけ**(`wall`/`floor`/`stairs` の
モデル差し替えと描画演出)。

## 1. 夢の演出言語(全地方共通)

どの地方でも守る「夢の中」の共通文法を先に定める:

- **部屋の外は虚空ではなく「夢のもや」。** フロアの外周を黒ではなく、
  地方色の淡い霧がゆっくり渦を巻く空間にする(大きな半透明の
  もやビルボードを数枚、ゆっくり回転・明滅)。床の最外周タイルは
  縁がもやに溶けるようにフェードさせる(頂点アルファ)。
  「どこまでも続く建物」ではなく「夢が形を結んでいる範囲だけ
  地面がある」という絵にする。
- **上方は夢空。** 天井は作らず、上方に地方色の緩いグラデーション
  +ぼんやり漂う光の粒(既存パーティクル基盤の低頻度流用)を置く。
- **壁はわずかに呼吸する。** 壁メッシュの頂点にごく小さな
  低周波の揺らぎ(振幅2〜3cm・周期5〜8秒)を入れ、静止した
  石ではなく「夢が保っている形」に見せる。酔わない振幅に留める。
- **ヨリシロの記憶の断片。** ときどき、スケールの外れた日用品が
  地形として埋まっている――巨大な湯呑みが池のように水を湛える、
  巨大なタルのたがが門になっている、巨大な木槌が壁にもたれて
  いる等。1フロアに0〜1個、装飾専用(当たり判定は下のタイルの
  まま)。夢らしさが最も安く出る一手。

## 2. 地方別タイルセット

`wall`/`floor`/`stairs` を地方ごとのセットに差し替える
(`TERRAIN_MODELS` を地方キー付きに拡張)。各セットは
壁3種+床3種のバリアントを持ち、ランダム配置+ランダム90度回転で
繰り返し感を消す。造形は `visual-quality-uplift.md` の基準
(ベベル・AOベイク・上下グラデーション)に従う。

| 地方 | 壁 | 床 | 階段 |
|---|---|---|---|
| うたたねの参道(一) | 苔むした太い木の根がうねって壁を成す | 踏み固められた土+木の根、木漏れ日の模様 | 根の段々 |
| 忘れ潮の湿地(二) | 葦の束と泥の土手 | ぬかるみ+点在する水たまり(反射) | 泥に沈む丸太 |
| まどろみの茸林(三) | 巨大きのこの軸と傘の壁、菌糸のカーテン | 菌糸の走る腐葉土、発光する小きのこ | きのこの傘の螺旋 |
| 骨積みの回廊(四) | 積まれた大骨と乾いた砂岩 | ひび割れた乾いた土、砂紋 | 骨の段 |
| なみだの滝つぼ(五) | 濡れて黒光りする岩+細い水の膜が流れ落ちる | 濡れ岩、浅い水面 | 水が流れる岩段 |
| こだまの尾根(六) | 風化した岩柱、隙間から夢空が見える | 風紋の岩盤 | 岩の張り出し |
| わすれられた祭りの跡(七) | 色あせたやぐらの木組み、破れた幕、消えた提灯 | 祭りの敷石、こぼれた紙吹雪 | やぐらの階段 |
| めざめの前庭(八) | 雲母のような半透明の夢石(内側に光が揺れる) | 鏡面がかった夢石、足元に星のような光 | 光の段 |

- 制作は既存のBlenderパイプライン(`tools/models/props.py` の
  wall/floor/stairs の置き換え関数群を地方別に増やす)。
  タイル単価の三角形数は `visual-quality-uplift.md` の予算
  (500〜1,000/タイル。特徴的な壁は〜2,000)に従う。
- 展開順: まず**第一地方(うたたねの参道)を1式作って
  エンジン内プレビューで検証**し、文法(もや・夢空・揺らぎとの
  合わせ方)を固めてから残り7地方へ横展開する。

## 3. フロアの中の見せ場

- 大部屋の1つに、その地方の**ランドマーク**を置く(第一=大樹の
  切り株の広間、第三=見上げるほどの傘の下、第七=朽ちた櫓の
  正面 等。装飾専用で盤面には干渉しない)。
  「どの部屋も同じ」を部屋単位でも壊す。
- 既存のフロアギミック(胞子・急流・宴 等)の見た目は、この
  タイルセットの上に従来どおり重なる(競合しない)。

## 受け入れ基準

1. 第一地方のフロアが「ブロックの積み上げ」に見えない
   (壁・床にバリアントと有機的なシルエットがあり、外周がもやに
   溶け、上方に夢空がある)。
2. 地方を移ると、色だけでなく**形が**変わる。
3. 壁の揺らぎ・もやの動きが酔いを誘わない(実機で確認)。
4. 生成ロジック・当たり判定・ミニマップの見え方は従来と同一。
5. モバイル実機で60fpsを維持(タイルはインスタンシング前提)。

## 対象外

- 盤面生成(部屋・通路のアルゴリズム)の変更
- 特殊ダンジョン(樽比べ・腕試しの間)の専用装飾(後続で検討)
