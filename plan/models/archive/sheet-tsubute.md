# ツブテガエル

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第一地方(うたたねの参道)。

1. **三語コンセプト**: 遠い記憶・待ち伏せ・つぶて
2. **シルエットの記号**: 手に持つ、角のある石つぶて。現行は丸い
   `uv_sphere`(`tsubute_stone`)だが、`common.gem`(正二十面体)に
   差し替えて硬い面を持たせる(plan/models/archive/
   silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: どっしりした二足のカエル型、1頭身
4. **パレット**: 基色=背の緑 `(0.36, 0.56, 0.26)` / 従色=腹の生成り
   `(0.82, 0.80, 0.55)` / 差し色=つぶての灰 `(0.45, 0.44, 0.42)`
5. **設定の見せ場**: design/characters.mdの「遠い日に見た景色の記憶が
   形になった」「離れた場所から石つぶてを投げてくる」設定を、手に
   持つ角のある石そのものに集約する
