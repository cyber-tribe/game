# 淵の主

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第五地方ボス。

1. **三語コンセプト**: 最も重い悲しみ・淵の底・動じない
2. **シルエットの記号**: 体の一部が沈んだ、角のある大きな重石を
   新設する(`common.gem`を大きく。淵の底から二度と離れない
   ことを示す。plan/models/archive/
   silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: 地方ボスの型で1.5倍程度、どっしりした水霊型
4. **パレット**: 基色=深い藍 `(0.16, 0.20, 0.38)` / 従色=淡い藍
   `(0.24, 0.30, 0.48)` / 差し色=目の淡青 `(0.55, 0.75, 0.92)`
5. **設定の見せ場**: design/characters.mdの「滝つぼの一番深いところに
   沈んだ、この地方でもっとも重い悲しみが凝った姿。動じることなく
   淵の底に居座り、地方の主として滝つぼ全体を見渡す」設定を、
   沈んだ重石そのもので表す
6. **逸脱項目**(plan/models/archive/boss-silhouette-differentiation.md):
   ①左右非対称(藻は右肩からしか垂れない) ②ネガティブスペース
   (胸の片側だけに水を湛えた淵そのものをくぼみとして持つ)
   ③通常種には無い大きな形(水底の藻・水を湛えた淵)
