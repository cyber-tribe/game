# こだまの主

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第六地方ボス。

1. **三語コンセプト**: 無数のこだま・重なり合う・尾根の中心
2. **シルエットの記号**: 既存の岩(`kodamanonushi_rock`素材)。丸い
   体表面に唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 地方ボスの型で1.5倍程度、こだまうさぎ〜おにの
   意匠を重ねた塊
4. **パレット**: 基色=岩の灰 `(0.52, 0.51, 0.49)` / 従色=土の茶
   `(0.60, 0.48, 0.34)` / 差し色=綿毛のような響きの塊 `(0.58, 0.57, 0.55)`
5. **設定の見せ場**: design/characters.mdの「尾根じゅうに響いてきた
   無数のこだまが、ひとつに重なり合って生まれた姿。地方の主として、
   絶えず響き続ける尾根の中心に立つ」設定を、無数の岩が寄り集まった
   塊で表す
6. **逸脱項目**(plan/models/archive/boss-silhouette-differentiation.md):
   ①ネガティブスペース(左の雲状の膨らみだけ、声が響き抜ける空洞に
   する) ②顔の配置の逸脱(重なり合った過去のこだまの名残として、
   高さも大きさも違う目をあと2つ、非対称に散らす) ③左右非対称
   (雲状の膨らみ自体の大きさを左右で変える)
