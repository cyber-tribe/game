# こだまぎつね

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。配合限定(やまびこぎつね×こだまうさぎ)。

1. **三語コンセプト**: 反響する攻撃・2度届く・繰り返し
2. **シルエットの記号**: 既存の岩(`kodamagitsune_rock`素材)。丸い
   体表面に唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: やまびこぎつねの体格に、こだまうさぎの大きな耳を
   足した比率
4. **パレット**: 基色=岩の灰 `(0.50, 0.49, 0.47)` / 従色=土の茶
   `(0.64, 0.51, 0.36)` / 差し色=喉の山吹 `(0.95, 0.75, 0.35)`
5. **設定の見せ場**: design/characters.mdの「攻撃が2回まで反響する
   ように連続で発動する」設定を、大きな耳で声を受け止め二重に
   響かせる姿で表す
