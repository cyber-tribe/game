# こだまの主(kodamaNoNushi)のアニメーション作り直し

## 経緯

plan/game/archive/animation-quality-guidelines.mdでパイロット5体
(garudo/purun/gajiri/honegarami/tsubute)に適用したタメ・ツメ・二次揺れの
規約を、この種族の骨格ファミリー(`gajiri`と同じ四つ足の関節構成)にも
適用する。第六地方(こだまの尾根)の地方ボスで、`kodamausagi`(長い耳)・
`kodamagumo`(雲状の膨らみ)・`kaerukodama`(見開いた目)の特徴を1体に
集約した姿。

## 現状

`build_kodamaNoNushi()`は`gajiri`と同じ`chest`-`hip`(尾)・`chest`-`neck`-
`snout`(頭)・`neck`-`ear.L/R`・`chest`-`hipF.L/R`-`footF.L/R`・
`hip`-`hipB.L/R`-`footB.L/R`の関節構成をボスらしく大きく育てたもの。
`hip`(0,0.260,0.340)・`chest`(0,-0.035,0.360)・`neck`(0,-0.260,0.325)は
Zがほぼ一定(0.32〜0.36)でYが大きく変化しており、`gajiri`本体と同じく
胴の芯がほぼ水平でボーンのローカルY軸が前後方向を向いている。`melee`
AI・`isRegionBoss: true`・HP76/atk31/def13で、大技(`summonEcho`、分身を
2体まで呼び出す)を持つ。

`kodamaNoNushi_animations()`は`neck = chest-neck`・`snout = neck-snout`・
`t1/t2 = hip-tail1/tail1-tail2`・`fL/fR = chest-hipF.L/R`・
`bL/bR = hip-hipB.L/R`を使い、idle 4キー(1/30/60/80)・walk 4キー
(1/9/17/25)・attack 4キー(1/7/13/24)・hit 3キー(1/5/18)・die 3キー
(1/12/30)という素朴な往復。`interp`・`partial`はいずれも未使用。
`chest-hip`自体はどのクリップでも直接キーされていない(`gajiri`/
`kodamagitsune`と同じく、水平な胴の芯は動かしていない)。

## 打ち直しの方針

`melee`ボスとして、規約の「guard/boss=振幅小さく・素早く」をhitに、
「地方の主」らしい重さと大きさをattack/dieに当てる。尾(`tail1`〜
`tail3`)の二次揺れは`gajiri`/`kodamagitsune`と同じ考え方で、耳
(`ear.L/R`)は既存クリップで未使用のため今回も新規には触れない。

- **attack**: 現行の4段(1/7/13/24)を、タメ(1→7f、`snout`を
  `(-36, 0, 0)`・`neck`を`(-28, 0, 0)`まで引く、現行値のまま)→ツメ
  (7→10f、LINEARで`snout`を`(22, 0, 0)`・`neck`を`(14, 0, 0)`まで叩き
  込み、`fL/fR`を`(14, 0, 0)`まで踏み込ませる、現行値のまま)→行き
  過ぎ(10→13f、ほんの少し余分に振り戻す)→戻り(13→24f、ゆっくり)の
  4段に分ける。地方ボスらしくタメの時間は他種族よりやや長め(6フレーム)
  に保つ。
- **hit**: 1f→4fの入りに`interp: LINEAR`を足す。boss規約(振幅小さく・
  素早く)どおり、現行の`neck: (20, 0, 0)`・`t1: (0, -20, 0)`という振幅を
  さらに小さく(`neck: (14, 0, 0)`・`t1: (0, -14, 0)`程度)絞り、のけぞり
  時間も5f→18fの現行から4f→15fへ短縮する。地方の主が並のダメージでは
  ほとんど揺るがない、という格の違いを出す。
- **idle**: 現行は`neck`と`t1`/`t2`が同じキーフレーム(1/30/60/80)で
  動く単振動。`t1`(尾の付け根)を`neck`より3フレーム、`t2`(尾の先)を
  さらに2フレーム遅らせて追従させる(`{"partial": True}`)。「尾根じゅう
  に響いてきた無数のこだまが重なり合う」設定に合わせ、首の動きが
  尾の付け根・先端へと波状に遅れて伝わる二次揺れにする。
- **walk**: `chest-hip`(および`chest-neck`)はZがほぼ一定でYが大きく
  変化する、ほぼ水平な骨(`gajiri`/`kodamagitsune`と同じ判定)。素直な
  接地沈み表現にならないため、footfall dip(loc接地沈み)はこのクリップ
  でも見送る。巨体を踏みしめる重さは、現行どおり脚の振り角度(22°)と
  尾の左右揺れ(±12°)で表現する方針を維持する。
- **die**: 初動(1f→3f程度)に`interp: LINEAR`を足して「重なり合って
  いたこだまが最初に鋭くほどけかける」感触を加える。現行の最終キー
  (30f)の後に、崩れ落ちた末端(前脚)の小さな跳ね返りを1回追加する。

## 対象外

- 骨格・造形そのものの変更(既存の.glbジオメトリはそのまま)
- 新規クリップの追加(5クリップ構成は変えない)
- 耳(`ear.L/R`)への新規アニメーション追加(現行クリップでも未使用の
  ため、今回のタメ・ツメ・二次揺れ規約の適用範囲には含めない)

## 未決事項

- 具体的な角度・フレーム数の最終調整(実装時にプレビューで詰める)
- 大技(`summonEcho`)の分身演出との整合(分身側のアニメーションは
  three.js側の実装範囲であり、この計画書の対象外)
