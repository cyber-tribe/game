# 商品確認用ターンテーブル ―― 最終判定を目で行う場所を決める

## 経緯

外部評価の第6回(2026-09-03)。ガルドは「数値としてはかなり良い」段階まで
来たが、**これ以上QAを増やすより、固定の目視確認を用意したほうが効く**
という指摘。

> 数値PASS + 6枚の目視PASS を最終判定にする。
> 過去に何度も「数値がPASSしているのに見た目がおかしい」が発生している。
> これは自動QAが悪いのではなく、キャラクターデザインという問題の性質。

同意する。実際このセッションだけでも「毛束の輪郭は95%通っているのに
後頭部が球に見える」「耳の可視率は基準内なのに縦の切れ込みに見える」が
起きている。**指標は「壊れていないこと」しか言えない。**

## 何を出すか

`npm run turntable`(`just turntable`)で1枚のPNG。
`tools/preview/turntable/<名前>.png`。

| 枚 | 中身 |
|---|---|
| 1〜5 | 0° / 45° / 90° / 135° / 180° |
| 6 | **ゲーム実カメラ**(距離8・仰角48°・注視点y0.5・FOV46) |

照明・ポストは全部ゲーム本編と同じ(`src/view/renderConfig.ts`)。

6枚目は**1080pで撮って等倍で切り出す**。距離8・FOV46だと主人公は
実機で約230px。420pxの枠へ引き伸ばすと「実際に何ピクセルで見えているか」
が分からなくなる。

## 作る途中で見つけたこと

### エンジン内プレビューの照明が本編と違っていた

ハーネス(`tools/preview-harness.ts`)は環境光とキー光しか置いておらず、
**フィル光と、プレイヤーに付いてまわる松明の光**(`PLAYER_LIGHT`、
強さ30・距離13)が抜けていた。ダンジョンの絵はこの松明で持っているので、
抜けたままだと**実際のゲームよりずっと暗い**。1枚目がほぼ黒で造形が
読めなかった。

「実際のゲームと同じ描画スタック」と謳っておきながら、灯りが違っていた。
`FILL_LIGHT_*` と松明の色は `renderer.ts` の中に閉じていたので、
共有用の `renderConfig.ts` へ移した(この2つは元から共有される想定の
ファイルにある)。

これは全77体のプレビューに効くので、まとめて撮り直した。

## 最初の6枚で見えたこと(所見)

**これは私の目視であって、判定ではない。** 判定は人がする。

* **背面(180°)では、髪はほとんど樽に隠れる。** このセッションで
  後頭部の毛束・分かれ目にかなり手を入れたが、実機の背面ではその大半が
  背負い樽の裏になる。造形の投資先としては効率が悪い。
* **ゲーム実カメラでは頭が約45px。** 耳の耳輪・耳甲介、毛束の分かれ目の
  線はこの大きさでは読めない。実機で効いているのは
  **シルエットと大きな色面**。
* 逆に言うと、**シルエットと色面の整理**(樽・スカート・シャツの明度差、
  頭のシルエット)は実機でそのまま効く。

## これをどう使うか

最終判定を **「数値PASS + 6枚の目視PASS」** にする。
数値だけでは通してはいけない。

そして**ここから先は設定画との一致を詰める作業を減らす**。
IoUを0.01上げるために形を変えるほうが、いまは品質を壊すリスクが高い。

## 残件

* 毛束の面の流れ・リズム、色面の整理はこのターンテーブルで見て決める話で、
  自動QAの対象ではない。
* 三角形は 23,308 / 予算 24,000。削るなら Hair Cap・`aux_back_fill`・
  見えない耳の裏・毛束同士の完全な重複面(外部評価の指摘)。ただし
  **完成後にやる**。

## 閉じるにあたって(2026-09-03)

ツールは入り(`npm run turntable` → `tools/preview/turntable/<名前>.png`)、
ガルドとぷるんの6枚が揃っている。残件のうち

* **毛束の面の流れ・色面の整理を目視で決める** ―― 判定は人がする話
  なので、この文書の作業ではない。ターンテーブルの絵を見て指示があれば
  そのとき着手する。
* **三角形を削る** ―― 予算 24,000 に対し 23,308 で収まっており、
  「完成後にやる」と決めた。削る必要が出るまでやらない。

ぷるんのリメイクでは、この6枚が実際に**最終判定の場**として働いた
(暖色照明で青が灰色に転ぶこと、回転体の水位線、目の色の派手さは、
すべて数値QAではなくこの絵で見つけて実機で測り直した)。閉じる。
