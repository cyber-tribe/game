# 看板モデル計画 ― 少数精鋭を「商品棚」水準まで磨き、技法を逆輸入する

## 実装状況(このセクションは実装セッションが追記した注記)

6体それぞれに以下を適用した:

- **ガルド**: 顔(鼻・眼窩・口)を頭部メッシュへ直接彫り込む造形に
  作り直した(`garudo.py`の`_sculpt_bump`、白目・瞳はまばたき機構の
  ため引き続き別メッシュ)。
- **ぷるん**: シルエット先行設計の観点で見直したが、現行の雫形1つで
  完結する輪郭こそが「この世界の顔」としての最小限の記号と判断し、
  再設計は見送った(`sheet-purun.md`参照)。
- **ガジリねずみ**: 腹側専用の色を新設し、`bake_procedural_detail`の
  新パターン"fur"(毛並みの流れ方向)を背側・腹側に焼き込んだ。
- **おおねぼすけ・掘り杭の主**: `boss-silhouette-differentiation.md`の
  一般則を先行適用(非対称・ネガティブスペース・重心比率のずらし等)。
  加えて個体固有の"scratch"識別子を焼き込んだ。
- **ゆめまよいの影**: タルへの擬態を裏付ける、近づいて分かる程度の
  異物感として"fuzz"(強さ0.08)を焼き込んだ。

`tools/preview/flagship_lineup.png`に6体を横並びにした比較画像を
残した。モバイル実機での60fps計測(受け入れ基準5)は、この
リポジトリの他PRと同様にエンジン内ヘッドレスプレイテストでの
動作確認に留め、実機計測は行っていない。

逆輸入は`character-design-language.md`と`texture-painted-detail.md`に
それぞれ追記した(彫り込み技法・"fur"/"fuzz"パターンの追加)。
残り59体を看板モデルと同じ工数で作り直すことはしない(対象外方針
どおり)。

## 経緯

外部審査(`ps2-quality-adversarial-review.md`以来の一連の改善を
見た第三者評価)の結論: 制作基盤(`tools/preview`のエンジン内
プレビュー、テクスチャパイプライン、アニメーション規約、
デザインシート)は十分強く、「個人制作感」から「明確なアート
パイプラインで量産しているゲーム」へ移行できた。一方で
**全68体を同じ密度でさらに磨いても、家庭用ゲームの商品棚に
並べて違和感がないラインには届かない**という指摘を受けた。

理由は技術基盤ではなく、**身体造形の言語がまだ単純**なこと:
`monsters.py`の大半が「関節点+半径+Skinモディファイア+
サブディビジョン」という丸い身体を基礎にし、そこへ硬い部品を
後付けする構造のため、量産には強いが「丸いモンスター+背中に石」
「丸いモンスター+背中に棘」のように、**装飾による差別化**に
留まりやすい。全68体を作り直すと終わらなくなるため、**少数の
「看板モデル」だけをシルエットから設計し直し、そこで完成した
技法を残り全体へ必要な範囲で逆輸入する**方針に転換する。

## 決定 ― 看板モデルの選定(6体)

外部審査の提案どおり、以下の6体を「看板モデル」とする:

1. **ガルド**(主人公。最も画面に映る時間が長い)
2. **ぷるん**(図鑑・宣伝の顔。design/characters.mdで「この世界の
   いわば『顔』」と位置づけ済み)
3. **ガジリねずみ**(第一地方の代表的な通常敵。既に耳・尻尾という
   機能するシルエット要素を持ち、アニメーション規約のパイロット
   5体にも含まれる実績がある)
4. **おおねぼすけ**(第一地方ボス)
5. **掘り杭の主**(最終地方=第八地方のボス)
6. **ゆめまよいの影**(作品を象徴する「変な敵」。タルに擬態する
   というこの作品固有のモチーフを体現し、見た目でも記憶に残る
   候補として選定)

この6体だけを対象に、以下の工程転換を行う。

## 変更内容

### 1. 工程の転換: 「装飾による差別化」から「シルエット先行設計」へ

看板モデルに限り、`build_skinned()`(Skinモディファイア+関節+半径)
を出発点にしない。代わりに:

- **黒塗りシルエットの下書きを先に描く**(`character-design-
  language.md`のデザインシートの「シルエットの記号」を、後付けの
  1項目ではなく**設計の出発点**にする)。
- シルエットが決まってから、それを実現する造形手段
  (`build_skinned`・`box`/`cylinder`等の硬い部品・両方の組み合わせ)
  を選ぶ。「まず丸い胴体を作ってから硬い部品を足す」の順序を
  逆転させる。
- 結果として、看板モデルは`silhouette-hard-surface-parts.md`が
  想定した「丸い胴+硬い部品1つ」の構成に縛られなくてよい
  (胴体そのものを非球形にする、複数の部位を組み合わせて
  丸くない輪郭を作る、等)。

### 2. ガルドの顔を主人公専用に手作業で作り直す

外部審査の指摘: ガルドの目の飛び出しは`eye-socket-fix.md`で
解消したが、**白目=UVスフィア、黒目=UVスフィア、鼻=UVスフィア、
口=ボックス、眉=ボックスというプリミティブ構成自体は残っている**。

- ガルドに限り、顔(目・鼻・口・眉の輪郭)を単純図形の組み合わせ
  ではなく、1つながりのメッシュとして手作業で造形し直す
  (頭部メッシュに直接彫り込む、またはブーリアン等で一体化する)。
- 全59体(モンスター)を同じ水準にする必要はない。**主人公だけの
  例外対応**として工数を割く。

### 3. テクスチャを「AOだけ」から「設計する」へ

`texture-painted-detail.md`(織り目・傷擦れ・毛羽立ちの3分類)を
基礎にしつつ、看板モデルではさらに**種族固有の質感の識別子**を
追加する:

- ガジリねずみ: 毛並みの流れ方向、腹側と背側の色むら
- おおねぼすけ・掘り杭の主: 個体固有の模様(布の継ぎ目、
  金具の錆・刻印等、その者だけの意匠)
- ゆめまよいの影: タルへの擬態を裏付ける、本物のタルと見分けが
  つく微妙な違い(近づいて初めて分かる程度の異物感)

### 4. ボスの差別化(おおねぼすけ・掘り杭の主に適用する当面のルール)

`boss-silhouette-differentiation.md`(別書)で全8地方ボスに
適用する規律を、看板モデルの2体(おおねぼすけ・掘り杭の主)には
本書のパイロットとして先行適用する。

### 5. 受け入れ基準としての「商品棚テスト」

外部審査が提案した基準をそのまま採用する: 6体を`tools/preview`に
横並びにし、**「これならSteam/Switchの商品ページにキャラクター
単体を載せられるか」**で判定する。実装セッションの自己判定でよいが、
新旧比較(現行の量産構成との比較)をPRに添付する。

### 6. 逆輸入

6体で確立した技法(シルエット先行設計・種族固有の質感)のうち、
**汎用化できる部分だけ**を、`character-design-language.md`の
デザインシート運用・`silhouette-hard-surface-parts.md`の部位
カタログ・`texture-painted-detail.md`の展開順に還元する。
残り59体を看板モデルと同じ工数で作り直すことはしない
(外部審査の「全体をさらに作り直す必要はない」という助言どおり)。

## 受け入れ基準

1. 看板モデル6体それぞれが、黒塗りシルエットだけで種族/個体が
   判別できる(装飾を消しても分かる輪郭)。
2. ガルドの顔がプリミティブの組み合わせでなく、1つながりの
   造形になっている。
3. 看板モデル6体のテクスチャに、AO以外の識別子(毛並み・個体
   固有の模様・微妙な異物感等)が確認できる。
4. `tools/preview`で6体を横並びにした画像で、既存の量産構成
   (他59体相当)と明確な質の差が見える。
5. モバイル実機で60fpsを維持する(看板モデルのポリゴン・
   テクスチャ増分をシーン合計予算に含めて計測する)。

## 対象外

- 残り59体(看板モデル以外)の同水準への引き上げ(技法の逆輸入
  のみ行う)
- 看板モデル以外のボス6体への`boss-silhouette-
  differentiation.md`の適用(別途、地方ごとに順次進める)

## 未決事項

- 「ゆめまよいの影」を象徴敵に選んだが、他候補(みずかがみ等)への
  差し替えは実装時の判断に委ねる
- ガルドの顔の造形手段(彫り込み vs ブーリアン)は実装時に
  Blenderでの作業コストを見て決める
- 6体の着手順序(ガルド→ぷるん→…の順が自然だが、並行できる
  部分は並行してよい)
