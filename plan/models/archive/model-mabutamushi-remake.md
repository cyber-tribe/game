# まぶたむし(mabutamushi)のアニメーション作り直し

## 経緯

plan/game/archive/animation-quality-guidelines.mdでパイロット5体
(garudo/purun/gajiri/honegarami/tsubute)に適用したタメ・ツメ・二次揺れの
規約を、この種族の骨格(`gajiri`と同じ「胴+頭+前後の脚」の関節の
"種類"を踏襲しつつ、尻尾・耳を削って半分ほどに軽量化した構成)にも
適用する。

## 現状

`build_mabutamushi()`は`body`(根)-`head`(頭)と、左右対称の`legF.L/R`
(前脚)-`footF.L/R`・`legB.L/R`(後脚)-`footB.L/R`だけの、`gajiri`より
はるかに単純な骨組み。`body`(0,0.020,0.075)・`head`(0,-0.098,0.058)は
Y差0.118に対しZ差0.017しかなく、`body-head`はほぼ水平な骨(前後方向)
になっている。`swarm`AI(`swarmSize: [2, 3]`)・HP5/atk3/def0という
この作品最初のswarmで最も紙装甲な種族。

`mabutamushi_animations()`は`head = body-head`・`legF_L/legF_R =
body-legF.L/R`・`legB_L/legB_R = body-legB.L/R`を使い、idle 4キー
(1/16/32/44、`legF`と`legB`が別フレームで動くが`partial`未指定のため
実際には全ボーンリセットが挟まり、意図した位相ずれにはなっていない)・
walk 4キー(1/5/9/13)・attack 4キー(1/3/7/14)・hit 3キー(1/3/11)・
die 3キー(1/8/18)。`interp`・`partial`はいずれも未使用。

## 打ち直しの方針

`swarm`AI・HP5/def0という「群れの中の1匹」らしい、極端に軽く素早い
反応を強調する。脚が4本しかなく尻尾・耳もないため、二次揺れは前脚/
後脚の位相ずれで表現する。

- **attack**: 現行の4段(1/3/7/14)を、タメ(1→3f、`head: (-16, 0, 0)`・
  `legF_L/legF_R: (-14, 0, 0)`まで引く、現行値のまま)→ツメ(3→5f、
  LINEARで`head: (22, 0, 0)`・`legF_L/legF_R: (10, 0, 0)`まで突く)→
  行き過ぎ(5→7f、ほんの少し余分に押し出す)→戻り(7→14f)の4段に
  分ける。小さな体格に合わせ、他種族よりさらに短い間隔のまま保つ。
- **hit**: 1f→3fの入りに`interp: LINEAR`を足す。HP5/def0という最弱格
  なので、規約の「coward=振幅大きく・ゆっくり戻る」に近い読み味で
  振幅を現行の`head: (18, 0, 0)`・`legB_L/legB_R: (-16, 0, 0)`より
  ひとまわり大きく(`head: (24, 0, 0)`・`legB_L/legB_R: (-22, 0, 0)`
  程度)し、戻り(3f→11f)も少し延ばして13f程度にする。小さな体が
  大きく怯む見た目にする。
- **idle**: 現在は`legF`(16f)と`legB`(32f)が別フレームにあるが
  `partial`が無いため実質は単なる往復になっている。`head`を主体に
  1f/16f/32f/44fで震わせ、`legF_L/legF_R`を`head`より2フレーム、
  `legB_L/legB_R`をさらに2フレーム(計4フレーム)遅らせて追従させる
  (`{"partial": True}`)。群れの中でそわそわ震える現行の演出を、
  頭→前脚→後脚と波状に伝わる本物の二次揺れに直す。
- **walk**: 主な胴の骨に相当する`body-head`はY差0.118・Z差0.017と
  明確に水平(前後方向)で、`gajiri`の「胴の骨がほぼ水平」判定と同じ
  理由によりfootfall dip(loc接地沈み)は見送る。加えて`body`自体が
  分岐点の根(単一関節)で、二点間の「胴」と呼べるボーンがそもそも
  存在しないため、沈み込みを乗せる先が無いことも理由に加える。
- **die**: 初動(1f→3f程度)に`interp: LINEAR`を足して「小さな夢が
  最初にびくっと縮む」鋭さを加える。現行の最終キー(18f)の後に、脚を
  縮めたまま消える前の小さな跳ね返り(scaleのわずかな戻り)を1回
  追加する。
