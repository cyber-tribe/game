# もぐらばあ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。村人。

1. **三語コンセプト**: 地に根ざした古老・杖・見守る側
2. **シルエットの記号**: 既存の手にした杖(`C.cylinder`+bevel)。
   丸みのある体表に硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 腰の曲がった小柄な体、2頭身
4. **パレット**: `tools/models/villagers.py`の `MOGURABAA_SKIN` /
   `MOGURABAA_CLOTH` 等、既存定数をそのまま使用
5. **設定の見せ場**: design/characters.mdの村の古老としての在り方を、
   長年使い込まれた杖に集約する
