# ゆめみるぷるん

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。配合限定(ぷるん×マドロミダケ)。

1. **三語コンセプト**: 混ざり合う夢・眠気の粒・まどろみ
2. **シルエットの記号**: 体の周りに浮く、角のある小さな胞子の結晶を
   新設する(`common.gem`。ぷるんの結晶(plan/models/sheet-purun.md)に
   マドロミダケの胞子が混ざった姿という位置づけ。
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: ぷるんと同じ雫形、色がラベンダーに変化
4. **パレット**: 基色=ラベンダー `(0.58, 0.50, 0.56)` / 従色=まぶた
   `(0.50, 0.42, 0.48)` / 差し色=浮遊する胞子の粒 `(0.86, 0.80, 0.94)`
5. **設定の見せ場**: design/characters.mdの「まどろみの余韻に眠気
   そのものが混ざり込み、攻撃に眠りを乗せるようになる。同じぷるんから
   出発しても、寄り添う相手しだいで別の夢に育つ」設定を、浮遊する
   胞子の結晶で視覚化する
