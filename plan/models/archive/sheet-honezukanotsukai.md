# ホネヅカのつかい

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第四地方(骨積みの回廊)。

1. **三語コンセプト**: ぬしに仕える使い・忠実・近い間合い
2. **シルエットの記号**: 既存の骨の輪(`tsukai_ring`素材)。丸い骨の
   輪郭に硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 小柄な骨の妖怪型、ホネヅカのぬしに似た意匠を
   小さくまとめた比率
4. **パレット**: 基色=骨の生成り `(0.87, 0.85, 0.76)` / 従色=灰
   `(0.44, 0.44, 0.46)` / 差し色=眼窩の淡青 `(0.55, 0.72, 0.85)`
5. **設定の見せ場**: design/characters.mdの「ホネヅカのぬしに仕える
   小さな使い。オイテケボシと同じく満腹度を削る攻撃を放つが、忠実な
   分だけ間合いは近い」設定を、主の意匠を継いだ骨の輪で表す
