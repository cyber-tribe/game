# ホネヅカのぬし

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第四地方ボス。

1. **三語コンセプト**: 無数の記憶・執念の総体・回廊の最奥
2. **シルエットの記号**: 既存の骨山と肋骨(`kotsuduka_rib`素材)。
   丸みを避けた無数の骨の積み重ねが硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 骨が寄り集まった巨体、地方ボスの型で1.5倍程度
4. **パレット**: 基色=骨の生成り `(0.85, 0.83, 0.73)` / 従色=灰
   `(0.52, 0.51, 0.48)` / 差し色=眼窩の橙 `(1.0, 0.5, 0.18)`
5. **設定の見せ場**: design/characters.mdの「この回廊に積もりに積もった、
   無数の古い記憶が寄り集まってひとつの巨体を成したもの。忘れられまい
   とする執念の総体として、回廊の最奥に居座り続ける」設定を、無数の
   骨が積み上がった巨体そのもので表す
