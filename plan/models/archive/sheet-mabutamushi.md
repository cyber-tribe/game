# まぶたむし

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第一地方(うたたねの参道)。まばたきは
plan/models/archive/eye-blink-liveliness.mdでパイロット実装済み。

1. **三語コンセプト**: 瞼の隙間・小さな夢・群れ
2. **シルエットの記号**: 背に1枚だけ乗る、面取りした小さな甲殻を
   新設する(`C.box`+ベベル。
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: 極小の4本脚の虫型
4. **パレット**: 基色=土埃 `(0.72, 0.63, 0.56)` / 従色=影の焦茶
   `(0.40, 0.32, 0.28)` / 差し色=甲殻(体より一段暗い焦茶)
5. **設定の見せ場**: design/characters.mdの「閉じかけた瞼の隙間に湧く
   小さな夢」「1匹1匹はか弱いが2〜3匹で群れる」設定を、小さいながら
   硬い甲殻で「実体を持ってしまった」感を出す
