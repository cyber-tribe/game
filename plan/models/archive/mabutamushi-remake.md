# まぶたむしを設定画に合わせてリメイクする

## 経緯

設定画ベースのリメイク5体目。まぶたむし(`species.ts`の
`mabutamushi`、第一地方1階〜のswarm AI)の設定画が提供された。
同様に**承認済みの2Dコンセプト+三面図**として扱う
(`turnaround-drawing-craft.md`「5. 正直な逃げ道」)。設定画は
`plan/models/reference-mabutamushi-sheet.png`として保存した。

## 設定画の読み取り(実物を目視)

- **概念**: 閉じかけた瞼の隙間に湧く小さな夢。1匹ではか弱く、
  2〜3匹で群れる(swarm AIの現行挙動と一致)。直接攻撃はせず、
  触れると気配を乱すだけ。光・風に弱く、ふく風でも散る。
- **体形**: **ふわふわの丸い毛玉の虫**。大きな黒い丸目、先に
  小さな粒のついた触角2本、**薄く透ける翅2枚**(何枚も重なって
  見えるが実際は薄い膜が2枚、と明記)、細く力の弱い脚。体は
  非常に軽く、ふわふわ浮くように動く。
- **翅**: 淡いベース色に薄紫の斑の模様。光にかざすと淡く
  きらめく。この種の**最大のシルエット記号**。
- **パレット9色**: 体メイン(淡い灰紫の毛)/体の影/翅のベース
  (ごく淡い色)/翅の模様(薄紫)/触角・脚(暗い茶)/目(黒)/
  きらめき=ハイライト(生成り)/瞼・地面(肌色)/涙・湿り気
  (淡い水色)。
- **状態**: 通常(ふわふわ)/好奇心/警戒/驚き/怯える/逃げる(散る)/
  風に流される/光に反応/眠る(うとうと)/消える(夢に還る)。
- **攻撃パターン**(攻撃はしないが気配を乱す): ①群れで近づく
  ②触れる ③すぐ逃げる。
- **行動**: まばたきで湧く/涙の粒に集まる/光に引き寄せられる/
  風で飛ばされる/群れでふわふわ移動。

## 現行モデルとの差分(実測)

`tools/models/monsters.py`の`build_mabutamushi()`は、docstringに
あるとおり「**gajiri(ねずみ)と同じ関節構成**」から尻尾と耳を
削った四足の小動物で、背に面取りした箱の甲殻を1枚載せている:

| 項目 | 現行 | 設定画 |
|---|---|---|
| 体形 | 四足の小動物(ねずみ由来) | ふわふわの丸い毛玉の虫 |
| 翅 | 無し | 薄い膜2枚+斑の模様(最大の記号) |
| 触角 | 無し | 2本、先に小さな粒 |
| 背の甲殻 | 硬い箱1枚(旧義務項目) | 無し(ふわふわの毛) |
| 配色 | 土埃の茶系 | 淡い灰紫の毛+ごく淡い翅 |
| 目 | 小さな目玉球(blink付き) | 大きな黒い丸目+ハイライト |

配色の茶系は「参道の土埃」という旧解釈で、あくびとかげと同じ
食い違い方をしている。

## 変更内容

### 1. 体を毛玉の虫に作り直す

- 四足獣の骨格をやめ、丸いひとかたまりの体+小さな頭(体と
  ほぼ連続)+**細い脚**(設定画どおり細く頼りない線状。左右
  2〜3対)+**触角2本**(先端に小さな粒)+**翅2枚**の構成にする。
- 「ふわふわの毛」は、毛のテクスチャではなく(フラット色面の
  方針)、体の輪郭に**数個の丸い毛の房のふくらみ**を重ねて
  シルエットの柔らかさとして表現する。
- 寸法・輪郭は三面図パネルから読み取る。

### 2. 翅

- 薄いシェル2枚を背に付ける。**半透明は使わない**(スリガラス・
  あくびとかげと同じ判断)。ごく淡いベース色(パレット「翅の
  ベース」)を不透明で使い、薄紫の斑を色面パッチで置く。
- 翅は専用の骨(wing.L/R)を持たせ、羽ばたけるようにする。
- swarmで2〜3匹同時に出る種のため、翅は1枚あたり少ない
  ポリゴンの平面シェルに抑える(現行が関節数を削って軽くして
  いる設計意図を引き継ぐ)。

### 3. 顔

- 大きな黒い丸目+ハイライト。現行のまばたき機構(blink付きの
  別メッシュ+`parent_to_bone`)は**そのまま引き継ぐ**(この種は
  まばたき採用済みの3種のうちの1つで、「まばたきのたびに湧く」
  という設定にも合う)。目のサイズだけ設定画に合わせて大きくする。
- 口は小さな微笑の線(設定画の通常表情)。

### 4. 甲殻の削除

- 背の硬い箱(旧`silhouette-hard-surface-parts.md`義務項目、
  `pin_weight_to_bone`適用済み)は**削除**する。シルエット記号の
  役割は翅2枚が引き継ぐ。これでこの種のピン留め対象は無くなる
  (翅は専用骨で動くため剛体固定は不要)。

### 5. アニメーションを設定画に合わせる

- idle: 「通常(ふわふわ)」— 翅のゆっくりした開閉+触角の
  ゆらぎ+体の浮き沈み(現行の頭→前脚→後脚の波状二次揺れの
  設計を、頭→触角→翅の位相ずれとして作り直す)
- walk: 「群れでふわふわ移動」— 翅の速い羽ばたき+軽い浮遊
  (地を駆ける動きにしない)
- attack: 「触れる」— ふわっと体を寄せる程度の小さな体当たり
  (攻撃意志のなさを保つ)
- hit: 「驚き」— 鋭く跳び退いて散る(swarmらしい過敏さは現行の
  方針を維持)
- die: 「消える(夢に還る)」— ふわりと浮き上がってしぼむ

### 6. 工程・検査

- 2D承認は設定画の提供をもって完了済み。3D化後に平行投影・
  黒塗りレンダーを三面図と重ねてシルエット照合する。
- 色はパレット9スウォッチから直接サンプリングする。
- swarm種のため、三角形数はモンスター予算(1,200〜5,000)の
  **下限寄り**を目標にする(2〜3匹同時表示が前提)。

## 受け入れ基準

1. 正面・側面・背面の黒塗りシルエットが設定画の三面図と重なる
   (照合画像で確認)。
2. 四足の小動物ではなく「翅と触角のあるふわふわの毛玉の虫」に
   見え、背の箱型甲殻が無い。
3. 淡い灰紫基調で、土埃の茶系の旧配色が残っていない。
4. まばたきが引き続き動作する(blink機構の維持)。
5. 翅が羽ばたき、idle/walkで浮遊感がある。
6. 三角形数が予算の下限寄り(2〜3匹同時表示で負荷が増えない)。
7. エンジン内プレビューの新旧比較で、設定画のキャラクターだと
   一目で分かる。

## 対象外

- 行動バリエーションのシステム化(涙の粒に集まる・光に引き
  寄せられる・風で散る等。ゲームデザイン凍結中のため見た目のみ)
- きらめきのパーティクル演出(`particles.ts`側の話。必要なら別途)
- ステータス・出現数の変更

## 未決事項

- 毛の房のふくらみの個数(シルエットが崩れない範囲でプレビューを
  見ながら決める)
- 翅の模様の斑の数・配置(設定画の翅を見ながら調整)

## 実装結果(2026-09-08)

`tools/models/mabutamushi.py` として実装。`monsters.py` には状態
アニメーション `mabutamushi_animations()` だけが残る。
実測 三角形 3,100 / 360KB(旧 3,140 / 125KB。容量は翅と体の
テクスチャぶん増えたが、予算 12,000三角形・700KB の内側)。

### 計画から変えた点

1. **翅は「不透明のシェル+色面パッチ」ではなく、設定画からトレース
   したアルファ抜きカード**にした。設定画の翅は縁が入り組んでいて
   (先が尖り、根元が細く、下縁が波打つ)、ローポリの板では出せない。
   ホネガラミの手・房で確立した手法をそのまま使った。半透明は使って
   いない(alphaCutout。glTF extras 経由でエンジンが alphaTest に直す)。
   上下2枚は必ず一緒に見えるので1枚のカードに収めた。
2. **カードは平面ではなく、根元から先へ向かって後ろへ反る帯**
   (根元 18°・先 62°、6分割)。平面だと側面から消える。
   詳細は `handbook/modeling-pitfalls.md` 4-20。
3. **「ふわふわ」は毛の房の球を重ねるのではなく、体の球そのものの
   頂点を半径方向へ押して作った。** 別オブジェクトの球は、大きさや数を
   どう変えても「毛」ではなく**木いちごの粒**にしか見えなかった
   (球はどれだけ小さくしても輪郭に丸い切れ目を作る)。
   振幅は輪郭線の太さと足し算になるので浅く抑え、輪郭を実際に破る
   房だけ別の項で数本足している(同 4-19)。
4. **口の線は入れていない。** 96px では体の中央に小さな汚れとしてしか
   見えず、大きな目の対比を弱めた。設定画の口も髪の毛ほどの細さ。
5. **骨は4本(body-head / body-wing.L・R / body-belly)。** 触角・脚・尾は
   変形しない剛体部品として骨へ親化してある。反転ハルの輪郭線は世界
   座標で固定の太さ(6.4mm)を持ち、直径 2.2mm の触角はハルに丸ごと
   飲まれて黒い棒になるので、材質へ `noOutline` を立てて輪郭線の対象から
   外した(`src/view/assets.ts`)。結合すると材質がメッシュに同居して
   切り分けられないため、別メッシュにする必要がある。
6. **体は単色ではなく手描き Base Color**(`handbook/hand-painted-standard.md`
   規約3)。下面の落ち込み・背中の紫寄りの沈み・きらめきの粒を
   `C.bake_albedo` の位置ベース関数で描いている。法線は
   `C.spherize_normals` で素の楕円体へ戻し、凹凸が陰影に出ないようにした
   ―― 戻さないとトゥーンの階調が谷ごとに落ち、体が「暗い輪っかの中の
   白い塊」に見える。

### エンジン側の変更(このモデルで発覚した不具合)

- `outlineColorFor` が**ほぼ白い基色に対して濃い山吹色の輪郭線**を
  作っていた。HSL の彩度が明度の端で発散するため。明度が端に寄った
  ぶんだけ彩度を薄めるよう直した(`modeling-pitfalls.md` 4-17)。
  淡い色のモンスター全体に効く修正。
- `skipOutline` / `toToonMaterial` に `noOutline` の受け渡しを足した。
  髪の毛のように細い部品を輪郭線の対象から外すための一般的な仕組み。

### 受け入れ基準の判定

| 基準 | 判定 |
|---|---|
| 1. シルエットが三面図と重なる | **合格**。正面の 全幅/全高 は設定画 0.940 / モデル 0.900 |
| 2. 毛玉の虫に見え、箱型甲殻が無い | **合格** |
| 3. 淡い灰紫基調、茶系が残っていない | **合格**(脚・触角だけ設定画どおり暗い茶) |
| 4. まばたきが動く | **合格**(blink 機構をそのまま維持) |
| 5. 翅が羽ばたき、浮遊感がある | **合格**(実機 gif で確認) |
| 6. 三角形数が予算の下限寄り | **合格** 3,100 |
| 7. 設定画のキャラクターだと一目で分かる | **合格**(`tools/preview/mabutamushi_gate96.png`) |

### 残っている差(ゲーム内評価に回す)

- **平均輝度が設定画の 87%**(139.6 対 159.8)。ゲームの環境光が寒色で
  暗いため、アルベドを白で頭打ちにしても届かない。これ以上は自己発光を
  上げるしかないが、上げると手描きの絵が眠くなる(`modeling-pitfalls.md`
  4-18)。ホネガラミと同じ壁で、照明側の課題。
- **背中の紫寄りの沈みが実機ではほとんど見えない。** テクスチャには
  設定画どおりの 0.81倍が焼けている(実測)が、トゥーンの階調と
  リムライトの加算で差が薄まる。
- 体の毛のきらめきの粒は 96px では溶ける。設定画も同じなので許容。
