# ふく

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。村人。

1. **三語コンセプト**: 商い・樽・箍
2. **シルエットの記号**: 既存の背負う樽の箍(`FUKU_HOOP`材、
   `C.cylinder`のリング)。丸みのある樽の体表に硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 樽を背負った丸みのある体、2頭身
4. **パレット**: `tools/models/villagers.py`の `FUKU_SKIN` /
   `FUKU_BARREL` / `FUKU_HOOP` 等、既存定数をそのまま使用
5. **設定の見せ場**: design/village-life.mdの行商人としての在り方を、
   背負う樽の箍に集約する
