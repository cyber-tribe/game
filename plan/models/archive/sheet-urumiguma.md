# うるみぐま

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第五地方(なみだの滝つぼ)。

1. **三語コンセプト**: ふさぎ込んだ悲しみ・動かない・そっとしておかれる
2. **シルエットの記号**: 抱え込むように丸めた前足の中に、角のある
   古い石を1つ新設する(`common.gem`。ふさぎ込んで動かない理由を
   物として持たせる。plan/models/archive/
   silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: 熊型、うずくまった低い姿勢
4. **パレット**: 基色=毛皮の藍 `(0.22, 0.26, 0.42)` / 従色=鼻先の
   淡藍 `(0.30, 0.34, 0.48)` / 差し色=抱えた石の灰
5. **設定の見せ場**: design/characters.mdの「ふさぎ込んだ古い悲しみ。
   ほとんど動かず、攻撃を受けなかったターンにわずかに癒える――
   悲しみに沈んだまま、そっとしておかれることでだけ少し軽くなる」
   設定を、抱え込んだ古い石で表す
