# 見世物のぬし

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第七地方ボス。

1. **三語コンセプト**: 出し物の記憶・朽ちてなお・会場の中央
2. **シルエットの記号**: 既存の飾り板(`misemono_plate`素材)。丸い
   輪郭に唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 地方ボスの型で1.5倍程度、かざりだるまを大きく
   飾り立てた比率
4. **パレット**: 基色=朱 `(0.52, 0.18, 0.17)` / 従色=金
   `(0.66, 0.54, 0.27)` / 差し色=飾り板 `(0.62, 0.50, 0.30)`
5. **設定の見せ場**: design/characters.mdの「かつての祭りでもっとも
   人目を引いた出し物の記憶が、朽ちてなお色濃く残った姿。今は誰も
   いない会場の中央に、当時のままの存在感で居座り続ける」設定を、
   誇らしげな飾り板で表す
