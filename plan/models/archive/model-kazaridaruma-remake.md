# かざりだるま(kazaridaruma)のアニメーション作り直し

## 経緯

plan/game/archive/animation-quality-guidelines.mdでパイロット5体
(garudo/purun/gajiri/honegarami/tsubute)に適用したタメ・ツメ・二次揺れの
規約を、この種族の骨格ファミリー(`honegarami`と同じ人型骨組みだが、
腕・脚をごく短く詰めた構成)にも適用する。

## 現状

`build_kazaridaruma()`は`honegarami`と同じ`hip`-`chest`-`neck`-`head`-
`crown`の芯と左右対称の`shoulder`-`elbow`-`hand`・`thigh`-`knee`-`foot`を
持つが、腕・脚の関節間隔をごく短く詰めて胴の丸みに埋もれさせ、縦に
大きく膨らんだ胴と丸い頭だけの、だるまらしい低重心のシルエットにして
ある。`hip`(0,0,0.150)・`chest`(0,0,0.335)でZ差0.185・XY差0と、`hipc`
(`hip-chest`)は`honegarami`/`garudo`と同様に縦向きの骨になっている。
`guard`AI・HP80/atk24/def26という高防御の据え置き型で、`fieldSkill:
"break"`を持つ。

`kazaridaruma_animations()`は`hipc = hip-chest`・`neck = neck-head`・
`armL/armR = chest-shoulder.L/R`・`legL/legR = hip-thigh.L/R`を使い、
idle 3キー(1/36/72、ほとんど静止)・walk 4キー(1/10/19/28、`hipc`の
locは未使用)・attack 4キー(1/8/14/24)・hit 3キー(1/4/16)・die 3キー
(1/10/26)というほぼ往復のみの構成。`interp`・`partial`はいずれも
未使用。

## 打ち直しの方針

`guard`AIの「その場をほとんど動かない・高い防御力」という性格を保った
まま、規約の「guard/boss=振幅小さく・素早く」を強く当てる。攻撃自体は
現行どおり「短い腕をまとめて押し出すだけの鈍い一撃」の重さを保つ。

- **attack**: 現行の4段(1/8/14/24)を、タメ(1→8f、`armL/armR`を
  `(-40, 0, 22)/(-40, 0, -22)`まで引く、現行値のまま)→ツメ(8→11f、
  LINEARで`armL/armR`を`(34, 0, 4)/(34, 0, -4)`へ押し出し、`neck`を
  `(-4, 0, 0)`へ振る、現行値のまま)→行き過ぎ(11→13f、ほんのわずかに
  余分に押し出す)→戻り(13→24f、ゆっくり)の4段に分ける。短い腕らしく
  タメ・ツメの間隔は他種族より詰めたままにする。
- **hit**: 1f→4fの入りに`interp: LINEAR`を足す。guard AIの規約
  (振幅小さく・素早く)どおり振幅は現行の`hipc: (-10, 0, 0)`・
  `neck: (-6, 0, 0)`という小さめの値をそのまま維持し、のけぞり時間も
  4f→16fの現行どおり短めに保つ(起き上がりこぼしのように大きくは
  揺るがない、という現行方針の強調)。
- **idle**: 現行はほぼ静止(`hipc`のみ1/36/72の3キー)。`neck`(頭)を
  `hipc`より2〜3フレーム遅らせて、`hipc`と同じ向きへごくわずか
  (±1〜2°程度)追従させる(`{"partial": True}`)。動かないだるまに
  最小限の重心の遅れ揺れを足す程度にとどめる。
- **walk**: `hipc`(`hip-chest`)は縦向きの骨なので、接地の瞬間に胴を
  わずかに沈める`honegarami`/`garudo`と同じ`hipc: {"loc": (0, -0.008, 0)}`
  形式の接地沈みを、脚が接地する10f・28f付近のキーに追加する(短い
  手足でころころ弾む現行の性格に合わせ、沈み幅は他種族よりさらに
  小さくする)。
- **die**: 初動(1f→3f程度)に`interp: LINEAR`を足して「起き上がり
  こぼしが最初にびくっと傾ぐ」鋭さを加える。現行の最終キー(26f)の
  後に、横転した末端(腕)の小さな跳ね返りを1回追加する。
