# ワスレガニを設定画に合わせてリメイクする

## 経緯

設定画ベースのリメイク10体目。ワスレガニ(`species.ts`の
`wasuregani`、第二地方7階〜、混乱付与)の設定画が提供された。
同様に**承認済みの2Dコンセプト+三面図**として扱う
(`turnaround-drawing-craft.md`「5. 正直な逃げ道」)。設定画は
`plan/models/reference-wasuregani-sheet.png`として保存した。

## 設定画の読み取り(実物を目視)

- **概念**: 置き忘れた記憶が時間の底で固まり、殻となって居座る
  もの。攻撃が当たると軽い混乱を起こす(ゲームの
  `inflicts: confuse`と一致)。頑固・執着・無口。
- **体形**: **横に広いドーム状の甲羅のカニ**。甲羅の下に体が
  隠れ、細い脚6本と、前に構えた**大きく硬い鋏2本**。
- **甲羅(最重要)**: 石のように硬く古びた質感で、**分厚い層**に
  なっている。表面に**記憶のカケラ(文字の書かれた紙片)**が
  複数貼り付き、**苔・藻**がところどころに生えている。
- **顔**: 目は甲羅の縁の下に**奥まった黒い丸目**。感情が
  読み取りづらい、と明記。
- **パレット9色**: 殻メイン(くすんだ青灰)/殻の影/殻ハイライト/
  足・ハサミ(紫灰)/足・ハサミの影/目(黒)/記憶のカケラ=紙
  (生成り)/苔・藻(くすんだ緑)/地面の影。
- **状態**: 通常(待機)/気配を消す(潜伏)/近づく/威嚇する/
  攻撃する/被弾(混乱付与)/混乱状態/硬直(殻を閉じる)/
  記憶が剥がれる(弱体)/瀕死(殻が割れる)。
- **攻撃**: ①潜伏 ②接近 ③初撃(記憶のハサミ、命中で混乱(軽))
  ④後退して通常行動へ。
- **デザインの継承関係**: 紙片(忘却札系)はホネガラミの
  忘却札と同系の意匠で、「忘れられまいとする記憶」の一族で
  あることが小物から読める。

## 現行モデルとの差分(実測)

`build_wasuregani()`は、docstringにあるとおり「**honegaramiと
同じ人型骨組み**」の直立二足に、背へ球の甲羅を重ね、両手を
小さな鋏(球+円錐)に変え、目を水色に発光(emission 1.3)させた
青緑の姿:

| 項目 | 現行 | 設定画 |
|---|---|---|
| 体形 | 直立した人型+背の甲羅 | 横に広い甲羅のカニ(体は甲羅の下) |
| 脚 | 人型の二本脚 | 細い脚6本 |
| 鋏 | 小さな球+円錐 | 大きく硬い二叉の鋏(開閉する) |
| 目 | 水色に発光 | 奥まった黒い丸目 |
| 記憶のカケラ | 無し | 紙片が殻に貼り付く(最重要記号) |
| 苔・藻 | 無し | 殻の上に色面で点在 |
| 配色 | 青緑系 | くすんだ青灰+紫灰 |

## 変更内容

### 1. 体をカニに組み直す

- 人型骨格を捨て、カニの骨格にする: 中心の胴(甲羅の芯)+
  **脚3対**(各1〜2節の細い脚)+**鋏の腕2本**(腕1節+開閉用の
  可動指の骨)。
- 甲羅は横に広いドームで、縁に**層の段**を1〜2段つける
  (設定画「殻は分厚く硬い」)。体・目は甲羅の縁の下に収める。
- 寸法・輪郭は三面図パネルから読み取る(接地面〜甲羅の頂で
  正規化)。

### 2. 記憶のカケラと苔

- **紙片を3〜4枚**、わずかに反らせた薄い四角形として甲羅に
  貼り付ける(生成り色。表面の文字は読める必要がなく、暗色の
  短い線を2〜3本描く程度に留める。実在の文字列は書かない)。
- **苔・藻**はくすんだ緑の色面パッチとして甲羅に数箇所置く
  (フラット方針。ふさふさの造形はしない)。
- 紙片は甲羅の骨に剛体で追従させる(甲羅自体が1本の骨なら
  自動で足りるが、揺れ演出で別骨にするなら
  `mark_for_pin`+`pin_weight_to_bone`を使う)。

### 3. 鋏と目

- 鋏は「固定側+開閉する可動指」の二叉に作り、attackで
  開いて挟む動きができるようにする(現行の球+円錐をやめる)。
- 目は**発光を廃止**し(ホネガラミ・モヤウツボと同じ判断)、
  甲羅の縁の影に奥まった黒い丸目にする。ハイライトは小さく
  入れてよいが、「感情が読み取りづらい」という設定を尊重して
  控えめにする。

### 4. 配色

- 青緑系をやめ、パレット9スウォッチから直接サンプリングする
  (殻=くすんだ青灰、脚・鋏=紫灰、紙=生成り、苔=くすんだ緑)。

### 5. アニメーションを設定画に合わせる

- idle: 「通常(待機)」— 思い出そうとして据わりが悪く
  ゆらゆら揺れる(現行idleの性格づけそのままを新骨格へ移植)。
- walk: 脚6本のゆっくりした小刻みな歩き(設定画「足は
  ゆっくりと動く」。素早く見せない)。
- attack: 「初撃(記憶のハサミ)」— タメてから鋏を開いて
  鋭く挟み込む(LINEARの鋭い入り)。
- hit: 甲羅が揺れ、紙片がわずかにはためく。
- die: 「瀕死(殻が割れる)」— 甲羅が傾いて沈み、脚が畳まれる
  (割れ目のジオメトリを入れるかは未決事項)。

### 6. 工程・検査

- 2D承認は設定画の提供をもって完了済み。3D化後に平行投影・
  黒塗りレンダーを三面図と重ねてシルエット照合する。
- 三角形数はモンスター予算(1,200〜5,000)内。脚6本と鋏で
  関節が増えるため、脚は細いチューブの簡素な作りに留める。

## 受け入れ基準

1. 正面・側面・背面の黒塗りシルエットが設定画の三面図と重なる
   (照合画像で確認)。
2. 直立の人型ではなく「甲羅の下に体が隠れた6本脚のカニ」に
   見える。
3. 甲羅の紙片・苔から「忘れられまいとする記憶」の意匠が読め、
   ホネガラミの忘却札と同系だと分かる。
4. 鋏が二叉でattackで開閉し、目の発光が無くなっている。
5. 青緑系の旧配色が残っていない。
6. エンジン内プレビューの新旧比較で、設定画のキャラクターだと
   一目で分かる。

## 対象外

- 潜伏・記憶剥がれ(弱体)・殻閉じ防御のゲームシステム化
  (ゲームデザイン凍結中のため見た目のみ。なお設定画は
  「ambush AI」と記すが現行は`ai: "guard"`。AI変更はゲーム
  デザイン側の話であり、本書では現行を正として触らない)
- 弱体時に紙片が落ちる等の状態変化の見た目(仕組みが無い)
- 派生種(ぬかるみガニ・かたくなガニ等)への波及(本種の完成を
  見てから判断)

## 未決事項

- dieで殻の割れ目ジオメトリを入れるか、傾いて沈むだけに
  留めるか(予算と見た目で判断)
- 脚の節数(1節で足りるか2節にするか。歩きの見え方で決める)

# 実施結果

造形は `tools/models/wasuregani.py`(新規)。`monsters.py` には
`build_wasuregani()`(委譲)と `wasuregani_animations()` だけが残る。
旧 `WASUREGANI_HALF` / `_RADII_HALF` / `_BONES_HALF` は参照が無くなったので削除した。

## 縮尺の決定

設定画の攻撃パターン ③ でカニと人影が同じ地面に立っている。実測でカニ 82px /
人影 72px。主人公ガルド(0.97m)基準なら設定画どおりは約 1.1m だが、F7 の通常
出現としては最大級になりすぎるため、**全高 0.80m**(オオネボスケ 0.836 級)に
決めた。三面図の比率はそのまま使う。1px = 0.80/157 m。

`MODEL_HEIGHT_BASELINE` を 0.618 → 0.777 へ(裸の造形の実測値。苔の瘤を
含めても 0.79 で、設定画の 0.80 に収まる)。

## Body Anatomy Gate

無地の甲羅・体・目・鋏・脚だけを設定画の三面図と重ねる。

| | 設定画 | モデル | IoU | 甲羅(縁より上) |
|---|---|---|---|---|
| 正面 | 188 x 157px | 190 x 153px | 0.855 | **0.947** |
| 側面 | 182 x 155px | 182 x 153px | 0.850 | **0.949** |

**残差はすべて下側の帯**で、これは設定画に焼き込まれた地面の影(パレットに
「地面の影」がある)。脚と同じ濃さで描かれていて値でも色でも分離できないため、
影の入らない甲羅だけの数字を併記している(`modeling-pitfalls.md` 4-59)。

ここまでに直したのは造形だけではない。**計測の側に3つ誤りがあった**:

1. 設定画のマスクに代表色サンプリング用の前処理(closing + fill_holes)を
   使い回していて、脚の隙間が溶けていた(4-57)
2. 実寸が判っているのに高さで正規化していて、苔の瘤ぶん低い裸のモデルが
   横へ引き伸ばされていた。直すだけで 0.796 → 0.855(4-58)
3. 外周の当てはめを最大誤差で採っていて、苔の瘤に引かれて甲羅が
   一貫して 10〜16% 太っていた(4-60)

## 造形

- **甲羅**: `C.loft` が使えない(角ごとに下端の高さが違う)ので断面を自前で積む。
  rx = 0.4306(1-v^2.00)^0.63 / ry = 0.3884(1-v^2.05)^0.58 / cy = -0.016 -0.172v +0.234v²。
  cy が単調でないのは、中ほどで 32mm 前へ張り出し天辺で 46mm 後ろへ戻る
  「目の上の庇」を作るため。
- **前縁の切り欠き**(深さ 0.205 / 角度 118°): 無いと目が甲羅に完全に隠れる。
  設定画の「目は奥まっている」は**縁より後ろ**という意味で、見えないという
  意味ではない。
- **鋏**: 設定画を6倍に拡大して測り直したところ実寸の半分以下だった(4-61)。
  掌は球ではなく `tapered_slab` で手首を絞る。指は掌の**前面**に2枚、
  x で 0.13m 離し、掌の高さの7割まで伸ばす(4-62)。
- **脚**: 腿・膝・脛の3部品。等太さの筒だと曲げたストローに見えた。
- **板割り**: ジオメトリにせず `bake_albedo` の color_fn で甲羅の座標系
  (θ, v) のまま描く。種は縁ほど小さく多く、天辺ほど大きく少ない。
  縁の帯(v<0.155)は板割りを入れず滑らかな厚い唇にする。
- **苔**: 色の面と丸い瘤の両方。`gem(subdivisions=0)` の二十面体は氷の結晶に
  見えたので丸い瘤へ。1房 5〜7個。
- **記憶のカケラ**: 甲羅の面をサンプルして曲げた薄い四角7枚。板1枚より小さく、
  傾きを散らす。文字は書かない。

## Color / Value Gate

設定画(三面図)とエンジン描画を**部位ごとに**測る(4-64)。

| 部位 | 設定画 | エンジン | 差 |
|---|---|---|---|
| 甲羅(縁より上) | L 104.1 / sd 32.7 / R-B +14.4 | L 107.3 / sd 30.6 / R-B +12.4 | L +3.2 / sd -2.1 / R-B -2.0 |
| 下半身 | L 96.5 / sd 39.0 / R-B +9.5 | L 96.2 / sd 38.6 / R-B +9.9 | L -0.3 / sd -0.3 / R-B +0.3 |

代表色は**カラーパレットのチップから色みを、三面図の描画から明度を**採った
(4-63)。描画から拾うと殻が R-B +6 のほぼ中性に見えるが、チップは -8 の青灰で、
脚(+14 の紫灰)との対比が設定画の肝。

一度**全身の平均だけで合わせて失敗した** ―― 平均 R-B +12 に寄せると甲羅まで
砂色になる。部位別に測り直し、補正倍率を `GAIN` に分けて置いた。

トゥーンの4段量子化(4-48)でスリガラスは sd 20 対 42 までしか寄せられなかったが、
こちらは差 2 まで入った。設定画側の明度差が小さい(36 対 42)ぶん天井に当たりにくい。

## リグとアニメーション

骨12本。**甲羅を独立した骨にした**のが要で、設定画の「攻撃が当たると軽い混乱を
起こす」「その殻がゆるく揺れ、景色を曇らせる」を甲羅の遅れた揺れで見せる。
根は `body-belly`(下向きの短い幹)―― 甲羅を根にすると殻を揺らしたときに脚まで
一緒に回る。

| クリップ | 設定画の対応 | 作り |
|---|---|---|
| idle | 通常(待機) | 体は動かさず甲羅だけがゆるく揺れ、胴が4フレーム遅れて追う |
| walk | 足はゆっくりと動く | 三脚歩行、振り幅 11°。速く見えると ambush の性格が消える |
| attack | 初撃(記憶のハサミ) | タメで鋏を上げ指を開き、LINEAR で挟む。甲羅は4フレーム遅れ |
| hit | 被弾(混乱付与) | 甲羅が鋭く振れて3回で収まる |
| die | 瀕死(殻が割れる) | 甲羅が傾いて沈み、脚が畳まれる |

脚は1本ずつ別の骨へ。片側3本を1つの骨に付けると歩行で同位相に振れて
「脚の生えた箱」になる。苔と紙片は甲羅の骨へ pin(自動ウェイトだと胴の骨を
拾って揺れたときに剥がれる)。

## 未決事項の決着

- **die の割れ目ジオメトリ**: 入れない。予算(容量が 660/700KB で残り少ない)と、
  96px では割れ目が潰れて汚れにしか見えないため。傾いて沈む表現に留める。
- **脚の節数**: 2節(腿+脛)+ 膝の玉。1節だと曲げたストローに見えた。
