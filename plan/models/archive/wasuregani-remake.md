# ワスレガニを設定画に合わせてリメイクする

## 経緯

設定画ベースのリメイク10体目。ワスレガニ(`species.ts`の
`wasuregani`、第二地方7階〜、混乱付与)の設定画が提供された。
同様に**承認済みの2Dコンセプト+三面図**として扱う
(`turnaround-drawing-craft.md`「5. 正直な逃げ道」)。設定画は
`plan/models/reference-wasuregani-sheet.png`として保存した。

## 設定画の読み取り(実物を目視)

- **概念**: 置き忘れた記憶が時間の底で固まり、殻となって居座る
  もの。攻撃が当たると軽い混乱を起こす(ゲームの
  `inflicts: confuse`と一致)。頑固・執着・無口。
- **体形**: **横に広いドーム状の甲羅のカニ**。甲羅の下に体が
  隠れ、細い脚6本と、前に構えた**大きく硬い鋏2本**。
- **甲羅(最重要)**: 石のように硬く古びた質感で、**分厚い層**に
  なっている。表面に**記憶のカケラ(文字の書かれた紙片)**が
  複数貼り付き、**苔・藻**がところどころに生えている。
- **顔**: 目は甲羅の縁の下に**奥まった黒い丸目**。感情が
  読み取りづらい、と明記。
- **パレット9色**: 殻メイン(くすんだ青灰)/殻の影/殻ハイライト/
  足・ハサミ(紫灰)/足・ハサミの影/目(黒)/記憶のカケラ=紙
  (生成り)/苔・藻(くすんだ緑)/地面の影。
- **状態**: 通常(待機)/気配を消す(潜伏)/近づく/威嚇する/
  攻撃する/被弾(混乱付与)/混乱状態/硬直(殻を閉じる)/
  記憶が剥がれる(弱体)/瀕死(殻が割れる)。
- **攻撃**: ①潜伏 ②接近 ③初撃(記憶のハサミ、命中で混乱(軽))
  ④後退して通常行動へ。
- **デザインの継承関係**: 紙片(忘却札系)はホネガラミの
  忘却札と同系の意匠で、「忘れられまいとする記憶」の一族で
  あることが小物から読める。

## 現行モデルとの差分(実測)

`build_wasuregani()`は、docstringにあるとおり「**honegaramiと
同じ人型骨組み**」の直立二足に、背へ球の甲羅を重ね、両手を
小さな鋏(球+円錐)に変え、目を水色に発光(emission 1.3)させた
青緑の姿:

| 項目 | 現行 | 設定画 |
|---|---|---|
| 体形 | 直立した人型+背の甲羅 | 横に広い甲羅のカニ(体は甲羅の下) |
| 脚 | 人型の二本脚 | 細い脚6本 |
| 鋏 | 小さな球+円錐 | 大きく硬い二叉の鋏(開閉する) |
| 目 | 水色に発光 | 奥まった黒い丸目 |
| 記憶のカケラ | 無し | 紙片が殻に貼り付く(最重要記号) |
| 苔・藻 | 無し | 殻の上に色面で点在 |
| 配色 | 青緑系 | くすんだ青灰+紫灰 |

## 変更内容

### 1. 体をカニに組み直す

- 人型骨格を捨て、カニの骨格にする: 中心の胴(甲羅の芯)+
  **脚3対**(各1〜2節の細い脚)+**鋏の腕2本**(腕1節+開閉用の
  可動指の骨)。
- 甲羅は横に広いドームで、縁に**層の段**を1〜2段つける
  (設定画「殻は分厚く硬い」)。体・目は甲羅の縁の下に収める。
- 寸法・輪郭は三面図パネルから読み取る(接地面〜甲羅の頂で
  正規化)。

### 2. 記憶のカケラと苔

- **紙片を3〜4枚**、わずかに反らせた薄い四角形として甲羅に
  貼り付ける(生成り色。表面の文字は読める必要がなく、暗色の
  短い線を2〜3本描く程度に留める。実在の文字列は書かない)。
- **苔・藻**はくすんだ緑の色面パッチとして甲羅に数箇所置く
  (フラット方針。ふさふさの造形はしない)。
- 紙片は甲羅の骨に剛体で追従させる(甲羅自体が1本の骨なら
  自動で足りるが、揺れ演出で別骨にするなら
  `mark_for_pin`+`pin_weight_to_bone`を使う)。

### 3. 鋏と目

- 鋏は「固定側+開閉する可動指」の二叉に作り、attackで
  開いて挟む動きができるようにする(現行の球+円錐をやめる)。
- 目は**発光を廃止**し(ホネガラミ・モヤウツボと同じ判断)、
  甲羅の縁の影に奥まった黒い丸目にする。ハイライトは小さく
  入れてよいが、「感情が読み取りづらい」という設定を尊重して
  控えめにする。

### 4. 配色

- 青緑系をやめ、パレット9スウォッチから直接サンプリングする
  (殻=くすんだ青灰、脚・鋏=紫灰、紙=生成り、苔=くすんだ緑)。

### 5. アニメーションを設定画に合わせる

- idle: 「通常(待機)」— 思い出そうとして据わりが悪く
  ゆらゆら揺れる(現行idleの性格づけそのままを新骨格へ移植)。
- walk: 脚6本のゆっくりした小刻みな歩き(設定画「足は
  ゆっくりと動く」。素早く見せない)。
- attack: 「初撃(記憶のハサミ)」— タメてから鋏を開いて
  鋭く挟み込む(LINEARの鋭い入り)。
- hit: 甲羅が揺れ、紙片がわずかにはためく。
- die: 「瀕死(殻が割れる)」— 甲羅が傾いて沈み、脚が畳まれる
  (割れ目のジオメトリを入れるかは未決事項)。

### 6. 工程・検査

- 2D承認は設定画の提供をもって完了済み。3D化後に平行投影・
  黒塗りレンダーを三面図と重ねてシルエット照合する。
- 三角形数はモンスター予算(1,200〜5,000)内。脚6本と鋏で
  関節が増えるため、脚は細いチューブの簡素な作りに留める。

## 受け入れ基準

1. 正面・側面・背面の黒塗りシルエットが設定画の三面図と重なる
   (照合画像で確認)。
2. 直立の人型ではなく「甲羅の下に体が隠れた6本脚のカニ」に
   見える。
3. 甲羅の紙片・苔から「忘れられまいとする記憶」の意匠が読め、
   ホネガラミの忘却札と同系だと分かる。
4. 鋏が二叉でattackで開閉し、目の発光が無くなっている。
5. 青緑系の旧配色が残っていない。
6. エンジン内プレビューの新旧比較で、設定画のキャラクターだと
   一目で分かる。

## 対象外

- 潜伏・記憶剥がれ(弱体)・殻閉じ防御のゲームシステム化
  (ゲームデザイン凍結中のため見た目のみ。なお設定画は
  「ambush AI」と記すが現行は`ai: "guard"`。AI変更はゲーム
  デザイン側の話であり、本書では現行を正として触らない)
- 弱体時に紙片が落ちる等の状態変化の見た目(仕組みが無い)
- 派生種(ぬかるみガニ・かたくなガニ等)への波及(本種の完成を
  見てから判断)

## 未決事項

- dieで殻の割れ目ジオメトリを入れるか、傾いて沈むだけに
  留めるか(予算と見た目で判断)
- 脚の節数(1節で足りるか2節にするか。歩きの見え方で決める)

# 実施結果

造形は `tools/models/wasuregani.py`(新規)。`monsters.py` には
`build_wasuregani()`(委譲)と `wasuregani_animations()` だけが残る。
旧 `WASUREGANI_HALF` / `_RADII_HALF` / `_BONES_HALF` は参照が無くなったので削除した。

## 縮尺の決定

設定画の攻撃パターン ③ でカニと人影が同じ地面に立っている。実測でカニ 82px /
人影 72px。主人公ガルド(0.97m)基準なら設定画どおりは約 1.1m だが、F7 の通常
出現としては最大級になりすぎるため、**全高 0.80m**(オオネボスケ 0.836 級)に
決めた。三面図の比率はそのまま使う。1px = 0.80/157 m。

`MODEL_HEIGHT_BASELINE` を 0.618 → 0.777 へ(裸の造形の実測値。苔の瘤を
含めても 0.79 で、設定画の 0.80 に収まる)。

## Body Anatomy Gate

無地の甲羅・体・目・鋏・脚だけを設定画の三面図と重ねる。

| | 設定画 | モデル | IoU | 甲羅(縁より上) |
|---|---|---|---|---|
| 正面 | 188 x 157px | 190 x 153px | 0.855 | **0.947** |
| 側面 | 182 x 155px | 182 x 153px | 0.848 | **0.946** |

**残差はすべて下側の帯**で、これは設定画に焼き込まれた地面の影(パレットに
「地面の影」がある)。脚と同じ濃さで描かれていて値でも色でも分離できないため、
影の入らない甲羅だけの数字を併記している(`modeling-pitfalls.md` 4-59)。

ここまでに直したのは造形だけではない。**計測の側に3つ誤りがあった**:

1. 設定画のマスクに代表色サンプリング用の前処理(closing + fill_holes)を
   使い回していて、脚の隙間が溶けていた(4-57)
2. 実寸が判っているのに高さで正規化していて、苔の瘤ぶん低い裸のモデルが
   横へ引き伸ばされていた。直すだけで 0.796 → 0.855(4-58)
3. 外周の当てはめを最大誤差で採っていて、苔の瘤に引かれて甲羅が
   一貫して 10〜16% 太っていた(4-60)

## 造形

- **甲羅**: `C.loft` が使えない(角ごとに下端の高さが違う)ので断面を自前で積む。
  rx = 0.4306(1-v^2.00)^0.63 / ry = 0.3884(1-v^2.05)^0.58 / cy = -0.016 -0.172v +0.234v²。
  cy が単調でないのは、中ほどで 32mm 前へ張り出し天辺で 46mm 後ろへ戻る
  「目の上の庇」を作るため。
- **前縁の切り欠き**(深さ 0.205 / 角度 118°): 無いと目が甲羅に完全に隠れる。
  設定画の「目は奥まっている」は**縁より後ろ**という意味で、見えないという
  意味ではない。
- **目**: 中心間 0.214m / 径 71 x 61mm / z 0.369m。顔は一様に暗いので
  単純なしきい値では顔ごと1塊になる ―― 顔の中の下位22%だけを開いて拾うと
  13x13px と 15x11px の2つの暗部が出る。**6倍の拡大図を目分量で読んで
  0.280m と置いたのは3割の過大**で、正面図の顔の中線(sheet x672)が
  甲羅の最大幅の行の中心(x683)から11pxずれていることにも気付けなかった。
  左右の対称性は目そのものの2点から取る。
- **鋏**: 設定画を6倍に拡大して測り直したところ実寸の半分以下だった(4-61)。
  掌は球ではなく `tapered_slab` で手首を絞る。指は掌の**前面**に2枚、
  x で 0.13m 離し、掌の高さの7割まで伸ばす(4-62)。
- **脚**: 腿・膝・脛の3部品。等太さの筒だと曲げたストローに見えた。
- **板割り**: ジオメトリにせず `bake_albedo` の color_fn で甲羅の座標系
  (θ, v) のまま描く。種は縁ほど小さく多く、天辺ほど大きく少ない。
  縁の帯(v<0.155)は板割りを入れず滑らかな厚い唇にする。
- **苔**: 色の面と丸い瘤の両方。`gem(subdivisions=0)` の二十面体は氷の結晶に
  見えたので丸い瘤へ。1房 5〜7個。
- **記憶のカケラ**: 甲羅の面をサンプルして曲げた薄い四角7枚。板1枚より小さく、
  傾きを散らす。文字は書かない。

## Color / Value Gate

設定画(三面図)とエンジン描画を**部位ごとに**測る(4-64)。

| 部位 | 設定画 | エンジン | 差 |
|---|---|---|---|
| 甲羅(縁より上) | L 104.1 / sd 32.7 / R-B +14.4 | L 107.3 / sd 30.6 / R-B +12.4 | L +3.2 / sd -2.1 / R-B -2.0 |
| 下半身 | L 96.5 / sd 39.0 / R-B +9.5 | L 96.2 / sd 38.6 / R-B +9.9 | L -0.3 / sd -0.3 / R-B +0.3 |

代表色は**カラーパレットのチップから色みを、三面図の描画から明度を**採った
(4-63)。描画から拾うと殻が R-B +6 のほぼ中性に見えるが、チップは -8 の青灰で、
脚(+14 の紫灰)との対比が設定画の肝。

一度**全身の平均だけで合わせて失敗した** ―― 平均 R-B +12 に寄せると甲羅まで
砂色になる。部位別に測り直し、補正倍率を `GAIN` に分けて置いた。

トゥーンの4段量子化(4-48)でスリガラスは sd 20 対 42 までしか寄せられなかったが、
こちらは差 2 まで入った。設定画側の明度差が小さい(36 対 42)ぶん天井に当たりにくい。

## リグとアニメーション

骨12本。**甲羅を独立した骨にした**のが要で、設定画の「攻撃が当たると軽い混乱を
起こす」「その殻がゆるく揺れ、景色を曇らせる」を甲羅の遅れた揺れで見せる。
根は `body-belly`(下向きの短い幹)―― 甲羅を根にすると殻を揺らしたときに脚まで
一緒に回る。

| クリップ | 設定画の対応 | 作り |
|---|---|---|
| idle | 通常(待機) | 体は動かさず甲羅だけがゆるく揺れ、胴が4フレーム遅れて追う |
| walk | 足はゆっくりと動く | 三脚歩行、振り幅 11°。速く見えると ambush の性格が消える |
| attack | 初撃(記憶のハサミ) | タメで鋏を上げ指を開き、LINEAR で挟む。甲羅は4フレーム遅れ |
| hit | 被弾(混乱付与) | 甲羅が鋭く振れて3回で収まる |
| die | 瀕死(殻が割れる) | 甲羅が傾いて沈み、脚が畳まれる |

脚は1本ずつ別の骨へ。片側3本を1つの骨に付けると歩行で同位相に振れて
「脚の生えた箱」になる。苔と紙片は甲羅の骨へ pin(自動ウェイトだと胴の骨を
拾って揺れたときに剥がれる)。

# 第2版 ―― レビューを受けた甲羅の再設計

## 受けた指摘

「ワスレガニとしては成立しているが、設定画が持っていた"忘却を背負って長く
生きた蟹"という物語性が、3D化の途中でかなり薄まっている」。技術不足ではなく、
**低解像度で読ませるための整理が進みすぎて、キャラクター固有の情報まで
削ってしまった**状態。優先順位は ①甲羅の石板を不規則化 ②甲羅外周を崩す
③堆積物をシルエットに参加させる ④紙片を古紙にする ⑤歩脚を誇張 ⑥鋏と目は
触らない。

## 合否基準の変更

シルエット照合と色の一致だけでは足りない。**96px で「古い甲羅」「堆積物」
「蟹」の3情報が同時に残ること**を完成条件に加えた。判定は
`tools/preview/wasuregani-96px.png`(設定画とモデルを 96px へ落とし、
ぼかした列を並べたもの)で行う。

## 直したこと

**甲羅を二層に分けた。** 前の版は全面を均等な石タイルで割っていて、石板が
甲羅を「構成している」ように読めた ―― つまり石造りの兜。設定画は元の甲羅の
上に石・泥・苔・紙が**覆い被さっている**。地(甲板 11区画・溝は細く浅く)と
堆積(不揃いな欠片)を分け、素肌が見える隙間を残した(4-66)。

**堆積物の粒を小さくして房に寄せた。** 最初に作った版は一粒が甲羅の幅の
6〜10% あり、不揃いにしても**迷彩柄**に見えた。設定画の石粒は幅の 2〜4%
で、96px では 1〜2px ―― 個々には読めず肌理として効く(4-67)。一様に撒くと
水玉になるので 150粒を 16房へ寄せ、房ごとに広がりと濃さを変えた(4-69)。
欠片の形は正多角形の半径式で作る ―― 正弦で半径を振った版は四つ葉になった
(4-68)。

**シルエットを崩した。** 外周に低周波(3山)のゆらぎを入れ、大きい堆積物
5個をジオメトリにして輪郭へ出した。**内側にだけ削る**(3-28)ので設定画から
測った最大幅は動かない。堆積物は甲羅の上に置かず半分埋める ―― 浮かせると
貼り付けた小石に見える。

**紙片を古紙にした。** 64px の絵を焼いて墨の縁取りと筆致を入れ(文字は
書かない)、四隅を欠き、端を浮かせた。5枚並べるより正面から読める1枚を
強くする方針に変えた。

**歩脚を誇張した。** 設定画では暗い脚が明るい紙の上にあるので鋏と同じ色でも
輪郭で分離するが、実機の背景は暗いので一塊になる。脚を鋏より 16% 明るくし、
掌を 22mm 内へ寄せて外側に背景の帯を作った(4-71)。設定画からの逸脱だが、
「甲羅・目・鋏の3要素しか残らない」よりは設定画に近い。

**鋏と目は触っていない**(指摘どおり、ここは成功している)。

|---|---|---|

# 第3版 ―― 顔と前肢の再設計

## 受けた指摘

「甲羅はかなり改善したが、その改善によって逆に、甲羅だけ設定画の密度に近づき、
顔とハサミだけ初期プロトタイプのように見えるアンバランスが発生している」。
小修正の繰り返しではなく、**目・眼窩・眼柄・前腕・ハサミをいったん削除して
再造形**すべき段階、という判断。

## 合格条件(レビューで明文化されたもの)

1. 96px のシルエットだけでも蟹と分かる
2. 96px でも二つの目が「黒丸」ではなく、甲羅の奥から覗いているように見える
3. 96px でもハサミに固定指・可動指の区別があり、「丸い手」に見えない
4. 設定画とモデルをグレースケール+ぼかしで比較して、大形状の配置が一致する
5. **甲羅を隠しても、顔+前肢だけでワスレガニとして成立する**

⑤のために `wg_facegate.py`(甲羅を外して顔と前肢だけ撮る)を足した。
これで撮って初めて、目が丸い胸板に載った「耳の生えた玉」になっていることと、
鋏が二股の拳であることが見えた(handbook 4-75)。

## 直したこと

**目を4部品の入れ子にした。** 立ち絵を8倍に拡大すると、設定画の目は
「甲羅の庇の影 → 暗い窪み → **灰色の眼窩の縁** → 黒い縦楕円 → 小さな光点」
という入れ子で、黒を黒地に置くのではなく**輪郭と光点で目の存在を示して
いた**。眼窩の縁(顔より明るい扁平な輪)・眼柄・眼球(縦横 1 : 1.35)・
光点を別部品・別材質にした(4-73)。

**顔の面を球から平たい板へ。** 甲羅を外して撮ると、丸い胸板の上に目が
2つ載った玉に見えた。前後を 0.112 → 0.086 に薄くし、上端を目の高さで止めた。

**鋏を3部品に作り直した。** 掌 + 固定指 + 可動指で、**2本の指の形を変える**
―― 可動指は外側の長い三日月、固定指は内側の短く太い刃。同形の刃を2枚
並べる限り、どれだけ大きくしても二股の拳にしかならない(4-74)。噛み合わせに
大きな歯を3つ。掌の体積は 15% 削った ―― 96px の情報量が 甲羅50 : 鋏40 :
顔10 で、設定画の 55 : 25 : 20 から離れていたため。

**前腕に節を入れた。** 胴 → 腕節 → 掌。巨大な鋏が胴に直接生えている感じが
消える。開閉用の骨(`claw.X-nip.X`)は指と歯に付け替えた。

**左右対称を崩した。** 右の鋏を 4% 大きく、左の可動指の先を 8% 欠けさせ、
眼柄の傾きを左右で変えた(4-76)。

# 第5版 ―― 鋏をトポロジーから作り直す

## 受けた指摘

「モデル側が一貫して『丸い塊からV字に2本の爪を出す』構造に収束している。
形状の修正として処理していて、ハサミの構造を作り直していない」。**そのとおり
だった** ―― 第1〜4版はすべて「掌 + ほぼ同形の刃2枚」というトポロジーの
内側で寸法と色を直していた。

あわせて、設定画の読み違いも1つ確定した。立ち絵で**掌の外側輪郭から連続して
いる太く明るい刃(L164)が固定指**、その内側の短く暗い刃(L130)が可動指。
第4版は役割を逆に置いていた。

## やったこと(他は一切触っていない)

既存の鋏定義(PALM_SPINE / DACTYL / POLLEX / TEETH / _blade / _teeth)を
**削除して**、部品構成から組み直した。

    palm ─────────── fixed_finger   ← 外側輪郭は1本の連続した曲線(1メッシュ)
      ╲
       ╲── movable_finger          ← 内側へ噛み込む、細く短い別部品

- 固定指は掌から生えた突起ではなく**掌の輪郭がそのまま細くなったもの**なので、
  palm と fixed_finger を1つのロフト(`_claw_body`)で作り、色の境だけ
  `FIXED_FROM` で切る。半径の表に段を作らない
- `_claw_body` は**上下非対称の断面**を積む ―― `tapered_slab` は楕円断面
  なので外側と内側を別々に絞れない。外側(背)が丸く内側(噛み合わせ)が
  平たい、この非対称が「刃」を作る
- 可動指は固定指の **0.71 倍の長さ / 0.40 倍の太さ**。掌の中央ではなく
  前方 90% の位置から出る
- 噛み合わせは固定指の内側に2つ、可動指の内側に1つ

## 不合格条件の判定(`wg_clawgate.py`)

レビューで示された7条件を**数値で**測る。片方の鋏だけを正面へ正射影した
96px の二値マスクと素の寸法から判定する。

| 条件 | 結果 |
|---|---|
| 正面から見て V 字 | 下半分の連結成分 1個 → 該当せず |
| 2本の指がほぼ同じ長さ | 差 29% → 該当せず |
| 2本の指がほぼ同じ太さ | 差 60% → 該当せず |
| palm 中央から分岐 | 付け根は前方 90% → 該当せず |
| 鋏全体が左右対称 | 左右反転 IoU 0.202 → 該当せず |
| 丸いミトンに切れ込み | 上下反転 IoU 0.717 → 該当せず |
| fixed finger が別の突起 | 継ぎ目の半径の跳び 22% → 該当せず |

**途中で2回落ちた。** 「ほぼ同じ長さ」(0.87倍)と「丸いミトン」(上下 IoU
0.852)で、どちらも目では合格だと思っていた。加えて「付け根が掌中心から
前方へ」の指標が符号を取り違えていて -70% と出ていた(前は -y。正しくは
+70% で合格)。落ちた項目を直しに行く前に指標を疑う(4-83)。

もう一つ、**指を前へ伸ばすと 96px で消える**ことが判った。実機のカメラは
正面寄りなので、視線方向の寸法は存在しないのと同じ。Δy 0.238 / Δz 0.268 の
比まで立てて、正面から先細りが読めるようにした(4-84)。

# 第6版 ―― 目の「眼鏡っぽさ」と脚

第5版で積み残しにした2点。

## 目

立ち絵を10倍で測ると、目の中心から外へ **L 7 → 28 → 50 → 77** と単調に
明るくなるだけで、**眼球を囲む明るい輪は存在しない**。第5版は眼窩の縁を顔より
明るく塗っていて、これがそのまま眼鏡のフレームに見えていた(4-85)。

- 眼窩を「顔より暗い窪み」へ(顔の 0.65 倍)
- 眼柄を顔の 1.12 倍へ。limb を当てていたので顔の倍近く明るく、目の下に
  白い杭が2本立っていた(4-88)
- 眼球を L30 → L13 相当へ。光点は眼球中心の 27倍(実測 L7 対 L201)
- 目の大きさを**中心間との比**で取り直した。実測 0.435 に対し 0.332 で
  作っていて、96px で黒い点になっていた(4-86)。縦横比も 1 : 1.36 へ
- 前縁の切り欠きを1山から**2山**へ。中央がいちばん高く抜けていたので、
  縁の明るい帯が両目の上端すれすれを水平に横切って眼鏡のブリッジに
  なっていた。目の方位(前から ±15°)を山にして中央を凹ませた(4-87)

3本をほぼ同じ前後位置に並べていたので、腿が側面のカメラで短縮して消え、
脛だけの円錐に見えていた。前脚を前へ、後脚を後ろへ振って前後に開き、膝の
節を膨らませ、脛の先を鋭くした(4-89)。開きすぎると奥行きが設定画を超える
ので、一度 0.960m まで出したあと 0.930m(設定画 0.927m)へ戻した。

# 第7版 ―― 表面の描き込み(形は据え置き)

## 経緯

「表面に質感が欲しい。形はこのままでテクスチャなどで対応して」。

`handbook/hand-painted-standard.md` 規約3は**単色マテリアルを貼らない**と
定めていて(基本色+グラデーション+描き込み陰影+継ぎ目+擦れ+ハイライトを
絵として描く)、甲羅は `bake_albedo` で描いていたが**鋏・脚・顔は単色の
まま**だった。ここが規約からの積み残しだった。

なお `archive/anime-look-art-direction.md` の「色面はフラットに(焼き込み
陰影・ノイズ禁止)」は `hand-painted-standard.md` が上書きしている ――
禁じられているのは写実的な AO と素材ノイズで、求められているのは意図して
描いたイラストの陰影。

## やったこと

**肢は頂点カラーで描いた。** UV を足すと TEXCOORD だけで 40KB 増え、
予算(700KB)を超える。頂点カラーなら 8B/頂点で済み、エンジン側は
`assets.ts` の `vertexColors` が既に対応している。補間で滲むので硬い継ぎ目
は描けないが、肢はもともと関節ごとに別オブジェクトなので継ぎ目は
オブジェクトの境界が作る。頂点カラーは「節の根元が暗い」「刃の背に稜線の
明かり」「先が汚れている」といった**面の中の階調**を受け持つ。

書き方の実測(4-90):

| | glb |
|---|---|
| FLOAT_COLOR / CORNER | 906KB |
| BYTE_COLOR / CORNER | 731KB |
| **BYTE_COLOR / POINT** | **676KB** |

**甲羅には継ぎ目の影と擦れを足した。** 溝そのものしか描いていなかったので、
厚みのある板ではなく「線を引いただけ」のドームに見えていた。溝のすぐ外に
落ちる影(面が下向きなら暗く・上向きなら明るく)と、上面の擦れを乗せた
(4-91)。遮蔽は測らない ―― 陰影ではなく絵なので面の向きで決め打ちする。

容量は甲羅テクスチャを 384 → 336px、苔の瘤を1房5個 → 4個にして捻出した。

| Color 下半身 | L+1.2 / sd-0.5 / R-B-0.0 | L+1.0 / sd-0.5 / R-B+0.2 |
| 鋏の7条件 | すべて該当せず | すべて該当せず |
| 三角形 / 容量 | 9,142 / 689.0KB | 9,022 / 676.0KB |

形は一切変えていない(Anatomy は完全に同値)。
