# ガルド

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。

項目2「シルエットの記号」は、丸い体表面の色分けだけでなく、黒塗り
シルエットの輪郭に影響する**硬い形状の部品を最低1つ**持つことを
必須にする(plan/models/archive/silhouette-hard-surface-parts.md)。

1. **三語コンセプト**: がんこ・まっすぐ・樽育ち
2. **シルエットの記号**: 背中の小さな背負いダル(肩ひも2本)+
   肩当て(`parts.build_pauldron`、たがと同じ鉄の意匠。丸い肩に
   角のある段差を作る硬い部品)
3. **図形と頭身**: 丸+四角の混合(主人公・村人の型)、2.5頭身
4. **パレット**: 基色=飴色の上着 `(0.82, 0.54, 0.20)` / 従色=灰青のズボン
   `(0.24, 0.26, 0.34)` / 差し色=房紐の赤 `(0.82, 0.10, 0.08)`
5. **設定の見せ場**: 樽守りという生業(背負いダル+ベルトをタルのたがに)
6. **看板モデル対応**(plan/models/archive/flagship-model-program.md):
   顔(目・鼻・口)を単純図形の組み合わせから、頭部メッシュへ直接
   彫り込む造形に作り直した。白目・瞳はまばたき機構
   (plan/models/archive/eye-blink-liveliness.md)のため引き続き
   別メッシュにするが、鼻の膨らみ・眼窩のくぼみ・口のくぼみは
   `garudo.py`の`_sculpt_bump`でheadメッシュ自身の凹凸として作り、
   継ぎ目のない1つながりの顔にした(眉は表情の視認性のため、
   色で目立たせる別メッシュのまま維持)
7. **衣装の独立立体化**(plan/models/archive/garudo-clothing-volume.md):
   上着を体の色分けから独立した立体にした。裾(腰まわりへ張り出す
   末広がりのリング)・襟(首の付け根の折り返し)・両袖口(肘の
   すぐ上で絞った膨らみ)を`box`/`cylinder`で追加し、
   `mark_for_pin`/`pin_weight_to_bone`(silhouette-hard-surface-
   parts.mdの手法)で該当の骨(hip-chest/chest-neck/shoulder-elbow)
   へ剛体固定した。皺は新設の`_sculpt_dent`(位相の三角形を増やさない
   軽い押し込み)で肘の内側・腰の帯の上に3本だけ入れた。三角形数は
   7,320→7,472(看板モデル基準4,000〜7,500の範囲内)。
