# ガルド

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。

項目2「シルエットの記号」は、丸い体表面の色分けだけでなく、黒塗り
シルエットの輪郭に影響する**硬い形状の部品を最低1つ**持つことを
必須にする(plan/models/archive/silhouette-hard-surface-parts.md)。

1. **三語コンセプト**: がんこ・まっすぐ・樽育ち
2. **シルエットの記号**: 背中の小さな背負いダル(肩ひも2本)+
   肩当て(`parts.build_pauldron`、たがと同じ鉄の意匠。丸い肩に
   角のある段差を作る硬い部品)
3. **図形と頭身**: 丸+四角の混合(主人公・村人の型)、2.5頭身
4. **パレット**: 基色=飴色の上着 `(0.82, 0.54, 0.20)` / 従色=灰青のズボン
   `(0.24, 0.26, 0.34)` / 差し色=房紐の赤 `(0.82, 0.10, 0.08)`
5. **設定の見せ場**: 樽守りという生業(背負いダル+ベルトをタルのたがに)
