# ホロホロチョウ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第三地方(まどろみの茸林)。

1. **三語コンセプト**: ちぎれた微睡み・欠片・群れ
2. **シルエットの記号**: 翅の先に付いた、面取りした小さな胞子の
   結晶を新設する(`common.gem`。plan/models/archive/
   silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: 蛾型、翅が大きく体は小さい
4. **パレット**: 基色=土の焦茶 `(0.30, 0.21, 0.14)` / 従色=翅の焦茶
   `(0.42, 0.32, 0.22)` / 差し色=胞子の山吹 `(0.84, 0.75, 0.48)`
5. **設定の見せ場**: design/characters.mdの「ちぎれた微睡みの欠片。
   1羽ずつは非力だが、微睡みが積み重なるように群れで現れる」設定を、
   翅の先の結晶(欠片)で表す
