# オオマドロミ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第三地方ボス。

1. **三語コンセプト**: 眠気の化身・煮詰まった夢・地方の主
2. **シルエットの記号**: マドロミダケの木質のつば(plan/models/
   sheet-madoromi.md)を、ボス格にふさわしい太く節くれ立った意匠に
   拡大する(`C.cylinder`+ベベル、複数段重ね)。
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目
3. **図形と頭身**: マドロミダケを1.5倍ほどに拡大した、どっしりした
   きのこ型
4. **パレット**: 基色=軸の生成り `(0.78, 0.72, 0.58)` / 従色=傘の
   深紅茶 `(0.46, 0.30, 0.24)` / 差し色=目の山吹 `(0.86, 0.70, 0.40)`
5. **設定の見せ場**: design/characters.mdの「マドロミダケが煮詰まりに
   まで煮詰まった、眠気そのものの化身。ヨリシロという存在の核に
   とりわけ近い夢で、この地方の主として茸林の奥深くに根を張る」設定を、
   マドロミダケの何倍も太く根を張ったつばで象徴する
6. **逸脱項目**(plan/models/archive/boss-silhouette-differentiation.md):
   ①左右非対称(傘そのものを片側へ倒すように傾ける) ②ネガティブ
   スペース(傘の裏に、眠気を吐き出す暗いひだの空洞を作る) ③通常種
   には無い大きな形(煮詰まって取り込んだ、もう1本の小さな傘を
   側面に育てる)
