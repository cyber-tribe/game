# ヨロイオイテケ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。配合限定(ヨロイムカデ×オイテケボシ)。

1. **三語コンセプト**: 置いていかれる恐れ・鎧・被弾で削り返す
2. **シルエットの記号**: 既存の甲殻と棘(`yoroioiteke_armor`/
   `yoroioiteke_thorn`素材)。丸い骨の輪郭に硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: ヨロイムカデより一段厚い甲殻をまとった体
4. **パレット**: 基色=骨の生成り `(0.80, 0.78, 0.70)` / 従色=甲殻の灰
   `(0.56, 0.55, 0.52)` / 差し色=棘の朱 `(0.72, 0.22, 0.14)`
5. **設定の見せ場**: design/characters.mdの「防御が上がり、被弾の
   たびに相手の満腹度を削り返す――『置いていかれる』恐れそのものを
   鎧に変えた姿」設定を、朱色の棘を突き立てた鎧で表す
