# ガジリねずみ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第一地方(うたたねの参道)。

1. **三語コンセプト**: 小さな不安・かじる・逃げ足
2. **シルエットの記号**: 既存の面取り角箱の前歯(`gajiri_teeth`)。
   丸い体表面に唯一の角のある面を作る、
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている
3. **図形と頭身**: 四足の小動物型、1頭身弱
4. **パレット**: 基色=毛の茶 `(0.52, 0.42, 0.34)` / 従色=耳の薄紅
   `(0.72, 0.48, 0.46)` / 差し色=前歯の白 `(0.95, 0.93, 0.84)`
5. **設定の見せ場**: design/characters.mdの「ふと感じた小さな不安が
   形になったもの。不安という感情が『何かをかじって落ち着けたい』
   という仕草から連想された」設定を、かじる前歯そのもので体現する
