# かたくなガニ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第四地方(骨積みの回廊)。

1. **三語コンセプト**: 意固地な古い意地・すばやい・盗んで逃げる
2. **シルエットの記号**: 既存の甲殻・鋏(`katakuna_shell`/
   `katakuna_claw`素材)。丸い体表面に硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: カニ型、他の湿地ガニより引き締まった細身
4. **パレット**: 基色=甲殻の生成り `(0.68, 0.65, 0.58)` / 従色=灰
   `(0.42, 0.42, 0.44)` / 差し色=鋏の縁 `(0.76, 0.72, 0.62)`
5. **設定の見せ場**: design/characters.mdの「意固地になった古い意地。
   すばやく近づいて所持金をかすめ取り、意地を張ったまま逃げていく」
   設定を、引き締まった甲殻と鋭い鋏で表す
