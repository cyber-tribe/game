# ホネガラミ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第一地方(うたたねの参道)。

1. **三語コンセプト**: 古い記憶・絡みつく・忘れられまい
2. **シルエットの記号**: 既存の刃状の爪(`hone_blade`素材)。丸い骨の
   連なりに、しがみつく刃だけが唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 蔦状に長く連なる体、5種中もっとも重厚
4. **パレット**: 基色=骨の生成り `(0.88, 0.86, 0.76)` / 従色=眼窩の黒
   `(0.05, 0.05, 0.07)` / 差し色=刃のような爪 `(0.52, 0.50, 0.46)`
5. **設定の見せ場**: design/characters.mdの「忘れられまいと自分自身に
   蔦のように絡みついて留まっている」「5種の中で最も重い」設定を、
   離さない刃状の爪で視覚化する
