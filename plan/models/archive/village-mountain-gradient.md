# 村の遠景の山を嘘っぽくしない ― 林から山へのグラデーション

## 実装状況(このセクションは実装セッションが追記した注記)

`src/view/village.ts`に、山の裾へ登る樹層(`buildForestSlope`。円錐の
簡略LODを`InstancedMesh`で束ね、既存の中景の丘(`buildHills`)の表面
高さに乗せて斜面を登っているように見せる)、木々の塊→森の輪郭への
移行帯(`buildTreeCanopyFringe`。上端をノイズで波打たせた帯を2枚)を
追加した。山影(`buildMountainBackdrop`)は単色ベタをやめ、山肌→稜線の
霞(=空の地平線色と同じ)の頂点カラーグラデーションにし、稜線の高さ・
幅にも低周波のゆらぎ(`ridgeNoise`)を足した。手前の稜線だけヨリシロの
「うずくまった背中」のこぶ(`yorishiroHunch`)を足してある。
昼/宵祭りの切り替えでも山影の色が空の地平線色に追従するようにした
(`recolorMountainBackdrop`)。

実装中、丘(`buildHills`)の footprint と樹層・移行帯の位置が重なり、
木が丘の内部に埋もれて見えなくなる不具合に気づいて直した
(`hillHeightAt`で丘の表面高さを求め、その上に乗せている)。
受け入れ基準1〜3はヘッドレスプレイテストの俯瞰スクリーンショットで
確認済み。基準4(モバイル実機の負荷)は本セッションでは検証手段が
なく、InstancedMesh・帯メッシュのみの静的ジオメトリで頂点数も
数千程度に収めた設計に留めている。

## 経緯

村の外側の三層構造(`plan/models/archive/village-surroundings.md`)の
実装で「孤島」問題は解消したが、**周囲の山々がのっぺりした
書き割りに見えて嘘っぽい**という実機フィードバックを受けた。
原因は、村の林(緑・木のディテールあり)と山(青一色・無地)の
間に**質感と色の飛び**があること。林から山へ連続的に
グラデーションさせる。

## 修正内容(近→遠の連続性を作る)

### 1. 樹層のグラデーション(質感の連続)

- 村の周辺リングの祠木の林を、**山の裾までそのまま登らせる**。
  裾野の斜面に木(`propHokoragi` の簡略LOD=円錐+球程度で可)を
  インスタンシングで帯状に生やし、**遠いほど小さく・密に・
  シルエット化**する。
- さらに遠い斜面は個々の木をやめ、**樹冠のもこもこした輪郭の
  帯メッシュ**(ノイズで上端を波打たせた板)を2〜3枚重ねる。
  「木々 → 木々の塊 → 森の輪郭」と、ディテールが距離で溶けていく
  段階を作る。
- 稜線より上(森林限界より上)だけを無地の山肌にする。

### 2. 色のグラデーション(色の連続)

近から遠へ、次の色階段で繋ぐ(急な色替えを作らない):

```
村の緑(明るい黄緑)
 → 林の深緑
  → 裾野の樹層(青みがかった深緑)
   → 山肌(青緑〜青灰)
    → 稜線の霞(空の地平線色に溶ける)
```

- 各帯の境目は、フォグと頂点カラーのグラデーションで馴染ませる。
- 空の縦グラデーション(実装済み)の地平線色を、最遠の山の
  霞色と**同じ色**にする(山と空の境が溶ける)。

### 3. シルエットの情報量

- 山の稜線を単調な弧にせず、**2〜3枚の尾根を前後にずらして重ね**、
  重なりで奥行きを出す(前の尾根ほど濃く、奥ほど霞む)。
- 稜線の輪郭に低周波のゆらぎ(ノイズ)を入れ、定規で引いた線に
  見せない。
- ヨリシロ本体の山(北)は「眠る巨人の山」として他より一回り
  大きく、稜線のこぶが**うずくまった背中**にどことなく見える
  シルエットにする(`design/world.md` の考証を絵にする。
  露骨な人型にはしない)。

## 受け入れ基準

1. 村の林から山の稜線まで、質感・色の飛びがなく連続して見える。
2. 山が単色の書き割りに見えない(樹層の帯・尾根の重なりがある)。
3. 最遠の山と空の境が霞で溶けている。
4. 追加ジオメトリはインスタンシング・帯メッシュ中心で、
   モバイル実機で負荷の体感悪化がない。
