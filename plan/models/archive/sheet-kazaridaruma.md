# かざりだるま

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第七地方(わすれられた祭りの跡)。

1. **三語コンセプト**: 飾られたまま忘れられた・動かない・高い防御
2. **シルエットの記号**: 飾られていた台座を新設する
   (`C.cylinder`+ベベル。「飾られたまま」その場から動けないことを
   台座で示す。plan/models/archive/
   silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: だるま型、丸みの強い1頭身
4. **パレット**: 基色=朱 `(0.58, 0.20, 0.18)` / 従色=金 `(0.66, 0.54,
   0.26)` / 差し色=顔の生成り `(0.90, 0.86, 0.76)`
5. **設定の見せ場**: design/characters.mdの「飾られたまま忘れられた
   縁起物。見世物のぬしの小型版のような姿で、高い防御力のままその場を
   動かない」設定を、台座に据えられたまま動かない姿で表す
