# 掘杭の主

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第八地方(めざめの前庭)、地方ボス。

1. **三語コンセプト**: 打ち込まれた杭そのもの・反発と痛み・いびつな依代
2. **シルエットの記号**: 山へ打ち込まれた角材の杭そのものを軸に据え、
   そこにヨリシロの反発が絡みついた歪んだ輪郭にする(`C.box`を
   長く伸ばした杭本体+`C.cylinder`の結び目)。
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている
3. **図形と頭身**: 地面から斜めに突き立つ杭を軸にした、非対称な
   いびつな体
4. **パレット**: 杭材の茶 `(0.62, 0.54, 0.42)` / 絡みつく反発の青灰
   `(0.36, 0.46, 0.48)` / 打ち込まれた跡の焦げ `(0.40, 0.28, 0.22)` /
   縄目の生成り `(0.60, 0.58, 0.52)` / 痛みの滲み `(0.20, 0.24, 0.38)` /
   古材の褐色 `(0.48, 0.40, 0.30)`
5. **設定の見せ場**: design/characters.mdの「近道屋が山へ打ち込んだ杭
   そのものに、ヨリシロの反発と痛みが絡みついてできあがった、いびつな
   姿」設定を、杭本体をそのまま体の軸に残す造形で表す
