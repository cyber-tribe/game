# あしあとどり

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第二地方(忘れ潮の湿地)。

1. **三語コンセプト**: 消えていく足跡・追いかける・群れ
2. **シルエットの記号**: 既存の角ばったくちばし・鉤爪(`ashiato_beak`
   /`ashiato_claw`素材)。丸い羽毛の輪郭に硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 鳥型、脚が長め
4. **パレット**: 基色=背の青緑 `(0.36, 0.52, 0.55)` / 従色=腹の淡青緑
   `(0.70, 0.80, 0.80)` / 差し色=脚の暗色 `(0.26, 0.30, 0.33)`
5. **設定の見せ場**: design/characters.mdの「消えていく足跡を追いかける
   鳥。1羽では頼りないが、いくつもの足跡につられて群れで現れる」設定を、
   長い脚と鉤爪で足跡を辿る仕草として見せる
