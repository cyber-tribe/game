# ほうしとび

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第三地方(まどろみの茸林)。

1. **三語コンセプト**: 舞い散る胞子・遠隔・眠りの化身
2. **シルエットの記号**: 既存の胞子を噴く硬いノズル(`houshi_nozzle`
   素材)。丸い体表面に唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: マドロミダケの遠隔版、細身の1頭身弱
4. **パレット**: 基色=幹の焦茶 `(0.32, 0.23, 0.15)` / 従色=胞子の
   山吹 `(0.82, 0.71, 0.44)` / 差し色=ノズルの暗色 `(0.14, 0.10, 0.08)`
5. **設定の見せ場**: design/characters.mdの「舞い散る胞子の化身。
   遠くから胞子を飛ばして眠りを誘う、マドロミダケの遠隔版」設定を、
   胞子を噴くノズルそのもので表す
