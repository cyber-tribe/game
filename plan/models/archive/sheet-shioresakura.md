# しおれざくら

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第五地方(なみだの滝つぼ)。

1. **三語コンセプト**: 涙で色あせた花・打たれるほど力を失う・散り際
2. **シルエットの記号**: 花の根元を支える、面取りした木質の萼
   (がく)を新設する(`C.cylinder`+ベベル。
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: 花型、茎が細く頭でっかち
4. **パレット**: 基色=茎の緑 `(0.30, 0.34, 0.30)` / 従色=花弁の藍紫
   `(0.44, 0.46, 0.62)` / 差し色=萼(体より一段暗い緑)
5. **設定の見せ場**: design/characters.mdの「涙で色あせた花。打たれる
   たびに力を失っていくが、散り際にだけ最後の力を振り絞る」設定を、
   花を最後まで支え続ける硬い萼で表す
