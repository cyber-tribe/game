# 村の画面構成の再設計(建物考証の反映)

## 実装状況(このセクションは実装セッションが追記した注記)

レイアウト原則・ライティング・色・内装の再設計・カメラワークは実装済み
(別PR)。カメラの配置(背後4m・高さ2m・見下ろし角10〜15度)・追従
(進行方向へ滑らかに回り込む)・遮蔽(割り込んだ建物を半透明化)を
`src/view/village.ts`に実装した。

「カメラワーク」節にある**入力をカメラ基準で解釈する**部分だけは、
意図的に実装しなかった。一度試作したところ、`tools/playtest.mjs`の
`walkToBuildingAndEnter`をはじめ、矢印キー=常にワールドのその方角、
という前提の自動操作が複数あり、カメラが回り込んだ状態で世界の方角と
画面の方角がずれると、狙った建物に正しく歩けなくなる回帰を実機での
通しプレイで検出したため差し戻した。加えて本書自身の「対象外」節が
「村マップの当たり判定・移動仕様の変更(見た目の再設計に徹する)」と
明記しており、入力の解釈方式は移動仕様そのものの変更にあたる。
両者を踏まえ、**この1点は本書のスコープ外として扱う**のが妥当と判断し、
実装しないままで本書を完了扱いとした(`src/view/village.ts`の
`VillageView.update()`のコメントに同じ理由を残してある)。

## 経緯

村なか歩き(`plan/game/archive/town-3d-exploration.md`)と建物内部
(`plan/game/village-interiors.md`)は機能としては仕様化済みだが、
見た目は「緑の平面に色つきの箱」の仮置きのまま。建物考証
(`design/village-buildings.md`)と祠木・タルの考証
(`design/yorishiro-and-barrels.md`)が固まったので、**村の屋外

モデル(建物・小道具)の造形仕様は `plan/models/model-village-
structures.md`(別PR)が担い、本書は**配置・カメラ・光・導線**を扱う。

## 屋外シーンの再設計

### レイアウトの原則(考証の反映)

1. **山を背景に置く。** シーンの奥(北)に、ヨリシロの稜線を模した
   遠景シルエット(霧がかった大きな山影)を常に見せる。
   「山に背を向けて建てない」の考証どおり、**主要な建物の入口は
   すべて山側(奥)を向く**=プレイヤーからは建物の正面が見える。
2. **洞窟の入口は村の最奥・山裾に置く。** 門柱の祠木一対+たが縄が
   村で一番目を引くランドマークになる。出発への導線が画面の構図
   としても「山へ向かう」動きになる。
3. **広場の囲炉裏火を村の中心に置く。** 常時ゆらめく炎(既存の
   焚き火表現の流用)+タルの腰掛け。ポチ・おたま(章進行後)は
   この火の周りに立つ。夜も明るい「現実側の錨」として、村の
   ライティングの光源中心にする。
4. **祠木をまばらに植える。** 村は祠木の林の中、という考証の表現。
   通行の邪魔にならない密度で5〜8本。渦を巻いた年輪の切り株を
   1〜2箇所に置く(座れる必要はない、景色として)。
5. 建物の配置は現行の `VILLAGE_BUILDINGS` の座標を土台に、
   上記1〜3を満たすよう調整する(倉庫・工房は広場を挟んで左右、
   ねむり小屋は静かな村はずれ、依頼板と看板は村の入口側)。

### カメラワーク ― 俯瞰をやめ、主人公の背後に寄る

村なか歩きのカメラを、ダンジョンの見下ろし視点とは別物にする。
**主人公の背後・低めに寄った三人称の追従カメラ**にし、地面ではなく
**村の風景と遠景(空・山影)が画面の大半を占める**構図を基本にする。
拠点系RPGの「村を歩くと、キャラの肩越しに家並みと遠くの山が見える」
定番の画作りを狙う(俯瞰は盤面の把握には向くが、村は盤面ではなく
"帰ってくる場所"なので、見上げる構図のほうが暮らしの実感が出る)。

- **配置**: カメラは主人公の後方約4m・高さ約2m。見下ろし角は
  10〜15度の浅さに留め、**ガルドは画面の下1/3**に置く。これで
  画面の上2/3が家並み・祠木・稜線・空になる。
- **追従**: プレイヤーの移動方向へカメラが緩やかに回り込む
  (`renderer.ts` のyaw補間と同じ指数補間でよい)。スティック/
  矢印の入力は**カメラ基準**で解釈する(forced-landscape・
  ダンジョン側で確立済みの画面基準入力と同じ考え方)。
- **遮蔽**: 建物がカメラと主人公の間に入ったら、その建物を
  一時的に半透明にする(カメラを壁の内側へ押し込むより実装が
  素直で、丸屋根のシルエットも保てる)。
- **山へ向かう構図**: レイアウト原則1・2(主要建物は山側を向く・
  洞窟の入口は最奥)と組み合わさり、出発のために山へ歩くときは
  正面に稜線と山の口が見え、村へ戻る(帰還直後の)向きでは
  広場の火と家並びが見える。**行き=山、帰り=火**という構図の
  対比を作る。
- **遠景**: 山影のシルエットに加えて空(昼の淡い空色+薄い雲)を
  背景に描く。低いカメラでは空が必ず画面に入るため、俯瞰時代の
  「背景=闇」は使えない点に注意。
- 内装のカメラ(`plan/game/village-interiors.md` の入口から見た
  斜め俯瞰)と、ダンジョンの見下ろしカメラは**変更しない**。
  村の屋外だけの話とする。

### ライティング・色

- 時間帯は**明るい昼**を既定にする(当初案の「常に夕暮れ〜宵」は、
  ダンジョンが暗い側である以上、ゲーム全体が薄暗くなってしまうため
  撤回)。世界観上も村は「目覚めている側」(`design/world.md` の
  現実/夢の対比)なので、**現実=日なたの明るさ、夢=薄暗がり**という
  コントラスト自体を画面の言語にする。ダイブから帰ってきた瞬間に
  「明るい場所に戻ってきた」と体で分かることを最優先する。
- 昼の光は暖白色の日ざし+柔らかい影。タルと同じ飴色の木肌が
  一番映える明度に合わせる(トゥーンシェーディングの階調と相性の
  よい、白飛びしない範囲の明るさ。#718 と同じ輝度基準で確認)。
  山側の稜線だけ薄く霧の寒色を残し、遠景の奥行きを出す。
- 囲炉裏火は昼でも絶やさず燃えている(「現実側の錨」の考証どおり。
  昼の画面では小さな暖色のアクセントとして働く)。
- **夕暮れ〜宵の見た目は宵祭りの開催時だけ**に取っておく
  (`design/village-festivals.md`)。祭りの日に村へ戻ると空が
  茜色に変わり、囲炉裏火と出店の明かりが主役になる――ふだんが
  明るいからこそ、祭りの晩が特別に見える。
- 各建物の窓・入口の暖色の明かりは、宵祭り時のみ強調する
  (昼は控えめでよい)。

### 導線・ヒント

- 建物ヒント(「決定: ◯◯へ」)に役割の一言を添える既存方針は
  そのまま。加えて、**建物の外観自体が役割を語る**(工房の煙突の
  煙、ねむり小屋の掛け布、依頼板の札 等。造形は models 側)ため、
  文字に頼る度合いを下げられる。

## 内装の再設計(village-interiors.md への上書き指定)

`plan/game/village-interiors.md` の内装要素表を、考証に基づき
次のとおり具体化する(構造・遷移・メニュー配置は同仕様のまま):

| 建物 | 内装の必須要素(考証出典) |
|---|---|
| モグラ婆の倉庫 | **伏せた古タルを転用した棚**に道具が並ぶ。帳場の机。屋根裏へ続くはしご(ガルドが育った屋根裏) |
| ゲンドの工房 | 炉(広場の火の株分け=同じ暖色)、金床、壁の工具、**寝かせて乾かす祠木の材**、作りかけのタル |
| ねむり小屋 | **名札と掛け布つきのタルの寝床**が並ぶ。宿めいた落ち着いた薄明かり。フクが寝床の間を回る |
| おキヨの図鑑小屋 | 本と標本瓶の棚、**タルの側板の木札の束**(図鑑の実体)、大机 |
| 記録の間 | 巻物棚(芯棒はタルのたが)、**年代記「ねむりのしおり」を広げた文机**、掲示された記録 |
| 村の発展の受付 | 村の模型(現在の発展段階を反映できるとよい)、図面 |
| ガルドの家 | 土間の支度タル、**壁の歴代樽守りの手形**、衣装掛け、寝床 |

- 内装のカメラは「入口から見た斜め俯瞰」の既存方針のまま。
- 内装内でも、窓の外に山側の霧(寒色)か広場の火(暖色)のどちらが
  見えるかを建物の向きと一致させる(細部だが世界の一体感に効く)。
