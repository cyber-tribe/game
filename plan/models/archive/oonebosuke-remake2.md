# おおねぼすけ リメイク2 ―― 新しい設定画に合わせて build_oonebosuke() を作り直す

## 経緯

新しい設定画(`design/characters/oonebosuke/generated/oonebosuke-sheet.png`、
ユーザー提供)に差し替わった。旧v2実装(`plan/models/archive/
model-oonebosuke-remake.md`、2026-09-01承認)は同じ構図・同じ設定
(座り込んだ巨体・藤紫のかいまき・ナイトキャップ・鼻ちょうちん)だが、
実機のターンテーブルで確認すると次の3点が大きく外れていた。**既存の
実装は破棄し、作り直す**(ユーザー指示)。

1. **肌のまだらが実質見えない**(暗くするだけの弱いノイズ)
2. **腹の露出範囲が等方の球判定(半径0.295)で、肩・脇まで飲み込んで
   いた**(設定画は腹だけが露出し、あとは着物という帯がはっきりしている)
3. **着物の星柄がほぼ無い**(cap以外に柄が入っておらず、色もラベンダーで
   金色になっていなかった)
4. 加えて目視で、**首が細くくびれて頭が浮いて見える**(設定画は首が
   ほぼ無く、頭が胴に沈み込んでいる)、**帽子の垂れが短すぎる**
   (設定画は肩を大きく越えて背中を這う)、**手の位置が高すぎる**
   (設定画は地面近くに手を置いている)ことも分かった。

## 設定画から測った値

三面図の高さ(正面・側面・背面で220px前後、差は数%)を、既存の
身長基準 0.836m(`tests/helpers/modelBaseline.ts`)に合わせて
1px ≈ 0.0038m とした。**この設定画にはサイズ目安の欄が無い**ため、
実寸(cm)は測れない。旧v1の設定画で「約300cm」とされていたのは
世界観上の設定であり、実機の高さ0.836mは過去にゲームバランスで
決めた値と判断し、そのまま維持する。

正面図の幅(10%刻み、上→下)を1px=0.0038mへ換算すると、**旧実装の
主要寸法(base rx=0.435 等)とほぼ一致した**。同じ構図の再生成画像
なので、体全体の envelope(概形)は正しかったと確認できる。ずれて
いたのは表面(色・柄)と、首・帽子・手といった部分ジオメトリだった。

側面図の前後端(10%刻み)から、**腹が体の最前面**であることを確認:

| 高さ(上から) | 前端px | 後端px |
|---|---|---|
| 60%(胸) | 898 | 1053 |
| 70%(腹の最突出) | **873** | 1071 |
| 80%(腹) | **860** | 1077 |
| 90%(膝) | 861 | 1060 |

顔(50%あたり)の前端は921px、胸(60%)は898pxで、**腹(70〜80%)の
ほうが顔より50px近く前に出ている**。旧実装の腹の前方オフセット
(-0.04〜-0.05)は弱く、この分だけ腹の突出感が足りなかった。

側面図で確認した他の点:
* **首がほぼ無い**。あご下の肉が直接肩・胸へ連続する。
* **帽子の垂れは肩を越えて背中を這い、先端(ぼんぼり)は腰の高さ**
  まで届く。旧実装は頭頂とほぼ同じ高さ(z=0.79)に収まっていた。
* 手は腹の前、地面に近い低い位置に置かれている。

正面図で確認した点:
* 鼻先から泡が出る(**鼻ちょうちん**。口ではない。旧実装のとおりで正しい)
* 目は閉じてまつげの線、眉は細い八の字の線(塗りつぶした楕円ではない)
* 頬の赤み、開いた口に歯1〜2本+舌
* 露出した肌(顔・腹・手・足)全体に**大きくはっきりした紫のまだら**
* 着物は紺紫の地に**金の星(十字型のきらめき)と三日月が高密度**に散る

## 作り直した箇所

1. **胴+頭のロフト**: 首の位置で急に絞る輪を無くし、あご下から頭へ
   なだらかに繋がる輪へ差し替え。腹のリングの前方オフセットを
   -0.04/-0.05 → -0.06/-0.07 へ強め、側面図で測った「腹が最前面」を
   反映。
2. **帽子**: 頭を覆う円錐(ロフト)と、垂れる先端(`curve_tube`)を
   分離。ロフトはz方向単調増加でしか組めず、背中を這って下がる形は
   作れないため。垂れは肩を大きく越えて腰の高さまで届かせ、ぼんぼりを
   その先端に付けた。
3. **手**: 腹の前・地面に近い低い位置へ下げた。
4. **肌のまだら**: 弱い減光ノイズから、はっきりした紫の斑
   (`blotch_col`、服のメインに寄せた色)へブレンドする方式に変更。
5. **腹の露出範囲**: 等方球(半径0.295)を、正面方向だけに絞った
   楕円体距離場へ変更(handbookに追記)。
6. **着物の柄**: ラベンダーの薄い点 → 金の星+三日月の高密度な柄
   (`gold_col`)へ差し替え。
7. **顔の眉**: 塗りつぶした楕円 → 細い線(まつげと同じ描き方)へ。

## 実装結果(2026-09-03)

`tools/models/monsters.py` の `build_oonebosuke()` を全面的に書き直した。
一度組んだ版をユーザーに「人型キャラなので再現にこだわってください」と
差し戻され、**首のくびれを消しただけでは顔の付いた壺になる**ことが
分かった。**腕を胴の彫刻融合から外し、本体のシルエットを明確に超える
位置・太さで別に融合する**ところまでやって、座った人型として読める
シルエットになった(handbook 3-22 / 3-34)。

```
三角形 9,012、判定 preflight PASS、tests 2,087 件 PASS
```

### 作りながら分かったこと(handbook へ転記済み)

- 肌の露出範囲は等方球だと肩・脇まで飲み込む → 正面に絞った楕円体
  距離場(3-33)
- 焼いたテクスチャの斑点は、対象の大きさに対して周波数が低いと
  「ぼんやりした一枚のグラデーション」にしかならない。焼いた
  テクスチャを直接書き出して見るまで気づかなかった(1-29)
- 部品を融合から外しても、本体の半径をわずかにしか超えなければ
  見えない。本体のその高さの半径を測ってから明確に上回らせる(3-34)
- Bone Heat の失敗数(実測 4416/4416)は部品数の多い彫刻メッシュでは
  大きくなりうるが、フォールバックが必ず救済する設計。
  `--pose-check` の実際の変形で壊れていないかを判定する(2-24)

### 見送ったこと

- 首の完全な解剖学的な形状(あご・頬・のどの区別)。トゥーンの
  簡略化された塗り分けでは、あご下の折り目1本(テクスチャ)で
  頭と胴の区切りを示す程度に留めた。
- 実機での大きさ(高さ0.836m、既存のゲームバランス値)は変更しない。
  設定画にサイズ目安の欄が無いため。
