# スリガラスを設定画に合わせてリメイクする

## 経緯

マドロミダケ・ホネガラミに続き、スリガラス(`species.ts`の
`surigarasu`、第一地方5階〜のthief AI)の設定画が提供された。
三面図・パレット7色・表情/状態10種・攻撃/行動パターンが揃って
おり、同様に**承認済みの2Dコンセプト+三面図**として扱う
(`turnaround-drawing-craft.md`「5. 正直な逃げ道」)。設定画は
`plan/models/reference-surigarasu-sheet.png`として保存した。

## 設定画の読み取り(実物を目視)

- **概念**: ヨリシロの「ふとした欲しさ」が形になった、カラスに
  似た姿。悪意はなく、光るものに気を取られるだけ。thief AIの
  現行挙動(近づいて所持金を盗み、すぐ飛び去る)と一致する。
- **体形**: **二本足で直立する、ずんぐりした鳥**。卵形の体に
  ふさふさと段になった羽、畳んだ翼、下向きの扇状の尾羽。頭は
  大きく、太いカラスの嘴。
- **羽の質感**: 黒を基調に、すりガラスのような半透明感。角度に
  よって淡い虹色にきらめき、羽の一枚一枚に細かなひび割れ。
  飛ぶときは羽のかけら(ガラス片)がきらきらと舞う。
- **目**: 白っぽく大きな丸い目に黒い瞳。好奇心に満ちた表情が
  この種の顔の要。
- **パレット7色**: 羽・体(ほぼ黒)/羽の反射(淡い虹色)/
  くちばし・脚(暗灰)/目・ハイライト(白っぽい)/ガラスの欠片
  (淡い半透明)/影色(紫がかった灰)/地面・土ぼこり(土色)。
- **状態**: きょろきょろ/光るもの発見/興味津々/近づく/盗む瞬間/
  得意げ/逃げる/警戒する/驚く/羽を整える。
- **攻撃**: ①観察する ②素早く近づく ③お金を盗む ④すぐに飛び去る。
- **行動**: 光るものに反応/宝箱をつつく/鏡に映る自分に興味を示す/
  仲間とじゃれ合う/雨上がりに現れる。

## 現行モデルとの差分(実測)

`tools/models/monsters.py`の`build_surigarasu()`は、docstringに
あるとおり「**gajiri(ねずみ)と同じ関節構成**をベースに鳥の
シルエットへ作り替えた」四足獣の骨格で、翼は肩に重ねた
**平たい潰し球**、配色は「参道の土色に馴染む素朴な淡い色合い」:

| 項目 | 現行 | 設定画 |
|---|---|---|
| 骨格 | 四足獣(前肢+後肢+尻尾) | 二本足で直立する鳥 |
| 翼 | 肩に貼った平たい潰し球 | 体側に畳んだ段のある翼 |
| 配色 | 土色(0.62, 0.56, 0.46)系 | 黒基調+淡い虹色の反射 |
| 羽の表現 | 無し(素の連続メッシュ) | 段になった羽+ひび割れの質感 |
| 目 | 小さな目玉球 | 白っぽい大きな丸い目(顔の要) |
| 耳 | 小さな耳が残る | 無し(鳥に耳はない) |
| ガラス片 | 無し | 周囲にきらめく欠片 |

体形・配色・質感のすべてが設定画と食い違っており、作り直しになる。

## 変更内容

### 1. 骨格を二本足の鳥に組み直す

- 四足獣ベースを捨て、直立した鳥の骨格にする: 卵形の胴
  (hip→chest→neck)、大きめの頭、嘴、**翼.L/R**(畳み・
  羽ばたき用に肩から1〜2節)、下向きの扇尾羽、短い脚.L/R+足。
- 寸法・輪郭は三面図パネルから読み取る(接地面〜頭頂で正規化)。
  耳は付けない。
- 嘴は現行の細いコーンより太く、カラスらしい上に湾曲した形へ。

### 2. 羽を段で造形する

- 胴の下半分〜翼に、**スカラップ状(うろこ縁)の羽の段を2〜3列**
  重ねる(`anime-look-art-direction.md`「髪は房で造形する」と同じ
  発想で、羽もシルエットに切れ込みが出る房として作る)。
  ひび割れ模様のテクスチャ再現はしない(フラット色面の方針)。
- 予算はモンスター基準(1,200〜5,000)内。羽の段は薄いシェルで
  枚数を絞る。

### 3. すりガラスの色をフラット色面で解釈する

- 基色は黒(パレット「羽・体」をサンプリング)。**半透明は
  使わない**(トゥーン+輪郭線のパイプラインで半透明メッシュは
  描画順・輪郭の破綻を招きやすい)。代わりに、羽の段の何枚かの
  先端を「羽の反射(淡い虹色)」の色面に塗り分け、角度で
  きらめく質感を**色のパターンとして**翻訳する。
- 影色(紫がかった灰)は、トゥーン階調が作る陰と干渉しない
  範囲で使う(基本はトゥーン任せ。必要なら翼の内側などの
  固有色に留める)。

### 4. 目と顔

- 白っぽい大きな丸い目+黒い瞳を、顔の曲面に沿う描き目として
  作る(この種は「好奇心に満ちた白い目」が顔の要なので、
  マドロミダケの閉じ目とは逆に、大きく開いた目を既定にする)。
  ハイライトを必ず入れる(既存の顔規格どおり)。

### 5. ガラスの欠片

- 淡い色の小さな欠片(四面体などの単純形)を2〜3個、体の周りに
  浮かせる(マドロミダケの浮遊胞子と同じ扱い)。飛び散る演出は
  ランタイムのパーティクルの領分なので対象外。

### 6. アニメーションを設定画に合わせる

- idle: 「きょろきょろ」(現行idleの首振り+尻尾の二次揺れを
  新骨格へ移植。方向性は現行のままでよい)
- walk: 「素早く近づく」— 二本足の小刻みなホップ+翼の浅い
  羽ばたき(thiefらしい俊敏さは現行のフレーム感覚を維持)
- attack: 「盗む瞬間」— 首を伸ばして嘴でかすめ取る(現行の
  前肢のツメから嘴の突きに差し替える)
- hit: 「驚く」— 羽を逆立てて跳び上がる(紙装甲らしい大きな
  振幅は現行の方針を維持)
- die: 消える直前に羽のかけらが崩れるように沈む(現行の消え方の
  骨格移植でよい)

### 7. 工程・検査

- 2D承認は設定画の提供をもって完了済み。3D化後に平行投影・
  黒塗りレンダーを三面図と重ねてシルエット照合する。
- 色はパレット7スウォッチから直接サンプリングする。

## 受け入れ基準

1. 正面・側面・背面の黒塗りシルエットが設定画の三面図と重なる
   (照合画像で確認)。
2. 四足獣ではなく「直立したずんぐりのカラス」に見え、耳が無い。
3. 黒基調+虹色の反射の塗り分けで、土色の旧配色が残っていない。
4. 白っぽい大きな目がハイライト付きの描き目になっている。
5. 羽の段がシルエットの切れ込みとして読める(のっぺりした
   連続メッシュ1枚に戻っていない)。
6. 三角形数がモンスター予算(1,200〜5,000)内。
7. エンジン内プレビューの新旧比較で、設定画のキャラクターだと
   一目で分かる。

## 対象外

- 行動バリエーションのシステム化(宝箱をつつく・鏡への興味・
  雨上がりの出現率など。ゲームデザイン凍結中のため見た目のみ)
- 盗んだ金貨・小物を嘴に持たせる状態切り替え(仕組みが無い。
  必要なら別途)
- 飛び去り・被弾時にガラス片が舞うパーティクル演出
  (`particles.ts`側の話。必要なら別途)
- ステータス・出現階層の変更(設定画「2F〜」と現行`minFloor: 5`の
  食い違いは本書では触らない)

## 未決事項

- 羽の反射(虹色)を塗る羽の枚数・配置(多すぎると黒基調が
  崩れるため、プレビューで2〜4枚程度から調整)
- 浮遊するガラス片をモデルに含めるか省くか(マドロミダケの胞子と
  同じく、まず内蔵で作って揺れの見え方で判断)

## 実装結果(2026-09、`tools/models/surigarasu.py`)

造形は `monsters.py` から専用モジュール `tools/models/surigarasu.py` へ移した
(`monsters.py` に残るのは状態アニメーション5クリップだけ)。

### 第1版と、その失敗

正面図・側面図の**外周マスク**から「高さ→幅」「高さ→前後」の表を自動で起こし、
`C.loft` へ積んで全身を同じ大きさの羽毛で覆った。胴体シルエットの IoU は
正面 0.904 / 側面 0.885 まで出た。

**それでも鳥に見えなかった。** 頭から裾まで連続的に膨らむ「羽毛でできた雫」で、
首も胸も翼もどこにも作っていない。外周には羽毛の縁が含まれるので、その形を
裸のボディにして上からまた羽毛を貼れば、ボディは最初から「膨らんだ輪郭」その
ものになる。**外周が合っていることは構造が合っていることを意味しない**
(`handbook/modeling-pitfalls.md` 4-39)。

### 第2版 ―― 裸の解剖から作り直す

外周ではなく**内側の線**を測り直した。決め手は正面図の幅の内訳:

    全幅 136px = 裸の胴 60px + 左右に垂れた翼 38px ずつ

**正面シルエットの過半は翼**で、胴ではない。第1版はこれを全部「胴の幅」として
読んでいたため、裸の頭も 54px → 76px と 25% 太っていた。嘴が小さく見えたのは
このせいで、嘴自体の寸法はほぼ合っていた。

構造は4つに分けた。

| 階層 | 作り |
|---|---|
| 裸の胴 | 実測17点の表を Catmull-Rom で引くロフト。首のくびれを持つ |
| 翼 | 肩から後下方へ伸びる稜線に沿ったレンズ形の塊 ×2 |
| 中羽・風切羽 | 中羽 4枚 + 風切羽 6枚 ×2。輪郭を切るのはこれ |
| 尾羽 | 5枚 |

羽毛も一様に敷き詰めるのをやめ、**頭部の短羽 / 胸腹の中羽 / 翼の雨覆 / 尾羽**の
4階層に分けた。

### 第3版 ―― 顔を2Dトレースへ

設定画の顔のアイデンティティは形ではなく**2D上の配置関係**(左右に大きく開いた
白目 / 小さな黒い瞳 / 目を囲む黒い縁 / 目の周りへ落ちる暗い羽毛 / 少し困った
ような視線)にあり、3Dの眼球とライティングでは「白い丸+黒い嘴」にしかならない。

| 3D | 2D |
|---|---|
| 頭蓋のボリューム、頬〜後頭部、**嘴**、頭頂の羽毛、顔のシルエット | 白目、黒目、目の黒縁、目の周りの暗色 |

**嘴は 3D のまま。** 側面では嘴の突出がこの種のシルエットそのもので、板に描いた
嘴は 90° で消える。眼球ジオメトリは廃止した。

貼り方は平面デカールではない。アトラスの横軸を**頭まわりの方位角 φ**に取り、
テクセルごとに `sheet_x = 704 + rx(z)・sin(φ)/SC` で設定画を舐めて焼く
(`face_atlas`)。**モデル自身の断面で正面投影を逆に解く**ので、0° では設定画の
正面と一致し、45°・90° では頭の丸みに沿って詰まる。

### 第4版 ―― 色を設定画からサンプリングし直す

パレットのスウォッチ7色だけを見て基色を一様な (65,63,60) と決め、寒色補正を
目分量で掛けていた。暗部を 1.30倍に持ち上げたぶん明暗差が両端から潰れ、実機は
「灰紫〜灰緑の靄」だった。

体のマスクを k-means で分け直すと、設定画の明度はこう広がっている:

| L | 面積 | | L | 面積 |
|---|---|---|---|---|
| 29 | 18% | | 106 | 18% |
| 53 | 27% | | 147 | 8% |
| 78 | 25% | | 205 | 3% |

**47% が L60 以下、11% が L140 以上。** 差し色(青・紫)は絶対値では淡く B-G が
+5 程度しかなく、「青紫にきらめく」と読めるのは**まわりが L30 の黒だから**。
パレットを 15色に組み直し(`SHEET`)、明度は設定画の値そのままで持つことにした。

灯りの寒色は**色みだけ回して**打ち消す(`_tint`)。掛けたあと元の平均へ正規化
するので L は動かない。回す強さは色ごとに変える ―― 全色へ同じ係数を掛けたら
白目と欠片が金色になり、青紫の差し羽根が灰色になった。

### 第5〜7版 ―― 羽毛の意匠を移植する

色は合ったが、羽毛は「同じ形の羽根を規則正しく敷き詰めた鎧」だった。原因は
**縦横比**で、幅 19.5mm × 長さ 16mm の横長の鱗を敷いていた。設定画の胸の羽根は
幅 16mm × 長さ 27mm の**槍の穂先**(1:2.3)。

効く順に直した。**3番だけやっても設定画には近づかない。**

1. **頭頂〜後頭部の大羽毛房**(`CROWN`、12個)。**根元は頭の面へ寝かせ、先だけ
   浮かせる** ―― 1枚ずつ起こした版は「ボサボサの冠」になった。`rise` で1本ずつ
   混ぜ、頭頂中央だけ 0.52〜0.55、頬・後頭部は 0.10〜0.20。**前後の稜線に
   並べる**(左右 45° に立てたら耳を立てたフクロウになった)。
2. **胸の主役の羽根**(`HERO`、8枚)。設定画から位置を拾って手で置く。中央3枚は
   15〜20% 大きくし、色も専用に取った(水色 (127,139,157)、紫 (108,94,107))。
   縞アトラスの先頭4本を主役専用に固定した。
3. **配列の規則性を崩す**。大きさ3段、位相・高さのずらし、±12° の傾き。
4. **翼を大構造へ分解**。頭と胸を作り込んだ結果、翼だけが急にローポリの板に
   見えるようになった(見る側は絶対的な密度ではなく**隣との差**を見る)。
   大きな翼面 → 中羽 4枚 → 風切羽 6枚。
5. **側面の禿げを直す**。雨覆の帯域を `th = π*(-0.80+1.60u)` に直し
   (**th=0 が外側の面**。+0.5π ずらしていたので帯の切れ目が横から見える面に
   来ていた)、段を 3→7 へ。翼塊に UV を与え、胴の羽の除外判定を球から断面の
   楕円へ変えた。

| 寸法 | 高さ 0.217m / 幅 0.172m / 奥行き 0.204m |
| 裸のボディ | 高さ 0.209m / 幅 0.121m / 奥行き 0.204m |

### 受け入れ基準の結果

1. シルエット照合 ― 外周を目標にしない方針へ変えたので、判定は Body Anatomy
   Gate へ差し替えた(理由は上記)。
2. 直立したずんぐりのカラス・耳無し ― 達成。
3. 黒基調+虹色の反射 ― 達成。BaseColor は設定画の明度分布と重なる。
4. 白っぽい大きな目 ― 達成(設定画からのトレースを頭の曲面へ貼った)。
5. 羽の段がシルエットの切れ込みとして読める ― 達成。
6. 三角形数 ― 10,772。計画時の「1,200〜5,000」は超えている。全身が羽で覆われ、
   かつ翼を独立した立体として持つ種で、削ると識別記号が消える。既定枠
   (12,000)の内側なので枠は上げていない。
7. エンジン内プレビューで設定画のキャラクターだと分かる ― 達成。

### 残った差

- **実機のコントラストが浅い。** 標準偏差は BaseColor 43.0 に対し実機 20.9。
  `TOON_GRADIENT_STEPS = [85,130,175,215]` の4段量子化と環境光の底上げにより
  **albedo L18〜197 が実機 L51〜163 へ圧縮される**。**BaseColor は設定画と
  重なっている**ので、これは engine の性質であってモデルの色の誤りではない。
- **背面がいちばん弱い。** 風切羽と尾羽が下で扇に開く。
- **冠羽が設定画より柔らかい。** 寝かせたぶん後頭部の鋭さは届いていない。
- **嘴が正面から小さく見える。** 側面図の嘴はほぼ水平、正面図では下向きに大きく
  描かれていて両立しない。輪郭に効く側面を採ってある。
- **まばたきが無い。** 眼球ジオメトリを廃したので `blink` の対象部品が無い
  (`BlinkController` は対象が無ければ何もしないので実害は無い)。通常 / 瞬き /
  警戒 / 被弾 を**目のアトラス切り替え**で出す仕組みはエンジン側の新機能。
- 「飛ぶときに羽のかけらが舞う」演出は入れていない(静止時の欠片を3個)。
