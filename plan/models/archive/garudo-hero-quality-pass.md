# ガルドを商品棚水準まで磨く ― テクスチャ解像度とパターンの粗さを直す

## 取り下げ

`plan/models/archive/anime-look-art-direction.md`の方針(キャラクターは
焼き込み陰影・手続きノイズを持たないフラットな色面にする)と正面から
矛盾するため、本書は**未実装のまま取り下げる**。上着の織り目を高解像度で
くっきり焼く方向自体が写実寄りの投資であり、フラット化すれば
「まだら模様に見える」という発端の問題ごと消える。実装はしない。

## 経緯

「主人公のモデルがゲーム屋さんの商品棚にあったら駄作だと思われる」
という指摘。`flagship-model-program.md`でガルドの顔は既に彫り込み
造形へ作り直し済みだが、実際のレンダリング画像を見ると、**上着の
生地が織り目ではなく汚れたような不揃いのまだら模様に見える**。
指摘とあわせて、家庭用ゲームのキャラクター単体の販促カットが
一般的に持つ水準(高解像度で塗り込まれたテクスチャ、生地の折り目・
使用感が破綻なく読める仕上げ)を目標として明確に置く。

## 診断(実測)

`garudo.py`のテクスチャ関連の呼び出し:

```python
C.bake_ao_to_texture(mesh, size=128)
C.bake_procedural_detail(mesh, {"garudo_tunic": "weave", "garudo_trousers": "scratch"})
```

`bake_procedural_detail`(`common.py`)の既定`scale=6.0`は、UV空間
0〜1に対しておよそ6周期のノイズを敷く。**128×128というテクスチャ
解像度に対して6周期は、1周期あたり約21ピクセル**にしかならず、
上着のような広い面に敷くと「細かい織り目」ではなく「粗く不揃いな
まだら」として見えてしまう。これが、ユーザーの screenshot で
上着が汚れたように見える直接の原因。

`flagship-model-program.md`は看板モデル6体を対象にしたが、
テクスチャ解像度そのもの(128px据え置き)は見直していなかった。

## 変更内容

### 1. ガルドのテクスチャ解像度を引き上げる

- `bake_ao_to_texture(mesh, size=128)`を**看板モデルの例外**として
  `size=512`(またはエンジン内プレビューで確認しながら256/512の
  どちらかに決定)へ引き上げる。他59体の既定(128px)は変更しない
  (`texture-rollout-unblock.md`の量産方針を維持する)。

### 2. 手続きパターンの周期を解像度に合わせて調整する

- `bake_procedural_detail`の`scale`引数を、解像度に見合う値
  (織り目として認識できる密度、目安1周期あたり4〜8ピクセル程度)
  まで引き上げる。512pxなら`scale`をおよそ64〜128の範囲で
  エンジン内プレビューを見ながら調整する。
- 引き上げ後、上着の模様が「まだら」ではなく「織り目」として
  視認できることを、新旧比較スクリーンショットで確認する。

### 3. 顔のさらなる磨き込み(必要に応じて)

- `_sculpt_bump`による彫り込み後の顔を、解像度を上げた状態で
  改めてエンジン内プレビューし、目・眉の造形に不自然さが残って
  いないか確認する。気になる箇所があれば、`eye-socket-fix.md`の
  「目の表面が頭部から突き出さない」規約の範囲内でパラメータを
  再調整する(新しい造形手段を持ち込む必要はなく、既存の彫り込みの
  深さ・目のサイズの微調整で足りる見込み)。

### 4. 「宣伝カット」水準の確認用レンダーを追加する

- `tools/preview_engine.mjs`の既定(512×512、`tools/preview/`用の
  一覧向けサイズ)とは別に、ガルドだけ**高解像度・単体構図**の
  確認用スクリーンショットを1枚追加する(既存のプレビュー基盤
  `engine-preview-snapshots.md`を流用し、対象をガルド1体・
  解像度だけ上げたオプションを足す)。家庭用ゲームの商品ページに
  耐えるかを確認するための「よそ行きの1枚」であり、`tools/preview/`
  の一覧用画像を置き換えるものではない。

## 受け入れ基準

1. ガルドの上着の模様が、まだらではなく織り目として視認できる
   (新旧比較スクリーンショット)。
2. 高解像度の確認用レンダーで、顔・上着・小物のいずれにも
   不自然な破綻(ぼやけ・まだら・突き出し)が無い。
3. 他59体のテクスチャ解像度・生成手段に変更がない。
4. モバイル実機で60fpsを維持する(ガルド1体のテクスチャ増分は
   シーン合計予算への影響が小さいと見込まれるが、念のため確認する)。

## 対象外

- 看板モデルの他5体への同様の解像度引き上げ(効果を見てから
  個別に判断する)
- 新しい造形手段(彫り込み以上の追加ジオメトリ等)の導入

## 未決事項

- テクスチャ解像度を256にするか512にするかは、ファイルサイズと
  見た目の効果を見比べて決める
- `scale`の最終値(織り目として自然に見える密度をプレビューで
  探る)
