# ヨリシロの残響

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第八地方(めざめの前庭)。出現率が
極めて低い特別種。

1. **三語コンセプト**: ヨリシロ自身の記憶・最高格・物語終盤の存在感
2. **シルエットの記号**: 既存の帯状の輪(`zankyo_band0`〜`band4`
   素材、5本)。丸い体表面に硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 全地方の色を帯びた特異な体、他種より一回り大きい
4. **パレット**: 5本の帯 `(0.44,0.40,0.46)` `(0.36,0.52,0.56)`
   `(0.46,0.56,0.40)` `(0.56,0.42,0.46)` `(0.58,0.50,0.34)` /
   差し色=目の白銀 `(0.85, 0.90, 0.96)`
5. **設定の見せ場**: design/characters.mdの「ヨリシロ自身の記憶その
   もの。出現率は極めて低いが、他のどの種族よりHP・攻撃・防御が高く、
   物語終盤にふさわしい存在感を放つ」設定を、全地方の色を帯びた
   5本の帯で表す
