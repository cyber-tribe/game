# ねむりモグラ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。配合限定(ユメクイモグラ×ホロホロチョウ)。

1. **三語コンセプト**: 確定の眠り・オオマドロミの力・進化した爪
2. **シルエットの記号**: 既存の掘削用の爪(ユメクイモグラ由来)に、
   オオマドロミの力を宿す証としてわずかに発光する胞子色の結晶片を
   1つ加える(`common.gem`、小さく)。
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目
3. **図形と頭身**: ユメクイモグラと同じモグラ型、耳を小さく尻尾を
   短く埋もれさせた比率
4. **パレット**: 基色=土の焦茶 `(0.28, 0.22, 0.16)` / 従色=腹の茶
   `(0.40, 0.34, 0.24)` / 差し色=胞子の斑点 `(0.78, 0.70, 0.42)`
5. **設定の見せ場**: design/characters.mdの「攻撃に眠りが確定で
   まとわりつくようになり、この地方のボス・オオマドロミの力を
   わずかに宿す」設定を、爪に加えた小さな結晶片で表す
