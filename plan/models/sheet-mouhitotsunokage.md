# もうひとつのかげ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第八地方(めざめの前庭)。

1. **三語コンセプト**: ゆめまよいの影のもう一つの姿・道具に擬態・見分けがつかない
2. **シルエットの記号**: 化けている落とし物の道具の欠片を残す
   (`C.box`または`C.cylinder`。ゆめまよいの影がタルの箍を残すのと
   対になる意匠。plan/models/archive/
   silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: ゆめまよいの影と同系統だが、タルより小さい道具の
   輪郭
4. **パレット**: 基色=殻の灰 `(0.46, 0.44, 0.42)` / 差し色=道具の
   欠片(化けていた道具の色を反映)
5. **設定の見せ場**: design/characters.mdの「ゆめまよいの影のもう
   一つの姿。タルではなく、落ちている道具に擬態する」設定を、
   道具の欠片が残る点でゆめまよいの影と対比させる
