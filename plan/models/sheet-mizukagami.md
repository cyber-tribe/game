# みずかがみ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第五地方(なみだの滝つぼ)。

1. **三語コンセプト**: 水面に映る古い姿・道具に化ける・擬態
2. **シルエットの記号**: 既存の壺(`mizukagami_jar`素材)。道具に
   化ける(mimic)姿そのものが硬い器の形をしている
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 壺型、水面の揺らぎを表す縦長の輪郭
4. **パレット**: 基色=壺の藍 `(0.20, 0.24, 0.36)` / 従色=波紋の明
   `(0.64, 0.74, 0.84)` / 差し色=波紋の暗 `(0.30, 0.40, 0.54)`
5. **設定の見せ場**: design/characters.mdの「滝つぼの水面に映る古い姿。
   道具に化けて息をひそめる、この地方ならではの水辺の擬態」設定を、
   壺そのものの硬い輪郭で表す
