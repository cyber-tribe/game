# キャラクターのシルエットに硬い形状の部品を組み込む

## 経緯

`ps2-quality-adversarial-review.md` 重大3の指摘: `common.py` の
`build_skinned()` は関節+半径のグラフをSkinモディファイア+
サブディビジョンで丸める方式のため、**構造的に球のつながりしか
作れない**。`garudo.py` の `classify_body()` を見ると、上着・ズボン・
靴の境界は同じ滑らかな1枚の皮の上の**色の境界でしかなく、形の境界
ではない**。黒塗りシルエットにすると、服の切り替えも分からない
一本のなめらかな棒になる。

`character-design-language.md` は「黒塗りシルエットで判別できない」
という診断は正しかったが、原因をデザインシート不足に置いていた。
実際の原因は造形ツールの表現力の天井であり、デザインシートを
書くだけでは解決しない。

技術面を調べ直すと、**解決手段自体は既にコードにある**ことが
分かった。`common.py` の `box()`/`cylinder()` はベベル付きの
硬い形状を作れ、`garudo.py` は鉢巻きの結び目・ベルト・なたを
`join()` で本体メッシュへ統合し、armatureへバインドしている
(なたは「自動ウェイトで前腕の骨に追従する」とコメントにある)。
つまり技術的な部品は揃っており、足りないのは**体の輪郭そのものを
崩す部品を、シルエットの記号として毎キャラに組み込む規律**である。

## 変更内容

### 1. デザインシートへの義務項目追加

`plan/models/sheets/*.md` の「シルエットの記号」項目に、以下を
必須にする:

- 各キャラは、黒塗りシルエットの輪郭に影響する**硬い形状の部品を
  最低1つ**持つ(装身具・防具・道具・角・羽根等)。丸い体表面の
  色分けだけで済ませない。
- 硬い部品は `box()`/`cylinder()`(ベベル付き)で作り、`join()` で
  本体(Skinモディファイア出力)へ統合したうえでarmatureへ
  バインドする(既存の鉢巻き・ベルトと同じ手順)。

### 2. 硬い部品のウェイトを単一ボーンへ固定する

`join()` 後の自動ウェイト計算は、関節をまたぐ位置にある頂点が
**複数ボーンにブレンドされ、曲げたときに部品自体が歪む**恐れがある
(現状の鉢巻き・ベルトのような胴体中心の部品では目立たないが、
肩・膝など可動域の大きい位置に付けるとゴム的に伸び縮みする)。

`common.py` に `pin_weight_to_bone(obj, vertex_group_indices, bone_name)`
を新設し、硬い部品の頂点だけを単一ボーンへ100%固定できるようにする。
これにより装甲・小物は曲げの影響を受けず、剛体として動く
(現実の鎧のふるまいに近い)。

### 3. 汎用「部位カタログ」を `parts.py` に追加する

全キャラ共通で使い回せる、シルエットを壊す部品の型を用意する:

- **肩当て**(半球+面取り箱)
- **膝当て・すね当て**(面取り角柱)
- **襟・裾の折り返し**(薄い面取り板)
- **靴底と甲の段差**(底面だけ別の直方体にして接地面を主張する)
- **頭部の飾り**(角・羽根・かんざし等、種族固有の記号)

`garudo.py` の `parts.build_hatchet` と同じ形式(関節位置・
スケール・回転を引数に取る)で汎用ビルダー化し、どのキャラからも
呼び出せるようにする。

### 4. character-design-language.md との関係

`character-design-language.md`(実装済み・アーカイブ)の
「シルエット第一の原則」は努力目標として書かれていたが、本書が
その実装手順(部位カタログ+単一ボーン固定)を補う。既存文書の
記述自体は変更しない。

## パイロット

ガルドに硬い部品を1つ追加して工程を検証する。候補は実装時に
エンジン内プレビューで比較して選ぶ(背負いダルの肩ひもの金具を
立体化する、または新規に小さな肩当てを足す、のいずれか)。

## 受け入れ基準

1. パイロットキャラの黒塗りシルエットに、丸い体表面の色分けだけでは
   出せない角・段差が現れる。
2. 追加した硬い部品が、攻撃・歩行の曲げ動作で歪まず剛体として動く
   (`pin_weight_to_bone` の効果をエンジン内プレビューで確認)。
3. `parts.py` の部位カタログが最低3種類そろい、他キャラから
   呼び出せる状態になっている。
4. デザインシートのテンプレート(既存の `garudo.md` 含む)に
   義務項目が反映されている。

## 対象外

- 全キャラへの一斉適用(パイロット検証後、展開順は
  `character-design-language.md` が定めた順序に従う)
- 顔部位の造形変更(`ps2-quality-adversarial-review.md` 重大4で
  別途扱う)
