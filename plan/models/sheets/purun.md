# ぷるん

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。展開順(ぷるん→地方ボス8体→村人)の
最初の1体。

1. **三語コンセプト**: 半透明・まどろみ・小さな芯
2. **シルエットの記号**: 背中に半分めり込んだ結晶の芯(`common.gem`、
   正二十面体そのまま。丸い雫形の体表面に唯一の角のある面を作る、
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: 丸(雫形)のみ、1頭身(体そのものが1つの丸みで完結)
4. **パレット**: 基色=半透明の水色の体 `(0.30, 0.62, 0.85)` / 従色=
   口の濃紺 `(0.10, 0.22, 0.34)` / 差し色=結晶の芯の琥珀色
   `(0.92, 0.72, 0.32)`(体の寒色と対比する暖色。わずかに発光させる)
5. **設定の見せ場**: design/characters.mdの「ヨリシロが見た、
   なんということもないまどろみの余韻が固まったもの」という設定を、
   体の中に固まった芯そのものとして視覚化する(進化形「とこしえの
   ぷるん」の「揺るぎなさだけが増していく」という性質変化にも、
   この芯が大きく/明るくなる余地として繋げられる)
