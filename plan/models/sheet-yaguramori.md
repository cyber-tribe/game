# やぐらもり

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第七地方(わすれられた祭りの跡)。

1. **三語コンセプト**: 櫓に住み着いた古い霊・見世物のぬしの手先・高所からの一撃
2. **シルエットの記号**: 既存の櫓の木組み(`yaguramori_wood`/
   `yaguramori_roof`素材)。角材と屋根が丸みを避けた硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 櫓の姿を背負った人型、縦に高い
4. **パレット**: 基色=木材の焦茶 `(0.34, 0.24, 0.18)` / 従色=屋根の朱
   `(0.56, 0.20, 0.19)` / 差し色=金の飾り `(0.68, 0.55, 0.27)`
5. **設定の見せ場**: design/characters.mdの「祭りの櫓に住み着いた古い
   霊。見世物のぬしの手先として、高い場所から矢のような一撃を放つ」
   設定を、背負った木組みの櫓そのもので表す
