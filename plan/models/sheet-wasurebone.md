# わすれぼね

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第四地方(骨積みの回廊)。

1. **三語コンセプト**: 誰のものかも忘れられた骨・非力・仲間を奮い立たせる
2. **シルエットの記号**: 既存の骨格そのもの(`wasure_bone`素材、
   骨の連なり)。丸みを避けた骨の輪郭が硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 小柄な骨の妖怪型、5種の中でもっとも簡素
4. **パレット**: 基色=骨の生成り `(0.80, 0.78, 0.70)` / 従色=灰
   `(0.50, 0.49, 0.46)` / 差し色=眼窩の淡青 `(0.55, 0.70, 0.85)`
5. **設定の見せ場**: design/characters.mdの「誰のものかも忘れられた
   骨。1体では非力だが、倒されると周りの骨系のモンスターを奮い立たせる」
   設定を、簡素な骨組みだけの姿で表す
