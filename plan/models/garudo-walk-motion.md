# ガルドの歩行モーションの見直し(人間離れした歩き方を直す)

## 経緯

村なか歩き(自由移動)でガルドの歩き方が人間離れして見える。
現行の `walk` クリップ(`tools/models/garudo.py`)を読むと原因は
明確で、**脚が付け根から±26度振れるだけで、遊脚の膝がほとんど
曲がらない**(shinは-12〜10度)。膝の伸びたまま脚を振る歩きは
コンパス(ぶんまわし)歩行になり、人形が滑っているように見える。
腕振り±24度も脚に対して大きすぎる。

さらに村は連続移動(`VILLAGE_MOVE_SPEED`)なので、クリップの
歩幅と移動速度が合っていないと**足が地面を滑る**。ダンジョンは
1マス移動の補間なので目立たなかった問題が、村で露呈した。

## 修正内容

### 1. walkクリップの打ち直し(1サイクル=左右2歩、4フェーズ)

人の歩行の基本4フェーズをキーに置く:

| フェーズ | 要点 |
|---|---|
| 接地(コンタクト) | 前脚は膝ほぼ伸展でかかと接地、後脚はつま先残し。胴はやや低い |
| 沈み込み(ダウン) | 接地脚の膝がわずかに曲がって体重を受ける(現行のhipc沈みは活かす)。胴が最も低い |
| 通過(パッシング) | **遊脚の膝を40〜50度曲げて**前へ運ぶ(ここが最重要)。支持脚は伸び、胴が最も高い |
| 蹴り出し(アップ) | 後脚のつま先で押し出し、次の接地へ |

- 腕振りは±15度程度に抑え、肘をわずかに曲げる(棒腕にしない)。
- 骨盤に小さなロール(左右2〜3度)とねじれを入れ、肩は逆位相。
- 頭(neck)は胴の上下動を打ち消す向きに1〜2度だけ補正
  (視線が安定して見える)。
- 少年らしさとして、テンポは軽快寄り(のしのし歩かせない)。

### 2. 足滑りの解消(村側の再生同期)

- クリップの1サイクルで進む歩幅(ストライド)を決め打ちし、
  村の移動速度に対して `再生速度 = 移動速度 / ストライド` で
  同期する(実装は `AnimationAction.timeScale` の調整のみ)。
- 停止時は `idle` へ0.15秒程度でクロスフェード(現状の即切り替えで
  カクつくようなら)。

### 3. 影響範囲

- ダンジョン側も同じ `walk` クリップを使うため、見た目は
  自動的に改善される(1マス移動の再生速度は現状のまま)。
- クリップ名・ボーン構成は変えない(既存の再生コードに手を
  入れない。村側のtimeScale同期だけが追加実装)。
- 村人モデル(`plan/models/model-*.md` の8人)は `idle`/`talk` のみで
  歩かないため影響なし。ただし本クリップの作りを、今後歩く村人を
  作る際の雛形にする。

## 受け入れ基準

1. 村なか歩きで、膝が曲がって足が交互に運ばれる人間の歩きに見える。
2. 足が地面を滑らない(移動速度と歩幅が同期している)。
3. ダンジョン内の1マス移動でも違和感が出ていない。
4. `tools/preview/` のレンダリングと実機の両方で目視確認。
