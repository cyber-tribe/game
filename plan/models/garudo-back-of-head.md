# 後頭部を「球に板」から「毛束の塊」へ

## 経緯

耳と横髪が片付いたあと、残っていた「後頭部の板っぽい面と `bk_nape` の
V字ファセット」に着手した。設定画の背面図は、毛束が上から下へ流れて
**襟足が毛先の尖りの並び**になっているのに、モデルは滑らかな球に板が
数枚貼ってあり、中央に大きなV字の折れが出ていた。

## 測って原因を出した

見た目をいじる前に、**何が見えているのかを色分けして数えた**。

```
毛束の隙間からcapが手前に来る割合   135° 47% / 180° 41%
```

見えている髪の4割が毛束ではなく **Hair Cap** だった。V字ファセットの
正体も、毛束の折れではなく**capが菱形に顔を出していた穴**。

さらに段(隣の画素と3mm以上の深さの差)を数えて地図にすると、段は
毛束の縁ではなく**capが顔を出している斑の境目**に集中していた。
「浮かせ量が大きすぎる」ではなく「埋めていない」が原因。

## やったこと

### 1. 背面図の髪の塊そのものを土台としてなぞる

`aux_back_fill`。既存の `major_back` は**毛束の輪郭**をなぞったもので、
設定画の後頭部の中央は輪郭線の無い一様な塊なので、そこには何も
traceされていなかった。塊全体を1枚なぞって下に敷く。

* 左右は 4mm 内側へ寄せる(シルエットは毛束の担当)
* **上端は 8mm 下げる**(頭頂の尖りを埋めない)
* **下端(襟足)は設定画の毛先の並びをそのままなぞる** ―― これで
  襟足の尖りが手に入る

### 2. 分割数を上げる

面積が広いので `cuts=1` だと内部が大きな三角形の平らな板になり、
丸い頭の内側へ沈んでcapが斑に出る(実測: 312頂点しか無く、後頭部の
中央付近には1点も無かった)。

| cuts | cap露出(180°) | 三角形 |
|---|---|---|
| 1 | 28% | 22,232 |
| 2 | **14%** | **23,308** |
| 3 | 10% | 28,988(予算24,000超) |

### 3. 土台の置き場所

「他のどの毛束より下」ではなく **「capのすぐ外、かつ他のどの毛束より
下」**。一番下(浮かせ1mm)へ沈めたらcapより内側になり、露出が
28%→39%へ悪化した。lift 1.5mm / thick 6.2mm に落ち着いた。

### 4. 上に載る毛束はほぼ面一に

`major_back` は lift 3.5mm / thick 4.5mm。5mm へ上げたら一枚ずつが
板の縁を見せて松かさに見えた。毛束の分かれ目は塗り(`_hair_color` の
筋)が受け持つ。

## QAに足したもの

```python
rate, _ = C.visible_fraction([cap], clumps, 視線)
assert rate <= CAP_EXPOSED_MAX      # 0.30
```

`[hair] 135° capが露出している割合` として毎ビルド出る。
「板っぽい」を目で気付く前に落とせる。

## 結果

```
cap露出 135° 47%→20% / 180° 41%→14%
髪 IoU 0.812(到達率 95%) / 肌 IoU 0.797(97%)
上部輪郭の凹凸 79%(基準70%)
三角形 23,308(予算 24,000)、判定 PASS、tests 513 passed
```

## 続き ―― 毛束の分かれ目を線として描く

土台で「球に板」は消えたが、後頭部は分かれ目の無い一様な塊のままだった。
**背面は長らく何も測っていなかった**ので、そうなっていても全部の指標が
通っていた。背面図と背面レンダーを同じ窓へ写して比べる計測を足した。

### 指標が何を数えているかを絵で見た

最初の比較は 設定画 3.9% 対 モデル 0.6% で、塗りをいくら強くしても
届かなかった。稜線を赤で塗った画像を見たら、**設定画の稜線の大半は
髪の塊を囲む黒いインクの輪郭**だった。モデルには輪郭線の描画そのものが
無いので、比べていたのは「毛束の分かれ目があるか」ではなく
「輪郭線があるか」。

マスクを5px内側へ削って輪郭を除いたのが正しい比較:

```
設定画 0.9% / モデル 0.4%
```

### 効いたのは「床の掛け方」

髪が黒い塊にならないよう `max(0.62, f)` の床を敷いてあったが、
**線を描く項も同じ床に当たって潰れていた**。暗くする項をいくら足しても
0.6%→1.1% までしか増えなかったのはこれが原因。

```python
f = max(0.62, f)                           # なだらかな階調には高い床
line = 分かれ目(細い溝) * 毛束の中の筋      # 線は別に作り
return _shade(HAIR, max(0.42, f * line))   # 線には低い床
```

筋の刻みは **細かくするほど良いわけではない** ―― 2.2→3.6 へ細かくしたら
1.4%→1.3% へ減った。線どうしが近いと局所平均がそれを追いかけて
コントラストが消える。太く・少なく・間を空ける。

### 結果

```
背面の毛束の分かれ目(輪郭線を除く)  設定画 0.9% / モデル 0.4% → 0.9%
```

顔一致QAに恒久的な項目として入れた(基準: 設定画の60%以上)。

## 残件

* **輪郭線の描画が無い。** 設定画の「線」の大半はインクの輪郭で、
  これは塗りでは出せない。インバーテッドハルなり後処理なりの
  **描画側の判断**が要るので、ここでは手を付けていない。
* 45°での耳の上部被覆は 0%。条件は満たすが「自然に覆う」なら
  10〜30% 見えるほうがよい。
* 三角形は 23,308 / 予算 24,000。形を足す余地はほぼ無い。
