# おおねぼすけ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。展開順(ぷるん→地方ボス8体→村人)の
第一地方ボス。

1. **三語コンセプト**: 巨躯・寝こけ・据わりきり
2. **シルエットの記号**: 頭の後ろに寄りかかった、角のある石の枕
   (`C.box`のベベル。丸い体表面に唯一の硬い面を作る、
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: 丸(purunと同じ縦2骨の雫形)を1.5倍に拡大、
   1.3頭身程度の据わった塊感(地方ボスの型)
4. **パレット**: 基色=参道の土に馴染む淡い肌色 `(0.74, 0.64, 0.50)` /
   従色=よだれの薄緑がかった白 `(0.80, 0.86, 0.82)` / 差し色=石の枕の
   くすんだ灰 `(0.40, 0.38, 0.36)`(体の暖色に対する唯一の寒色で、
   「決して離れない眠りの重石」を暗示する)
5. **設定の見せ場**: design/characters.mdの「眠りこけて起き上がれ
   なくなった、途方もない眠気そのものが人の形を借りた姿」「参道の
   最奥に居座る」という設定を、頭を預けたまま二度と離れない石の枕
   として視覚化する
