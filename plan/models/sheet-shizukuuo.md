# しずくうお

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第五地方(なみだの滝つぼ)。

1. **三語コンセプト**: こぼれ落ちる涙・儚い・群れ
2. **シルエットの記号**: 尾の先が結晶化した、角のある小さな氷状の
   雫を新設する(`common.gem`。plan/models/archive/
   silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: 雫形の小魚、1頭身弱
4. **パレット**: 基色=深い青 `(0.20, 0.30, 0.52)` / 従色=淡い水色
   (体より一段明るい) / 差し色=尾の結晶
5. **設定の見せ場**: design/characters.mdの「こぼれ落ちる涙のしずく
   そのもの。1匹では儚いが、涙は次々こぼれるように群れで現れる」
   設定を、尾の先で固まりかけた結晶で表す
