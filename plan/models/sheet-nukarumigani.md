# ぬかるみがに

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第二地方(忘れ潮の湿地)。

1. **三語コンセプト**: 足を取られた思い出・根を張る・力比べ
2. **シルエットの記号**: 既存の甲殻・鋏(`nukaru_shell`/`nukaru_claw`
   素材)。丸い体表面に硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: カニ型、ワスレガニよりどっしり低い姿勢
4. **パレット**: 基色=甲殻の青緑 `(0.38, 0.50, 0.52)` / 従色=腹の
   暗青緑 `(0.22, 0.30, 0.34)` / 差し色=鋏の縁 `(0.66, 0.76, 0.74)`
5. **設定の見せ場**: design/characters.mdの「足を取られた思い出その
   もの。ぬかるみに根を張るように動きが鈍い代わり、力比べになると
   存外強い」設定を、低く構えた鋏の力強さで表す
