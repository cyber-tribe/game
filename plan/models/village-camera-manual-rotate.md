# 村のカメラの回り込みをやめ、手動回転(ダンジョンと同じ操作)にする

## 経緯

村の三人称カメラ(`plan/models/archive/village-scene-redesign.md`)は
「プレイヤーの移動方向へカメラが緩やかに回り込む」自動追従にしたが、
実機で方針を見直す。**カメラの向きは基本固定とし、回したいときは
ダンジョンと同じ操作で明示的に回す**。

理由: 移動のたびに視界がぐるぐる変わると、行きたい建物との位置
関係を見失いやすい(村は狭い盤面を行き来する場所なので、向きの
安定のほうが快適さに効く)。また「回す操作はQ/E・二本指回転」という
既存の学習をダンジョンと村で共通にできる。

## 変更内容

1. **自動の回り込みを廃止する。** カメラのyawはプレイヤーが操作
   しない限り変わらない(位置の追従=プレイヤーの後方に付いていく
   動きは残す。回転だけを固定する)。
2. **手動回転はダンジョンと同一の操作**:
   - キーボード: `Q` / `E` で90度単位の回転(既存の
     `rotateLeft` / `rotateRight` アクションをそのまま村でも受ける)
   - タッチ: 二本指回転ジェスチャ(`src/ui/touch-controls.ts` の
     既存実装をそのまま有効化)
   - 回転のアニメーションはダンジョンと同じ指数補間(`targetYaw`)
3. **移動入力は現在のカメラ向き基準のまま**(画面基準入力の既存
   方針。カメラが固定でも、スティックを倒した画面方向へ歩く)。
4. 初期向きは村に入った時点で**山(北)を正面**にする(帰還直後は
   広場側を向く既存の演出があればそちらを優先してよい)。
5. 建物の遮蔽半透明化・低いアングル・画面下1/3のガルド、という
   構図の指定は変更しない。

## 受け入れ基準

1. 村なかで移動してもカメラの向きが勝手に変わらない。
2. Q/E(キーボード)・二本指回転(タッチ)で、ダンジョンと同じ
   手応えでカメラが回る。
3. 回転後も移動入力は画面基準で一貫している。

## 対象外

- ダンジョン・内装のカメラ(変更なし)
- ズーム操作の追加(現状の村カメラの距離感を固定のまま)
