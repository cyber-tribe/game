# きりみずち

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第二地方(忘れ潮の湿地)。

1. **三語コンセプト**: 忘れられかけた道しるべ・霧・実体の薄れ
2. **シルエットの記号**: 既存の角ばった棘(`kiri_spike`素材)。丸い
   体表面に唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 細長い水霊型、実体が薄れ始めた印象の淡い輪郭
4. **パレット**: 基色=下半身の暗青緑 `(0.30, 0.40, 0.43)` / 従色=
   上半身の淡青緑 `(0.58, 0.70, 0.72)` / 差し色=水弾のしずく
   `(0.55, 0.78, 0.85)`
5. **設定の見せ場**: design/characters.mdの「霧を纏う、忘れられかけた
   道しるべの成れの果て。実体を失いつつあるぶん近づかず、離れた
   ところから水弾を飛ばす」設定を、上半身ほど淡く透けるような配色で
   表す
