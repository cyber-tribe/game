# ねだやまびこ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第六地方(こだまの尾根)。

1. **三語コンセプト**: 根を張った響き・動かない・物音を遠くまで響かせる
2. **シルエットの記号**: 既存の甲殻(`nedayamabiko_shell`素材)。丸い
   体表面に唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 尾根に根を張った、動かない塊型
4. **パレット**: 基色=肌の茶 `(0.44, 0.32, 0.22)` / 従色=甲殻の灰
   `(0.62, 0.61, 0.58)` / 差し色=眼窩の暗色 `(0.05, 0.05, 0.07)`
5. **設定の見せ場**: design/characters.mdの「尾根に根を張ってしまった
   古い響き。ほとんど動かず、周囲の物音(罠・戦闘)をさらに遠くまで
   響かせる――地方固有ギミックそのものを体現する種族」設定を、根を
   張ったまま動かない硬い甲殻で表す
