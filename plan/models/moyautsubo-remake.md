# モヤウツボを設定画に合わせてリメイクする

## 経緯

設定画ベースのリメイク9体目。モヤウツボ(`species.ts`の
`moyautsubo`、第二地方7階〜のambush AI)の設定画が提供された。
同様に**承認済みの2Dコンセプト+三面図**として扱う
(`turnaround-drawing-craft.md`「5. 正直な逃げ道」)。設定画は
`plan/models/reference-moyautsubo-sheet.png`として保存した。

## 設定画の読み取り(実物を目視)

- **概念**: 霧に紛れた油断が形になったもの。隣接するまで気配を
  消し、油断したところへ初撃を強く叩き込む(ambush AIの現行挙動と
  一致)。攻撃後は姿を消して距離を取り、再潜伏する。
- **体形**: **手足の無い、長い蛇体のウツボ**。霧の山(雲の塊)から
  上体が立ち上がり、尾は霧に溶け込む。背面図ではほぼ霧の塊にしか
  見えない。
- **顔(最大の見せ場)**: 大きく開く顎に**白い牙がずらりと並ぶ**。
  もこもこした柔らかい霧の体との対比で、口の中だけが凶暴。
  目は暗い縁の中に浮かぶ**小さな白い点**で、「目と口だけが霧の
  中でも浮かび上がる」と明記。
- **体表**: 体は霧の粒でできており、**もこもこした凹凸**が全身を
  覆う。輪郭は常にぼやけ、形は常にゆらいでいる。
- **パレット7色**: 霧メイン(淡い灰藤)/霧(濃)/霧(薄)/
  内部の渦(紫灰)/目・口の周辺(暗色)/牙(生成りの白)/
  地面の影。
- **状態**: 通常(潜伏中)/気配を消す/近づく/姿を現す/威嚇する/
  噛みつく(初撃)/体当たり/霧に溶ける(後退)/警戒する/疲弊する。
- **攻撃**: ①潜伏(気配を消す) ②近づく ③強襲(初撃が強力)
  ④後退して再潜伏。
- **行動**: 霧の中を素早く移動/壁や障害物に沿う/霧から垂直に
  飛び出す/分身のように揺らぐ(フェイント)。

## 現行モデルとの差分(実測)

`build_moyautsubo()`は、docstringにあるとおり「**tsubuteと同じ
関節構成**」を引き伸ばした低い四足の獣(前腕+後脚つき)で、
青緑系の配色、小さな潰し球の口、平たい霧の房4個、背に硬い
鰭の箱3個:

| 項目 | 現行 | 設定画 |
|---|---|---|
| 体形 | 低い四足獣(前腕+後脚あり) | 手足の無い蛇体+霧の山 |
| 口 | 小さな潰し球 | 大きく開く顎+白い牙の列(見せ場) |
| 目 | 目玉球 | 暗い縁の中の小さな白い点 |
| 体表 | 滑らかな連続メッシュ | もこもこした霧の粒の凹凸 |
| 霧 | 平たい房4個 | 体を包む霧の土台の山 |
| 背びれ | 硬い箱3個(旧義務項目) | 無し |
| 配色 | 青緑系 | 淡い灰藤の霧 |

## 変更内容

### 1. 体を「霧の山から立ち上がる蛇体」に作り直す

- 四足の骨格を捨て、**蛇体の骨格**にする: 根元(霧の山の中心)
  から背骨4〜6節で立ち上がり、頭+**開閉できる顎**で終わる。
  手足は付けない。
- 根元に**霧の土台の山**(大小の球を寄せた、もこもこの塊)を
  置き、蛇体がそこから生えている構成にする。尾の先は土台の中へ
  消える(あくびとかげの尾の消え際と同じ「先端を淡い色で
  塗り分ける」翻訳を使ってよい)。
- 寸法・輪郭は三面図パネルから読み取る(接地面〜頭頂で正規化)。

### 2. 体表のもこもこ

- 蛇体の表面に、**もこもこした霧の粒の凹凸**を作る。手法は
  実装の裁量とするが、候補は2つ:
  (a) `fluff_ring`(villagers.pyのもこもこ襟)と同じ「小さな球を
  体に沿わせて並べる」方式、(b) 頂点を法線方向へ不規則に
  押し出す変位(`build_wall`の手彫りの応用)。予算内で
  シルエットに凹凸が読めるほうを選ぶ。
- 「内部の渦」は紫灰の色面パッチとして体側に1〜2箇所置く程度に
  留める(フラット方針。渦のアニメーションはしない)。

### 3. 顔(牙と点の目)

- 顎は専用骨で大きく開き、**上下の顎に白い牙のジグザグ列**
  (三角形の帯)を仕込む。口内は暗色(パレット「目・口の周辺」)。
  柔らかい霧の体と凶暴な口の対比がこの種の要。
- 目は**暗色の縁パッチの中に小さな白い点**。発光はごく弱いか
  無しでよい(白点+暗い縁のコントラストだけで「浮かび上がる」
  印象は出る。ホネガラミで強発光を廃した判断と揃える)。

### 4. 配色

- 青緑系をやめ、パレット7スウォッチ(淡い灰藤の霧の階調)から
  直接サンプリングする。背の硬い鰭の箱は削除する(設定画に無く、
  もこもこの輪郭と矛盾する)。

### 5. アニメーションを設定画に合わせる

- idle: 「潜伏中」— ほぼ動かず、霧の土台がわずかに揺らぐ
  (現行idleの「ほとんど動かない」方向性を維持)。
- walk: 蛇行しながら滑るように進む(四足の歩行をやめる)。
- attack: 「強襲」— タメを短くし、顎を大きく開いて鋭く突き込む
  (ambushの「初撃が強力」を、LINEARの鋭い入りで表現)。
  攻撃後の後退は現行AIの挙動側にあるためモーションは戻りのみ。
- hit: 体の霧が乱れて形が崩れ、すぐ戻る。
- die: 霧の土台へ溶け崩れて消える。

### 6. 工程・検査

- 2D承認は設定画の提供をもって完了済み。3D化後に平行投影・
  黒塗りレンダーを三面図と重ねてシルエット照合する。
- 三角形数はモンスター予算(1,200〜5,000)内。もこもこの粒は
  数を絞り、シルエットの凹凸に効く外周を優先する。

## 受け入れ基準

1. 正面・側面・背面の黒塗りシルエットが設定画の三面図と重なる
   (照合画像で確認。背面はほぼ霧の塊に見えること)。
2. 四足獣ではなく「霧の山から立ち上がる、手足の無い蛇体」に
   見え、背の硬い鰭が無い。
3. 顎が開き、白い牙の列と暗い口内が見える(attackで大きく開く)。
4. 目が目玉球ではなく「暗い縁+小さな白い点」になっている。
5. 体表・輪郭にもこもこした凹凸が読める(滑らかなチューブに
   なっていない)。
6. 青緑系の旧配色が残っていない。
7. エンジン内プレビューの新旧比較で、設定画のキャラクターだと
   一目で分かる。

## 対象外

- 潜伏・フェイント・分身のゲームシステム化(ambush AIの現行
  挙動のまま。ゲームデザイン凍結中のため見た目のみ)
- 姿を消す/現すときの霧のパーティクル演出(`particles.ts`側)
- 派生種(カスミウツボ等)への波及(本種の完成を見てから判断)
- ステータス・出現階層の変更(設定画「B2F〜」と現行`minFloor: 7`
  =第二地方の食い違いは本書では触らない)
