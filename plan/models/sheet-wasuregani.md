# ワスレガニ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第二地方(忘れ潮の湿地)。

1. **三語コンセプト**: 置き忘れた記憶・硬い殻・思い出せない混乱
2. **シルエットの記号**: 既存の甲殻(`wasuregani_shell`素材)。丸い
   体表面に唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: カニ型、横に広い1頭身弱
4. **パレット**: 基色=肌の青緑 `(0.42, 0.52, 0.54)` / 従色=甲殻の
   暗青緑 `(0.26, 0.34, 0.38)` / 差し色=眼窩の淡青 `(0.55, 0.72, 0.80)`
5. **設定の見せ場**: design/characters.mdの「置き忘れた記憶が硬い殻を
   まとって居座るもの。攻撃が当たると軽い混乱を起こす」設定を、
   殻の硬さと淡く光る眼窩で表す
