# かげぼうし

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第七地方(わすれられた祭りの跡)。

1. **三語コンセプト**: 影絵芝居の忘れ物・不意打ち・眠りを誘う
2. **シルエットの記号**: 操られていた細い操り棒を新設する
   (`C.cylinder`。影絵芝居の人形がまだ棒に繋がれたままという
   見立て。plan/models/archive/
   silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: 平たい影絵人形型、薄いシルエット
4. **パレット**: 基色=影の暗色 `(0.05, 0.045, 0.055)` / 差し色=淡く
   光る縁 `(0.85, 0.66, 0.28)`
5. **設定の見せ場**: design/characters.mdの「祭りの影絵芝居の忘れ物。
   めんかぶりこぞうと同系統の奇襲役だが、混乱の代わりに眠りを誘う」
   設定を、まだ棒に繋がれた影絵人形の姿で表す
