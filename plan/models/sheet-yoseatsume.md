# よせあつめ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第八地方(めざめの前庭)。

1. **三語コンセプト**: バラバラな由来・寄り集まった群れ・なんとなく
2. **シルエットの記号**: 各地方の硬い部品の欠片(石つぶて・骨片・
   甲殻・提灯の竹輪など)を1つずつ寄せ集めて体表にまとわせる
   (既存素材の断片的な再利用。
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: 由来がバラバラなまま寄り集まった、不揃いな塊
4. **パレット**: 6地方の色 `(0.72,0.62,0.48)` `(0.40,0.52,0.54)`
   `(0.46,0.30,0.24)` `(0.74,0.70,0.62)` `(0.22,0.26,0.42)`
   `(0.58,0.48,0.34)`
5. **設定の見せ場**: design/characters.mdの「様々な地方の残響が
   寄り集まった群れ。1体1体の由来がバラバラなまま、なんとなく群れを
   なしている」設定を、統一感のない硬い欠片の寄せ集めで表す
