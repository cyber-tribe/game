# まつりのぬし

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。配合限定(めんかぶりこぞう×かざりだるま)。

1. **三語コンセプト**: 祭りの高揚・状態異常無効・自分を守る
2. **シルエットの記号**: 既存のお守り(`matsurinonushi_charm`素材)。
   丸い輪郭に唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: めんかぶりこぞうの面をかざりだるまの丸い体に
   乗せた比率
4. **パレット**: 基色=褪せた朱 `(0.32, 0.18, 0.16)` / 従色=金
   `(0.50, 0.41, 0.24)` / 差し色=お守り `(0.60, 0.49, 0.26)`
5. **設定の見せ場**: design/characters.mdの「状態異常を受けつけなく
   なる――祭りの高揚が、正気を失わせる悪戯からも自分を守るように
   なる」設定を、身につけたお守りで表す
