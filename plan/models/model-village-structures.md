# 村の建物・小道具(village-structures)の3Dモデル

村なか歩きの建物は現在、Three.jsのプリミティブ(色つきの箱)で
仮置きされている(`src/view/village.ts` の `buildStructure`)。
建物考証(`design/village-buildings.md`)が固まったので、建物と
主要な小道具をBlenderパイプライン(`tools/models/`、既存の
`props.py` にタル・壁・罠の前例あり)の正式なモデルに置き換える。

配置・カメラ・光は `plan/game/village-scene-redesign.md` が扱う。
本書は造形のみ。

## 共通の造形言語(考証の反映)

- **建材は祠木=タルと同じ飴色の木肌。** 既存のタルモデル
  (`props.py` の `_barrel_body`)と同じ木色パレットを流用し、
  「タルと同じ木でできた村」を色で語る。
- **屋根は伏せたタルを思わせる緩い丸屋根**(半円筒か浅いドーム)。
  板張りの筋を数本入れてタルの側板を連想させる。
- 建物ごとの個性は**屋根の上と入口まわりの小道具**で付ける
  (シルエットで判別できることを最優先)。
- 三角形数の目安: 建物1棟あたり1,500〜4,000(モンスターより
  低精細でよい。数が並ぶため)。トゥーンシェーディングは読み込み側で
  自動適用。

## 建物モデル(8棟)

| モデルid | 建物 | シルエットの決め手 |
|---|---|---|
| houseStorage | モグラ婆の倉庫 | 横に長い平屋+壁沿いに伏せた古タルの列。入口脇に手押し車 |
| houseWorkshop | ゲンドの工房 | **煙突と煙**(村で唯一)。軒下に寝かせた祠木の材、入口横に金床 |
| houseHut | ねむり小屋 | 丸屋根が一番深い(かまくら形)。入口に掛け布ののれん、軒に小さな風鈴 |
| houseCompendium | おキヨの図鑑小屋 | 屋根に天窓、壁の外にも木札が鈴なりに掛かる |
| houseRecords | 記録の間 | 切妻の几帳面な直線的シルエット(丸屋根の村で唯一の直線)、入口に巻物の看板 |
| houseDevelopment | 村の発展の受付 | 屋根なしの東屋(柱4本+陣幕)。中央に村の模型台 |
| houseGarudo | ガルドの家 | 一番小さい。土間の支度タルが戸口から見える。壁に手形の跡 |
| caveGate | 洞窟の入口 | 岩肌の穴+**祠木の門柱一対+たが縄**。村最大のランドマーク |

- 依頼板・旅の看板は建物ではなく小道具(下記)として作る。

## 小道具モデル

| モデルid | 内容 |
|---|---|
| propQuestBoard | オトネの依頼板。大タルの底板を並べた板壁+貼られた依頼札(数枚は裏返し=達成済み) |
| propSignpost | 旅の看板。タルの側板の再利用らしい湾曲した板 |
| propBonfire | 広場の囲炉裏火。石組み+薪+火(火はシェーダー/ビルボードでよい)。タルの腰掛け3〜4個を同梱 |
| propHokoragi | 祠木。ひげ根が地表に張り、幹の木目が渦を巻く低ポリ樹木。バリエーション2種+渦の切り株1種 |
| propBarrelBed | ねむり小屋のタルの寝床(横倒しのタル+掛け布+名札)。内装用 |
| propShelfBarrel | 古タル転用の棚。内装用(倉庫・工房で使い回す) |

- 内装用の机・棚・炉などの汎用什器は、既存の箱プリミティブ+
  上記の考証小道具の組み合わせで足りる(全部をBlender化しない。
  「考証を語る小道具」だけをモデルにする)。

## アニメーション

- 建物は基本静止。動きは3点だけ:
  工房の**煙**(シェーダーかビルボードのループ)、広場の**火**、
  ねむり小屋の**風鈴の揺れ**(頂点アニメか小さな回転ループ)。
  クリップを持つ場合は `idle` 1本に統一する。

## 進め方

- 1棟=1PRで順に置き換えてよい(モンスターモデルと同じ運用)。
  優先順は caveGate → propBonfire+propHokoragi(村の骨格)→
  houseWorkshop → houseHut → 残り。
- 置き換えの間、未対応の建物は現行の箱表示のままで構わない
  (`buildStructure` を段階的にモデル参照へ差し替える)。
