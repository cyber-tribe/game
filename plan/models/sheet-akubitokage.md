# あくびとかげ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第一地方(うたたねの参道)。

1. **三語コンセプト**: 取るに足らない・あくびの影・すぐ離れる
2. **シルエットの記号**: 背に一列並んだ、面取りした小さな三角柱の棘
   を新設する(`C.box`+ベベル。
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: 小さな四足のとかげ型、1頭身弱
4. **パレット**: 基色=影の焦茶 `(0.34, 0.28, 0.21)` / 従色=土埃の淡茶
   `(0.74, 0.66, 0.52)` / 差し色=口の中の暗褐色 `(0.20, 0.15, 0.13)`
5. **設定の見せ場**: design/characters.mdの「あくびの合間に紛れ込んだ
   影」「取るに足らない存在」という儚さを、控えめな棘の連なりで
   縁取るだけにとどめる
