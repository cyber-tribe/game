# ユメクイモグラ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第三地方(まどろみの茸林)。

1. **三語コンセプト**: 浅い眠りの夢食い・潜る・不意打ち
2. **シルエットの記号**: 既存の掘削用の爪(`yumekuimogura_claw`
   素材)。丸い体表面に唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: モグラ型、前足が大きい
4. **パレット**: 基色=毛皮の紫がかった灰 `(0.30, 0.28, 0.35)` /
   従色=腹の茶 `(0.42, 0.36, 0.30)` / 差し色=爪の山吹
   `(0.74, 0.66, 0.42)`
5. **設定の見せ場**: design/characters.mdの「浅い眠りの中の夢食い。
   地面に潜って進み、不意にプレイヤーの近くへ顔を出す」設定を、
   潜るための大きな爪で表す
