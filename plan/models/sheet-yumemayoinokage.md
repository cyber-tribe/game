# ゆめまよいの影

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第八地方(めざめの前庭)。

1. **三語コンセプト**: 主を見失った夢・タルに擬態・見分けがつかない
2. **シルエットの記号**: 化けているタルの箍(たが)の欠片を、正体を
   見破られた後も残しておく(`C.cylinder`+ベベル。
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: タル型、`props.barrel_body`の輪郭を踏襲
4. **パレット**: 基色=殻の灰紫 `(0.42, 0.40, 0.44)` / 従色=フードの
   藍紫 `(0.34, 0.32, 0.40)` / 差し色=箍の欠片(木の色)
5. **設定の見せ場**: design/characters.mdの「主を見失った夢。タルに
   擬態しており、持ち上げる/投げるまで見分けがつかない」設定を、
   化けが解けても残る箍の欠片で表す
