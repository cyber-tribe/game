# モヤウツボ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第二地方(忘れ潮の湿地)。

1. **三語コンセプト**: 霧に紛れた油断・不意打ち・気配なし
2. **シルエットの記号**: 背に連なる、面取りした小さな鰭状の棘を
   新設する(`C.box`+ベベル。
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: 細長いウツボ型、低い姿勢
4. **パレット**: 基色=背の青緑 `(0.46, 0.58, 0.58)` / 従色=腹の
   暗青緑 `(0.28, 0.38, 0.40)` / 差し色=纏う霧 `(0.82, 0.90, 0.90)`
5. **設定の見せ場**: design/characters.mdの「霧に紛れた油断が形に
   なったもの。隣接するまで気配を消し、油断したところへ初撃を強く
   叩き込む」設定を、霧に紛れて見えにくい体色と、気づいたときには
   遅い鰭の棘で表す
