# マドロミダケ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第一地方(うたたねの参道)。

1. **三語コンセプト**: 眠気そのもの・きのこ・胞子
2. **シルエットの記号**: 軸の根元に食い込む、面取りした木質の輪
   (つば)を新設する(`C.cylinder`+ベベル。
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: きのこ型(軸+傘)、1頭身弱
4. **パレット**: 基色=軸の生成り `(0.90, 0.86, 0.74)` / 従色=傘の
   赤紫 `(0.62, 0.24, 0.42)` / 差し色=傘の白い斑点 `(0.94, 0.92, 0.86)`
5. **設定の見せ場**: design/characters.mdの「眠気そのものが形になった、
   きのこの姿の夢のかけら」「今回の物語の異変(悪夢化)が最初に色濃く
   出る」設定を、地に食い込む木質のつばで「根を張った眠気」として
   見せる
