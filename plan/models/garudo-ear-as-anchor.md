# 耳を「横髪の位置決め基準」として作り込む

## 経緯

外部評価の第4回(2026-09-03)。横髪を3D毛束(`C.clump_volume`)へ置き換えた
あとの指摘。耳は単体の完成度の話ではなく、**こめかみ〜横髪〜頬の境界を
成立させる形状の基準点**として要る、という判断。

> 横髪と耳を別々に完成させないこと。耳は横髪の位置決めガイドとして使う。

「頭が坊主に見える」「横幅が妙に広い」という以前からの違和感も、
耳と周囲の肌が同じベタ色で、境界が読めないことが一因だった。

## 何が問題か

それまでの耳は**頭部に埋めた楕円体のふくらみ**だった。

| 症状 | 原因 |
|---|---|
| 側面図で耳が読めない | 形が楕円で、耳輪・耳穴という内部構造が無い |
| 正面図で耳の位置が分からない | 耳と頬が同じ肌色のベタ塗り |
| 45°で横髪と耳の前後が曖昧 | 耳が頭部と一体なので、横髪が「耳の上に乗る」関係にならない |
| 頭の横幅が広く見える | 耳の外端が髪の最大シルエットより外へ出ていた |

`sculpt_merge(voxel=0.0038)` を通すので、薄い板は太る。それを見越さずに
厚みを決めると、耳がただの丘になる(後述 実測)。

## 方式

### 1. シルエットはメッシュ、内部構造はテクスチャ

外形だけを独立した薄い立体メッシュにし、耳輪・耳穴・耳たぶは**アルベドで
描く**。溝を彫らない。トゥーンの絵として読ませるほうが、この解像度では
安定して読める(`handbook/hand-painted-standard.md` と同じ方針)。

### 2. 外形 ―― 雫形の薄板

完全な楕円ではなく、**上が少し広く、下が細い雫形**。頂点数は 6〜12 で足りる。

`EAR_RINGS` は `(z, 半厚x, 半奥行きy, 中心y)` の表で、`C.loft` で立てる。
中心xは `_head_at(z)` の頭部半径から 1mm だけ内側に置き、頭部表面から
わずかに浮かせる。

位置は側面図基準で **目尻より少し後ろ・鼻先よりはるかに後ろ・顎関節の上**。

### 3. 塗り分け(`_ear_paint`)

| 部位 | 色 | 意図 |
|---|---|---|
| 耳の外側 | `SKIN` | 肌のまま |
| 耳輪 | `EAR_HELIX`(茶の中間影) | 1本の暗い弧として描く。溝ではない |
| 耳穴 | `EAR_CANAL`(耳輪よりさらに一段暗い) | 黒にしない。小面積 |
| 耳の下部 | `EAR_LOBE`(わずかに赤み) | 耳たぶは強調しない(12〜13歳の少年) |
| 耳の外周 1.05〜1.40 | `SKIN`→`EAR_HELIX` の接地影 | 耳と頬を同じベタ色にしない |

**耳と周囲の肌を同じベタ色にしないこと**が、坊主に見える問題に一番効く。

### 4. 横髪との関係

耳の上 1/3〜1/2 は横髪(`lock_front`)で隠す。ただし設定画の正面図では
耳はむしろ**見えている**(肌の外端 54.5mm@z852 → 77mm@z848)ので、
毛束は耳の**前**ではなく**外側**(方位角 az≈92°)を通す。

耳の外端は髪の最大シルエット(|x| 最大)を超えてはいけない。

## QA(`C.visible_fraction`)

3/4の設定画が無いので IoU は測れない。代わりに、耳の位置に検査用の板を
立てて**光線が耳に届く割合**を 0°/45°/90° で数える。

| 角度 | 受け入れ条件 |
|---|---|
| 0°(正面) | 耳が 40〜90% 見える(左右とも一部だけ見える) |
| 90°(側面) | 耳が 50〜90% 読める |
| 45° | 90°−5% 〜 0°+5% の間(単調に減る) |
| 45°の耳の上1/3 | 35% 以下(こめかみ毛束が自然に覆う) |
| 全角度 | 耳の外端 ≤ 髪の最大 \|x\| |
| 塗り | 頬とアルベド耳穴の明度差 ≥ 0.25 |

## 実装結果(2026-09-03)

`tools/models/garudo.py` / `tools/models/common.py`。

```
[ear] 0°  耳が見える割合 78%(上1/3は 0%)
[ear] 45° 耳が見える割合 62%(上1/3は 0%)
[ear] 90° 耳が見える割合 57%(上1/3は 0%)
[ear] 頬と耳穴の明度差 0.47
```

顔一致QA: 肌 IoU 0.802(到達率 97%) / 髪 IoU 0.829(97%) /
ランドマーク 平均1.2mm・最大2.7mm。三角形 20,492。

### 途中で踏んだ穴(handbook へ記録済み)

- **薄板は voxel merge で太る。** 4mm の板が +2.1〜3.6mm の尾根として残る。
  厚みは「仕上がりの厚み」ではなく「voxel を通したあとの厚み」で決める。
- **耳を毛束の前に通すと正面で隠れすぎた**(31%)。設定画は正面で耳が
  見えているので、毛束は耳の**外側**を通す。
- **顔デカールの薄め方**は |x| でも奥行きでもなく**面の向き**。平面投影の
  伸び率は 1/|法線y| なので、傾きで薄める。ただし帯を広く取ると頬の階調
  まで消える(0.30〜0.55 で肌IoU 0.802→0.783)。
- **薄めるのに使う法線はメッシュではなく解析法線**(頭の断面楕円)。
  融合後のメッシュ法線は面ごとに飛ぶので、閾値で切ると境界がぎざぎざの
  島に割れた。楕円の法線に替えて 0.795→0.802。

## 残件

- 45°での耳の上部被覆は 0%(完全に隠れている)。受け入れ条件は満たすが、
  評価は「自然に覆う」なので、いずれ 10〜30% 見える程度に緩めたい。
- 後頭部毛束の板っぽい面と `bk_nape` のV字ファセットは未着手。
