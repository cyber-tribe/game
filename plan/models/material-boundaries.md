# 材質の境目はジオメトリで決める(QAも材質で判定する)

## 経緯

外部評価の第5回(2026-09-03)。「肌と髪の色が滲む」のは耳の造形の話では
なく、マテリアル/テクスチャ生成方式の話だという指摘。

> 髪・肌・耳の意味的な領域分離をRGB色分類に依存しない構造へ変更する。
> 材質境界を跨いでBaseColorをベイクしない。QAもRGB分類ではなく
> Material ID passを正として形状を評価する。

## まず現状を測った ―― 前提の一部は成り立っていなかった

「全部を1枚の384²アルベドへ焼いている」という前提で書かれていたが、
書き出した glb を読むと**そうはなっていない**。

```
materials: 15  images: 11  meshes: 2
  garudo_body   → garudo_albedo      1024²
  garudo_face   → garudo_face_atlas  768²×3コマ
  garudo_hair   → garudo_hair_tex     256²   ← 別メッシュ・別材質・別画像
  ...(革・金具・樽・手・手袋・ブーツも各々別画像)
```

髪はすでに独立したメッシュ・材質・テクスチャで、384²でもない。
テクセルの色を数えても

| 画像 | 髪寄り | 肌寄り | どっちつかず |
|---|---|---|---|
| `garudo_hair_tex` | 100.00% | 0.00% | **0.00%** |
| `garudo_face_atlas` | 36.57% | 63.43% | 1.17% |

`garudo_hair_tex` に肌色は**1テクセルも無い**。髪→肌の滲みはUV補間でも
ミップでも起こりようがない。

**ただし指摘の芯は当たっていた。** 滲んでいたのは髪と肌のあいだではなく、
**肌テクスチャの中**だった。顔のデカール(`tools/trace_face_svg.py`)は
設定画の顔を明度で量子化して**まるごと**写すので、髪も一緒に描かれている。
それを肌の材質へ焼くと、面が傾いた頬の外側で薄まり、平面投影で奥行きへ
引き伸ばされ、「輪郭のぼやけた薄い髪の幽霊」になる。

## やったこと

### 1. QAの分類を色から材質へ

`tools/compare_face.py` に**材質IDパス**を足した。同じ組み立てのまま
材質ごとに単色のEmissionを割り当ててもう1枚描く(ビルドは85秒かかるので
1回のビルドで2パス)。

```
髪  = garudo_hair 材質か            ← 色は一切見ない
肌  = 肌材質の中で、地の肌色のところ  ← 材質で枠を決め、内側だけ色で見る
```

**材質の境目はジオメトリが決め、材質の内側だけを絵で見る。**
これで「耳を茶色くするほどQAが通る」という逆向きの圧力が消える。

切り替えた瞬間、髪IoUは 0.826 → **0.816** に落ちた。差の 0.010 は
**塗りで稼いでいた分**で、落ちたのが正しい数字。

### 2. 「肌材質へ焼かれた髪色」を新しい合否項目にした

顔パッチ(目・眉・口)は肌材質の中に描く絵なので暗くて当然。別グループ
にして除き、素の肌材質に残った髪色だけを数える。

```
肌材質へ焼かれた髪色 178px  ok  (基準<=400px)
顔パッチに描かれた暗い絵    7,668px  参考
```

もみあげを毛束へ置き換える前は、この数がずっと大きかった。

### 3. なぞった毛束の輪郭の中にはデカールを塗らない

`_in_hair_xz(x, z)` で、正面からなぞった毛束の輪郭の中かを判定し、
中なら塗らない。そこは毛束ジオメトリの担当。

### 4. 耳の地の色を SKIN へ戻した

茶系へ寄せるのをやめ、**肌色の立体+内部の影**にした。

| 部位 | 色 | 役 |
|---|---|---|
| 耳輪 | 肌より少し明るい | 隆起 |
| 対耳輪 | 肌の影 | 稜線 |
| 耳甲介 | もう一段暗い | 窪み |
| 耳穴 | 暗い赤茶(黒にしない) | 穴 |
| 外周 | 細い落ち影 | 設定画の輪郭線の役 |

ここで2回間違えた。**耳輪を暗く・中を明るく**すると立体が反転して
ただの浅いへこみに見え、**耳甲介を耳いっぱいに広げる**と稜線が消えて
一枚の窪み(傷のよう)になった。輪・稜線・窪みの3段が要る。
外周の落ち影も、広いグラデーションにすると頬に溶けて耳が消える。
**設定画で耳を耳として読ませているのは輪郭線**なので、細い帯にする。

## やらなかったこと(と、その理由)

* **skin.png / hair.png への分割** ―― すでに分かれている(上の実測)。
* ~~**耳を頭部から分離して独立メッシュにする**~~ ―― **やった**(下記)。
  「材質が混ざるから」ではないが、もっと強い理由があった。
* **UVパディングを増やす** ―― `bake_albedo` はすでに島の外周を4px
  膨張させている。1024²/768²で、実測の滲みは 178px まで落ちたので
  現状で足りている。足りなくなったら測ってから増やす。

## 耳を独立オブジェクトにした

材質の観点では、耳も頭も同じ肌材質なので守るべき境界は無い ―― と最初は
判断した。しかし**もっと強い理由**があった。

`sculpt_merge(voxel=0.0038)` は**薄い板を潰す**。融合していたころは
voxelに負けないよう半厚を4mm(=厚さ8mm)にしていたが、それでも出て
くるのは+2〜3mmの尾根で、**耳の形そのものは残っていなかった**。
形が残らないから陰影で補うことになり、その陰影が茶色へ寄っていった。
「耳が髪に見える→耳を茶色くする→肌と髪が滲む」の出発点はここ。

```
Head mesh   → garudo_body / garudo_face
garudo_ear  → garudo_ear_tex 128²   ← 別メッシュ・別材質・別画像
garudo_hair → garudo_hair_tex 256²
```

耳は `neck-head` ボーンへ剛体追従(髪と同じ)。半厚2mmの板がそのまま
出るので、耳の中身の色は**耳自身のテクスチャ**が持ち、頭のテクスチャに
残るのは**耳の落ち影だけ**になった。材質の境目=ジオメトリの境目。

### 踏んだ穴

* **耳を上へ伸ばしたら側面の可視率が落ちた**(57%→48%)。伸ばした分は
  横髪に隠れる帯なので、隠れる面積が増えただけだった。
* **法線を頭の球へ寄せ忘れた** ―― 本体には掛けてあるので、耳だけ素の
  スムーズシェーディングだと下半分が鋭いハイライトの三角形に光り、
  「ヒレ」に見えた。
* **細い段が頭を突き抜けて継ぎ目の線になった**。板は一段につきxを1つ
  しか持てないが、頭は前後に丸い。前後に細くなる段(上端と耳たぶ)は
  同じxだと表面から出てしまう。**細い段ほど深く埋める**。

### 結果

```
肌 IoU 0.804(到達率 97%)  ← これまでで最良
髪 IoU 0.814(95%、材質ID基準)
肌材質へ焼かれた髪色 170px  ok
耳 0°70% / 45°57% / 90°54%、頬と耳穴の明度差 0.39
三角形 21,228(+504)、判定 PASS、tests 513 passed
```

## 耳輪を形として作る

融合から外したので、**耳輪の隆起を実際にモデリングできる**ようになった。
`C.loft` の断面は楕円で、必ず中央が厚く縁が薄い**レンズ**にしかならない
から、縁が隆起して中央が窪む耳の断面は作れない。断面の点を呼び出し側が
置ける `C.section_loft` を足して解いた。

起伏は `_ear_relief(off)` ―― 中心からの正規化距離で、耳輪の峰(off≈0.70)
を +3.6mm、耳甲介を +1.2mm、縁は -1.6mm(頭へ潜り込ませる)。

### ここでも3回外した

* **起伏を内側へ彫った** ―― 窪みの底が頭の表面より内側になり、頭に
  飲み込まれて耳輪の稜線2本だけが細く覗く「切れ込み」に見えた。
* **段ごとに1つのxしか持たせなかった** ―― 板は前後にまっすぐなのに頭は
  丸いので、耳の中央だけ頭とほぼ同じ高さになって同じ症状が出た。
  **耳を頭の曲面に沿わせ、起伏はその上に乗せる**のが正解。
* **耳たぶをベタ色で上書きした** ―― 耳の下半分から耳輪・耳甲介の段が
  丸ごと消え、明るい三角形の板に見えた。色味を足すだけにする。

### 基準を評価の言葉どおりに締めた

見た目を目で見て直そうとして何度も外したので、**基準のほうを疑った**。
外部評価の受け入れ条件は「側面で耳の60〜80%が読める」なのに、実装した
assertは 0.50〜0.90 に緩めてあった。実測55%は「耳」ではなく「縦の
切れ込み」に見える状態だったのに、それを通していた。

締めたら、`lock_front` が耳の上を通っていることが原因だと分かった。
方位角を 92/96 → 101/105 へ回して耳の**後ろ**を通し、65%になった。

### 結果

```
肌 IoU 0.797(到達率 97%) / 髪 IoU 0.816(95%)
肌材質へ焼かれた髪色 124px、顔の最大幅 +1.0mm
耳 0°70% / 45°64% / 90°65%(受け入れ 60〜80%)
頬と耳穴の明度差 0.39、三角形 21,612、判定 PASS、tests 513 passed
```

## 残件

* 45°での耳の上部被覆は 0%。条件は満たすが「自然に覆う」なら
  10〜30% 見えるほうがよい。
* 後頭部毛束の板っぽい面と `bk_nape` のV字ファセット。
