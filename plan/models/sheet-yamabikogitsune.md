# やまびこぎつね

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第六地方(こだまの尾根)。

1. **三語コンセプト**: 響いて返る声・気づかせてしまう・尾根じゅうに
2. **シルエットの記号**: 既存の岩(`yamabikogitsune_rock`素材)。丸い
   体表面に唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: きつね型、尾が大きく響きを表す
4. **パレット**: 基色=岩の灰 `(0.54, 0.53, 0.51)` / 従色=土の茶
   `(0.60, 0.48, 0.34)` / 差し色=喉の山吹 `(0.95, 0.75, 0.35)`
5. **設定の見せ場**: design/characters.mdの「響いて返ってくる声その
   もの。プレイヤーを見つけた瞬間、その声が尾根中に響き渡り、他の
   モンスターにまで気づかせてしまう」設定を、岩に響く喉の色で表す
