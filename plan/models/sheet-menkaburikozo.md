# めんかぶりこぞう

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第七地方(わすれられた祭りの跡)。

1. **三語コンセプト**: 出し物の陰・悪戯・不意打ちで混乱
2. **シルエットの記号**: 既存の面(`menkaburikozo_mask`素材)。丸い
   輪郭に唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 小柄な人型、1.5頭身程度
4. **パレット**: 基色=布の焦茶 `(0.30, 0.26, 0.24)` / 従色=面の朱
   `(0.62, 0.24, 0.22)` / 差し色=面の金 `(0.68, 0.56, 0.28)`
5. **設定の見せ場**: design/characters.mdの「出し物の陰に潜む悪戯。
   隣接するまで気配を消し、不意打ちが決まると相手を混乱させる」設定を、
   顔を隠す面そのもので表す
