# なみだぐま

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。配合限定(しずくうお×うるみぐま)。

1. **三語コンセプト**: こらえた涙・底力・力強い熊
2. **シルエットの記号**: うるみぐまが抱えていた古い石(plan/models/
   sheet-urumiguma.md)が、こらえきれずに割れて欠片になった姿を
   新設する(`common.gem`を砕けた形で。
   plan/models/archive/silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: つぶてガエル系の関節をがっしりした熊の体格に
   作り替えた比率
4. **パレット**: 基色=毛皮の藍 `(0.22, 0.26, 0.38)` / 従色=前足の
   暗藍 `(0.13, 0.16, 0.26)` / 差し色=涙の筋(淡い水色)
5. **設定の見せ場**: design/characters.mdの「HPが減るほど攻撃力が
   上がる――こらえきれずにこぼれた涙が、そのまま底力に変わる」設定を、
   割れた石の欠片で表す
