# よせあつめ(yoseatsume)のアニメーション作り直し

## 経緯

plan/game/archive/animation-quality-guidelines.mdでパイロット5体
(garudo/purun/gajiri/honegarami/tsubute)に適用したタメ・ツメ・二次揺れの
規約を、gajiriと同じ骨格ファミリー(`chest`-`hip`-`neck`-`snout`、
`hip`-`tail1`-`tail2`-`tail3`、`neck`-`ear.L/R`、`chest`-`hipF.L/R`-
`footF.L/R`、`hip`-`hipB.L/R`-`footB.L/R`)を使うこの種族にも適用する。

## 現状

`build_yoseatsume()`はgajiriと全く同じ関節構成を全体およそ0.62倍に
縮小し、甲羅などの追加パーツは持たせず、第一〜第七地方の配色を角度で
不揃いに継ぎ接ぎしただけの、複数体まとめて出現する`swarm`前提の
簡略シルエット。`ai: "swarm"`、`swarmSize: [3, 4]`。

`yoseatsume_animations()`は5クリップだが、**gajiriの打ち直し前の
構成のまま据え置かれている**(gajiriだけがパイロットとして先に
打ち直され、同じ骨格を使うこの種族には規約が展開されていない)。

- **idle**(4キー): `t1`(`hip-tail1`)と`neck`(`chest-neck`)が同じ
  frameで同時に動く。gajiriの打ち直しで入った「尻尾が首より3フレーム
  遅れる」二次揺れ・`partial`が未反映。
- **walk**(5キー): gajiriの数値をそのまま流用した5キー構成。
- **attack**(4キー): `interp: LINEAR`指定が無い。
- **hit**(3キー): `interp: LINEAR`指定が無い。
- **die**(2段、3キー): frame1(neutral)→frame9→frame24の2段構成で、
  gajiriの打ち直し後にある「接地後の小さな跳ね返り」に相当する4キー目
  が無い。

## 打ち直しの方針

同じ骨格を使うgajiriの打ち直し内容(`plan/models/archive/`で実装済み)を、
0.62倍サイズ・`swarm`という群れ前提の性格に合わせて移植する。

- **idle**: gajiriと同じ「尻尾(`t1`)が首(`neck`)より3フレーム遅れる」
  二次揺れをそのまま移植する。`(1, {neck:(0,0,0), t1:(0,0,0)})` →
  `(14, {neck:(-4,0,0), snout:(5,0,0)})` → `(17, {t1:(0,0,16)},
  {"partial": True})` → `(28, {neck:(0,0,0)})` → `(31, {t1:(0,0,-16)},
  {"partial": True})` → `(45, {t1:(0,0,0)}, {"partial": True})`。
  gajiriと全く同じフレーム数値で問題ない(小さな個体だが、群れの中で
  複数体が同期しすぎないよう、実装時に個体ごとの位相ずらしを検討しても
  良い)。
- **walk**: gajiriの5キー構成(交互の4足パターン)をそのまま踏襲する。
  ただし0.62倍のミニチュアで`swarm`らしい機敏さを出すため、フレーム
  間隔をgajiriのおよそ8割(1→5→9→13→17程度)に詰めることを検討する。
- **attack**: gajiriのタメ→ツメ(LINEAR)→行き過ぎ→戻りの4段
  (`(1, neutral)` → `(4, {neck:(22,0,0), snout:(14,0,0), t2:(0,0,20)},
  {"interp": "LINEAR"})` → `(7, {neck:(-34,0,0), ...})` →
  `(9, {neck:(-26,0,0), ...})` → `(18, neutral)`)をそのまま移植する。
- **hit**: gajiriと同じ`{"interp": "LINEAR"}`をframe1に追加し、振幅
  (`neck:(26,0,0)`, `t1:(0,0,24)`, `snout:(12,0,0)`)もそのまま踏襲する
  (`swarm`AIに専用の振幅補正指定は無いためgajiri基準でよい)。
- **die**: gajiriの4キー構成(`(1, neutral, {"interp": "LINEAR"})` →
  `(7, ...)` → `(20, ...)` → `(24, ...)` という、20で大きく倒れてから
  24でわずかに戻す跳ね返り)をそのまま移植する。現行の2段(9, 24)構成は
  廃止する。
- **walk-dip**: `chest: (0, -0.0124, 0.130)`→`hip: (0, 0.093, 0.124)`
  はy方向の変化(0.105)がz方向の変化(0.006)より大きく支配的な、
  ほぼ水平な骨のため、gajiriと同じ理由(胴の骨のローカルY軸が前後方向を
  向いており、素直な沈み込み表現にならない)でfootfall dipは提案しない。

## 対象外

- 骨格・造形そのものの変更(既存の.glbジオメトリはそのまま)
- 新規クリップの追加(5クリップ構成は変えない)
- 「群れの中に複数種族の性質が混在する」実装(既存の注記どおり対象外の
  まま)

## 未決事項

- walkのフレーム間隔をgajiriよりどの程度詰めるか(群れらしい機敏さと
  4体同時表示時の視認性のバランスは実機で確認する)
