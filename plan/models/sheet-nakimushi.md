# なきむし

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第五地方(なみだの滝つぼ)。

1. **三語コンセプト**: 泣きやまない・小さな夢・声が大きくなる
2. **シルエットの記号**: 頬に固まってこびりついた、角のある小さな
   涙の結晶を新設する(`common.gem`。plan/models/archive/
   silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: 小さな夢の姿、1頭身弱
4. **パレット**: 基色=肌の藍 `(0.24, 0.28, 0.42)` / 従色=口の暗色
   `(0.10, 0.08, 0.14)` / 差し色=涙の結晶(淡い水色)
5. **設定の見せ場**: design/characters.mdの「泣きやまない小さな夢。
   群れで現れ、仲間が倒されるたびに、残ったものの声がいっそう大きく
   なる」設定を、乾いて固まった涙の結晶で表す
