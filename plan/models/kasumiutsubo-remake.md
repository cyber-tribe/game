# かすみウツボを設定画に合わせてリメイクする

## 経緯

設定画ベースのリメイク14体目。かすみウツボ(`species.ts`の
`kasumiutsubo`、配合限定=モヤウツボ+ワスレガニ、回避率つき)の
設定画が提供された。同様に**承認済みの2Dコンセプト+三面図**として
扱う(`turnaround-drawing-craft.md`「5. 正直な逃げ道」)。設定画は
`plan/models/reference-kasumiutsubo-sheet.png`として保存した。

## 設定画の読み取り(実物を目視)

- **概念**: モヤウツボにワスレガニを繰り返し夢あわせて育つ姿。
  「忘れる」というテーマをさらに煮詰めた結果、**存在感そのものが
  薄れ**、攻撃をかすめて避けやすくなる(ゲームの
  `evadeChance: 0.15`と一致)。捕えようとしても指先からすり抜ける。
- **体形**: モヤウツボに形は似た、**手足の無い蛇体**。ただし
  実体がさらに希薄で、体は霧と水が混ざった半透明の質感。輪郭は
  常に揺らぎ、**尾の先は霧に消えることもある**。地面や水面に
  触れると境界がさらに曖昧になる。
- **顔**: 開いた顎に細かい牙の列。ただしモヤウツボより線が細く、
  凶暴さより「かすかな影」の頼りなさが勝つ。目は小さく暗い。
- **パレット8色**: 霧(メイン/濃/薄)/内部の濁り/水泡・反射/
  深み(影)/目・口の周辺(暗色)/地面の影。
- **状態**: 通常(漂う)/気配を薄める(潜む)/かすめる(回避中)/
  警戒(身構える)/水弾を放つ(牽制)/逃走開始(深みへ)/
  深みへ沈む(消失)/姿を消した後の気配/混乱(執着される)/
  疲弊(息を潜める)。
- **攻撃**: ①距離を取る ②水弾を放つ(牽制) ③かすめて回避
  ④深みへ逃走。
- **配合親の読み取り**: 形はモヤウツボ(蛇体・牙)を継ぎ、
  ワスレガニの寄与は殻などの部品ではなく「忘れられて存在が
  薄れる」性質(=さらに淡い色・崩れやすい輪郭・回避)として
  表れている。設定画に甲殻の欠片は無い。

## 現行モデルとの差分(実測)

`build_kasumiutsubo()`は、docstringにあるとおり「**tsubuteと
同じ関節構成**」を引き伸ばした平たく低い四足(腕・脚あり)で、
小さな目玉球、潰し球の口、背に**ワスレガニの殻の欠片の箱2枚**
(旧「硬い部品」義務の産物)、青緑系:

| 項目 | 現行 | 設定画 |
|---|---|---|
| 体形 | 平たい四足獣(腕・脚あり) | 手足の無い細い蛇体+霧水の土台 |
| 口 | 小さな潰し球 | 開く顎+細かい牙の列 |
| 目 | 小さな目玉球 | 小さな暗い目 |
| 殻の欠片 | 背に箱2枚 | 無し(親の寄与は性質で表現) |
| 体表 | 滑らかな連続メッシュ | 細かいもこもこ+水泡 |
| 配色 | 青緑系 | さらに淡い灰藤の霧3階調 |

モヤウツボのリメイク(`moyautsubo-remake.md`)と同じ問題
(四足獣への誤訳)に加え、配合親の表現が「殻の箱を貼る」という
部品の付け足しになっていた。設定画は親の寄与を**存在の薄さ**で
語っており、そちらに従う。

## 変更内容

### 1. 体をモヤウツボ系の蛇体に作り直す

- `moyautsubo-remake.md`で定める蛇体+霧の土台の構成を
  **そのまま流用**する(配合親の形の継承がそのまま実装の再利用に
  なる)。ただし本種の三面図から輪郭を実測し、以下で差別化する:
  - 体をモヤウツボより**細く、S字のうねりを強く**。
  - **尾の先を土台の外へ見せ、先端を霧(薄)色へ塗り分けて
    消す**(モヤウツボは尾を土台に隠す構成、本種は「消えかけ」を
    見せる構成)。
  - 土台は霧に**水面の波紋の縁**を混ぜる(わすれみずちの波紋の
    水皿の手法を細く添える。「霧と水が混ざった」質感の翻訳)。
- 水泡(小さな球)を2〜3個浮かせる。
- 背の殻の欠片は**削除**する。

### 2. 顔

- 顎は開閉できる分割にし、牙はモヤウツボより**小さく細かく**
  する(親子で並んだとき、迫力の差=存在感の差として読める
  ように)。口内・目の周辺は暗色。
- 目は小さな暗いパッチ(目玉球・発光は使わない)。

### 3. 配色

- 青緑系をやめ、パレット8スウォッチから直接サンプリングする。
  モヤウツボより**一段淡い**階調に寄せ、「実体がさらに希薄」を
  色の淡さで表す(現行のemission 0.04〜0.05も廃止)。

### 4. アニメーションを設定画に合わせる

- idle: 「気配を薄める(潜む)」— ほぼ動かない(現行idleの
  方向性を新骨格へ移植)。
- walk: 細い体でくねって滑る(モヤウツボより軽く、するりと)。
- attack: 素早く伸びてかすめ取るように噛み、すぐ引く
  (ambushの初撃だが、モヤウツボの重い強襲との差として
  「当て逃げ」の軽さにする)。
- hit: 体が霧のように大きく乱れてすり抜けそこねたように戻る
  (`evadeChance`の性質を被弾時の見た目でも語る)。
- die: 「深みへ沈む(消失)」— 土台へ溶け崩れ、波紋と気配だけ
  残して消える(現行dieの「霧へ紛れて消える」意匠を継承)。

### 5. 工程・検査

- 2D承認は設定画の提供をもって完了済み。3D化後に平行投影・
  黒塗りレンダーを三面図と重ねてシルエット照合する。
- 三角形数はモンスター予算(1,200〜5,000)内。

## 受け入れ基準

1. 正面・側面・背面の黒塗りシルエットが設定画の三面図と重なる
   (照合画像で確認)。
2. 四足獣ではなく「霧水の土台から立ち上がる細い蛇体」に見え、
   殻の欠片・目玉球・発光が無い。
3. モヤウツボ(リメイク後)と並べたとき、同族と分かりつつ
   「より淡い色・細い体・見えている消えかけの尾・小さな牙」で
   区別がつき、存在感の差が読める。
4. 青緑系の旧配色が残っていない。
5. エンジン内プレビューの新旧比較で、設定画のキャラクターだと
   一目で分かる。

## 対象外

- 回避・潜行・分身のゲームシステム化(既存ambush+`evadeChance`の
  まま。ゲームデザイン凍結中のため見た目のみ)
- 水弾・消失のパーティクル演出(`particles.ts`側)
- ステータス・入手方法の変更(設定画「B2F〜」と現行の配合限定の
  食い違いは、いしずえねずみ等と同じくゲーム側を正として触らない)

## 未決事項

- モヤウツボとの体格差の最終値(細さ・高さの比率。2体を並べた
  プレビューで決める)
- 波紋の縁をどの程度混ぜるか(霧が主・水は従。見え方で調整)
