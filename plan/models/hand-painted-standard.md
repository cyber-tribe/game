# 手描きテクスチャ規約 ― 「3Dになった手描きキャラクター」を全モデルの基準にする

> 実際に踏んだ失敗と、その原因・対処は `plan/models/modeling-pitfalls.md` にまとめてある。
> 新しいモデルに着手する前に一度目を通すこと。


## 経緯

ガルド品質向上の途中、ユーザーから「据置き/携帯機の全盛期にあった、
イラスト感を残した3Dキャラクター」の参照画像2枚とともに、詳細な
制作方針の指示があった(2026-09-01)。要旨: **ポリゴン数ではなく、
形状・テクスチャ・陰影をどこまで2Dデザインとして制御するかが本質**。
リアル化(高精細ノーマル+PBR+リアル照明)とは逆方向で、
Base Colorを「完成イラストの色塗り」として描き込む。

本書はこの指示を、ガルドだけでなく**全モデル共通の制作規約**として
明文化する。`archive/anime-look-art-direction.md`の
「色面はフラットにする(焼き込み陰影・ノイズ禁止)」の節は、
本書が**上書きする**(描き目・房の髪・トゥーン階調・輪郭線の節は
そのまま生きる)。フラット規定が禁じたのは「写実的なAO・素材ノイズ」
であり、本書が求めるのは「**意図して描いたイラストの陰影・描写**」。
同じ焼き込みでも文法が違う。

## 規約(重要度順)

1. **シルエット** ― 髪・服・手足を大きな塊として作る。
   ポリゴンは均等に使わず、輪郭に効く場所(前髪・顔輪郭・手・袖口・
   靴)へ寄せ、平坦な面(胸・背中・服の平面)は減らす。
2. **顔はテクスチャ主体** ― 眼球・鼻をリアルに造形しない。
   まず正面顔を2Dイラストとして成立させ、それを単純な頭部に貼る
   発想で組む(まばたき等の機構部品は最小限の薄い面パーツ)。
3. **手描きBase Color** ― 単色マテリアルを貼らない。基本色+
   グラデーション+描き込み陰影(「この面は少し暗い」)+縫い目・
   継ぎ目・擦れ・ハイライトまでを**絵として**テクスチャに描く。
   照明が変わってもキャラクター性が壊れないのはこのため。
   例(樽・樽板エプロン): 木材ベース+木目+**板ごとの微妙な色差**+
   上側を明るく/下側を暗く+**たが直下の描き込み影**+角の明るい線+
   擦れ。服なら「服を一枚のイラストとして塗る」感覚。
4. **法線の設計(custom normals)** ― 素のスムーズシェーディングは
   頬の変な影・髪のデコボコ・妙にリアルな胴を生む。「もっと大きな
   球の表面だったらどうなるか」の方向へ法線を寄せ、どこに光が
   当たるかを造形と別に設計する(顔・髪で特に有効)。
5. **輪郭線** ― Inverted Hull(実装済み)を維持。将来は部位ごとの
   太さ制御(顔は細く・足元は太く。頂点カラー等)を検討する。
6. **トゥーンシェーダは最後の20%** ― 2階調程度の抑制された
   ライティング。シェーダで魅力を作ろうとしない(形+テクスチャ+
   顔+輪郭が先)。
7. **背景も同じ思想**(将来適用) ― 石は一個ずつ絵として描く。
   キャラだけアニメ調で背景がリアル、という不一致を作らない。

## 制作工程(モデル1体の標準)

① 2D設定画 → ② 正面顔を完成イラスト品質に → ③ シルエット中心の
3Dモデル → ④ UV展開 → ⑤ 手描きBase Color → ⑥ 顔テクスチャ →
⑦ 法線調整 → ⑧ トゥーンライティング → ⑨ 輪郭線 →
⑩ ゲーム内カメラで再調整

## 実装手段(確立済みの道具との対応)

- ⑤⑥はコードでは`C.bake_albedo`のcolor_fn(3D位置ベース)で描く。
  ジオメトリを結合した硬い部品でも、UV島の割れ方に関係なく
  3D位置から一貫した絵が描ける(島はSmart UVで雑に開いてよい)。
  顔は`C.organic_uv`のboost(領域の島を拡大)で密度を確保する。
- ⑦は`C.spherize_normals`(球面へ法線を寄せる。本規約とともに追加)。
- 縁テクセルの二重塗りで線が点描に割れる問題は`bake_albedo`の
  二段塗りで解決済み(ガルドで実測)。

## 適用

- パイロット: ガルド(進行中の作り直しへ全面適用)。
- 以後の新規・再設計モデルはすべて本規約に従う。既存59体への
  遡及適用は展開計画(別途)で優先順位を決める。
