# きりみずち(kirimizuchi)のアニメーション作り直し

## 経緯

plan/game/archive/animation-quality-guidelines.mdでパイロット5体
(garudo/purun/gajiri/honegarami/tsubute)に適用したタメ・ツメ・二次揺れの
規約を、この種族(`tsubute`と同じ関節構成を流用しつつ座標だけ作り直した
骨格)にも適用する。

## 現状

`build_kirimizuchi()`は`tsubute`の関節構成(`chest`/`hip`/`head`/`armF`/
`handF`/`kneeB`/`ankleB`/`footB`)をそのまま流用しているが、座標は
ゼロから設計し直されている。特に胴の芯`chest-hip`は、`tsubute`側では
`hip`(0,0.10,0.17)・`chest`(0,-0.05,0.19)とZがほぼ同じ(差0.02)で前後
(Y、差0.15)に伸びる水平な骨なのに対し、`kirimizuchi`側は`hip`
(0,0.02,0.10)・`chest`(0,-0.03,0.34)とZの差が0.24、Yの差が0.05しかなく、
「縦に伸びて頭が前へ傾いだ」ドクストリングどおり明確に縦向きの骨になって
いる。腕(`armF`)は水を飛ばす触手として長く垂らし、頭には注ぎ口と霧の奥に
灯る弱い光の目がある。

`kirimizuchi_animations()`は`head = chest-head`・`trunk = chest-hip`・
`armL/armR = chest-armF.L/R`・`foreL/foreR = armF.L-handF.L/armF.R-handF.R`・
`legL/legR = hip-kneeB.L/R`を使い、idle 4キー(1/22/44/60)・walk 4キー
(1/8/16/24、trunkの回転のみでlocは未使用)・attack 4キー(1/5/10/20)・
hit 3キー(1/4/14)・die 3キー(1/12/26)の素朴な往復で構成されている。
`interp`・`partial`はいずれも未使用。

## 打ち直しの方針

`ranged`AI(射程4、深みタイルで+2)・HP20/def4というやや紙装甲寄りの
構成を踏まえ、動きの起点は「霧がゆっくり渦を巻く」「注ぎ口から鋭く
水弾を突き出す」の対比を強調する。

- **attack**: 現行の4段(引く→突き出す→戻る、キー無指定)を、タメ
  (1→5f、`head: (-6, 0, 0)`程度までゆっくり引く)→ツメ(5→8f、LINEARで
  `armL/armR`を`(24, 0, -9)/(24, 0, 9)`、`foreL/foreR`を`(22, 0, 0)`まで
  鋭く突き出し`head`を`(16, 0, 0)`まで振る)→行き過ぎ(8→10f、現行の
  `(22, -8)/(22, 8)`相当をわずかに超えるオーバーシュート)→戻り
  (10→20f、ゆっくり)の4段に分ける。
- **hit**: 1f→3fの入りに`interp: LINEAR`を足して鋭さを出す。振幅は
  現行の`head: (16, 0, 0)`・`trunk: (-10, 0, 0)`・`armL/armR: (-14, 0, 14)`を
  ほぼ維持しつつ(def4の中間的な防御なので極端に大小どちらへも振らない)、
  戻りを14f→16fへ少し延ばしてゆっくり戻す。
- **idle**: 「霧がゆっくり渦を巻くように、頭と触手が漂う」現行の演出を
  活かしつつ、`head`を主体として先に動かし、`armL/armR`・`foreL/foreR`
  (触手)を2〜3フレーム遅らせて追従させる(`{"partial": True}`)。頭が
  引き寄せ、触手が霧の中で遅れてなびく二次揺れになる。
- **walk**: `trunk`(`chest-hip`)はZ方向の差が0.24とY方向の差0.05より
  はっきり大きく、縦向きの骨と判定できる(`tsubute`本体は同じ関節名でも
  水平でスキップ対象だったが、`kirimizuchi`は座標が別物なので個別に
  判定する)。honegarami/garudoと同じ`hipc: {"loc": (0, -0.010, 0)}`
  形式の接地沈みを、脚(`legL`/`legR`)が接地する8f・24f付近の`trunk`
  キーに追加する。
- **die**: 初動(1f→3f程度)に`interp: LINEAR`を足して「霧の輪郭が
  最初に鋭く崩れる」感触を加える。現行の最終キー(26f)の後に、着地後の
  小さな跳ね返り(scaleや`head`のわずかな戻り揺れ)を1回追加する。

## 対象外

- 骨格・造形そのものの変更(既存の.glbジオメトリはそのまま)
- 新規クリップの追加(5クリップ構成は変えない)
