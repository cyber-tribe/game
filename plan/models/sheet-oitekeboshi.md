# オイテケボシ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第四地方(骨積みの回廊)。

1. **三語コンセプト**: 置き去りの未練・満腹度を削る・独自の攻め方
2. **シルエットの記号**: 既存の牙(`oiteke_fang`素材)。丸い骨の
   輪郭に硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 骨の妖怪型、1頭身
4. **パレット**: 基色=骨の生成り `(0.72, 0.68, 0.60)` / 従色=灰
   `(0.42, 0.42, 0.44)` / 差し色=目の淡青 `(0.62, 0.72, 0.80)`
5. **設定の見せ場**: design/characters.mdの「置き去りにされた未練。
   HPではなく満腹度を削るという、この種族だけの特殊な攻め方」設定を、
   何かを噛みちぎるような牙で表す
