# ヌシガエルを設定画に合わせてリメイクする

## 経緯

設定画ベースのリメイク15体目にして**初の地方ボス**。ヌシガエル
(`species.ts`の`nushigaeru`、第二地方ボス、ranged AI・2フェーズ制)の
設定画が提供された。同様に**承認済みの2Dコンセプト+三面図**として
扱う(`turnaround-drawing-craft.md`「5. 正直な逃げ道」)。設定画は
`plan/models/reference-nushigaeru-sheet.png`として保存した。

## 設定画の読み取り(実物を目視)

- **概念**: ツブテガエルがこの霧深い湿地でたどり着いた、最も濃く
  重たい「遠い記憶」の姿。石つぶてを飛ばし(口を開けて放つ)、
  湿地の奥に居座る主。
- **甲羅(最大の記号)**: 長年の記憶が固まった**石つぶてが背一面に
  びっしり付き、甲羅**になっている。石は湿り気を帯び、**苔や藻が
  石の間に生える**。頭頂〜背に**古い紋様の刻まれた一回り大きな
  石板**があり、遠い記憶の証とされる。
- **体**: 半透明のぬめり肌の大きなヒキガエル。並のツブテガエルより
  一回り大きく、四肢は太く踏ん張りが強い。湿地の泥や苔が体に
  深く根付いている。のど袋は低く構える程度。
- **顔**: **琥珀の虹彩+瞳の大きな目**。濁ったように深く、光を
  **鈍く**反射する(発光ではない)。への字の大きな口は投擲時に
  開く。
- **パレット10色**: 体(メイン/影部)/お腹/石つぶて(メイン/影)/
  苔・藻/目(虹彩)/目(白目)/口内/地面の影。
- **状態**: 通常(待機)/威圧(睨む)/怒り(目を細める)/警戒
  (頭を上げる)/呼吸を整える/攻撃予備(低く構える)/石つぶて投擲
  (口を開く)/踏みつけ直後(ため息)/被弾(苦痛)/瀕死(体を沈める)。
- **攻撃**: ①石つぶて投擲(単発) ②連続投擲 ③踏みつけ(近接)
  ④後退からの再投擲。霧や水面に隠れて視線を切る(ゲームの
  `hidesInQuagmire`・2フェーズ制と一致)。

## 現行モデルとの差分(実測)

`build_nushigaeru()`は、tsubute拡大+`boss-silhouette-
differentiation.md`の逸脱3項目(①片側の後ろ足だけ太い
②片寄せの巨大な喉袋 ③背の睡蓮の葉と葦)で差別化した青緑の蛙。
目は単色で発光(emission 1.4)、石は手元のgem1個:

| 項目 | 現行 | 設定画 |
|---|---|---|
| 背 | いぼ+睡蓮の葉+葦 | 石つぶての甲羅+苔+紋様の石板 |
| 目 | 発光する単色球 | 琥珀の虹彩+瞳、鈍い反射 |
| 喉袋 | 片側に寄せた巨大な袋 | 控えめ(低く構える程度) |
| 石 | 手元にgem1個 | 背の甲羅そのものが石の集積 |
| 非対称 | 後ろ足の太さ | 特筆なし(三面図はほぼ対称) |
| 配色 | 青緑系 | オリーブ茶の蛙+灰の石+苔 |

旧逸脱3項目は設定画の到着により**役目を終える**。ボスの差別化は
設定画自身が「石の甲羅と紋様」で語っており、そちらに従う
(ツブテガエル=石を投げる蛙が、生涯ぶんの石を甲羅として
まとった、という進化の物語が輪郭で読める)。

## 変更内容

### 1. 背の甲羅を「石つぶての集積」に作り直す

- 睡蓮・葦・いぼ・片寄せ喉袋を撤去し、背一面に**面取りした
  石の多面体**を大小びっしり積んでドーム状の甲羅にする。
  手法は`ishizuenezumi-remake.md`の石鎧(頂点を崩した多面体の
  積層)をボス規模に拡大して流用する。
- 石の間に**苔・藻の色面パッチ**を挟む(フラット方針)。
- 頭頂寄りに**一回り大きな暗色の石板**を置き、表面に
  **読めない古い紋様**(浅い彫りの抽象的な線。実在の文字・
  記号は使わない)を刻む。
- 石・石板は胴の骨をまたぐ硬い部品なので、
  **`mark_for_pin`+`pin_weight_to_bone`を必ず使う**(現行の
  睡蓮で既に実践済みの規律を全石に適用)。

### 2. 顔

- 発光する単色球をやめ、**白目+琥珀の虹彩+暗い瞳+小さな
  ハイライト**の目にする(emissionなし。「濁って鈍く反射」は
  虹彩の彩度を落とすことで表す)。上まぶたを重く被せ、
  「威圧(睨む)」の据わった表情を既定にする。
- 口はへの字の線を基本に、投擲時に開く顎の分割を入れる
  (口内はパレットの口内色)。

### 3. 体と配色

- 青緑系をやめ、パレット10スウォッチから直接サンプリングする
  (体=オリーブ茶、腹=生成り、石=灰2階調、苔=くすんだ緑)。
- 四肢は太く踏ん張りの利いた形に(現行の左右非対称の誇張は
  廃止し、三面図の対称なずんぐりに合わせる)。
- 接地部に泥・苔の根付きを小さな色面で添える。

### 4. アニメーションを設定画に合わせる

- idle: 「通常(待機)」— 重厚にほぼ動かず、喉が低く脈打つ。
  ときどき「警戒(頭を上げる)」の首上げ。
- walk: 重い四肢の踏みしめ(甲羅の重さを感じる低速)。
- attack: 「石つぶて投擲」— 低く構えて(タメ)口を大きく開き、
  吐き出す反動で体が揺れる(LINEARのツメ)。弾はランタイム側。
- hit: 「被弾(苦痛)」— 甲羅の石が軋むように震える(石が
  本体に追従することをGIFコマ抜きで確認)。
- die: 「瀕死(体を沈める)」— 湿地へ沈み込み、甲羅の背だけを
  残して水面下へ消える(2フェーズ制の「深みに潜む」意匠とも
  地続きの終わり方)。

### 5. 工程・検査

- 2D承認は設定画の提供をもって完了済み。3D化後に平行投影・
  黒塗りレンダーを三面図と重ねてシルエット照合する。
- 三角形数は**地方ボス予算(6,000〜16,000)**内
  (`texture-pipeline-adoption.md`基準)。石の集積に予算を
  優先配分する。

## 受け入れ基準

1. 正面・側面・背面の黒塗りシルエットが設定画の三面図と重なる
   (照合画像で確認。背面は石の甲羅のドームとして読めること)。
2. 睡蓮・葦・片寄せ喉袋・発光眼・左右非対称の誇張が無くなり、
   「石つぶての甲羅+紋様の石板+苔」がボスの記号になっている。
3. 紋様が実在の文字・記号になっていない。
4. 目が琥珀の虹彩を持つ鈍い反射の目で、睨みの表情が既定に
   なっている。
5. 甲羅の石がdie・hitの大きな姿勢変化でも本体に追従する
   (GIFコマ抜き検査で置き去りが無い)。
6. ツブテガエル(通常種)と並べたとき、同族と分かりつつ
   「石の甲羅」で主の格が一目で読める。
7. エンジン内プレビューの新旧比較で、設定画のキャラクターだと
   一目で分かる。

## 対象外

- 連続投擲・踏みつけ・霧や泥濘の環境変化のゲームシステム化
  (既存のranged+2フェーズ制のまま。ゲームデザイン凍結中の
  ため見た目のみ)
- 石つぶての飛翔・水面の演出(`particles.ts`側)
- ツブテガエル(通常種)本体のリメイク(設定画が来たら別途。
  その際は本種との親子の意匠整合を確認する)
- ステータス・出現方法の変更

## 未決事項

- 石の個数・大きさの分布(ボス予算内でシルエットが「石の
  ドーム」に読める密度をプレビューで探る)
- 紋様の石板を1枚にするか、背面にもう1枚足すか(三面図の
  背面パネルを実測して決める)
