# マドロミダケを設定画に合わせてリメイクする

## 経緯

ユーザーからマドロミダケ(`species.ts`の`madoromi`、第一地方
4階〜の眠り付与きのこ)の**設定画**が提供された。三面図(正面・
側面・背面、Aポーズ)・体の特徴・色パレット・表情/状態10種・
攻撃/行動パターンまで揃った完全な設定画であり、
`turnaround-drawing-craft.md`「5. 正直な逃げ道」(ユーザー提供の
下絵を清書・寸法源に使う)がそのまま適用できる。**この設定画を
承認済みの2Dコンセプト+三面図として扱い**、SVGでの描き起こしは
行わずに3Dリメイクへ進む。

設定画は`plan/models/reference-madoromidake-sheet.png`として
リポジトリに保存した。寸法・色・表情はすべてこの画像を出どころに
する。

## 設定画の読み取り(実物を目視)

- **体形**: 大きくやわらかい傘(体幅の1.6〜1.7倍、全高の4割強)が
  ぽってり垂れ、その下に洋梨形のずんぐりした体。体の前面下部に
  **小さな足(菌糸の塊)2つ**がのぞき、ふわっと体を支えている。
  側面図では傘の縁が前後に波打って垂れる。
- **顔**: 傘のすぐ下の体上部に、**閉じた目(下向きの弧の線)**+
  小さな開き口(口の中は暗い赤)。眠りこけた表情が既定。
  `anime-look-art-direction.md`の「描き目」文法そのもの。
- **傘の模様**: 花形(4〜5弁)のふわっとした斑が複数。夢の濃さに
  応じて変化するという設定。
- **胞子**: 淡い紫の綿毛状の胞子が体の周りにふわふわ浮遊する。
- **色**: パレット8色が明記されている(傘メイン=くすんだ紫、
  傘の模様=薄紫、胞子=淡桃紫、体メイン=生成り、体の影=灰茶、
  口の中=暗赤、ほか地面・草花は環境色)。全体に淡くやさしい
  マットな質感=フラット色面+トゥーン階調の方針と合致する。
- **状態**: 通常(眠りこけ)/うとうと/半目/きょとん/ふわふわ漂う/
  びっくり/胞子を出す/ぐっすり/悪夢化(目が赤く濁る)/しぼんでいる。
- **行動**: ゆらゆら漂う・その場で揺れる・地面に根付く・
  胞子をためる・胞子を一気に放つ。

## 現行モデルとの差分(実測)

`tools/models/monsters.py`の`build_madoromi()`:

| 項目 | 現行 | 設定画 |
|---|---|---|
| 傘の色 | ワインレッド`(0.62, 0.24, 0.42)` | くすんだ紫 |
| 傘の模様 | 白の扁平球5個(水玉) | 花形の薄紫の斑 |
| 目 | 潰した暗色球2個(楕円板の文法) | 閉じた弧の描き目 |
| 口 | 潰した球 | 小さな開き口+口内の暗赤 |
| 足 | 無し | 小さな菌糸の足2つ |
| 根元 | 木質の硬いつば(collar) | 無し(やわらかい体のみ) |
| 胞子 | 無し | 周囲に浮遊 |

現行は「楕円板の目」「プリミティブ貼り付けの水玉」という、
これまで指摘され続けた文法で作られている。設定画への追従は
そのままアニメ調方針の実地適用第1号になる。

## 変更内容

### 1. 造形を三面図に合わせる

- 傘: 現行の円錐近似(`cap_surface_z`)をやめ、縁が波打って垂れる
  ぽってりした傘に作り直す。側面図の縁の垂れを輪郭に出す。
- 体: 洋梨形。前面下部に小さな足2つ(小さな塊でよい)を足す。
- 根元の木質つば(collar)は**削除**する
  (`silhouette-hard-surface-parts.md`の「硬い部品」義務の産物だが、
  設定画にはなく、やわらかい质感の方針と矛盾する。この種の
  シルエット記号は「波打つ花模様の傘」が担う)。
- 寸法はすべて三面図パネルから読み取る(接地面〜頭頂で正規化)。

### 2. 顔を描き目で作る

- 目は閉じた下向きの弧(顔の曲面に沿う細い曲面メッシュ)。
  現行の潰した球は廃止。
- 口は小さな開き口。口内に暗赤の面を置く(設定画のパレット
  「口の中」)。
- まばたき機構は「閉じ目が既定」のため適用しない(逆に、hitの
  瞬間だけ目を開く「びっくり」を後述のアニメーションで表現する)。

### 3. 傘の模様と色

- パレット8色のうちモデルに関わる6色を、**設定画のスウォッチから
  直接サンプリング**して`make_material`のBase Colorに使う
  (参照PNGがリポジトリにあるため、目分量の再発明をしない)。
- 花形の斑は、フラット色面の方針で許される「輪郭のはっきりした
  意図的な柄」として、花形の薄い曲面メッシュを傘表面に沿わせて
  4〜6個置く(現行の水玉の置き方=中心距離に応じた高さ計算は
  流用できる)。

### 4. 胞子の浮遊

- 淡桃紫の小さな綿毛(球2〜4個の房)を2〜3個、傘の周囲に
  浮かせて配置し、idleで上下にゆっくり漂わせる。
- 攻撃演出(胞子を一気に放つ)はランタイムのパーティクル
  (`particles.ts`)の領分なので、モデル側は「ためる」姿勢が
  読める範囲に留める(演出強化は対象外)。

### 5. アニメーションを設定画の行動に合わせる

`madoromi_animations()`を状態パターンに対応づけて調整する:

- idle: 眠りこけたまま「その場で揺れる」(現行の揺れを維持しつつ
  胞子の漂いを追加)
- walk: 「ゆらゆら漂う」(現行の左右揺れを維持)
- attack: 「胞子をためる(タメ)→一気に放つ」(現行の傘振り打撃を、
  ためて膨らみ→ぽんと開放の動きに差し替える)
- hit: 「びっくり」(目を開く差し替え、または傘の跳ね上げ)
- die: **「しぼんでいる」**(傘と体が萎んで潰れる。設定画に
  そのまま終了状態が描かれている)

### 6. 工程・検査

- この設定画を承認済み三面図として扱うため、**2D承認工程は完了
  済み**。3D化後に平行投影・黒塗りレンダーを設定画の三面図と
  重ねるシルエット照合(`2d-turnaround-first-workflow.md`)を行う。
- ポリゴン予算はモンスター基準(1,200〜5,000)内。
- `five-character-redesign-gate.md`の「通常敵2体」の未定だった
  2体目を本種とする(ユーザーが設定画を提供した=選定済み。
  がじりねずみと合わせて枠が埋まる)。

## 受け入れ基準

1. 正面・側面の黒塗りシルエットが設定画の三面図と重なる
   (照合画像で確認)。
2. 色が設定画のパレットからのサンプリング値になっている。
3. 目が「潰した球」でなく閉じた弧の描き目、口内に暗赤がある。
4. 木質つばが無くなり、足2つ・浮遊胞子がある。
5. die が「しぼむ」動きになっている。
6. エンジン内プレビュー(`tools/preview/`)の新旧比較で、
   設定画のキャラクターだと一目で分かる。

## 対象外

- 悪夢化状態(目が赤く濁る・胞子の色が濃くなる)のモデルバリアント
  (ゲーム側に階層による見た目切り替えの仕組みが無いため、
  必要なら別途企画する)
- 胞子放出のパーティクル演出強化(`particles.ts`側の話)
- ステータス・出現階層などゲームデータの変更(設定画の
  「出現階層1F〜」と現行`minFloor: 4`の食い違いは本書では
  触らない。気になる場合は別途判断)
- 派生種(ほうしとび・おおまどろみ・ゆめみるぷるん)への波及
  (本種の完成を見てから個別に判断)
