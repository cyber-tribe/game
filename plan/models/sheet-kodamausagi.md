# こだまうさぎ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第六地方(こだまの尾根)。

1. **三語コンセプト**: 繰り返す木霊・響きあう・群れ
2. **シルエットの記号**: 既存の岩(`kodamausagi_rock`素材)。丸い
   体表面に唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: うさぎ型、耳が大きく響きを受け止める形
4. **パレット**: 基色=岩の灰 `(0.52, 0.50, 0.47)` / 従色=土の茶
   `(0.62, 0.50, 0.36)` / 差し色=耳の内側 `(0.66, 0.54, 0.40)`
5. **設定の見せ場**: design/characters.mdの「繰り返す木霊。1匹の声が
   響きあってこだまするように、群れで現れる」設定を、大きな耳と
   岩の質感で表す
