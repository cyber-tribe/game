# げんどう

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。村人。

1. **三語コンセプト**: 職人・木槌・手仕事
2. **シルエットの記号**: 既存の手にした木槌(`C.cylinder`+bevel)。
   丸みのある体表に硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: がっしりした体格、2頭身
4. **パレット**: `tools/models/villagers.py`の `GENDO_SKIN` /
   `GENDO_SHIRT` 等、既存定数をそのまま使用
5. **設定の見せ場**: design/characters.mdの職人としての在り方を、
   手に馴染んだ木槌に集約する
