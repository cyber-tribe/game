# とこしえのぷるん

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。配合限定(ぷるん×ぷるん)。

1. **三語コンセプト**: 揺るぎなさ・重ねた余韻・不変
2. **シルエットの記号**: 既存の輪状の硬い縁取り(`tokoshie_ring`
   素材)。ぷるん本体の結晶の芯(`common.gem`、plan/models/
   sheet-purun.md)が育って表に出た姿という位置づけにする
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: ぷるんと同じ雫形、より落ち着いた輪郭
4. **パレット**: 基色=くすんだ黄土 `(0.70, 0.60, 0.46)` / 従色=口の
   濃色 / 差し色=輪 `(0.54, 0.46, 0.34)`
5. **設定の見せ場**: design/characters.mdの「まどろみの余韻を重ねすぎた
   結果、被弾を和らげる性質が常に発動する。姿はぷるんのままだが、
   揺るぎなさだけが増していく」設定を、芯が輪となって表に出た姿で
   見せる
