# かえるこだま

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第六地方(こだまの尾根)。

1. **三語コンセプト**: 跳ね返る声・逃げ足・追い詰められて反撃
2. **シルエットの記号**: 既存の岩(`kaerukodama_rock`素材)。丸い
   体表面に唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 小さなカエル型、跳ねる姿勢
4. **パレット**: 基色=岩の灰 `(0.56, 0.55, 0.53)` / 従色=土の茶
   `(0.62, 0.50, 0.36)` / 差し色=口の暗色 `(0.20, 0.17, 0.13)`
5. **設定の見せ場**: design/characters.mdの「跳ね返る声を追いかける
   小さな生き物。気配に敏感ですぐ逃げるが、追い詰められると跳ねて
   反撃する」設定を、跳ねやすい岩がちの体で表す
