# ヌシガエル

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第二地方ボス。

1. **三語コンセプト**: 濃く重い記憶・湿地の主・大きな図体
2. **シルエットの記号**: 抱えた、角のある巨大なつぶて岩を新設する
   (`common.gem`をツブテガエルより一回り大きく。ツブテガエルの
   石つぶて(plan/models/sheet-tsubute.md)が地方ボス級に育った姿
   という位置づけ。plan/models/archive/
   silhouette-hard-surface-parts.mdの義務項目)
3. **図形と頭身**: ツブテガエルを1.4倍ほどに拡大した、どっしり
   したカエル型
4. **パレット**: 基色=皮膚の青緑 `(0.36, 0.46, 0.48)` / 従色=腹の
   淡青緑 `(0.56, 0.64, 0.62)` / 差し色=目の淡青 `(0.68, 0.86, 0.82)`
5. **設定の見せ場**: design/characters.mdの「ツブテガエルがこの霧深い
   湿地でたどり着いた、最も濃く重たい『遠い記憶』の姿。並より一回り
   大きな図体から石つぶてを飛ばし、地方の主として湿地の奥に居座る」
   設定を、巨大化したつぶて岩そのもので象徴する
