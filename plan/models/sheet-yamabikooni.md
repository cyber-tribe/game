# やまびこおに

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第六地方(こだまの尾根)。

1. **三語コンセプト**: 声の実体化・強い個体・呼び声に応じる
2. **シルエットの記号**: 既存の岩(`yamabikooni_rock`素材)。丸い
   体表面に唯一の硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: 鬼型、やまびこぎつねより大柄でがっしり
4. **パレット**: 基色=岩の灰 `(0.50, 0.48, 0.46)` / 従色=土の茶
   `(0.56, 0.44, 0.32)` / 差し色=目の橙 `(0.95, 0.65, 0.20)`
5. **設定の見せ場**: design/characters.mdの「声そのものが実体化した鬼。
   やまびこぎつねの呼び声に応じて現れる、尾根の奥にひそむ力の強い
   個体」設定を、岩を思わせる硬いがっしりした体で表す
