# はじめの夢

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。隠し最終局面。

1. **三語コンセプト**: 最初に見た夢・ひとり分の姿・すべての起点
2. **シルエットの記号**: 既存の `hajime_root` 材(根のような硬い
   支持部)。地に食い込む根の輪郭で硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: つぼみが開きかけたような、ひとり分の輪郭。他種より
   一回り大きい
4. **パレット**: 基色=起源の白 `(0.92, 0.90, 0.83)` / 従色=つぼみの
   生成り `(0.88, 0.84, 0.72)` / 差し色=根の褐色 `(0.60, 0.56, 0.46)`
5. **設定の見せ場**: design/characters.mdの「ヨリシロがこの世でいちばん
   最初に見た夢そのものが、ひとり分の姿を取ったもの」設定を、地に
   食い込む根とつぼみが開きかけた輪郭で、すべての起点であることを表す
