# ヨロイムカデ

plan/models/archive/character-design-language.mdのデザインシート
先行工程(1キャラ1枚、5項目)。第四地方(骨積みの回廊)。

1. **三語コンセプト**: 積み重なった記憶・通路をふさぐ・道具封じ
2. **シルエットの記号**: 既存の甲殻(`yoroimukade_armor`素材)。丸い
   骨の連なりに硬い面を作る
   (plan/models/archive/silhouette-hard-surface-parts.mdの義務項目を
   既に満たしている)
3. **図形と頭身**: ムカデ型、通路を塞ぐ横に長い体
4. **パレット**: 基色=骨の生成り `(0.82, 0.80, 0.72)` / 従色=甲殻の
   灰 `(0.48, 0.47, 0.44)` / 差し色=眼窩の光 `(0.85, 0.55, 0.20)`
5. **設定の見せ場**: design/characters.mdの「積み重なって固まった記憶。
   通路をふさぐように居座り、噛みつかれると道具が封じられる――
   思い出に囚われて身動きが取れなくなる感覚」設定を、通路いっぱいの
   甲殻の連なりで表す
