# 横髪を「投影ごとの殻」から「頭を回り込む1本の毛束」へ

## 経緯

外部評価の第3回(2026-09-02)。前後の髪を「なぞった毛束の輪郭」で作り直した
判断は成功(髪IoU 0.752→0.845、顔一致QA PASS)。ただし**横髪が設定画と違う**
という指摘が残っており、原因は実装方式にあるという判断。

> 正面と側面で別々に見えている形を、同じ一本の3D毛束として結び直す。
> 次の解決策は「もっと側面図を正確になぞる」ではありません。

## 何が問題か

いまは概念的に

| 設定画 | 作っているもの |
|---|---|
| 正面図 | x-z 平面の殻(`clump_shell`) |
| 背面図 | x-z 平面の殻 |
| 側面図 | y-z 平面の殻(`clump_shell(plane="yz")`) |

となっている。側面のシルエットを合わせるにはとても強い。しかし髪の毛は
「正面用の毛束・側面用の毛束・背面用の毛束」という別々の物体ではない。
**1本の毛束が 頭頂→こめかみ→耳の前→頬 と3D空間を回り込んでいる。**

いまの方式だと、側面から見ると設定画に近くても、3/4から見ると
正面毛束・側面毛束・Hair Cap・後頭部毛束が別々の面として重なり、
「髪型」ではなく**複数方向から貼った殻**に見える。

正面OK・側面OK・3/4 NG という典型的な失敗で、
`handbook/modeling-pitfalls.md` の「ウニ問題」と同じ構造
―― **指標は通っているが髪型としては違う**。

## 方式

### 1. `C.clump_volume` ―― 3Dの中心線にレンズ断面をロフトする

```
clump_volume(name, path, width, thickness, normals)
```

* `path` : 中心線の3D点(4〜6点)
* `width` : 各点の半幅。頭皮に沿う方向
* `thickness` : 各点の半厚。頭皮の法線方向
* `normals` : 各点での頭皮の外向き。**断面の向きはこれで決まる**

以前の `hair_clump`(中心線+幅)へ戻すのではない。違いは2つ。

1. **法線を外から渡す。** `hair_clump` は「横」を world の +Z から作るので、
   真下へ流れる毛束では横方向が定まらず、頭の側面を回り込む房で断面が
   ねじれる
2. **width と thickness を点ごとに変える。** 一律の厚みは
   「太いソーセージ」か「カード」のどちらかにしかならない。
   根元 薄い → 中間 厚い → 毛先 薄い にする

### 2. 意味的ランドマークで中心線を置く

側面図の黒い領域を面にするのではなく、**部位**で定義する。

```
root  = 分け目
mid1  = こめかみ
mid2  = 耳の上端
mid3  = 耳の前端
tip   = 毛先
```

方位角と高さで置く(`_scalp_point`)ので、毛束は必ず頭を回り込む。
耳の読み取り(「耳の上半分はこめかみの毛束に隠れる」)がそのまま使える。

### 3. 両方の投影を制約にする

「側面図を再現する毛束を作れ」ではなく

> この同一毛束を、正面投影すると front contour、側面投影すると
> side contour になるように3D形状を構築せよ

を解く。正面側はすでに `tools/compare_face.py` の**毛束の輪郭QA**が
測っている(なぞった輪郭にモデルの髪が出ているか)。側面側は同じ検査を
側面図に対して足す。

### 4. 横髪は1本ではない

設定画の横髪の領域(いまの `temple_L` / `flare_L` の輪郭)は、正面図で
z870 のとき x56..104 の48mm幅がある。頭皮に沿う1本の毛束の正面投影は
その高さでせいぜい20mm程度なので、**この領域は1本ではない**。
片側3本に分ける。

| 毛束 | 流れ | 役割 |
|---|---|---|
| `lock_front` | 分け目→こめかみ→耳の前→頬 | 顔にかかる横髪 |
| `lock_flare` | 分け目→こめかみ→外へ跳ねる | シルエットの最大幅 |
| `lock_back` | 分け目→耳の後ろ→襟足 | 耳の後ろ |

## 受け入れ基準

1. `plane="yz"` の側面専用の殻を**使わない**
2. 顔一致QAが PASS のまま(肌の到達率>=95% / 髪IoU>=0.80 /
   毛束の輪郭 設定画・モデルとも>=90% / ランドマーク 平均<=3.0mm 最大<=6.0mm)
3. 側面図に対する毛束の輪郭QAを足し、同じ基準を満たす
4. **3/4(45°)ビューの重なり順QA**を足す。設定画に3/4図は無いのでIoUでは
   測れない。代わりに前髪 > こめかみ毛束 > 耳 > 後頭部毛束 の
   深さ順を検査する
5. 三角形 <= 24,000
6. 見た目: 正面・45°・側面・背面の4枚を並べて確認する

## やらないこと

* 前髪・後頭部の作り直し。いまの輪郭ベースで改善しているので壊さない
* 毛束の厚みの一律調整。薄くし過ぎるとカードへ戻る
