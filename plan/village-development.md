# 村の発展

これまで拠点(ネンネ村)には施設(倉庫・ねむり小屋・ゲンドの工房・依頼板)
を並べてきたが、いずれも「最初から全部揃っている」前提だった。ここでは
**物語の進行とお金の投資に応じて村そのものが少しずつ発展していく**仕組みを
足し、拠点にも成長の手触りを作る。あわせて、これまでの文書に残っていた
未決事項をいくつかここで解消する。

## 村の発展段階

`design/story.md` の章の節目と、投資した金額の両方を条件にする
(物語を進めるだけでも、稼ぐだけでも到達できない、という二重の縛りに
して村の発展そのものをやり込み要素にする)。

### 段階1: 始まりの村(既定)
現状の実装そのまま。倉庫・モグラ婆・ゲンドの工房(基本形)のみ。

### 段階2: 依頼板が建つ(第一章クリア + ゴールド投資)
- `design/village-life.md` の**肝いりのオトネ**の依頼板(`plan/quest-board.md`)
  が正式に建つ。
- **ねむり小屋に初めて収容数の上限が設定される**(目安12体)。
  `plan/monster-fusion.md` で保留していた「ねむり小屋の収容数に上限を
  設けるか」という未決事項への回答で、初期状態は無制限ではなく、村の
  発展で広げていくものとする。

### 段階3: 工房の拡張(第二章クリア + ゴールド投資)
- `plan/equipment-forging.md` で保留していた「印を将来2つ目まで拡張するか」
  に決着をつける: **段階3以降、武器・盾は印を2つまで刻めるようになる**。
- 物知りのおキヨの図鑑小屋(`design/village-life.md`)が建ち、
  `plan/monster-compendium.md` の図鑑が村の中に物理的な置き場所を持つ。
- ねむり小屋の収容数上限が広がる(目安20体)。

### 段階4: 山を静めたあとの村(第四章クリア=物語クリア後)
- 近道屋が残していった資材(`design/story.md` の対立構造の決着)を
  使って村が改築される、という筋書きにする。
- `plan/achievements.md` の実績帳が正式な掲示板として村に建つ。
- ねむり小屋の収容数上限がさらに広がる(目安30体、実質ほぼ困らない数)。
- `plan/multiple-dungeons.md` の「④夜ごとの夢」の窓口もここに置く。

## お金の使いみち

これまでの機能で貯まった所持金(`plan/shops-and-thieves.md` の店・
`plan/quest-board.md` の依頼報酬など)の、**最終的な主な使いみち**が
村の発展になる。段階を上げるための必要金額は、直前の段階までに
自然に貯まる想定額のやや上を狙い、「依頼をいくつかこなせば届く」程度に
調整する(具体的な金額は実装時にバランス確認)。

## データ構造

```ts
export interface SaveData {
  // ...既存フィールド
  villageStage: 1 | 2 | 3 | 4; // 既定は1
}

// ねむり小屋の収容上限は段階から算出する
export function hutCapacity(stage: SaveData["villageStage"]): number {
  return { 1: 8, 2: 12, 3: 20, 4: 30 }[stage];
}
```

段階を上げる操作自体は、村で「発展させる」を選び、条件(章・金額)を
満たしていれば即座に反映する形にする。専用の建築ミニゲーム等は作らない
(`design/balance-philosophy.md` の「操作の複雑さを大きく崩さない」方針)。

## バランス上の注意

- 発展で得られるものは**容量の拡張(ねむり小屋)・育成の幅(印2つ目)・
  施設の解放**であり、攻撃力・防御力に直接効く数値は増やさない。
- 段階3の印2つ目は、`design/balance-philosophy.md` のパワーバジェット
  上限(同種効果の合算に上限を設ける方針)の対象にそのまま含める。
  2つ目の印を刻めるようになっても、効果が単純加算で青天井にならない
  ことを実装時に確認する。
