# 武器種の拡充

現状の武器は「なた」「鉄のなた」の2つだけで、どちらも**隣接1マスを殴る**
という同じ攻撃パターンのまま強さだけが違う(`src/items/catalog.ts`)。
`design/regions.md` で地方ごとに敵の性質を変えたのに合わせ、**攻撃の
パターンそのものが違う武器**を追加し、「どの武器で潜るか」がプレイの
組み立てに関わるようにする。

## 方針

- 新しい武器系統は、単純に数値が高い上位互換にしない。**範囲・間合い・
  速さのどれかを伸ばす代わりに、他の面で既存の「なた」に劣る**トレード
  オフを必ず持たせる(`design/balance-philosophy.md` のパワーバジェット
  方針)。
- 既存の `plan/equipment-forging.md`(強化値+印)は**すべての武器系統に
  共通で適用できる**仕組みのまま変えない。武器種を増やすことと、装備の
  育て方(強化・印)を増やすことは別軸にする。
- 各系統は基本形・上位形の2段階を用意し、既存の「なた/鉄のなた」と
  同じ構成(入手階層違いの2段)に揃える。

## 武器系統一覧

| 系統 | 攻撃パターン | 特徴 | 初出地方 |
|---|---|---|---|
| なた(既存) | 隣接1マス | もっとも素直な性能。基準点 | 第一地方 |
| 穂突き | 正面方向、2マス先まで直線に届く(間の敵も巻き込む) | 1マス先の攻撃力はなたよりやや低いが、間合いを保ったまま戦える。`plan/monster-compendium.md` の `guard` 系(ワスレガニ・ヨロイムカデ)のように動かない敵に有利 | 第二地方 |
| 大鉈 | 向いている方向を中心に、正面と斜め前2方向の計3マス | 1体あたりの威力はなたよりやや低いが、`plan/monster-house.md` の密集地形で真価を発揮する | 第三地方 |
| 双樽鉤 | 隣接1マス(通常と同じ)、ただし会心率+15%・そのラン最初の1手が必ず先制 | 攻撃力そのものは低め。手数と先手を活かす、`plan/monster-compendium.md` の `ambush` 系との撃ち合いに強い | 第四地方 |
| 主の大槌 | 隣接1マス、威力は最大級。ただし振るった次のターンは隙が生まれ、行動が1手遅れる | もっとも高い攻撃力。地方ボス(`plan/region-bosses.md`)級の相手にじっくり付き合う終盤向けの選択 | 第五地方 |

## データ構造

```ts
export type WeaponPattern = "single" | "line2" | "arc3" | "quickSingle" | "heavySingle";

// ItemDef(category: "weapon")に追加
attackPattern?: WeaponPattern; // 省略時は "single"(既存のなた系)
```

戦闘計算(`src/systems`)側で、`attackPattern` に応じて攻撃対象の
候補マスを変えるだけで済むようにする。`line2`・`arc3` は複数体に
同時ヒットしうるため、1体あたりの `bonus`(攻撃力)を「なた」より
控えめに設定してバランスを取る(具体的な数値は実装時に調整)。

`heavySingle`(主の大槌)の「次のターンに隙ができる」は、`Actor` に
一時的な行動遅延フラグを立てるだけで表現できる(`plan/region-bosses.md`
の予兆つき大技を実装する際の「1ターン遅延」の仕組みと共通化できる)。

## 選び方の余地

`plan/protagonist-equipment.md` の頭防具・装身具が「利便性の選択」だった
のに対し、武器種は**戦い方そのものの選択**にする。1回のダイブに持ち込む
武器は(強化・印を育てた思い入れも含めて)基本1本なので、拠点で
「今回はどの間合いで戦うか」を決める楽しさを作る。

## バランス上の注意

- `line2` `arc3` は複数ヒットする関係上、単純な合計ダメージでは
  `single` 系を上回りやすい。**1体あたりの威力を下げる**ことで
  雑魚複数戦とボス単体戦とで得意不得意が入れ替わるようにし、
  「どんな相手にも一番強い武器」を作らない。
- `heavySingle` の行動遅延は、`design/regions.md` 第五地方や
  `plan/region-bosses.md` のような一撃が重い相手には強く刺さるが、
  `plan/monster-house.md` のような多数戦では隙が命取りになる、という
  対称的な弱点にする。
