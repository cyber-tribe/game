# 最初の階をぷるんだけにする

プレイヤーから「最初のダンジョンの敵が強すぎる。最初の方の階はぷるん
だけでも良さそう」との報告があった。`design/regions.md` は第一地方
(うたたねの参道)をチュートリアルを兼ねる地方と位置づけているが、
`src/entities/species.ts` の現状では、1階目からぷるん(`minFloor: 1`)と
ガジリねずみ(`minFloor: 1`)の**2種が同時に出現**しており、初見の
プレイヤーには早すぎる可能性がある。

## 変更内容

- **1階目は、ぷるんだけが出現するようにする。** ガジリねずみの
  `minFloor` を `1` から `2` へ引き上げる。
- `plan/monster-roster-expansion-species.md` で第一地方に追加した2種
  (あくびとかげ・まぶたむし)も、1階目には出現させない
  (`minFloor: 2` 以降にする)。まだ数値・`minFloor` が未確定のため、
  この文書の方針として明記しておく。
- 2階目以降は、既存の `minFloor` の階段状の導入順(ガジリねずみ→
  ツブテガエル(3階)→マドロミダケ(4階)→スリガラス(5階)→
  ホネガラミ(6階))をそのまま維持する。この「1種類ずつ増えていく」
  設計自体は既に良く機能しているため、1階目だけを直す。

## 狙い

- 1階目は「ぷるんとだけ戦って操作に慣れる」区間にする。プレイヤーが
  最初に覚える戦闘の手触り(体当たりでの押し出し・専用攻撃キー・タルで
  捕まえる)を、1種類の敵だけでじっくり試せるようにする。
- `design/balance-philosophy.md` の「チュートリアルの体験を守る」方針
  (`plan/archive/floor-gimmicks.md` が「第一地方の1階目にはフロア
  ギミックを乗せない」としているのと同じ考え方)に、モンスター構成の面
  でも合わせる形になる。

## 対象外

- ぷるん自体のステータス調整(数値が強すぎるという報告ではなく、
  同時に出会う種類数が多いという報告のため、ぷるんの数値は変更しない)
- 2階目以降の出現バランス(変更しない)

- あくびとかげ・まぶたむしの具体的な `minFloor`
