# 第三地方(まどろみの茸林)固有ギミック: 眠りの胞子

`design/regions.md` の第三地方(まどろみの茸林・13〜18階)の固有ギミック
を実装可能な形に仕様化する。`plan/region-expansion.md` による48階への
拡張を前提とする。`plan/wetland-quagmire.md`(第二地方)と同じ位置づけの、
地方に常駐する固定ギミック。

## 内容

第三地方(13〜18階)の各フロアで、一部の部屋が**胞子部屋**になる。

- 生成時、階段の部屋・出店・モンスターハウスを除く部屋のうち約40%を
  `spored: true` にする(`plan/wetland-quagmire.md` の深みタイル付与と
  同じ除外ルールを踏襲)。
- 胞子部屋に誰か(プレイヤー・仲間・モンスターのいずれか)が居続けると、
  8ターンごとに部屋全体へ**胞子が満ちる**。そのとき部屋の中にいる
  全アクター(敵味方問わず)に、既存の状態異常付与と同じ仕組み
  (`chance`/`turns`、既存の `inflicts: { kind: "sleep", ... }` と同じ
  形)で睡眠を付与する(目安 `chance: 0.6, turns: 3`)。プレイヤー・
  モンスター・仲間のいずれも区別なく判定する(敵にも有効に働くことで、
  「敵も寝る部屋」として利用する余地を残す。既存の睡眠状態の効果
  (行動不能)がそのまま適用されるだけで、新規の効果は増やさない)。
- **ばくはつタルをその部屋で爆発させると、以後そのフロア滞在中は
  その部屋の `spored` が `false` になる**(胞子を吹き飛ばして無効化)。
  既存の `explode()` 処理(`src/game.ts`)に、爆心が属する部屋の
  `spored` を解除する1行を足すだけで実装できる。爆発そのものの
  ダメージ・巻き込み処理は変更しない。

## ねらい

`design/regions.md` に明記の通り、既存の**ばくはつタル投げ**という
アクションに新しい使いどころ(睡眠ギミックの解除)を与える。新規の
操作・UIは一切増やさない。プレイヤーは「胞子部屋を避けて通る」
「ばくはつタルを持ち込んで先に潰す」「多少眠らされる前提で押し通る」の
3通りの選び方ができるようになる。

## 生成方法・データ構造

- `Room` に `spored?: boolean` と、実行時カウンタ用の
  `sporeTimer?: number`(既定0、部屋に誰かがいるターンごとに+1、8に
  達したら胞子パルスを起こして0に戻す。誰もいないターンはカウントしない)
  を追加する。
- フロア生成(`src/dungeon/generate.ts`)の depth が13〜18のときだけ、
  対象部屋の約40%に `spored: true` を割り当てる後処理パスを追加する
  (`plan/wetland-quagmire.md` の深みタイル付与パスと同様の位置に置く)。

## 実装への影響の見積もり

- `src/core/types.ts`: `Room.spored?: boolean`・`Room.sporeTimer?: number`
  を追加。
- `src/dungeon/generate.ts`: 第三地方の深さ範囲で胞子部屋を割り当てる
  後処理パスを追加。
- `src/game.ts`:
  - ターン処理の中で、各部屋の在室者を数えて `sporeTimer` を進め、
    閾値に達したら在室アクター全員へ睡眠を判定する処理を追加
    (既存の状態異常付与ロジック・`GameEvent`(message)をそのまま流用)。
  - `explode()` に、爆心の属する部屋の `spored` を `false` にする1行を
    追加。
- `src/entities/ai.ts`: 変更不要(モンスターは胞子部屋を特別扱いせず、
  睡眠状態は既存の状態異常処理がそのまま行動を止める)。

## 未決事項

- 胞子部屋の割合(40%)・パルス間隔(8ターン)・睡眠確率(0.6)は
  実装後の体感で調整する。
- 第八地方(めざめの前庭、`design/regions.md`)でこのギミックが他地方の
  ギミックと混在する際の扱い(`spored`同士が重ならない前提で問題ないか)
  は、第八地方の固有ギミック仕様化(別の `plan/` 文書)で改めて検討する。
- ボス部屋(第三地方ボス「オオマドロミ」、`plan/archive/region-bosses.md`
  の初期案では大技そのものがこの胞子ギミックと同種の効果を持つ)との
  重複関係は、第三地方ボスの仕様化(別の `plan/` 文書)側で扱う。
