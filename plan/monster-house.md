# モンスターハウス

README の「これから」にある「モンスターハウス」を仕様化する。
`design/story.md` で先に触れた「乱掘で夢が渋滞して溜まった場所」という
理屈をそのまま採用する。

## 世界観との接続

近道屋が寝穴のあちこちに杭を打ち込み、無理やり夢を早回しで取り出している
影響で、本来ゆっくり生まれるはずの夢のかけら(モンスター)が、抜け道を
失った場所に渋滞して溜まってしまうことがある。それが一部屋に大量の
モンスターがひしめく「モンスターハウス」の正体、という設定にする。
突然大量に湧いて出る不自然さに、プレイヤーの目線でも理由がついた状態にする。

## 既存実装との相性(重要な前提)

- モンスターは生成時 `aware: false`(`src/dungeon/populate.ts` の
  `createMonster`)で置かれ、プレイヤーを視認する(`ai.ts:121` の
  `if (sees) monster.aware = true;`)まで徘徊するだけ。
- 部屋は入室した時点でおおむね全体が視界に入る前提の実装になっている
  (README「追跡AIと陣営」参照)。
- **つまり、1部屋に通常より多い数のモンスターを `aware: false` のまま
  配置するだけで、入室した瞬間ほぼ全員が同時に主人公を視認し、一斉に
  襲いかかってくる**という「モンスターハウスらしさ」は、既存のAI・視界の
  仕組みに何も手を入れずに再現できる。新規に必要なのは、**そういう部屋を
  意図的に作ること**と、**退路を塞がないこと**の2点だけに絞れる。

## 出現条件

- `Room` に `kind?: "monsterHouse"` を追加(`plan/shops-and-thieves.md` の
  `kind?: "shop"` と同じ拡張ポイントを共有する。1部屋が同時に両方を
  兼ねることはない)。
- 3階以降、フロア生成時に一定確率(深いフロアほど上昇。近道屋の乱掘が
  深部ほど激しい、という設定に合わせる)で、広さが一定以上の部屋を1つだけ
  モンスターハウスに指定する。1フロアに複数は出さない。

## 中身の生成

- 通常のフロア別モンスター数の予算(何体湧かせるか)とは別枠で、
  `speciesForDepth(depth)` から**その部屋にまとめて 5〜8体**を追加生成する
  (体数は深さに応じて増やす)。
- 全員 `aware: false` で部屋の中にランダム配置する(既存の `createMonster` /
  `findFreeTile` をそのまま使える)。
- 部屋の中央付近に、通常より豪華な**タルとアイテムのご褒美**を1〜2個
  置く(近道屋が溜め込んでいた収穫物、という説明づけにする)。これが
  リスクを取って部屋に踏み込む動機になる。

## 退路について

**入室しても通路や出口を塞がない。** 既存の「フラッドフィルで全部の床
タイルに階段から到達できることを検証」する不変条件(README参照)を
壊さない設計に徹する。プレイヤーは危険と判断すれば、モンスターが
追いついてくる前に部屋の外(通路)へ引き返す選択ができる。
「閉じ込めて全滅させる」より「気づいたら囲まれかけている、どうする」
という判断をプレイヤーに委ねる方向にする。

## 予告(警告)の手段

理不尽な奇襲にしないため、何らかの事前警告を用意する。

- 案A: モンスターハウスの部屋に隣接する通路のタイルに立つと、
  「(部屋の奥で何かがひしめいている気配)」という警告メッセージを出す
  (`FloorState.traps` の `alarm` 罠に近い仕組みを流用できる)。
- 案B: 特定のアイテム(スクロールや杖)で、次に入る部屋がモンスター
  ハウスかどうかを事前に知る手段を用意する。
- 初弾は案Aのみで十分。案Bはアイテム設計(別の `plan/` 案件)に持ち越す。

## バランス上の注意

- 5体前後を同時に相手取ることになるため、`plan/companion-orders.md` の
  「そばにいろ」構えが真価を発揮する場面として想定しておく
  (護衛AIを先に作っておくと、モンスターハウスの体感難易度が調整しやすい)。
- ばくはつタル(既存実装)がモンスターハウス相手の主力になりうる。
  密集地形での爆発が刺さるように、部屋の広さ・配置密度を調整する。

## データ構造まとめ

- `Room.kind?: "monsterHouse" | "shop"`
- フロア生成側(`src/dungeon/generate.ts` 相当)に、モンスターハウス部屋を
  1つ選ぶ抽選ロジックを追加
- `populate.ts` 側に、モンスターハウス部屋専用の一括湧かせ関数を追加
