# チェックポイント選択

`design/regions.md` で表の寝穴を5地方・全30階に広げたことで、素朴に
「毎回1階から潜り直す」ままだと、やり込むほど**前半地方の再走が作業に
なる**。これを避けるための仕組みを仕様化する。

## 方針

**一度たどり着いた、めざめの階段は「知っている場所」として記憶され、
以後のダイブでは最初からそこに直接入れる。** 加えて、めざめの階段は
「そこで区切って持ち帰る」チェックポイントとしても機能させ、**全30階を
一息に踏破しなければ何も持ち帰れない、という一本道の緊張感を、
地方単位の短い区切りに分割できる**ようにする。

## 挙動の詳細

### 1. めざめの階段に到達した時点で「既知」になる
そのダイブの結果(踏破・全滅)にかかわらず、**足を踏み入れた瞬間に**
そのめざめの階段は既知として記録される。「そこまでは安全にたどり着けた」
という事実そのものが、以後のロストを免れない知識として残る、という
世界観上の理屈にする(`design/world.md` の「知識・記録は失われない」
原則、`design/balance-philosophy.md` のリスクとリターンの節を踏襲)。

### 2. めざめの階段は「使う」とそこで区切ったダイブの成功になる
めざめの階段の上で選択できる:
- **使って戻る**: そのダイブはここで「踏破(区切り)」として成立する。
  現在の持ち物・仲間・所持金がすべて拠点に持ち帰られる
  (`design/world.md` の全滅時ロストの規則の裏返し)。以後の地方は次回
  以降のダイブで挑む。
- **使わずに先へ進む**: そのまま次の地方へ潜り続ける。ここでロスト
  対象から除外されるわけではない――以後全滅すれば、この階段を使わずに
  持ち込んでいたものは通常どおりすべて失われる。

これにより、**「全30階を一気に踏破しないと何も持ち帰れない」を廃止**し、
1地方(6階)ずつの「安全に区切って持ち帰る」プレイと、「区切らずに
深追いする」ハイリスクなプレイの両方を選べるようにする。

### 3. 次のダイブでは、既知のめざめの階段から選んで出発できる
拠点でのダンジョン選択(`plan/multiple-dungeons.md`)に、既知のめざめの
階段一覧からの出発地点選択を追加する。

- 第一地方の入口(1階)は常に選べる。
- 第二〜第五地方の入口は、対応するめざめの階段が既知になっていれば選べる。
- どこから出発しても、持ち込む道具・仲間の選び方(倉庫・ねむり小屋から
  選ぶ)は変わらない。

## データ構造

```ts
// SaveData に追加
knownCheckpoints: number[]; // 既知のめざめの階段がある階(例: [1, 6, 12])

// RunOptions に追加
startDepth?: number; // 省略時は1階(第一地方の入口)
```

`Game` 側は `startDepth` を初期 `depth` として渡すだけで済み、フロア生成
自体は各地方の出現テーブル・生成パラメータ(`design/regions.md`)を
そのまま使えるので、地方ごとに専用の初期化コードを増やす必要はない。

## バランス上の注意

- プレイヤーのレベルはダイブ開始時に常に1へ戻る(現行実装 `createPlayer`
  のまま変更しない)。深い地方から出発すると、浅い地方で稼げたはずの
  レベリングの猶予がない状態で強い敵と当たることになる。これは意図的な
  トレードオフとして残す: **深くから始めるほど、道具・仲間・装備の質で
  補う必要がある**、という上級者向けの選択肢にする
  (`design/balance-philosophy.md` のパワーバジェットの考え方と整合)。
- 「知識は失われない」原則により、めざめの階段の既知フラグ自体は
  全滅しても消えない。消えるのは、そのダイブで持ち込んでいた実体
  (道具・仲間・所持金)だけ。
- 深い地方から出発しても、その地方より浅い階のモンスター・アイテムの
  出現テーブルには影響しない(スキップした地方の内容を変える必要がない)。
