# 主人公専用の装備・アイテム拡充

`design/protagonist.md` の方針(モンスターは種族・特技・特性・進化で個性を
作り、ガルドは装備・技・レベルで個性を作る)に沿って、現状「武器・盾のみ」
の装備を広げる。既存の `plan/equipment-forging.md`(強化値・印)は
そのまま武器・盾に適用され続ける前提で、**新しい装備の置き場所**を増やす。

## 新しい装備スロット

`Inventory`(`src/items/inventory.ts`)に、`weaponUid` `shieldUid` と並べて
2枠追加する。

```ts
export interface Inventory {
  items: Item[];
  maxSize: number;
  weaponUid: number | null;
  shieldUid: number | null;
  headUid: number | null;   // 頭防具
  charmUid: number | null;  // 装身具
}
```

`ItemCategory`(`core/types.ts`)に `"head"` `"charm"` を追加し、`equip()`
の分岐を武器・盾と同じパターンで増やすだけで実装できる。

## 頭防具

武器・盾と同じ「数値で殴り合いを底上げする」枠ではなく、**耐性・視界・
捕獲率**といった、探索の質に効く方向にする(火力インフレを避ける狙い。
`design/balance-philosophy.md` のパワーバジェット方針)。

| 名前 | 効果 | 入手階層目安 |
|---|---|---|
| 樽守りの笠 | 状態異常(眠り)にかかる確率-20% | 1階〜 |
| 見晴らしのはちまき | 視界範囲+1マス | 3階〜 |
| 鉄兜 | 防御+2、ただし状態異常耐性なし(頭防具どうしの選択を作る) | 6階〜 |
| 千里眼の輪 | `plan/monster-house.md` の警告(気配メッセージ)を、部屋に入る前の通路からさらに1マス手前で察知できる | 10階〜 |

## 装身具

装身具は**利便性**に寄せ、武器・盾・頭防具のどれとも取り合いにならない
方向にする。

| 名前 | 効果 |
|---|---|
| 満たされ石 | 満腹度の減りが2割減る |
| 樽なじみの腕輪 | からのタルでモンスターを吸い込める確率が一律+10%(`design/world.md` の樽の仕組みそのものへの補正) |
| 身がわりの鈴 | 致死ダメージを1回だけHP1で耐える(1ダイブ1回)。`plan/monster-compendium.md` の「しぶとい」特技と同種の効果だが、こちらは主人公専用装備として持たせる |
| ほこら粉寄せの匂い袋 | `plan/equipment-forging.md` のほこら粉のドロップ率が上がる |

いずれか1つしか装備できないため、「今回は捕獲重視で潜るか、安全重視で
潜るか」という**ダイブごとの方針選択**の道具にする。

## 新カテゴリ「道具(tool)」

杖(繰り返し使える)・巻物(効果を発動して消える)とは別に、**1回きりの
判断を伴う専用アクション**を持つ「道具」カテゴリを新設する。

| 名前 | 効果 |
|---|---|
| 送り火の粉 | その場でダイブを打ち切り、現在の持ち物・仲間を持ったまま安全に麓へ戻る。ただしそのダイブは`plan/checkpoint-select.md`の「めざめの階段を使った」扱いにはならない(既知の階段を踏んでいない限りチェックポイントは進まない)、深追いを諦めるための保険 |
| 樽の目利き | 使うと、視界内にある未確認のタル(`caught`かどうか等)がすべて見分けられるようになる |
| 望郷の綱 | はぐれた・`plan/companion-orders.md`の「そこで待て」で離れた場所にいる仲間を、その場に強制的に呼び寄せる |

`ItemCategory` に `"tool"` を追加し、杖のような回数制ではなく**1個=1回の
消費アイテム**として扱う(食料・草と同じ枠組みを流用できる)。

## データ構造まとめ

```ts
export type ItemCategory = "herb" | "scroll" | "staff" | "food" | "weapon" | "shield" | "head" | "charm" | "tool";
```

## バランス上の注意

- 頭防具・装身具はいずれも**攻撃力・防御力を直接押し上げない**方向で
  統一する(武器・盾+強化値+印がすでにその役割を担っているため、
  `design/balance-philosophy.md` のパワーバジェットに新しい抜け道を
  作らない)。
- 「道具」カテゴリは、失敗を取り返す・安全に切り上げるための保険として
  設計しており、深追いを助長する方向の効果(即座に深い階へ進める、等)は
  持たせない。

## 未決事項

- 頭防具・装身具の新規3Dモデル制作(README記載のBlenderパイプラインを
  流用。武器・盾と同様、キャラクターへの装着表現が必要になる)
- 「送り火の粉」がチェックポイント制度(`plan/checkpoint-select.md`)と
  併存しても保険として意味を持ち続けるかは、両方実装されたあとに
  バランスを見て判断する
