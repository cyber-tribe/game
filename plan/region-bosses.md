# 地方ボス

`design/regions.md` で各地方の最終階(6階目)に置くとした地方ボスを
仕様化する。通常のモンスターの使い回しではなく、**地方ごとに1体、
手作りの多段階攻撃を持つボス**を置き、「また同じような戦闘」という
マンネリ化を地方の節目ごとに断ち切る。

## 共通仕様

- ボスは `design/balance-philosophy.md` の目安通り、その地方の雑魚最上位
  種の**HP1.8〜2.2倍・攻撃力1.3倍程度**を基準にする。
- ボス部屋には道中のような野生モンスターは湧かせない(ボス以外の変数を
  減らし、戦闘の質そのもので難易度を作る)。`plan/floor-gimmicks.md` の
  フロアギミックもボス階には乗せない(既存仕様のまま)。
- ボスは**予兆つきの大技**を最低1つ持つ。使う前の1ターン、専用の
  警告メッセージ(例:「――大きく息を吸い込んだ」)を出し、プレイヤーに
  1手だけ対応の猶予を与える。既存の `GameEvent`(`message`)の枠組みで
  実装できる、新規UIを増やさない仕組みにする。
- 撃破すると、その地方でしか手に入らない**専用の素材**(ほこら粉・
  刻印石の上位互換、または地方限定の刻印石)を確定ドロップする。
  `plan/equipment-forging.md` の経済に地方ごとの目標を作る。
- ボスは `plan/monster-fusion.md` の夢あわせ素材にはできるが、通常個体
  より遥かに重いため**夢あわせの「糧」に使うと通常の3体分の経験値換算**
  になる、という特別ルールを設ける(ボスを仲間にする体験を、単なる
  効率アイテムにしない。仲間として連れて歩く価値を持たせる)。

## 地方ごとのボス(初期案)

### 第一地方: おおねぼすけ(うたたねの参道・6階)
ぷるんが大きくなりすぎた姿。単純な単一フェーズで、突進からの叩きつけ
という分かりやすい大技を1つだけ持つ、**チュートリアル的な最初のボス**。
`design/balance-philosophy.md` の「ボス戦ごとに理不尽さの質が変わらない」
の基準そのものになる存在として、最初に置く。

### 第二地方: ヌシガエル(忘れ潮の湿地・12階)
巨大なツブテガエル。HP50%を境に2フェーズ。
- フェーズ1: 遠距離から石つぶてを連射する(既存のranged挙動の強化版)。
- フェーズ2: 水中に潜り、地方固有ギミックの「深み」タイルに姿を消して
  移動する。深みタイルにいるプレイヤーへの跳躍攻撃が予兆つきの大技。
  乾いた地面に留まれば回避しやすい、という地形読みを持ち込む。

### 第三地方: オオマドロミ(まどろみの茸林・18階)
巨大なマドロミダケ。予兆つきの大技は**部屋全体への眠りの胞子放出**。
`design/regions.md` で定義した「ばくはつタルで胞子を吹き飛ばせる」仕様が
ここでも通用し、**予兆が出た直後にばくはつタルを当てると大技そのものを
無効化できる**、というタル活用の集大成にする。

### 第四地方: ホネヅカのぬし(骨積みの回廊・24階)
無数のホネガラミが積み重なってできた巨体。防御力が高く、通常攻撃だけで
削るには時間がかかる。予兆つきの大技は**部屋全体への封じ(seal)付与**で、
発動されると一定ターン道具・杖が使えなくなる。回廊の狭さもあって
`plan/companion-orders.md` の「そこで待て」で仲間に足止めさせ、隙を作る
立ち回りが機能する場を意識して設計する。

### 第五地方: 淵の主(なみだの滝つぼ・30階)
滝つぼの底に長く沈んだ、古い悲しみが形を取った巨体。予兆つきの大技は
**奔流の呼び込み**で、発動されると部屋の広い範囲に地方固有ギミックの
「奔流」タイルが一時的に生まれ、乗っていると流される。乾いた場所を
選んで戦う、`design/regions.md` の第五地方のギミックをそのままボス戦に
持ち込んだ形。

### 第六地方: こだまの主(こだまの尾根・36階)
物音がよく響く尾根に棲み着いた、繰り返す記憶そのもの。予兆つきの大技は
**こだまの分身**で、発動されると自分と同じ姿の分身を2体呼び出す
(本体と分身はHPを共有するが、分身の攻撃力は低い)。本体を狙い続けるか、
分身ごと巻き込む範囲攻撃(`plan/protagonist-weapons.md` の大鉈系等)で
押し切るかの選択になる。

### 第七地方: 見世物のぬし(わすれられた祭りの跡・42階)
かつての賑わいの記憶が歪んでできた、祭りの呼び込みのような姿の異形。
予兆つきの大技は**見世物の入れ替わり**で、発動されると自分そっくりの
幻影が周囲に並ぶ(地方固有ギミックの「偽の階段・タル」と同じ理屈)。
本物を選んで攻撃しないと大技が発動し、外すと反撃を受ける。`plan/
monster-compendium.md` の `mimic`(擬態)AIの発想をボス戦の駆け引きに
昇華させたもの。

### 第八地方: 掘り杭の主(めざめの前庭・48階)
近道屋が打ち込んだ杭が、ヨリシロの夢と混ざり合ってできた異形。
`design/story.md` の対立構造(近道屋の乱掘)を戦闘として初めて可視化する
存在にする。予兆つきの大技は**地面からの杭の突き上げ**で、床の特定
パターン(前もって地面のひび割れで示唆される)を避けて動く必要がある。
撃破すると `plan/multiple-dungeons.md` の「③山の芯」への道が開く。

## データ構造

```ts
export interface BossTelegraph {
  message: string;
  /** 発動までの猶予ターン数。基本1 */
  warnTurns: number;
  /** 発動時の効果。既存のダメージ/状態異常付与の仕組みに乗せる */
  effect: "aoeDamage" | "aoeSleep" | "aoeSeal" | "targetedStrike";
}

export interface BossDef extends Species {
  regionId: string;
  telegraphs: BossTelegraph[];
  /** 撃破時の確定ドロップ */
  guaranteedDrop: string;
}
```

`Species` を拡張する形にし、通常モンスターと同じ枠組み(`speciesById` 等)
に載せられるようにする。予兆の管理は `Actor` に `telegraphing?: BossTelegraph`
を持たせ、AI決定時に「予兆中なら次ターンで発動」という1段だけの状態機械で
扱える(既存のターン処理を大きく作り替えずに済む)。
