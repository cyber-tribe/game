# 第五地方(なみだの滝つぼ)固有ギミック: 奔流タイル

`design/regions.md` の第五地方(なみだの滝つぼ・25〜30階)の固有ギミック
を実装可能な形に仕様化する。`plan/region-expansion.md` による48階への
拡張を前提とする。`plan/wetland-quagmire.md`(深み)・`plan/spore-
grove.md`(眠りの胞子)とは異なり、**望まない位置へ動かされる**という
空間パズル寄りの危険を導入する。

## 内容

第五地方(25〜30階)の各フロアで、床の一部が**奔流タイル**になる。

- 奔流タイルは向き(`Dir`、既存の8方向型をそのまま使う)を1つ持つ。
- **奔流タイルへ移動が確定した瞬間、その移動処理の一部として、
  向きの方向へさらに1マス強制的に押し流される。** 押し流された先も
  奔流タイルなら、さらに連鎖して押し流される(上限: 1回の移動で最大
  4マスまで。無限ループ・極端な移動を防ぐための上限)。
- 押し流された先が壁、または別のアクター(モンスター・仲間・タル)が
  いるマスの場合は、その手前で止まる(衝突ダメージ等は発生しない。
  あくまで「流された結果、止まった」というだけの処理)。
- **プレイヤー・仲間・モンスターのすべてが対象**になる(奔流タイルは
  地形の一部であり、敵味方を区別しない)。既存の移動解決処理の末尾に
  「移動先が奔流タイルなら押し流し処理を挟む」という1ステップを足す
  だけで、行動主体を問わず共通に適用できる。
- 押し流されている間もターン消費は増えない(1回の移動入力・1回の
  モンスター行動の中で完結する)。新しい入力・新しいターンの概念は
  増やさない。

## ねらい

`design/regions.md` に明記の通り、「乾いた地面を選んで進む」という
地形読みの緊張感を作る。`plan/wetland-quagmire.md`(足を止められる)
とは逆に、**望まない方向へ動かされる**という異なる種類の不利を第五地方に
割り当てることで、地方ごとの体感の違いを作る。

## 生成方法・データ構造

- `Tile` に `torrent?: Dir` を追加する(`plan/wetland-quagmire.md` の
  `quagmire?: boolean` と同じ位置づけの、地形属性フィールド)。
- フロア生成(`src/dungeon/generate.ts`)の depth が25〜30のときだけ、
  対象部屋の一部(目安20%程度)に、一定方向へ連なる奔流タイルの筋を
  生成する後処理パスを追加する(`plan/wetland-quagmire.md`・
  `plan/spore-grove.md` と同じ除外ルール: 階段の部屋・出店・
  モンスターハウスには付与しない)。
- 奔流の向きは、生成した部屋の中で意味のある方向(例: 部屋の長辺方向)
  に揃える程度の単純な規則で決める。複雑な流路パズルの自動生成は行わない
  (実装コストを抑えるため、`design/balance-philosophy.md` の
  「操作の複雑さを大きく崩さない」方針にも合わせ、あくまで軽い障害物
  として扱う)。

## 実装への影響の見積もり

- `src/core/types.ts`: `Tile.torrent?: Dir` を追加。
- `src/dungeon/generate.ts`: 第五地方の深さ範囲で奔流タイルの筋を
  割り当てる後処理パスを追加。
- `src/game.ts`(または移動解決の共通処理箇所): 移動確定後、移動先が
  奔流タイルなら押し流し処理(最大4マス連鎖、壁・アクターで停止)を
  挟む。プレイヤー・仲間・モンスターの移動処理が共通の関数を通っている
  前提でそこに1箇所追加する想定(別々の実装になっている場合は、
  共通のヘルパー関数に切り出すことを推奨)。
- `src/entities/ai.ts`: 変更不要(モンスターの移動判断自体は今まで
  通りで、結果として押し流されるだけ)。

## 未決事項

- 奔流タイルの割合(20%)・連鎖上限(4マス)は実装後の体感で調整する。
- 押し流された結果、階段や罠の上に止まった場合の扱い(通常通り効果を
  発動させてよいか)は実装時に既存の移動解決処理の順序に合わせて判断する。
- 奔流タイルの見た目は3Dモデル側の対応が必要になる可能性があり、
  本文書のスコープ外とする。
