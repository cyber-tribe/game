# はじめの夢のBGM: ハミングの追加

## 経緯・現状

はじめの夢(`trueAwakening`、3階)には専用BGM
(`public/audio/bgm/true-awakening.wav`。弦+笛、65bpm、太鼓ほぼ
無し、最深の残響)がすでにある。

一方、`design/audio-direction.md` は真の目覚めについて
**「既存曲の要素を引用しつつ、歌(ハミング程度)を1本足す。物語の
締めくくりであることを音でも示す」**と定めており、このうち
**歌(ハミング)が未実装**のまま残っている。この1点を実装可能な形に
落とす。

## 曲の狙い

「ヨリシロがいちばん最初に見た夢。誰もいない頃の記憶」。誰もいない
はずの場所に、誰かの鼻歌だけが聞こえる――ヨリシロ自身の声とも、
夢が覚えている誰かの声ともつかない、輪郭のあいまいなハミング。
歌詞・言葉は持たせない(ボイスは `design/audio-direction.md` の
未決事項のままなので、あくまで「声のような楽器」として扱う)。

## 仕様

### 合成(`tools/audio/synth.ts` に1関数追加)

`humVoice(freq, duration, sampleRate, velocity)`:

- 正弦波の基音+第2倍音0.2+第3倍音0.05程度(口を閉じた「んー」は
  倍音が少ない)。
- ゆっくり深めのビブラート(4.5Hz前後・深さ0.8%前後。笛の
  0.6%/5Hzより深くゆっくり=人の声の揺れ)。
- アタック・リリースとも長め(各、音価の25%程度)。
- ごく薄いノイズを混ぜて息の感触を出す(シード付き乱数。音量2%以下)。

### 作曲(`tools/audio/compose.ts`)

- `TrackParams` に `humLayer?: boolean`(既定false)を追加する。
- true のとき、**2小節ごとにコードの根音(中央オクターブ)を
  2小節ぶんの長さで歌う**専用レイヤーを重ねる。旋律は歌わない
  (歌い上げると「歌もの」になりすぎる。締めくくりの気配に留める)。
- 定位は中央、音量は主旋律より一段下。リバーブには他の楽器と同じ
  バスで送る(残響の中に声が溶ける)。

### 対象ファイル

`public/audio/bgm/true-awakening.wav` のみ再生成。`build.ts` の
該当エントリに `humLayer: true` を足すだけで、seed・テンポ・重み・
残響は現状のまま。他の曲には `humLayer` を付けない。

## 受け入れ基準

1. `true-awakening.wav` に、弦・笛と聴き分けられる「声のような
   持続音」が2小節周期で入っている。
2. 他の10曲の波形が変わらない。
3. `humVoice` が有限値を返すこと・決定性のテストが通る。

## 対象外

- 歌詞・言葉のあるボイス(未決事項のまま)
- 「既存曲の要素の引用」の強化(表の寝穴のモチーフ導入
  `plan/sound/bgm-main-cave.md` が入ったら、第一地方のモチーフを
  ハミングに歌わせる案があるが、それは後続の改善に回す)

## 未決事項

- ビブラート・倍音・音量の最終値(「声に聞こえるか」は聴感でしか
  決められないため、実装セッションが調整して確定する)
