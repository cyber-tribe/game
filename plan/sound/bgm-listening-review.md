# BGMの聴感評価 ― 自動テストの先にある「曲としての魅力」を確かめる

## 経緯

外部審査の指摘: BGMの技術基盤(ステレオ化・Schroeder型リバーブ・
地方ごとのテンポ・拍子・8〜16小節構成・ベースライン・コード転回・
A/B相当の変化)は8/10級で強いが、**自動生成技術としての完成度と、
最終的な「作曲作品」としての魅力は別問題**。実際に
`plan/sound/archive/bgm-quality-upgrade.md`にも「ヘッドホンでの
左右の広がり・聴感上の質の主観評価は本セッションでは実施していない
(自動テストと波形上の検証に留めている)」と明記されている。
**音楽はテストが全部通っても名曲にはならない**という指摘のとおり、
波形・デコードの検証だけでは「曲として良いか」は判定できない。

## 変更内容

### 1. 聴感評価の基準を、世界観の言葉から具体化する

`design/audio-direction.md`が掲げる基準
(「重く暗いホラーではなく、素朴で温かい、少し可笑しみのある田舎の
民話」「村の縁側で誰かが弾いているような」)を、**曲を聴いた人が
YES/NOで判定できる項目**に落とし込む:

1. 楽器の音が「電子的に正しいが人間味がない」と感じないか
   (シンセ的な質感が強すぎないか)。
2. メロディに、繰り返し聴いても飽きない**引っかかり
   (覚えやすい動機)**があるか(`compose.ts`の
   `LEITMOTIF_DEGREES`等、既存の動機がちゃんと耳に残るか)。
3. 地方ごとのテンポ・拍子(村90/第一95/第二80/第三70・3拍子/
   第七105・2拍子/第八60/ボス108)が、**数値上の違いとしてでなく、
   聴いた瞬間に「雰囲気が違う」と感じられるか**。
4. ループの継ぎ目で不自然な間・音の途切れを感じないか。
5. 「初めて聴く民謡のようで、AIが機械的に組んだようには聞こえない」
   と感じるか(この項目だけは評価者の主観に委ねてよい)。

### 2. 聴感評価のセッションを設計する

- 対象: BGM11本+SFX6本(外部審査が数え上げた本数)。
- 手順: `npm run audio`でビルドした`.wav`を、実際に**ヘッドホンで
  通しで聴く**(波形ではなく音として)。1本につき上記5項目を
  記録する。
- 記録先: `plan/sound/bgm-listening-review-findings.md`(新規、
  実施のたびに追記)。曲ごとに「合格/要修正」と、要修正の場合は
  具体的にどこが気になったか(例: 「第三地方のイントロが単調で
  30秒同じフレーズ」)を書く。
- この評価は**人間の耳で行う**(自動化しない)。実装セッションが
  自分の耳で判定してよい(基準さえあれば、機械的な波形比較より
  ずっと再現性が上がる)。

### 3. 修正の入り口を2段階に分ける

聴感評価で「要修正」になった曲は、直しやすさに応じて経路を分ける:

- **パラメータ調整で直る**(テンポ・音量バランス・リバーブ量・
  楽器の選択等、`compose.ts`/`synth.ts`の既存パラメータの範囲内):
  該当箇所を1件1PRで調整する。
- **構成そのものの見直しが要る**(動機が弱い、展開が単調等):
  個別の`bgm-*.md`仕様書を新規に立てて、その地方・場面の曲の
  構成から練り直す(既存の地方ごとのBGM仕様書と同じ粒度)。

## 受け入れ基準

1. BGM11本+SFX6本すべてについて、`bgm-listening-review-
   findings.md`に評価が記録される。
2. 「要修正」と判定された曲が、パラメータ調整/構成見直しの
   どちらに振り分けられたかが分かる。
3. 少なくとも1本は、聴感評価をきっかけに実際の修正PRへつながる
   (評価して終わりにしない)。

## 対象外

- 新規BGM・SFXの追加(既存アセットの評価と手直しに限定する)
- 生成パイプライン自体の作り直し(`audio-synthesis.md`の技術基盤は
  そのまま。パラメータ・構成の調整のみ)
