# 地方ごとに異なるコード進行の骨格を持たせる

## 経緯

`plan/sound/archive/bgm-listening-review.md`の聴感評価で、ユーザーから
「BGMは酷い。どれも同じに聴こえる」という所見を得た
(`bgm-listening-review-findings.md`参照)。

原因は`tools/audio/compose.ts`の`CHORD_SKELETON`(コード進行の骨格:
ペンタトニック上の度数列、8小節ぶん)が**全11曲で単一のパターン
`[0, 3, 4, 2, 1, 3, 4, 0]`に固定**されていたこと。音階・ボイシング・
メロディ生成アルゴリズム・曲の2部形式(前半モチーフ提示/後半変奏)も
すべて全曲共通で、地方ごとに変えていたのは楽器の重み・テンポ・拍子・
小節数・リバーブ・4音のモチーフだけだった。これらは音色・速さの違いに
とどまり、**曲を曲たらしめる和声の起伏そのものが全曲で一言一句同じ**
だったため、「どれも同じ」という結果になった。

## 変更内容

`composeTrack`(`TrackParams`)に`chordSkeleton?: readonly number[]`を
追加する(省略時は既存の`CHORD_SKELETON`のまま。既存の6曲
(shortcut/trial-chamber/mountain-core/tarukurabe/nightly-dream/
lost-and-found。今回の聴感評価の対象外)には影響しない)。

`composeTrack`内で`CHORD_SKELETON`を直接参照している3箇所
(メイン生成ループのコード度数決定・モチーフ提示区間のコード度数決定・
`quoteMotif`の断片配置)を、すべて`params.chordSkeleton ?? CHORD_SKELETON`
経由に差し替える。

`tools/audio/build.ts`の`BgmSpec`に`chordSkeleton?: readonly number[]`を
追加し、聴感評価の対象だった11曲(village・region1〜8・boss・
true-awakening)にそれぞれ異なる進行を割り当てる。値はいずれも既存の
`CHORD_SKELETON`と同じ0〜4の度数範囲(ペンタトニック上、オクターブ違いは
既存のロジックが別途処理する)。

| 曲 | 進行 | ねらい |
|---|---|---|
| village | `[0,0,3,3,4,4,0,0]` | 根音への帰着が多い、地に足のついた「おかえり」感 |
| region1 | `[0,1,2,1,0,2,3,0]` | 段階的な上下動、素直で歩き出しやすい |
| region2 | `[0,4,3,4,0,3,4,0]` | 根音に落ち着き切らない、霧の中を漂う不安定さ |
| region3 | `[4,3,2,1,0,1,2,0]` | 一方向に降りていく、まぶたが落ちる感触 |
| region4 | `[0,0,3,0,4,4,0,3]` | 同音の反復が多い、乾いた回廊の刻み |
| region5 | `[4,4,3,1,0,1,3,4]` | 高低の振れ幅が大きい、滝の情感の起伏 |
| region6 | `[0,3,0,3,4,0,4,0]` | 2音の呼びかけの反復、こだまの構造そのもの |
| region7 | `[0,4,0,2,4,0,3,0]` | 大きく跳ねる動き、囃子の弾む感じ |
| region8 | `[0,1,4,3,2,4,1,0]` | 広い音域を巡る、全地方の記憶が入り乱れる様子 |
| boss | `[0,4,3,4,0,4,3,4]` | 根音と五度相当を往復する緊張感 |
| true-awakening | `[4,2,0,1,0,2,4,0]` | 広がりを持って根音へ収束する、静かな終着 |

## 受け入れ基準

1. 11曲それぞれのコード進行が波形上で異なる(`composeTrack`に
   `chordSkeleton`を渡すと出力が変わり、省略時は既存曲と一致する)。
2. 既存の6曲(`chordSkeleton`を指定しない)は再生成しても波形が
   変わらない(無指定時は完全な後方互換)。
3. 再生成後の差分がvillage・region1〜8・boss・true-awakeningの
   11ファイルのみであること。

## 対象外

- 音階(ペンタトニック)・ボイシング・メロディ生成アルゴリズム・
  曲の2部形式そのものの変更(`bgm-listening-review.md`の対象外どおり、
  今回はコード進行の差別化のみに絞る。これらも「同じに聴こえる」
  要因である可能性は残るため、今回の変更後に再度聴感評価し、
  なお不十分なら別途検討する)
- 聴感評価の対象外だった6曲(shortcut等)への適用(必要なら別PR)
