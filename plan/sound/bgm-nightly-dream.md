# 夜ごとの夢のBGM

## 経緯・現状

夜ごとの夢(`nightlyDream`、無限)は専用BGMが無く、ダイブ中も
直前の曲(通常は村のテーマ)が流れ続ける(`src/main.ts` の
`bgmForDive` が対象外にしているため)。「潜れるだけ潜って自己ベストを
更新する」というやり込みの場に、終わりの気配のない専用曲を1本作る。

## 曲の狙い

- **果てが無い感じ**: 何十分も聴き続ける前提の曲。盛り上がりで
  煽らず、終止感を意図的に薄くして「まだ続く」を保つ。
- **夜**: 村人が寝静まったあとの挑戦。弦と笛の静かな編成で、
  太鼓は薄く。深い残響で遠さを出す。
- 集中の邪魔をしない。無限ダンジョンのBGMは「聞き流せること」自体が
  品質である。

## 仕様

`tools/audio/build.ts` の `BGM_SPECS` に1エントリ追加する。

| 項目 | 値(目安。聴感で調整可) |
|---|---|
| id | `nightly-dream` |
| ファイル | `public/audio/bgm/nightly-dream.wav`(ステレオ、22.05kHz) |
| seed | 5000(聴感で選び直してよい) |
| tempoBpm | 84 |
| beatsPerBar | 4 |
| bars | **12**(下記「終止感を薄くする」参照。約34秒) |
| weights | mallet 0.1 / drum 0.12 / flute 0.35 / string 0.5 |
| reverb | wet 0.33 / roomSize 0.55 / damping 0.25 |

### 終止感を薄くする仕掛け

- コード骨格(`CHORD_SKELETON`、8小節)はそのままに、**ループ長を
  12小節**にする。12小節目はコード骨格の4番目(下属寄りの度数)で
  ループが折り返すため、「終わって戻った」ではなく「続きの途中に
  戻った」ように聞こえる。骨格の定数は変えないので他曲に影響しない。
- 旋律の発音確率を下げて音数を間引く。`TrackParams` に
  `melodyDensity?: number`(既定1。旋律・和声の発音確率に掛ける係数)を
  追加し、この曲では0.8前後にする。静けさと「聞き流せる」余白を作る。

## 再生側の接続

`src/main.ts` の `bgmForDive` に分岐を1つ足す:
`dungeonId === "nightlyDream"` なら `"nightly-dream"` を返す。
深さ・周回数(`nightlyDreamStatMultiplier`)では曲を変えない
(無限に対して曲を増やし始めるときりがない。1本で通す)。

## 受け入れ基準

1. 夜ごとの夢に潜ると専用曲へ切り替わり、帰還で村のテーマに戻る。
2. 1曲を3ループ以上通して聴いたとき、ループの継ぎ目で「曲が終わった」
   感じがしない(受け皿は主観だが、12小節ループと折り返しコードで
   構造的に担保する)。
3. 既存曲(`melodyDensity`未指定)の波形が変わらない。

## 対象外

- 深さ・周回数によるレイヤー変化や曲の差し替え
- ヨリシロの気分レイヤーとの連動(既存仕様のまま)
