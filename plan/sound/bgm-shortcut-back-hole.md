# 近道屋の裏穴のBGM

## 経緯・現状

近道屋の裏穴(`shortcutBackHole`、5階)は専用BGMが無い。
`src/main.ts` の `bgmForDive` が表の寝穴と真の目覚め以外を対象外に
しているため、**ダイブ中も直前の曲(通常は村のテーマ)が流れ続ける**。
のどかな村の曲のまま、モンスターハウス率1.5倍の手荒な穴を潜るのは
ちぐはぐなので、専用の1曲を作る。

## 曲の狙い

「近道屋が無理やり掘った、短く手荒なダンジョン。出店が必ず出る」
(`src/entities/dungeons.ts`)。乱掘の当事者の穴であり、README/
`design/world.md` の近道屋の性格――悪人ではないが、せっかちで
商売っ気が強い――を音にする。

- **せかせかした刻み**: 速めのテンポ+裏拍の木琴で、落ち着かない
  足取り。掘りかけの穴の「仕上げの雑さ」。
- **狭く乾いた響き**: 残響は浅く。掘りたての土壁は響かない。
- 暗さ・怖さには寄せない。あくまで「胡散臭くて騒がしい」寄り。

## 仕様

`tools/audio/build.ts` の `BGM_SPECS` に1エントリ追加する。

| 項目 | 値(目安。聴感で調整可) |
|---|---|
| id | `shortcut` |
| ファイル | `public/audio/bgm/shortcut.wav`(ステレオ、22.05kHz) |
| seed | 4000(聴感で選び直してよい) |
| tempoBpm | 112(全曲中最速。ボス108より速いが軽い編成なので緊張ではなく慌ただしさになる) |
| beatsPerBar | 4 |
| bars | 8(短いダンジョンなのでループも短くてよい。約17秒) |
| weights | mallet 0.5 / drum 0.5 / flute 0.05 / string 0.2 |
| reverb | wet 0.2 / roomSize 0.35 / damping 0.3(狭く乾いた穴) |

### 裏拍の木琴(小さな拡張)

`TrackParams` に `offbeatProb?: number`(既定0)を追加し、各拍の
裏(8分裏)に確率で短い木琴(音価は拍の1/4程度、音量控えめ)を置く。
この曲では0.5前後にして「せかせか」を出す。既存曲は0のままなので
波形に影響しない。この拡張が大きいと感じるなら、初版は裏拍なしで
出してテンポと太鼓だけで性格を付け、裏拍は後続PRに回してもよい。

## 再生側の接続

`src/main.ts` の `bgmForDive` に分岐を1つ足す:
`dungeonId === "shortcutBackHole"` なら `"shortcut"` を返す
(深さでは変えない。5階通しで1曲)。

## 受け入れ基準

1. 近道屋の裏穴に潜ると村のテーマから専用曲へクロスフェードし、
   帰還すると村のテーマに戻る。
2. 表の寝穴・他ダンジョンのBGMは従来どおり。
3. `npm run audio` の再生成で `shortcut.wav` が決定的に生成される。
