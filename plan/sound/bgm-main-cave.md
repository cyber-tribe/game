# 表の寝穴のBGM: 地方ごとの固有モチーフ

## 経緯・現状

表の寝穴(`mainCave`)は8ダンジョン中で唯一、地方ごとのBGM
(`region1.wav`〜`region8.wav`+ボス階の`boss.wav`)がすでに揃っている。
`plan/sound/archive/bgm-quality-upgrade.md` の実装で、テンポ・拍子・
楽器の重み・残響の深さによる描き分けと、ベースライン・前後半の起伏も
入った。

残る弱点は**旋律が完全なランダム徘徊**であること。コード度数の周りを
シード付き乱数で揺れるだけなので、質感は地方ごとに違っても、
「この地方の歌」と口ずさめる主題が無い。曲としての記憶に残りにくい。

## 決定

**8地方それぞれに、書き下ろしの固有モチーフ(ペンタトニック上の
度数列、4〜8音)を1つずつ持たせ、旋律生成を「モチーフの提示と変奏」に
変える。**

ランダム性を捨てるのではなく、モチーフを「毎回必ず現れる背骨」として
足し、それ以外の拍は従来どおりシード付き乱数で埋める(手続き的生成+
固定の設計、というこのリポジトリの定石のまま)。

## 仕様

### 生成側(`tools/audio/`)

- `compose.ts` の `TrackParams` に `motif?: readonly number[]`
  (ペンタトニック上の度数列。コード度数からの相対値)を追加する。
- モチーフ指定時の旋律生成:
  - **各半分(前半/後半)の最初の小節**は、拍の頭からモチーフの音を
    順に鳴らす(1拍1音。モチーフが小節に収まらない分は次の小節へ
    続けてよい)。これで「ループのたびに同じ歌い出し」が保証される。
  - それ以外の拍は従来のランダム徘徊のまま。ただし揺れの中心を
    「直前に鳴らしたモチーフ音」に寄せると旋律がつながりやすい
    (実装裁量)。
  - **後半の提示は変奏にする**: 1オクターブ上げる/音価を半分にして
    2回繰り返す、のどちらかをシードで選ぶ。
- モチーフ未指定なら従来どおり(村・ボス・他ダンジョンの曲に影響なし)。

### 8地方のモチーフの性格(度数列は目安。最終値は聴感で決めてよい)

| 地方 | 性格 | 度数列の目安 |
|---|---|---|
| 第一 うたたねの参道 | 素直に上って戻る。歩き出しの歌 | `[0, 1, 2, 1]` |
| 第二 忘れ潮の湿地 | 長く伸びて半歩沈む。霧の中の遠い声 | `[2, 2, 1, -1]` |
| 第三 まどろみの茸林 | 3拍子に乗ってゆっくり降りる。まぶたが落ちる形 | `[4, 2, 0]` |
| 第四 骨積みの回廊 | 同音の連打から跳ねる。乾いた足音 | `[0, 0, 3, 0]` |
| 第五 なみだの滝つぼ | 高い所から続けて落ちる。滝の形をなぞる | `[5, 4, 2, 1]` |
| 第六 こだまの尾根 | 呼びかけ2音+同じ形の反復(こだま) | `[3, 0, 3, 0]` |
| 第七 わすれられた祭りの跡 | 囃子の掛け合い。跳ねて戻る | `[0, 2, 0, 3]` |
| 第八 めざめの前庭 | 第一のモチーフを引き延ばした形(全地方の記憶の入口が最初の記憶に戻る) | `[0, 1, 2, 1]` を2倍の音価で |

### 対象ファイル

`public/audio/bgm/region1.wav` 〜 `region8.wav`(`npm run audio` で
再生成)。`build.ts` の `BGM_SPECS` に `motif` を追記するだけで、
シード・テンポ・拍子・残響は現状のまま変えない(モチーフの効果だけを
聴き比べられるようにする)。

## 受け入れ基準

1. 同じ地方のBGMを再生し直すと、毎回同じ音列(モチーフ)で歌い出す。
2. 地方が違えばモチーフも違う(第八の意図的な引用を除く)。
3. モチーフ未指定の曲(村・ボス)は波形がビット単位で変わらない、
   または聴感上従来と同等である。
4. `composeTrack` の決定性(同シード同波形)のテストが通る。

## 対象外

- 村・ボス・真の目覚めのモチーフ(それぞれ別プランで扱うか現状維持)
- 他ダンジョン(近道屋の裏穴など)の新曲(各ダンジョンの個別プラン参照)
- テンポ・拍子・楽器重みの再調整

## 未決事項

- 各モチーフの最終的な度数列(上の表は目安。実装セッションが聴感で確定)
- 変奏のバリエーションを増やすか(反行・逆行などは今回は見送ってよい)
