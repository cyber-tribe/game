# 山の芯のBGM

## 経緯・現状

山の芯(`mountainCore`、3階)は専用BGMが無く、ダイブ中も直前の曲
(通常は村のテーマ)が流れ続ける(`src/main.ts` の `bgmForDive` が
対象外にしているため)。近道屋との決着の場が村のテーマのまま、という
のは物語上いちばんもったいない欠落なので、専用の1曲を作る。

## 曲の狙い

「ヨリシロの意識の核に近い、特別な夢。近道屋との決着の場」
(`src/entities/dungeons.ts`)。出現テーブルは第八地方
(めざめの前庭、43〜48階)の流用(`floorOffset: 42`)で、実装上も
第八地方の延長線にある。

- **第八地方から地続きの荘厳さ**: `region8.wav`(60bpm・4種均等・
  遅く荘厳)の空気を引き継ぐ。プレイヤーには「前庭のさらに奥」だと
  音でも分からせる。
- **決着の切迫**: ただし前庭より太鼓を厚くし、テンポをわずかに上げて、
  「対峙している」緊張を足す。ボス戦テーマ(108bpm)ほどは煽らない。
  3階しかない短いダンジョンなので、道中曲でありながら決戦前夜の
  性格を持つ。
- **最深の残響**: 意識の核=いちばん深い場所。残響は真の目覚めと
  並ぶ最深クラスにする。

## 仕様

`tools/audio/build.ts` の `BGM_SPECS` に1エントリ追加する。

| 項目 | 値(目安。聴感で調整可) |
|---|---|
| id | `mountain-core` |
| ファイル | `public/audio/bgm/mountain-core.wav`(ステレオ、22.05kHz) |
| seed | 8000(聴感で選び直してよい) |
| tempoBpm | 66(region8=60より少し前のめり) |
| beatsPerBar | 4 |
| bars | 8(約29秒) |
| weights | mallet 0.3 / drum 0.5 / flute 0.25 / string 0.4(4種を鳴らしつつ太鼓を厚く) |
| reverb | wet 0.38 / roomSize 0.7 / damping 0.15(真の目覚めと同格の深さ) |

新しい合成機能は不要。既存の `TrackParams` だけで作れる。

## 再生側の接続

`src/main.ts` の `bgmForDive` に分岐を1つ足す:
`dungeonId === "mountainCore"` なら `"mountain-core"` を返す。
3階通しで1曲(近道屋との決着イベント自体の演出音楽は対象外)。

## 受け入れ基準

1. 山の芯に入ると専用曲へ切り替わり、帰還で村のテーマに戻る。
2. `region8.wav` と並べて聴いたとき、同じ系統の空気でありつつ
   太鼓の厚さとテンポで「さらに奥」だと分かる。
3. 既存曲の波形が変わらない。

## 対象外

- 近道屋との決着イベント・カットシーン用の専用曲や無音演出
  (ストーリー演出側の仕様が固まってから別途)
- ボス戦テーマの差し替え
