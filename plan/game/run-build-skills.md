# レベルアップ時のスキル選択 ― そのダイブ限りのビルドを作る

## 経緯

主人公ガルドはダイブごとにLv1から始まる(現行仕様のまま)。
レベルアップの成長は「鍛え方」(`plan/game/archive/
protagonist-training.md`: balance/offense/defense の3方針を出発時に
1回選ぶ)による**数値の自動成長のみ**で、ダイブ中の意思決定が無い。

そこで、**レベルアップのたびに3択からスキルを1つ選び、そのダイブ
限りのビルドを組む**仕組みを足す。ダンジョンの状況 × 連れている仲間
× スキルビルドの組み合わせが毎回変わることで、「今回はどう攻略
するか」というローグライクの即興性を強める。

## 基本の流れ

1. レベルアップすると、その場で**スキル選択モーダル**が開く
   (3択+説明1行。選ぶまでゲームは進まない。既存のモーダル類と
   同じ入力方式でキーボード・タッチ両対応)。
2. 提示される3枠は、**攻撃・回復/仲間・タルの3系統から1つずつ**。
   系統内のどのスキルが出るかは未習得のものから抽選する
   (同系統を伸ばし続けるビルドも、広く取るビルドも組める)。
3. 選んだスキルは**そのダイブ限り**。踏破・力尽きるで消える。
   持ち越さないからこそ毎回思い切って偏らせられる。
4. 「鍛え方」による数値の自動成長は従来どおり並走する(数値は
   鍛え方、選択肢はスキル、と役割を分ける)。

## スキル系統と初期セット

**数値の強化(「攻撃+10%」等)ではなく、できることが増えるスキルを
主体にする**という方針で選ぶ。各系統6件・計18件から始める。

### 攻撃系統(自分の戦い方が変わる)

| スキル | 効果 |
|---|---|
| なぎはらい | 攻撃が正面3方向に当たるようになる |
| ふみこみ | 攻撃時、1マス踏み込んで斬る(間合いが1伸びる) |
| かちあげ | 攻撃した敵を1マス吹き飛ばす |
| がまんのかまえ | 足踏み(その場待機)した次のターン、与ダメージ2倍 |
| すてみ | 与ダメージ+50%、被ダメージ+25%(常時) |
| とどめのさき | HP1/4以下の敵への攻撃が必ず急所に当たる |

### 回復/仲間系統(パーティを維持する)

| スキル | 効果 |
|---|---|
| わけあう手 | 草を使うと隣接する仲間にも半分の効果 |
| はげましの声 | 仲間のゆめわざのクールダウン-25% |
| かばいあい | 隣接する仲間への攻撃を確率で代わりに受ける(逆も) |
| ねぎらい | 敵を倒すたび仲間全員のHPが1回復 |
| つれさりの心得 | 捕獲確率+15% |
| 目覚めのいのり | 仲間が倒れたとき、一度だけHP1で踏みとどまらせる(1ラン1回) |

### タル系統(タル・地形の攻略力)

| スキル | 効果 |
|---|---|
| ころがし | タルを投げる代わりに直線に転がせる(壁か敵に当たるまで進み、轢いた敵全員に小ダメージ) |
| かるがる | タルを抱えたままの移動でターン消費が増えない+投げ射程+2 |
| いたわり投げ | 空のタルを投げても捕獲対象を倒さず、必ずHP1で止める(plan/game/barrel-capture-clarity.mdの保険を強化する再利用スキル) |
| つぎたし | あけた元素タル(plan/game/barrel-arts.md)が1回ぶん中身を残す |
| タルやぶり | 置かれたタルを攻撃で割ると、中身の効果が破裂して広がる |
| かつぎばしり | タルを抱えている間、移動のたび低確率で敵の注意を引かない |

## バランス指針

- 1つ1つは「攻略手段が1つ増える」粒度に抑え、複合で化ける余地を
  残す(かちあげ×石タルの壁、ころがし×ねむタル 等)。
- ダイブ限りなので、多少強めでも恒久インフレしない。強すぎる
  組み合わせは通しプレイ(auto-tester)の統計で個別に調整する。
- 表示はモーダルの3択に説明1行で完結させ、図鑑的な一覧は
  記録の間に「みつけたスキル」として後日追加してよい(未決事項)。

## データ構造

```ts
// そのダイブ限りなのでセーブ(SaveData)には持たせない。
// Game(ラン状態)にのみ持つ
runSkills: RunSkillId[];
```

死亡・踏破で消えるため、セーブ互換の考慮は不要(ダイブ中断の
オートセーブ(plan/game/archive/mid-dive-autosave.md)にだけ
runSkillsを含める)。

## 受け入れ基準

1. レベルアップ時に3系統1件ずつの3択モーダルが開き、1つ選ぶまで
   進行が止まる。
2. 選んだスキルがそのダイブ中ずっと効き、ダイブ終了で消える。
3. 同じスキルは同一ダイブ中に二度提示されない。
4. 鍛え方の数値成長は従来どおり並走する。

## 対象外

- スキルの恒久解放・メタ進行(ダイブ限りを貫く)
- 敵・仲間へのスキル選択の適用(仲間はゆめわざ側が担当)
