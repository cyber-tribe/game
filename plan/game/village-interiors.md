# 村の建物の中を作り込み、村人を3Dで立たせる

## 経緯

`plan/game/archive/village-scoped-menus.md`(実装済み)で建物ごとの
役割分担はできたが、建物に入ったときの画面は**メニューのパネルが
出るだけ**で、建物の「中」は存在しない。また村人(モグラ婆・ゲンド
等)はテキストの中にしか登場せず、3Dの姿を持たない。

建物に入ったら**その建物の内装の3Dシーンに切り替わり、番人の村人が
そこに立っていて、メニューはその場面の上で開く**ようにする。
「誰の所へ何をしに行くか」が絵として伝わる村にする。

前提として、村人8人の専用モデルは `plan/models/model-*.md`
(mogurabaa / gendo / otone / okiyo / pochi / otama / fuku / ito)で
仕様化済み。本書はそれらを置く「内装」と画面遷移を扱う。

## 対象の建物と内装・住人

内装を持つのは屋内系の7件。屋外系(旅の看板・依頼板・広場・
洞窟の入口)は村マップ上の演出のみとする(後述)。

| 建物 | 住人 | 内装の要素(小道具) |
|---|---|---|
| モグラ婆の倉庫 | モグラ婆 | 壁一面の棚、積まれたタル・木箱、吊りランプ |
| ゲンドの工房 | ゲンド | 炉(暖色の光源)、金床、壁の工具掛け、作りかけのタル |
| ねむり小屋 | フク | 並んだ寝床(小さなタルが寝かされている)、天蓋の布、夜色の薄明かり |
| おキヨの図鑑小屋 | おキヨ | 本棚、標本瓶の棚、大きな机に開いた帳面 |
| 記録の間 | イト | 巻物棚、掲示された記録の紙、文机と筆 |
| 村の発展の受付 | (なし) | 村の模型が乗った台、図面の壁貼り |
| ガルドの家 | (なし) | 寝床、衣装掛け、鏡台 |

- 屋外系のうち**依頼板のそばにオトネ**、**広場にポチ**(章進行後は
  **おたま**も)を、村マップ(`src/view/village.ts` のシーン)に
  直接立たせる。屋外の村人は建物に入らなくても見える、村の
  にぎわい要素を兼ねる。

## 実装方針

### 1. 内装は「建物ごとの小さな独立シーン」

図鑑ギャラリー(`src/view/gallery.ts`)・村なか歩きと同じ流儀で、
内装ごとに小さな `THREE.Scene` を作り、`renderer.renderer` に
相乗りして描く。

- 内装のジオメトリは、村の建物と同じく**Three.jsのプリミティブの
  組み合わせでコード内に作る**(`src/view/village.ts` の
  `buildStructure` の内装版)。Blenderパイプラインは使わない
  (棚・机・タル程度の箱物にBlenderアセットは過剰。既存のタルの
  メッシュ等、流用できるものは流用してよい)。
- 村人モデルは `Assets` からロードし(`plan/models/model-*.md`)、
  `idle` クリップをループ再生して定位置に立たせる。
- カメラは固定1アングル(部屋の入口から見た斜め俯瞰)。歩き回りは
  させない(メニュー操作の背景としての内装なので、自由移動を
  作り込むコストは掛けない)。

### 2. 画面遷移とメニューの重ね方

1. 村なか歩きで建物に入る(既存の確定操作)
2. 内装シーンに切り替わり、村人が `talk` クリップで一拍応える
3. その建物の役割メニュー(`village-scoped-menus.md` のスコープ付き
   `TownScreen`)が、**画面の片側(左右どちらか)に寄せたパネル**で
   開く。反対側に内装と村人が見え続けるレイアウトにする
4. メニューを閉じる(Escape/もどる)と村なか歩きへ戻る

- 現在の「ダンジョンの上に半透明パネル」よりも情報量が増えるため、
  スマホでの列幅・重なりは `plan/game/archive/mobile-layout-redesign.md`
  のゾーンの考え方に従って確認する。
- 村人には吹き出し風の一言(既存の`design/flavor-details.md`の
  せりふプールから、その村人に合うもの)を表示してよい(任意)。

### 3. 屋外の村人

- `src/view/village.ts` の村マップに、オトネ(依頼板の横)・ポチ
  (広場)・おたま(広場、第二章の救出後のみ)を配置し、`idle` を
  ループ再生する。
- 近づいたときのヒント表示(既存の建物ヒント)に村人名を出す
  (例:「決定ボタン: オトネの依頼板へ」は現状のままでよい)。

## 受け入れ基準

1. 屋内系7件の建物に入ると、それぞれ異なる内装が表示され、
   住人のいる建物では村人モデルが待機モーションで立っている。
2. メニューは内装を隠しきらず、操作(列の巡回・選択・閉じる)は
   従来どおり機能する(キーボード・タッチとも)。
3. 村なか歩きで依頼板のそばにオトネ、広場にポチが見える。
   第二章クリア後は広場におたまも現れる。
4. 内装の追加でロード時間・描画負荷が体感で悪化しない(内装は
   プリミティブ中心、村人モデルは既存モデルと同規模のため
   問題にならない想定)。

## 対象外

- 内装の中の自由移動(歩き回り)
- 村人との会話システムの拡張(既存の「NPCと話す」の仕組みのまま。
  絆システム自体は `design/village-life.md` の別スコープ)
- 屋外マップの地形拡張
