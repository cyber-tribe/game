# 二次揺れの遅延フレーム数を、部位の長さから機械的に決める

## 経緯

`ps2-quality-adversarial-review.md` 中程度6の指摘: `add_action()` の
部分キー打ち(`archive/animation-quality-guidelines.md` で実装済み)を
使った二次揺れは、遅延フレーム数がモデルごとに個別の目分量で
決まっている(ガルド・ホネガラミの頭は2フレーム遅れ、ガジリの尻尾は
3フレーム遅れ、ツブテの腕は2フレーム遅れ)。**全キャラ共通の規律として
式や表になっておらず、新規キャラ・改修のたびに人が目分量で決め直す
手間が発生している。**

## 修正方針

`tools/models/common.py` に、部位の長さから遅延フレーム数を
機械的に返す関数を新設する:

```python
def secondary_delay_frames(length_ratio: float) -> int:
    """
    二次揺れの遅延フレーム数を、部位の長さの比から機械的に決める。

    length_ratio: 対象パーツ(尻尾・耳・房紐・帯など)の長さを、
    胴の基準長(root〜chest、または該当モデルの主要な1ボーン長)で
    割った比。長く垂れたものほど遅れて追従する、という実際の物理の
    近似(単振り子の周期は長さの平方根に比例する、を簡略化した目安)。

    - 0.15未満(耳・短い房・小さな突起): 2フレーム
    - 0.15以上0.35未満(標準的な尻尾・帯・房紐): 3フレーム
    - 0.35以上(長い尻尾・垂れ幕・長い帯): 4フレーム

    上限は4フレームに留める(それ以上遅らせると本体の動きから
    浮いて見える。既存のパイロット5体の実測値2〜3フレームとも整合する)。
    """
```

- 既存パイロット5体(ガルド・ぷるん・ガジリ・ホネガラミ・ツブテ)の
  遅延値をこの関数で計算し直し、**現行の目分量値と一致するかを
  検証する**(一致しない場合は、既存値を正としてしきい値を
  再調整する。実測を無視した机上の式にしない)。
- 以後の新規キャラ・改修キャラは、この関数の戻り値をそのまま
  `add_action()` の部分キーのフレームオフセットに使う。目分量での
  決め打ちを禁止するわけではないが、既定の手順として先にこの関数を
  通す。
- 対象は「胴から生えて先端が自由に動く付属肢」全般(尻尾・耳・
  房紐・帯・触手・角の飾り等)。腕・脚のような主要な可動部位
  (遅延ではなく別の役割の関節)は対象外。

## 質量感(硬さ)による調整

長さだけでなく、`silhouette-hard-surface-parts.md` で導入する
硬い部品(装甲・角等)は揺れないほうが自然(硬いものは遅延0)。
`secondary_delay_frames()` は**布・毛・紐のような柔らかい付属肢**に
限定して使い、硬い部品には適用しない、という区別を明記する。

## 受け入れ基準

1. `secondary_delay_frames()` が既存パイロット5体の実測遅延値
   (2〜3フレーム)と矛盾しない結果を返す。
2. 以後の新規モデルスクリプトが、二次揺れの遅延フレーム数を
   目分量ではなくこの関数から得ている(モデルスクリプトのコード上で
   確認できる)。
3. `npm run test`・`tools/compare_models.mjs` がgreenのまま
   (既存パイロット5体の出力を変えない場合。しきい値調整の結果
   既存値を変える場合は、変更後の値でエンジン内プレビューを
   再確認する)。

## 対象外

- パイロット5体以外への遡及適用(次にそのキャラを触るPRで
  この関数を使えばよく、今回のための一斉打ち直しはしない)
- 腕・脚など主要な可動関節のタイミング設計(対象は付属肢の二次揺れのみ)

## 未決事項

- しきい値(0.15/0.35)の具体値は既存パイロット5体の実測との
  突き合わせで調整する余地がある
- 質量感(布か毛か紐か)によって同じ長さでも遅延を変えるべきかは、
  今回は見送り長さのみで決める(必要になれば別途拡張する)
