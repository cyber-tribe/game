# 第四地方(骨積みの回廊)固有ギミック: 狭い回廊とモンスターハウス多発

`design/regions.md` の第四地方(骨積みの回廊・19〜24階)の固有ギミックを
実装可能な形に仕様化する。`plan/region-expansion.md` による48階への
拡張を前提とする。

第二・第三地方(`plan/wetland-quagmire.md`・`plan/spore-grove.md`)と
違い、**新しいタイル種別・状態は一切増やさない**。既存の生成パラメータの
値を、この地方の深さ範囲だけ変える、という最小のギミックにする
(`design/regions.md` 自身が「既存仕様のまま」と明記している通り)。

## 内容

### 1. 通路が1マス幅になる区間が多い

現行の地形生成(`src/dungeon/generate.ts`)は、区画割り→全域木→
フラッドフィルという共通アルゴリズムで通路を作っており、通路幅の
パラメータは既に存在する想定(2×3〜3×3の区画割りに対して通路を
つなぐ処理)。19〜24階の間だけ、通路生成時に**幅を広げる分岐を
スキップする(常に1マス幅で確定させる)**ことで、「狭く入り組んだ
回廊」を表現する。新しいアルゴリズムは不要で、既存の通路幅決定処理に
depth範囲チェックを1つ足すだけで実装できる想定。

### 2. モンスターハウス出現率をこの地方だけ通常より高くする

`src/dungeon/generate.ts` の `generateFloor` は既に
`monsterHouseChanceMultiplier`(既定1)を受け取れる(`plan/multiple-
dungeons.md` で「近道屋の裏穴」向けに導入済みの仕組み)。表の寝穴
(`MAIN_CAVE_ID`)であっても、depthが19〜24のときは `enterFloor`
(`src/game.ts`)からこの乗数を1.5程度で渡すだけで実現できる。
新しいパラメータ・新しいコード分岐は不要で、既存の仕組みの呼び出し方を
1箇所変えるだけ。

## ねらい

`README.md`・`design/story.md` に既にある「深いフロアほど乱掘が激しい」
という世界観の記述と一致させる、**通路の狭さ×モンスターハウスの多さ**の
組み合わせによる圧迫感。新規の操作・UI・状態は増やさない
(`design/balance-philosophy.md` の「操作の複雑さを大きく崩さない」に
最も忠実な地方ギミックになる)。

## 実装への影響の見積もり

- `src/dungeon/generate.ts`: 通路幅決定処理に「depth 19〜24なら常に
  1マス幅」の分岐を追加。
- `src/game.ts`: `enterFloor` の生成オプション組み立てで、
  `MAIN_CAVE_ID` かつ depth 19〜24 のとき `monsterHouseChanceMultiplier:
  1.5` を渡す(`plan/region-expansion.md` で導入する地方境界の判定と
  同じ考え方を流用)。

## 未決事項

- モンスターハウス出現率の乗数(1.5)の具体値は実装後の体感で調整する。
- 通路幅を完全固定(常に1マス)にするか、確率で狭い区間を増やす程度に
  留めるかは、既存の通路生成アルゴリズムの実装詳細を見て実装時に判断する
  (フラッドフィルによる到達可能性検証が壊れない範囲で調整する必要が
  あるため)。
