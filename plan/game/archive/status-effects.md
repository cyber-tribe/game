`core/types.ts` には `sleep` `confuse` `seal` の3種が定義済みで、
`plan/monster-compendium.md` の新種(マドロミダケ・ワスレガニ・
ヨロイムカデ)がそれぞれ付与するところまで仕様化した。しかしコードを
確認すると、**状態異常を途中で解除する手段が一切ない**(ターン経過で
自然に切れるのを待つのみ)。ここでは治療手段を新設し、あわせて
新しい状態異常「毒」を1つ追加する。

## 現状の確認

- `hasStatus` はターン数が残っているかを見るだけで、`removeStatus` に
  相当する関数はコード上に存在しない。
- アイテム図鑑(`src/items/catalog.ts`)にも、状態異常を治す効果を持つ
  ものは無い。

## 治療アイテムの新設

| アイテム | 種別 | 効果 |
|---|---|---|
| めざめ草 | 草(herb) | 眠り・混乱を即座に治す |
| 毒消しの実 | 草(herb) | 毒(後述)を即座に治す |

- **封じ(seal)だけは治療アイテムを用意しない。** 封じは「道具・杖が
  使えなくなる」という妨害そのものなので、封じられている間はその
  治療アイテムすら使えない、という理屈になり一貫しない。封じは
  ターン経過でしか解けない、という現状の弱点をそのまま**封じの
  価値**として残す(`design/balance-philosophy.md` のパワーバジェット
  方針、何でも打ち消せる状態にしない)。
- `plan/protagonist-equipment.md` の頭防具「樽守りの笠」(眠り耐性)とは
  役割を分ける。笠は**かかりにくくする**予防、めざめ草は**かかった後に
  治す**対処、という two-layer の設計にする。

## 新しい状態異常: 毒

```ts
export const STATUS_POISON = "poison";
export type StatusKind = ... | typeof STATUS_POISON;
```

- 行動そのものは妨げない(眠り・混乱・封じと違い、殴る・逃げるは
  普通にできる)。**ターン経過でじわじわHPが減る**、既存の満腹度切れ
  (HPが減り続ける)と似た仕組みを状態異常として個体に紐づけたもの。
- 付与源は新規モンスターを作らず、**罠(`TrapKind`)に `"poison"` を
  追加する**形で導入する(既存の `damage` `sleep` `alarm` `pitfall` と
  並べるだけで実装できる)。踏むと毒を受ける罠、という位置づけ。
- `plan/hidden-dungeon.md` の忘れ物蔵(謎解き・資源管理寄り)は、
  戦闘の脅威が薄い代わりに罠の比重が高い設計にしていたので、毒罠の
  初出はここに置くとコンセプトに合う。

## 重ね掛けのルール

- 同じ種類の状態異常を重ねて受けた場合、**残りターン数を上書きせず、
  長い方を採用する**(既存の付与処理に「短ければ上書きしない」
  1行を足すだけで済む)。
- 異なる種類の状態異常は同時に持てる(眠りながら毒を受けている、等は
  許容する)。ただし眠り・混乱・封じのうち複数を同時に受けても、
  行動不能である事実は変わらないため体感上の違いは小さい。
