# 仲間のレベルアップと「ゆめわざ」(特技・魔法)で育成を面白くする

## 経緯

仲間モンスターには `level`(捕獲時・夢あわせで決まる)と、パッシブの
特技2枠(`src/entities/skills.ts`、夢あわせで継承)が既にあるが、
**連れ歩いても仲間自身は一切成長しない**(`src/dungeon/populate.ts` の
コメントに「仲間自身の経験値蓄積・レベルアップはまだ実装されていない」
と明記)。育成の柱が夢あわせ(合成)となじみ(連れ歩き回数)だけで、
「一緒に戦って強くなる」実感が無い。

そこで2本柱を足す:

1. **仲間の経験値・レベルアップ**(ダイブ中に育つ)
2. **ゆめわざ**(レベルで覚える能動的な特技・魔法。既存のパッシブ
   特技とは別枠)

## 1. 仲間の経験値・レベルアップ

- **経験値はプレイヤーと同じ発生源を分配する。** モンスターを倒した
  とき、その経験値の全量をガルドへ(従来どおり)、同量の50%を
  **生存して連れている仲間全員**にそれぞれ与える(頭割りにしない。
  複数連れのパーティが不利にならないように)。
- レベルアップに必要な経験値はガルドの `expForLevel` 曲線を流用し、
  仲間は係数でやや軽くする(捕獲階=適正レベル帯から育て直すため、
  追いつきが苦行にならないように)。
- **レベルアップ時の成長**は、既存の「レベルに応じた底上げ」式
  (`createAllyFromStored` の `level×8%`)をそのまま動的にする:
  レベルが上がった瞬間に同じ式で maxHp/atk/def を計算し直す。
  保存(`StoredMonster.level`)にも反映し、次のダイブへ持ち越す。
- レベルアップ時は**全回復**する(`plan/game/archive/levelup-full-heal.md`
  のプレイヤー仕様と揃える)。
- 表示: ログ「◯◯はレベル5になった!」+HUDのなかま欄で一瞬ハイライト。
  ねむり小屋の一覧にもレベルを表示(既にlevel欄があるならそのまま)。

## 2. ゆめわざ(能動的な特技・魔法)

### 位置づけ

- 既存のパッシブ特技(`skills.ts`、最大2)は**そのまま**。夢あわせの
  継承価値を壊さない。
- ゆめわざは**種族ごとの固有アクション**で、パッシブとは別に
  最大2つまで覚える(レベル習得)。「夢のかけらが見せる夢の断片」
  という設定で、魔法に相当する不思議な業もここに含める。

### 習得

- 各種族に**習得表(レベル→ゆめわざ)を2件**持たせる。目安:
  1つ目はLv5前後、2つ目はLv12前後(成熟系・ボス系はもう少し遅く
  強力に)。
- 習得時はログ+なかま欄ハイライトで祝う。「◯◯は『ねむりのうた』を
  ゆめみた!」のような専用文言にする(覚える=夢に見る、という語彙)。
- 成熟(夢あわせでの種族変化)後は新種族の習得表に切り替わる。
  習得済みのゆめわざは引き継ぐ(枠2を超える場合は古いものから
  忘れ、ねむり小屋で付け替え可能にする)。

### 使いどころ(AI発動)

- 操作の複雑さを増やさないため(`design/balance-philosophy.md`)、
  **発動は仲間AIの自動判断**とする。プレイヤーの入力は増やさない。
- 各ゆめわざに発動条件とクールダウン(ターン数)を持たせ、条件を
  満たしたターンに通常行動の代わりに使う。
- 既存の「構え」(`plan/game/archive/companion-orders.md`)で
  間接制御できるようにする: 「ゆめわざ控えめ」を構えの選択肢に
  1つ足す(使わせたくない場面用)。

### ゆめわざの種類(初期セット12件)

種族タイプ(AI・地方)ごとに割り当てる。代表例:

| ゆめわざ | 効果(能動) | 想定種族タイプ |
|---|---|---|
| ねむりのうた | 隣接する敵1体を眠らせる(クールダウン長め) | まどろみ系(madoromi等) |
| つぶてなげ | 2マス先まで届く小ダメージの遠隔攻撃 | つぶて系 |
| かたやぶり | 次の一撃を防御無視にする自己強化 | 甲殻系(katakunagani等) |
| いやしのしずく | ガルドか仲間1体のHPを小回復 | 水辺系(shizukuuo等) |
| こだまがえし | 受けた次の1撃の半分を相手へ返す | やまびこ系 |
| ちいさなかぜ | 隣接する敵全員を1マス押し出す | 風系(nadakaze等) |
| ほのかなあかり | 3ターンの間、視界+1 | 発光系(chouchinokuri等) |
| おどしなき | 隣接する敵1体を1ターン怯ませる(行動スキップ) | 群れ系 |
| ねばりつき | 敵1体の移動を2ターン封じる | 泥・粘体系 |
| ゆめのかけぶとん | 仲間全員の被弾を1ターン1割軽減 | ぷるん系 |
| ホネつよし | 自分のdefを3ターン強化 | 骨系 |
| わすれさせ | 敵1体の「気づき」を解除する(未発見に戻す) | 忘却系(wasure系) |

全約60種族への割り当て表は本書では固定しない(実装時に
`species.ts` へ `dreamArts: [{ level, id }]` を追加しながら、
上記タイプ対応を目安に機械的に割り当ててよい。ボス種は専用の
強力版を後続で仕様化する)。

## バランス指針

- ゆめわざは**1つで戦況を決めない小粒の効果+クールダウン**を原則に
  する(`design/balance-philosophy.md` のパワーバジェット。強さは
  レベル・夢あわせ側が担い、ゆめわざは「らしさ」と手数の彩り)。
- 経験値50%分配は、ソロ攻略との差を付けすぎないための初期値。
  実装後の通しプレイ(auto-tester)でクリアターン・死亡率を見て
  調整してよい。

## データ構造

```ts
// species.ts
dreamArts?: readonly { level: number; id: DreamArtId }[];

// StoredMonster / AllyActor
exp: number;                 // 蓄積経験値(新規)
dreamArts: DreamArtId[];     // 習得済み(最大2)
```

セーブ互換: 既存セーブの仲間は `exp: 0`・`dreamArts: []` として
読み込み、現在のレベルから育成を始める(`plan/game/archive/
save-compat-testing.md` の方針でマイグレーションを追加)。

## 対象外

- プレイヤーが発動タイミングを直接指示するUI(まず自動発動で出し、
  要望があれば「指示」拡張として別途仕様化)
- ボス種専用ゆめわざ(後続PR)
- 敵側モンスターへのゆめわざ付与(敵の行動は既存のAI・ボス仕様の
  まま。仲間だけの特権にして「捕まえて育てる」動機を強める)

## 未決事項

- 全種族への `dreamArts` 割り当て表の確定(実装時にタイプ対応で
  割り当て、図鑑・ねむり小屋で確認できるようにする)
