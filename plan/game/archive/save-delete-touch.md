# セーブデータをスマホ(タッチ)から削除できるようにする

## 経緯

セーブ枠の削除は実装済みだが、**Deleteキー限定**
(`src/ui/slot-select.ts`。確認を挟んでから消す誤操作対策つき)。
スマホにはDeleteキーが無く、タッチではセーブデータを消す手段が
存在しない。

## 変更内容

1. **セーブ枠選択画面(slot-select)の各枠に「削除」ボタンを置く。**
   - 枠の行の端に小さな「削除」を常設(タッチ・マウス共通。
     キーボードのDeleteも従来どおり残す)。
   - 押すと既存の確認フロー(`confirmingDelete`)に入る。確認の
     選択肢(「本当に削除する/やめる」)も**タップできるボタン**に
     する(現状がキー操作のみなら、ここもタッチ対応が必要)。
   - 空の枠には削除ボタンを出さない。
2. **確認文言に失うものを明記する。**
   「枠◯のデータを削除する。持ちもの・仲間・記録がすべて消え、
   元に戻せない。」のように、取り返しがつかないことをはっきり
   書く(既定カーソル/フォーカスは「やめる」)。
3. **「≡」メニューの設定からも削除に辿れるようにする。**
   設定画面の末尾に「セーブデータの管理」を1項目足し、選ぶと
   スロット選択画面(削除ボタンつき)を開くだけでよい
   (新しい削除UIは作らない。導線を増やすだけ)。
   プレイ中のデータをその場で消す操作は**現在のダイブ中は不可**に
   する(拠点でのみ有効。ダイブ中に消すと状態が宙に浮くため)。

## 受け入れ基準

1. スマホで、セーブ枠選択画面から任意の枠を削除できる
   (削除→確認→タップで確定、の全段がタッチで完結)。
2. 確認で「やめる」を選べば何も消えない。誤タップ1回では消えない。
3. キーボードのDelete操作は従来どおり使える。
4. 設定の「セーブデータの管理」から同じ画面に辿れる(拠点でのみ)。

## 対象外

- クラウド同期・エクスポート等のバックアップ機能
- 個別データ(仲間1体だけ等)の部分削除(逃がす機能が既にある)
