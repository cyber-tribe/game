# 力尽きた後、タッチ操作でも拠点に戻れるようにする

## 経緯

スマホ版で、力尽きた(またはダイブを終えた)あとのオーバーレイに
「R キーで拠点にもどる」という案内文しか無く、**タップできる
ボタンが存在しない**ため、キーボードの無い端末では拠点に戻れない
(タッチUIの「≡」メニュー内のRに気づけば戻れるが、導線として
成立していない)。

## 現状

`src/main.ts` の `finish()` / `finishTarukurabe()` が
`hud.showOverlay(見出し, 本文, フッター文)` を呼び、フッター文に
「— R キーで拠点にもどる」を埋め込んでいるだけ。オーバーレイは
表示専用で、操作要素を持たない。

## 修正方針

1. **オーバーレイにタップ可能な「拠点にもどる」ボタンを追加する。**
   `showOverlay` を拡張し(またはボタン付きの派生を用意し)、
   押すと**Rキーと同じ処理経路**(拠点へ戻る既存のハンドラ)を
   呼ぶ。新しい戻り方は作らない。
2. **対象はゲームオーバー・踏破・樽比べ終了の3つのオーバーレイ**
   (いずれも現状「R キーで拠点にもどる」を案内している)。
3. **表示はタッチ端末に限定しない。** デスクトップでもクリックで
   戻れて困ることは無いので、常時ボタンを表示し、フッター文の
   「R キーで〜」はキーボード環境向けの補足として残す
   (タッチ端末での文言出し分けは
   `plan/game/mobile-layout-redesign.md` の文言対応に含める)。
4. ボタンの見た目は既存のタッチボタン(`.touch-btn`)や
   拠点画面のボタンと統一感のあるスタイルにする。

## 受け入れ基準

1. スマホ実機で、力尽きた後のオーバーレイに「拠点にもどる」ボタンが
   表示され、タップすると拠点(村)に戻る。
2. 踏破成功時・樽比べ終了時も同様に戻れる。
3. キーボードのRキーでも従来どおり戻れる。

## 対象外

- オーバーレイ全体のデザイン刷新(必要なら
  `plan/game/mobile-layout-redesign.md` 側で扱う)
- エンドロール(`plan/game/archive/ending-sequence.md`)の操作。
  こちらは既存の進行のまま
