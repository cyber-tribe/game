> 本文中の未決点・曖昧な点は次のとおり実装時に決めた。
>
> - **購入フローの矛盾の解消**: 本文には「goldが足りなければ拾えない」と
>   「未払いのまま持ち出すと万引きになる」の両方が書かれており、
>   文字どおりだと矛盾する(拾えないなら未払い所持自体が起こらない)。
>   実装では「足りれば自動購入、足りなければ`unpaid`フラグ付きで
>   持ち出せる」という形にし、両方を成立させた。
> - **盗まれるのは所持金のみ**: 本文は`stolen: { itemUid?; gold? }`と
>   アイテムも盗めるデータ構造を提案していたが、実装では`stolenGold`
>   (金額のみ)に簡略化した。所持品を奪う場合、対象アイテムの選定・
>   インベントリからの除去・落とした際の復元など考慮が増えるため、
>   まずは金貨のみの往復(奪う→倒せば取り戻せる)に絞った。
> - **消滅条件は「未探索領域」ではなく「視界外」**: 本文の「壁の向こう・
>   未探索領域まで到達すると消滅」を文字どおり実装すると、生成直後の
>   フロアはほとんどが未探索のため、逃走を始めた瞬間にほぼ消えてしまい
>   理不尽になる。既存の`isVisible`(部屋単位の視界規則)を使い、
>   「プレイヤーの視界から外れたら消滅」に読み替えた。
> - **評判システムは対象外**: 本文が明記するとおり、万引き後の割高価格
>   より先(ストーリー分岐等)は今回のスコープに含めない。

## 世界観・ストーリーとの接続

- **店 = 近道屋の出店(でみせ)。** 近道屋はヨリシロの夢から掘り出した
  夢のかけらや道具を、深い階のあちこちに勝手に店を出して売りさばいている。
  正規の商店ではなく、**乱掘のついでの副業**という位置づけにする
  (`design/story.md` の対立構造そのままの延長)。
- **泥棒 = 近道屋の強欲さがヨリシロの夢に映り込んでできた、寄生的な
  夢のかけら。** 新モンスター種族として **スリガラス** を追加する。
  カラス型で、近道屋の物欲を真似るように光る物(所持金・道具)を奪って
  逃げる。`design/characters.md` の「手下: 穴掘りのソバカス」の
  盗賊的な立ち回りを、モンスターという形に落としたもの、という設定にする。

この2つを対にすることで、「近道屋から金を奪われることもあれば、
近道屋の店で金を使わされることもある」という一貫した経済圏になる。

## 店の仕様

### 出現
- 4階以降、一定確率で1フロアに1部屋だけ「近道屋の出店」部屋が生成される
  (`Room` に `kind?: "shop"` を追加。既定は通常部屋)。
- 部屋の中に店主(近道屋の行商人・戦闘不可のNPCアクター)と、
  売り物のアイテムが床に並ぶ。売り物は通常のドロップ品と見た目は同じだが、
  内部的に「未払い」フラグを持つ(`GroundItem` に `forSale?: { price: number }`
  を追加)。

### 価格
- 価格はアイテムの `minFloor` と `weight`(レア度)から自動算出する式にする。
  例: `price = 20 + minFloor * 8 + (10 - weight) * 5` のような、レアなものほど
  出現階が深いものほど高くなる式(係数は実装時に調整)。武器・盾は `bonus`、
  杖は `charges` も加味する。
- 所持金 `gold` はダンジョン内で敵を倒す・床に落ちている金貨(新規の
  `ItemCategory` は不要で、`GroundItem` とは別に軽量な `GoldPile { pos, amount }`
  をフロアに置く案)を拾うことで増える。踏破/生還すれば所持金はそのまま
  ねむり小屋の道具や仲間と同様、拠点に持ち帰れる。全滅時は所持していた金も
  失う(道具・仲間と同じロスト規則で世界観と一致させる)。

### 購入フロー
- 「未払い」の床アイテムの上に乗ると、通常の拾得(Space)ではなく
  購入確認が出る。gold が足りれば購入して持ち物に入る。足りなければ拾えない。
- 何も払わずに部屋の外へ持ち出そうとする(＝未払いのままアイテムを持って
  部屋の出口を越える)と **万引き** 扱いになる。

### 万引きした場合
- 店主が豹変し、店主専用の強力な攻撃(通常のモンスターよりかなり高い攻撃力)
  でその場にいるプレイヤーを攻撃してくる。店主自身は移動しない(店を離れない)
  ため、部屋を出てしまえばそれ以上追ってはこない。
- そのラン中、以後遭遇する近道屋の出店はすべて最初から警戒状態になり、
  購入価格が割高になる(「噂が回った」という説明で一貫させる)。
- 店主を倒しても品物をすべて奪えるが、近道屋がらみのペナルティ(後述の
  ストーリー分岐・評判)が伴う想定。詳細な評判システムは本仕様の対象外とし、
  将来の拡張課題とする。

## 泥棒(スリガラス)の仕様

### 種族データ案(`src/entities/species.ts` に追加)
```ts
{
  id: "surigarasu",
  name: "スリガラス",
  model: "surigarasu",
  maxHp: 8,
  atk: 4,
  def: 1,
  exp: 10,
  ai: "thief",       // 新設するAI種別
  minFloor: 5,
  weight: 4,
}
```
既存の `AiKind`(`"melee" | "ranged" | "coward"`)に **`"thief"`** を追加する。

### 挙動
1. プレイヤーまたは仲間に隣接すると、通常攻撃の代わりに**盗み**を試みる
   (確率判定。所持品からランダムに1つ、または所持金の一部)。
2. 盗みに成功すると、対象は `stolen: { itemUid?: number; gold?: number }` を
   保持したまま**即座に逃走状態**になる(`coward` AIの「HPが減ると逃げる」を
   流用しつつ、トリガーを「盗みの成否」に変える形で実装できる)。
3. 逃走中に**そのフロアの外(壁の向こう・未探索領域)まで到達すると消滅し、
   盗んだ物は失われる**。到達前に討伐すれば、その場に盗品をドロップする。
4. 盗みを試みる前(逃走を始める前)なら、通常のモンスター同様に討伐しても
   何もドロップしない(手ぶらのまま来ている個体もいる、という前提)。

### 出現階
5階以降。近道屋の活動が本格化する `design/story.md` 第一章〜第二章の
時期に合わせている。

## データ構造まとめ

- `Room.kind?: "shop"`
- `GroundItem.forSale?: { price: number }`
- 新規 `GoldPile { pos: Vec2; amount: number }` を `FloorState` に追加
  (または `GroundItem` の一種として扱ってもよい。実装時に既存の
  アイテム動線とどちらが素直かで判断する)
- `AiKind` に `"thief"` を追加
- `Actor`(モンスターのみ)に `stolen?: { itemUid?: number; gold?: number }`

## 未決事項

- 万引き後の「評判」がその後の店の価格以上に物語へ波及するか(近道屋との
  最終対決の難易度に影響する等)は `design/story.md` 側の詳細化を待つ。
- 金貨をアイテム欄の1枠として扱うか、専用のステータス欄(所持金表示)に
  するかは実装時に決める(現状 `PlayerState.gold` があるので専用欄が自然)。
- スリガラスの3Dモデルは新規作成が必要(既存5種のいずれとも別モデル)。
