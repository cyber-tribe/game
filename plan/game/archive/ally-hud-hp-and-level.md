# 仲間HUDの体力バー見切れとレベル非表示を直す

## 経緯

スマホ実機のスクリーンショットで、なかまパネル(`#allies`)の
仲間1体(ぷるん)について「**体力ゲージが見切れている**」
「**レベルが表示されない**」という2点の指摘。どちらも実コード・
実測で原因を特定した。

## 診断(実測)

### 1. レベルが表示されない(実装漏れ)

`src/view/hud.ts`の仲間行の描画(205〜249行)は、1体につき
**名前(`ally-name`)+HP数値(`ally-hp`)+HPバー(`ally-bar`)+
構え(`ally-stance`)+状態異常(`ally-status`)**しか作っておらず、
**レベルを描く要素が存在しない**。

一方、仲間は`level`フィールドを持つ(`src/core/types.ts`の
アクター構造体、351行`level: number`)。`companionGrowth.ts`の
とおり仲間はダイブ中に経験値を得て**レベルアップする**。プレイヤー
HUDは`hud.level`("Lv {level}"、`src/i18n/ja.ts`)でレベルを
出しているが、**仲間行はこの表示を一度も呼んでいない**。つまり
「表示されない」のではなく、最初から描いていない(実装漏れ)。

### 2. 体力バーが見切れる(コンパクト表示のレイアウト脆弱性)

スクリーンショットは仮想パッド・アクションボタン(`#touch`)が
出ており、これは`index.html`515行の
`@media (pointer: coarse) { #touch { display: block } }`でしか
表示されない。JSによる別経路の表示は無いため、**この端末では
`pointer: coarse`が真=なかまパネルのコンパクト表示(577〜615行)も
適用されている**。

コンパクト表示の該当CSS:

```css
#allies {                       /* 577行〜 */
  width: auto;                  /* 内容に合わせて縮む */
  max-width: 200px;
  padding: 5px 9px;
}
#allies .ally { display: flex; align-items: center; flex-wrap: wrap; gap: 7px; }
#allies .ally-row  { flex: 1 1 auto; min-width: 0; }  /* 名前。0まで縮む */
#allies .ally-bar  { flex: 0 0 56px; margin: 0; }     /* バー。56px固定・縮まない */
#allies .ally-hp   { display: none; }                 /* HP数値は隠す(issue #552) */
#allies .ally-stance { display: none; }
```

- パネルは`width: auto`の**縮小幅(shrink-to-fit)**。名前が短い
  仲間(「ぷるん」)だと、パネルは名前+バーぶんまで細く縮む。
- バーは`flex: 0 0 56px`で**固定幅・縮小不可**。
- `.ally`は`flex-wrap: wrap`。**名前+gap(7px)+バー(56px)が
  1行に収まらないほどパネルが細く縮むと、バーが次の行へ折り返す**
  (折り返しても56px固定なので、名前の下に56pxのバーが居座り、
  その右端がパネルの右padding・角丸に衝突して「見切れ」に見える)。
- コンパクト表示は`.ally-hp`(数値)も隠すため、**HPの手がかりが
  バー1つしかなく**、その見切れが余計に痛い。

ヘッドレスChromiumではパネルが約116pxに落ち着き折り返さない
(バー右端はpaddingの内側)。だが実機ではフォントメトリクス・DPRの
差でパネルがより細く縮み、折り返しが起きていると考えられる。
**要は「縮小幅パネル+固定幅バー+折り返し許可」の組み合わせが
脆く、端末によって崩れる**。

## 修正方針

### 1. 仲間行にレベルを表示する(`src/view/hud.ts`)

- 名前の隣に**レベルを描く要素を追加**する(例: `ally-level`)。
  文言はプレイヤーHUDと同じ`hud.level`("Lv {level}")を流用し、
  `ally.level`を渡す。
- コンパクト表示で名前が長いと横幅が厳しいので、レベルは名前の
  すぐ後ろに小さく添える(名前は`text-overflow: ellipsis`で
  縮む、レベルは`flex-shrink: 0`で最後まで残す、といった優先度に
  する)。デスクトップ表示では名前・HP数値と同じ行に自然に並べる。

### 2. コンパクト表示のバー見切れ・折り返しを止める

以下のいずれか(実装時に実機で見ながら決めてよい。狙いは
「バーが必ず名前と同じ行に収まり、右端がpaddingの内側に入る」):

- **案A(推奨):** バーを`flex: 0 0 56px`の固定幅でなく
  `flex: 1 1 auto`(+`min-width`を40px程度)にして、パネル幅に
  応じて**伸縮**させる。名前+バーが常に1行で共存し、狭ければ
  バーが縮む。折り返しの原因(固定幅)そのものを無くす。
- **案B:** 名前+バーを載せる行だけ`flex-wrap: nowrap`にして
  折り返しを禁止し、`.ally-status`だけを別要素として次の行へ
  回す(現状`.ally-status`が`flex: 1 0 100%`で改行しているのは
  維持)。
- あわせて`#allies`に**下限幅**(例: `min-width` を「名前数文字+
  バー+padding」ぶん)を与え、パネルが過度に細く縮まないように
  する。
- バーの右端がパネルの角丸・paddingに接触しないよう、バー右側の
  余白(または`.ally`側のpadding-right)を1〜2px確保する。

### 3. HPの手がかりを補う(任意・軽微)

- コンパクトで`.ally-hp`(数値)を隠す方針(issue #552)は維持して
  よいが、バーだけになるぶん、**バーの最小可視幅**(危険域でも
  数px残る)を保証しておくと、瀕死の仲間が「空バー=見えない」に
  ならず状態が読める。

## 受け入れ基準

1. 仲間行に**Lv 表示が出る**(スマホ横持ちの実機で、名前と一緒に
   レベルが読める)。ダイブ中にレベルアップしたら数値が更新される。
2. なかまパネルの**HPバーが名前と同じ行に収まり**、右端が
   パネルの枠内に入る(折り返し・見切れが起きない)。名前の
   長さ・仲間の数・端末幅を変えても崩れない
   (`ally-name`が長い場合はバーではなく名前側が省略される)。
3. デスクトップ(`pointer: fine`)の見た目が実質変わらない
   (レベル追加ぶんを除く)。
4. 状態異常ラベル(`.ally-status`)の改行挙動(issue #950の対応)が
   維持される。

## 対象外

- なかまパネルの位置・最大高さ・スクロール(現状維持)
- コンパクトで構え(`.ally-stance`)・HP数値(`.ally-hp`)を隠す
  方針そのもの(issue #552。数値は「≡」→仲間へ指示で見られる)
- プレイヤーHUD側のレベル・経験値表示(既に表示済み)

## 未決事項

  (まず常時出す案で実機確認し、破綻するようなら名前の後ろで
  省略可能にする)
- `#allies`の下限幅・バーの最小/最大幅の具体値(実機の
  フォントメトリクスを見ながら詰める)
