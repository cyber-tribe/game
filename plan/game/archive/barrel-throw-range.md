# タルの投擲距離が長すぎるのを詰める

## 経緯

「タルの飛距離が長すぎる」という指摘。タルは捕獲・爆発・属性など
戦術の中心道具だが、いまの基本射程だと部屋のほぼ端から端まで一撃で
届き、位置取りの駆け引きが薄れる。カメラ既定距離を近づける方針
(`plan/game/archive/dungeon-camera-distance.md`)とも噛み合わず、
タルが画面の外まで飛んでいくため「制御できない・長すぎる」体感に
なっている。

## 診断(実測)

- 基本射程は`src/domain/barrel/barrelThrow.ts`の
  **`BARREL_RANGE = 8`**(マス)。
- 実効射程は`src/application/dungeonRun/game.ts`の
  `effectiveThrowRange()`(1052〜1053行):
  ```ts
  const lightCarryBonus = this.runSkills.includes("lightCarry") ? LIGHT_CARRY_RANGE_BONUS : 0;
  return (this.dungeon.id === TARUKURABE_ID ? TARUKURABE_THROW_RANGE : BARREL_RANGE) + lightCarryBonus;
  ```
  - スキル「かるがる」で**+2**(`LIGHT_CARRY_RANGE_BONUS`)。
  - **樽くらべ(TARUKURABE)は専用の`TARUKURABE_THROW_RANGE`**を
    使い、既に日常ダンジョンの射程と切り離されている。
- 比較となる値:
  - 部屋サイズは最大**11×8**マス、多くは横4〜11(`generate.ts`の
    `MIN/MAX_ROOM_W/H`)。射程8は**大半の部屋を横断してしまう**。
  - アイテム投擲は`ITEM_THROW_RANGE = 10`(別物。今回は触らない)。
  - 遠距離敵の例: きりみずち`range: 4`。プレイヤーのタルが射程8だと、
    多くの遠距離敵より遠くから一方的に当てられる。
- `traceThrow`は**実際の投擲と投げる前の見込み表示
  (captureOutlook)の両方**が共有している(barrelThrow.ts)。
  `BARREL_RANGE`を下げれば予測線と着弾が同時に短くなり、齟齬は
  出ない。

## 修正方針

- **`BARREL_RANGE`を8から短くする**(たたき台: **5前後**)。
  - 5なら「かるがる」込みで7。スキルの価値を保ちつつ、素の状態では
    大部屋の横幅いっぱいには届かない=部屋の中で「近づいてから
    投げる/角度を作る」判断が生まれる。
  - カメラ既定距離(近づける方針)の視野内に着弾が収まりやすくなり、
    画面外へ飛ぶ体感が減る。
- **触らないもの**:
  - `TARUKURABE_THROW_RANGE`(樽くらべは飛距離を競う遊びなので
    長いままが正しい。既に分離済み)。
  - `LIGHT_CARRY_RANGE_BONUS`(+2)自体。基本射程が下がっても
    「+2」は相対的に効き続ける。
  - `ITEM_THROW_RANGE`(アイテム投擲。別系統)。
- **追随確認**(同じPR内):
  - `game.ts`337行付近の「遠の的(距離9)は通常の
    `BARREL_RANGE`(8)より遠い」というコメント・前提。基本射程を
    下げると差が開くだけで破綻はしないが、コメントの数値を更新する。
  - 捕獲の見込み表示(captureOutlook)が新しい射程で正しく短くなって
    いること(共有`traceThrow`のため自動で追随するはずだが、実機で
    確認)。

## 判断保留と検証の関係

- これは新機能の追加ではなく、**既存の中心道具の手触り調整**。
  ただしタル戦術は判断密度検証
  (`plan/game/archive/region1-tactical-validation.md`)の測定対象
  そのものなので、射程を変えたら**その検証は変更後の値で取り直す**
  (「タルによって戦術が変わった回数」は射程に直接依存する)。
- 最終値(5前後をたたき台に、4〜6のどれにするか)は、エンジン内で
  実際に大部屋・小部屋で投げてみて、「近づく判断が生まれる」かつ
  「捕獲が理不尽に難しくならない」範囲を目視で詰める。

## 受け入れ基準

1. 素の状態でのタルの飛距離が短くなり、標準的な部屋で「端から端へ
   一撃」ができなくなる(新旧の着弾距離を比較)。
2. 「かるがる」スキルの+2が引き続き体感できる(スキル有無で射程が
   変わる)。
3. 樽くらべの投擲距離は変わっていない。
4. 投げる前の見込み表示(予測線・着弾マス)が実際の着弾と一致して
   いる。
5. カメラ既定距離の視野内に、素のタルの着弾が概ね収まる。

## 対象外

- アイテム投擲(`ITEM_THROW_RANGE`)の距離
- 樽くらべの投擲距離・遠の的の位置
- 爆発・属性・捕獲などタルの効果そのもの(距離だけを調整する)
- タルの投擲アニメーション・エフェクト(見た目は
  `plan/models`/`particles`側)
