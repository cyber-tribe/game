# 表の寝穴を地方ごとの別ダンジョンに分割する(入口も分ける)

## 実装状況(このセクションは実装セッションが追記した注記)

受け入れ基準の1・2・3(8つの地方ダンジョンから行き先を選べる・各ダンジョンは
1階から始まり最終階のボス撃破で次が解放される・横穴に入ると分岐ダンジョンへ
移り踏破で元の階へ戻る)を実装済み。以下は意図的に見送った・保留した点:

- **階数は8地方とも均等にREGION_SIZE(6階)のまま**。本文の「後半ほど
  長い勾配(合計60階)」は未実装(未決事項どおり初期値のまま)。
- **横穴(分岐ダンジョン)は「ぬかるみの底」(忘れ潮の湿地2階)・
  「こだまの巣」(こだまの尾根2階)の初期2件のみ実装**。入り口は
  低確率(30%)で生成され、入るとGame.hostContextへ元のダンジョン・階数・
  フロアの状態を退避し、分岐ダンジョンの1階目を生成する。プレイヤー・
  仲間・持ち物・ターン数・気分・難易度は一切変更しない。分岐ダンジョンの
  最終階でdescendすると退避しておいたフロアをそのまま復元し、入ってきた
  マスへ戻す(入り口自体は1回きりで消える)。横穴の追加数・出現階の拡張は
  未決事項のまま残す。
  - ダイブ中オートセーブ(`plan/mid-dive-autosave.md`)は横穴の中にいる間
    書き出しを止め、入る直前の(元の地方ダンジョンの)状態を残す設計にした
    (`Game.inBranchDungeon`)。横穴の中でクラッシュした場合、横穴内で
    進めた分だけ失われるが、「元のダンジョンへ戻れなくなる」ことはない。
- **記録の間・依頼板の「ダンジョン別」表示への読み替えは未実装**。
  「最深到達」ラベルから「(表の寝穴)」の表記だけ外したが、記録自体は
  引き続き全ダンジョン共通の1つの値のまま。
- **旧セーブの引き継ぎ**: 明示的な変換コードは書いていない。地方ボス
  撃破済み一覧(`SaveData.defeatedRegionBosses`)は分割前から実際の
  撃破と連動して記録され続けていたため、この解放判定にそのまま使うだけで
  旧セーブも正しく引き継がれる(検証済み)。
- 分割の副作用で、村の発展段階(`entities/village.ts`)・夜ごとの夢の
  解放条件・章立て(`entities/story.ts`のstoryChapter)が、いずれも
  「最深到達記録」から「撃破済み地方ボス数」ベースの判定に変わった
  (1ダイブの深さが1地方=6階を超えなくなり、最深到達記録が48まで
  伸びなくなるため。備考: 実績帳「挑戦」カテゴリの無道具フルクリア系は、
  最終第八地方ダンジョン単体のノーアイテムクリアに読み替えた。旧来の
  48階連続ノーアイテムより難度が下がる点は、地方ごとに入口を分けた
  設計上の帰結として受け入れている)。

## 経緯

現在のメインダンジョン「表の寝穴」は8地方×6階=48階の一本道
(`plan/game/archive/region-expansion.md`)。これを**地方ごとに独立した
ダンジョン**へ分割し、入口も分ける。ダンジョンごとに階数が異なって
よく、あるダンジョンから分岐して入れる横穴ダンジョンも設ける。

狙い: 1回のダイブを「1つのダンジョンを入口から踏破する」単位に
揃え(`plan/game/remove-checkpoint-start.md` の1階出発と対になる)、
「今日はどこへ潜るか」を選ぶ楽しさと、ダンジョンごとの攻略の
性格づけを作る。

## ダンジョン構成

既存の複数ダンジョン基盤(`src/entities/dungeons.ts` の `DungeonDef`:
`maxDepth`・`floorOffset`・`unlock`)をそのまま使い、表の寝穴1件を
8件に置き換える。地方の内容(出現種族・ギミック・ボス・BGM)は
`design/regions.md` の対応をそのまま各ダンジョンへ移す。

| ダンジョン(地方) | 階数 | 解放条件 |
|---|---|---|
| 始まりの森の寝穴(第一) | 5階 | 最初から |
| 忘れ潮の湿地穴(第二) | 6階 | 第一のボス撃破 |
| まどろみの茸林洞(第三) | 7階 | 第二のボス撃破 |
| 乾いた回廊(第四) | 7階 | 第三のボス撃破 |
| なみだの滝つぼ道(第五) | 8階 | 第四のボス撃破 |
| こだまの尾根穴(第六) | 8階 | 第五のボス撃破 |
| わすれられた祭りの跡(第七) | 9階 | 第六のボス撃破 |
| 山の芯への道(第八) | 10階 | 第七のボス撃破 |

- 階数は「後半ほど長い」勾配の初期値(合計60階)。難易度・出現
  テーブルは各ダンジョン内で1階→最終階に向けて上がる
  (`floorOffset` で従来の深度テーブルに対応付ければ、種族・
  アイテムの出現定義は大きく作り直さずに済む)。
- **最終階はボスの間**(`plan/game/dungeon-boss-rooms.md`(別PR)で
  仕様化)。ボス撃破で踏破となり、次の地方のダンジョンが解放される。
- めざめの階段は各ダンジョンの中間(階数の半分の階)に1つ置き、
  「区切って持ち帰る」専用とする(出発地点には使わない)。
- 章立て(`design/story.md`)の進行条件は「第N地方のボス撃破」に
  読み替える(到達深度ベースの条件を置き換える)。

## 入口の分け方

- 村の「洞窟の入口」から山道が枝分かれしている、という体裁で、
  **入口で行き先ダンジョンを選ぶ**(既存の「潜るダンジョン」列の
  拡張。リストに8件+既存の特殊ダンジョンが並ぶ)。
- 村マップ上に8つの入口を物理的に並べることはしない(村なか歩きの
  導線が長くなりすぎる)。将来、村の発展で入口前の広場を作る等は
  別途検討してよい(未決事項)。
- 未解放のダンジョンはリストに「???(第◯地方のぬしを鎮めると
  ひらける)」のように条件だけ見せる。

## 分岐ダンジョン(横穴)

- 一部のダンジョンの特定階に、低確率または固定で**「横穴」の入り口
  タイル**が生成される。入ると短い分岐ダンジョン(2〜4階)へ移り、
  踏破すると元のダンジョンの同じ階へ戻る(報酬: レア素材・タル・
  仲間にしやすい種族の巣 等)。
- 初期実装は2件でよい:
  - 第二の湿地穴 → 「ぬかるみの底」(2階。水系素材の宝庫)
  - 第六の尾根穴 → 「こだまの巣」(3階。やまびこ系種族の巣)
- 既存の近道屋の裏穴・腕試しの間などの特殊ダンジョンは従来どおり
  独立ダンジョンとして残す。

## 既存要素との整合

- **記録の間・実績**: 「最深記録」はダンジョン別の踏破記録に
  読み替える(全体の一枚看板の数字は「踏破したダンジョン数」へ)。
- **依頼板**: 討伐・探索依頼の対象階指定を「ダンジョン+階」に
  読み替える。
- **難易度モード・鍛え方・持ち込み**: 変更なし(出発準備の
  フローはそのまま)。
- **セーブ互換**: 旧「表の寝穴 深度N」の記録は、N を地方境界で
  割り当てて各ダンジョンの踏破状況に変換する(第k地方のボス撃破済み
  相当なら第k+1まで解放)。

## 受け入れ基準

1. 出発時に8つの地方ダンジョン(+特殊ダンジョン)から行き先を
   選べ、未解放のものは条件が表示される。
2. 各ダンジョンは1階から始まり、最終階のボス撃破で踏破・次が解放
   される。
3. 横穴に入ると分岐ダンジョンへ移り、踏破で元の階へ戻る。
4. 旧セーブが地方換算で正しく引き継がれる。

## 対象外

- ボスの間・扉の詳細(`plan/game/dungeon-boss-rooms.md`)
- 山の芯(最終決戦)の演出変更(`plan/game/archive/mountain-core.md`
  の流れは第八ダンジョンの最終階として維持)

- 横穴の追加数・出現階(初期2件から様子を見て拡張)
- 村マップに入口前の広場を作るか(村の発展との連動)
