# めざめの階段の確認モーダルに「区切って帰還」を含める

## 経緯

区切って持ち帰る操作(bankRun)は、めざめの階段の上で**Rキー**を
押すという、画面に出ない隠し操作になっている(タッチでは「≡」→
「区切り/再挑戦」)。一方、階段上で決定を押すと出る確認モーダル
(`src/ui/stairs-confirm.ts`)は「降りる/やめる」の2択しかない。

**「区切る」ことこそめざめの階段の存在意義**なのに、その操作が
確認モーダルに無く、分かりにくいという報告があった。

## 変更内容

**めざめの階段の上で決定を押したときの確認モーダルを3択にする:**

1. **つぎの階へ降りる**
2. **ここで区切って持ち帰る**(既存のbankRun。持ち物・仲間・所持金を
   持ち帰ってダイブを成功で終える)
3. **やめる**(既定カーソル。誤操作防止の既存方針を維持)

- 通常の階段(めざめの階段でない階)は従来どおり「降りる/やめる」の
  2択のまま。
- 「区切って持ち帰る」を選んだときの挙動は既存のRキーと完全に同じ
  経路(bankRun)を呼ぶ。**新しい帰還処理は作らない**。
- Rキー・「≡」メニューの既存操作も残す(慣れたプレイヤーの
  ショートカットとして)。
- タルを抱えているときの既存の制限(降りられない・押し戻される)は
  そのまま適用される。
- 各選択肢に1行の説明を添える(例: 区切る→「持ちものと仲間を
  持ち帰って、今回の探索を終える」)。ここで初めて仕組みに触れる
  プレイヤーへの説明を兼ねる。

## 受け入れ基準

1. めざめの階段の上で決定を押すと、「降りる/区切って持ち帰る/
   やめる」の3択が出る。
2. 「区切って持ち帰る」でRキーと同じ帰還処理が走る。
3. 通常の階段では従来どおり2択。
4. キーボード・タッチどちらでも3択を選べる。

## 対象外

- Rキーの割り当て変更・廃止
- めざめの階段以外からの帰還手段の追加
