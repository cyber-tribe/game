# 樽守りの技

> **実装済み。** `src/entities/arts.ts`(技定義)・`src/entities/player.ts`
> (`artCooldowns`・各種readyフラグ)・`src/core/types.ts`(`Actor.captureBonus`)・
> `src/game.ts`(`useArt` コマンド・各技の効果・クールダウン管理)・
> `src/ui/arts.ts`(技メニュー)・`src/view/input.ts`(Cキー)・
> `src/main.ts`(メニュー配線)。テストは `tests/protagonist-arts.test.ts`。
>
> 実装時の判断・簡略化:
> - 「目覚ましの一喝」は `plan/region-bosses.md` が未実装のため、常に
>   「しかし、それらしい気配はなかった……」という不発メッセージを返す
>   だけの実装にした(習得・クールダウン消費はする)。地方ボスの実装後、
>   予兆つき大技の中断処理をここに接続すること。
> - 「なだめの手つき」は、既存のHPを変えず `Actor.captureBonus` を
>   加算する形で実装し、樽の捕獲判定(`captureChance`)にだけ加味されて
>   消費される。対象はプレイヤーの正面1体に限定した。
> - 「抱え投げの奥義」は、からのタルが直線上の複数体に当たった場合、
>   手前の相手には通過ダメージだけを与え、最後に当たった相手にだけ
>   通常どおりダメージ+捕獲判定を行う(タルは1体しか収容できないため)。
>   モンスター入り・爆発タルへの貫通は対象外(単一目標のまま)。
> - 「樽受け身」は「発動から1ターンだけ有効」を、技の発動そのものが
>   1ターンを消費する仕様と組み合わせ、「発動した command 呼び出しの
>   中で受けた攻撃だけを無効化し、ターン終了時に必ず失効する」という
>   形で実装した。トラップ・毒・満腹度ダメージには適用されない
>   (攻撃を受けた場合のみを「被弾」として扱う)。

`design/protagonist.md` の方針(ガルドは装備・技・レベルで個性を作る)の
「技」にあたる部分を仕様化する。モンスターがAIに従って自動で殴り合う
だけの存在なのに対し、**ガルドだけがプレイヤーの判断で繰り出す特別な
一手**を持つ、という違いをはっきりさせる。

## 位置づけ

- 技はレベルアップ(`EXP_TABLE`、最大レベル20)の節目で1つずつ覚える。
  現状「レベルが上がるとステータスが伸びるだけ」だったレベルアップに、
  能動的な報酬を足す。
- 資源(MPのようなゲージ)は新設しない。**技ごとの再使用クールダウン
  (ターン数)** だけで管理し、新しいUIバーを増やさない
  (`design/balance-philosophy.md` の「操作の複雑さを大きく崩さない」方針)。
- 操作: 新規キー **C**(「技」)で一覧を開き、`src/ui/town.ts` と同じ
  一覧UIパターンで選ぶ。使うと1ターンを消費する。

## 技の一覧(初期案)

| 技 | 習得レベル | クールダウン | 効果 |
|---|---|---|---|
| 会心の樽投げ | 3 | 10ターン | 次に投げるタルのダメージ・捕獲判定が最大値になる(捕獲を確実に成功させたい場面の切り札) |
| なだめの手つき | 7 | 6ターン | 隣接するモンスターに、ダメージを与えずに「弱らせ」だけを与える(`design/world.md` の樽の捕獲判定が参照するHP割合を、実際にHPを減らさず一時的に下げる)。トドメを避けつつ樽を当てやすくする、殺さずに連れ帰りたいときの手段 |
| 樽受け身 | 12 | 8ターン | 次の1回、被弾ダメージを無効にする(発動から1ターンだけ有効)。タルを抱えている間は攻撃できない(README記載)弱点を技で補う |
| 目覚ましの一喝 | 16 | 12ターン | `plan/region-bosses.md` の予兆つき大技を**1回だけ強制的に中断させる**。ボス戦における高難度の切り返し手段 |
| 抱え投げの奥義 | 20 | 15ターン | 抱えているタルを、通常の直線1体止まりではなく、当たったマスの先まで貫通させて投げる。`plan/monster-house.md` の密集地形で真価を発揮する |

## なぜモンスターには持たせないのか

`design/protagonist.md` の非対称設計の方針どおり、モンスター側の
「プレイヤーの判断を介さない自動戦闘」という性質を保つため。仲間に
技を持たせたくなった場合は、まずこの技システムではなく
`plan/monster-fusion.md` の特技(SkillId)側で表現できないかを検討する
こと。両方に似た仕組みを重複させない。

## データ構造

```ts
export interface ArtDef {
  id: string;
  name: string;
  unlockLevel: number;
  cooldownTurns: number;
  description: string;
}

// PlayerState に追加
artCooldowns: Record<string, number>; // 技id → 残りクールダウンターン数
```

技の発動は既存の `GameEvent` の枠組み(ダメージ・状態異常・特殊効果)に
乗せられるものが大半で、「なだめの手つき」のような新しい効果(HPを
減らさず捕獲判定だけ動かす)だけ、捕獲判定処理(`src/game.ts` の樽処理
まわり)に小さな分岐を1つ足す形で実装できる。

## バランス上の注意

- 技はいずれも**恒常的な火力の底上げにはしない**(会心の樽投げ・
  抱え投げの奥義は、ここぞという場面のための切り札であり、クールダウンが
  長いぶん連発できない)。`design/balance-philosophy.md` のパワーバジェット
  方針に合わせ、装備・強化値・印の上にさらに積み上がる数値にしない。
- 「目覚ましの一喝」はボス戦専用の切り返しであり、雑魚戦では実質的に
  空振りになる効果(モンスターは予兆つき大技を持たないため)にして、
  用途を絞る。
- レベル20到達は現状かなり後半(`EXP_TABLE` 参照)なので、「抱え投げの
  奥義」は物語終盤(第五地方〜山の芯)でようやく手に入る、という
  到達感を意図的に残す。
