# チュートリアル専用ダンジョン「ひなたの寝穴」

## 経緯

チュートリアルは現在、通常のダイブ中に文脈でtipを出す方式
(`plan/game/archive/tutorial.md`)と、1階の敵を弱くする調整
(`plan/game/archive/tutorial-floor-easing.md`)で成り立っている。
これを一歩進め、**最初のダンジョンを本編とは別に作り、そこで操作
説明を行う**。あわせてこのダンジョンは**明るく見通しのよい**環境に
し、暗がりで操作を覚える負担をなくす。

主人公が光りすぎる問題(#718)とは独立に、「最初の体験は明るい場所で」
という方針をダンジョン側で保証するもの。

## 設定(考証)

名前は**ひなたの寝穴**。地表のすぐ下にある一番浅い夢で、**うたたね
――日なたでうとうとする浅い眠り――の夢**だから、外の光が夢にまで
差し込んでいる(明るさの考証)。ヨリシロの眠りが浅い場所なので
出てくる夢のかけらも弱く、樽守りの見習いが最初に入る修練の場として
村が代々使ってきた、という位置づけ(`design/village-buildings.md` の
「洞窟の入口=初代が器の世話を始めた場所」と両立する、入口脇の
浅い横穴とする)。

## ダンジョン仕様

- `DungeonDef` に追加: `id: "hinata"`, `maxDepth: 3`,
  `unlock: "always"`。**初回プレイ(セーブに一度も踏破記録が無い
  状態)では、出発時の行き先選択を出さずに自動でここへ潜る。**
  踏破後は行き先リストに常に並び、いつでも入り直せる(操作を
  忘れたときの読み返し場所を兼ねる)。
- ひなたの寝穴を一度踏破するまで、他のダンジョンは選べない
  (`plan/game/dungeon-per-region.md` の解放連鎖の先頭に置く。
  第一地方の解放条件を「ひなたの寝穴の踏破」にする)。
- **既存セーブ(踏破記録あり)は対象外**: 自動誘導せず、行き先
  リストに追加されるだけ。

### 明るさ・見通し

- 専用のムード視覚(`plan/game/archive/mood-visual-effects.md` の
  仕組みを流用): **ambientを強く、fogを遠く**、色味は日なたの
  暖白色。松明表現(playerLight)はこのダンジョンでは補助程度まで
  弱めてよい(全体光で十分見えるため)。
- フロアは**小さめ・部屋数少なめ・一本道寄り**の生成パラメータに
  する(迷わせない)。罠・ギミック・モンスターハウスは生成しない。
- 出現はぷるんのみ(数も少なく)。3階に番人としてぷるん2体だけの
  「小さな群れ」を置き、ボスの間・扉は作らない(ボス戦の作法は
  第一地方で初めて出会う)。

### チュートリアルの流れ(階ごとの課題)

案内役はモグラ婆(チュートリアル語り役、`design/characters.md`)。
姿は出さず、**ログに「モグラ婆の声」としてtipを流す**(既存の
`tutorialTip` の仕組みをそのまま使い、このダンジョン専用のtip群を
追加する。文言は入力方式で出し分ける既存の枠組みに乗せる)。

| 階 | 覚えること | 仕掛け |
|---|---|---|
| 1階 | 移動・向き変え・攻撃(X/攻撃ボタン)・階段 | 短い一本道。中間にぷるん1体。階段の手前で「区切り」はまだ教えない |
| 2階 | タルを持つ・投げる・捕獲・命名 | 空のタルを部屋に必ず1つ配置。弱ったぷるんに当てるとほぼ確実に捕獲(barrel-capture-clarity.mdのHP1保護で保証)。捕獲後は命名ダイアログの流れも自然に体験する |
| 3階 | 道具(草・かたパン)・満腹度・めざめの階段 | いやしの葉とかたパンを床に必ず配置。最奥に**めざめの階段**があり、3択モーダル(checkpoint-stairs-menu.md)から「区切って持ち帰る」を選ぶと踏破=チュートリアル完了 |

- 各階のtipは**その階で必要になる操作だけ**を、必要になる直前に
  1つずつ出す(一度に流さない)。既読管理は既存の仕組みのまま。
- 踏破時にモグラ婆の締めの一言(「これでお前も見習い卒業だね」等)
  +第一地方(始まりの森の寝穴)の解放を告知する。

## 既存要素との整合

- `plan/game/archive/tutorial-floor-easing.md` の「1階はぷるんのみ」
  調整は、本編第一地方では**不要になったら戻してよい**(チュートリアル
  の役目がひなたの寝穴へ移るため。戻すかどうかは実装側の裁量)。
- 既存の文脈tip(初めて拾った・初めて持ち上げた等)は本編でも
  従来どおり出す(ひなたの寝穴で学び損ねた操作の保険)。
- 記録の間・実績: ひなたの寝穴は踏破数・最深記録の集計対象に
  含めない(修練場のため。依頼板の対象からも除外)。
- 序章「見習い樽守り」(`design/story.md`)の実体がこのダンジョンに
  なる(章側の文言更新は不要。あらすじと一致している)。

## 受け入れ基準

1. 新規セーブの初回出発で自動的にひなたの寝穴(3階)へ潜り、
   階ごとのtipが表の順で出る。
2. 全体光で照らされ、松明の光の輪に頼らず画面全体が見通せる。
3. 2階でタル捕獲→命名までが自然に一度体験できる。
4. 3階のめざめの階段で「区切って持ち帰る」を選ぶと踏破になり、
   第一地方が解放される。
5. 踏破後も行き先リストから再訪できる。既存セーブには自動誘導しない。
