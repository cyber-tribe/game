# ダンジョンごとのボスの間(扉つき)と撃破報酬

## 実装状況(このセクションは実装セッションが追記した注記)

受け入れ基準1・2(前室→扉→ボスの間の固定構造、扉の確認で「やめる」を
選ぶ限りボス戦が始まらない)は既存PR(#739)で実装済み。今回のPRで
受け入れ基準4(2回目以降の踏破では置き土産が一段軽い)を実装し、
受け入れ基準3のうち「置き土産」の部分を実装した。残りの意図的に
見送った点:

- **「ぬしの置き土産」の中身**(`src/entities/bossTreasure.ts`)は、
  高強化値(+3〜+5)の武器/盾・印つき装備・レア素材の束、の3枠から
  等確率で抽選する。doc本文が挙げる「そのダンジョンでは拾えない上位の
  草・巻物」は、草・巻物のminFloorが最大でも4(`items/catalog.ts`)しか
  なく、ボス階(tableDepth>=6)には常にすでに出揃っていて「拾えない
  上位」が実在しないため、この一枠は残り2枠に統合した(未決事項どおり
  中身は未確定だったため、実装セッションの裁量で決めた)。
- **「撃破後、部屋の奥に踏破の階段が現れる」は未実装のまま**。#739の
  MVPどおり、階段は最初からボスの間の奥に置いてある(倒す前から見える)。
  受け入れ基準3はこの部分だけ満たしていない。

## 経緯

地方ボス自体は実装済み(`plan/game/archive/region-bosses.md`。地方の
最終階に出現)だが、通常フロアの中に他のモンスターと同列に湧く形で、
「ボス戦が始まる」区切りが無い。地方別ダンジョン化
(`plan/game/dungeon-per-region.md`)に合わせ、**各ダンジョンの
最終階を専用のボスの間にし、入る前に扉で立ち止まれる**ようにする。

## ボスの間の構造

最終階は通常のフロア生成を使わず、**専用の固定構造**にする:

```
[小部屋(入口)] ─通路─ [扉] ─ [ボスの間(大部屋)]
```

1. **小部屋(前室)**: 階段で降り立つ部屋。敵は湧かない安全地帯。
   ここにめざめの階段は置かない(帰還は中間階で済ませている前提。
   撤退するなら道具・技で戻る)。
2. **扉**: 前室とボスの間を仕切る、1マスの扉タイル。
   - 扉の前に立って決定すると確認モーダルを出す:
     「◯◯のぬしの気配がする。扉をあけますか?(あける/やめる)」。
     既定カーソルは「やめる」(`stairs-confirm` と同じ誤操作防止方針)。
   - **開けるまでボス戦は始まらない**。持ち物整理・回復・仲間の構え
     指示・タルの準備をここで済ませられる。
   - 一度開けたら閉じられない(扉タイルは開放状態になる)。
3. **ボスの間**: ボス+少数の取り巻きだけがいる大部屋(モンスター
   ハウス級の広さ)。ボス戦中は新規湧きなし。ボスのAI・大技は
   既存の地方ボス仕様(`region-boss-*.md` 各アーカイブ)をそのまま
   使う。

## 撃破報酬

ボスを倒すと、既存の確定ドロップ(`bossGuaranteedDrop`: 地方限定
素材)に加えて、**宝箱相当の「ぬしの置き土産」を1つ**その場に落とす:

- 中身は「強いかレアか」を保証する専用テーブルから抽選する:
  高強化値(+3〜+5)の武器/盾、印つき装備
  (`plan/game/archive/equipment-forging.md`)、そのダンジョンでは
  拾えない上位の草・巻物、レア素材の束、のいずれか。
- 同じダンジョンの**2回目以降の踏破では置き土産の内容を一段軽くする**
  (初回踏破の特別感を守りつつ、周回の意味も残す)。
- 撃破後、部屋の奥に踏破の階段(帰還)が現れる。降りると踏破として
  ダイブ成功で終わる(次のダンジョン解放は
  `plan/game/dungeon-per-region.md` の通り)。

## 演出

- 扉を開けた瞬間にボスBGMへ切り替える(既存のボスBGM遷移を扉開放
  トリガーに移す)。`plan/sound/` 側に「扉のきしみ」のSFXを1つ
  追加依頼。
- ボスの間に入ると、ボス名の帯(「◯◯のぬし」)を短く表示する。

## 受け入れ基準

1. 各ダンジョンの最終階が「前室→扉→ボスの間」の固定構造になる。
2. 扉の確認で「やめる」を選ぶ限りボス戦が始まらず、前室で自由に
   準備できる。
3. ボス撃破で確定ドロップ+置き土産が落ち、奥に踏破の階段が現れる。
4. 2回目以降の踏破では置き土産が一段軽い。

## 対象外

- ボスそのもののAI・ステータス変更(既存の地方ボス仕様のまま)
- 山の芯(第八)の最終決戦演出(`plan/game/archive/mountain-core.md`
  の既存の流れを優先し、扉+前室の構造だけ揃える)
- 腕試しの間などの特殊ダンジョンへのボスの間追加

## 未決事項

- 置き土産テーブルの具体的な中身・抽選率
- 前室に商人や回復の泉のような救済を置くか(まずは何も置かない)
