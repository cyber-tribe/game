# スマホ版の画面構成を全面的に見直す

## 経緯

タッチUI(`plan/game/archive/touch-controls.md`)と重なり対策
(`plan/game/archive/touch-ui-overlap-fix.md`)を入れた後の実機
スクリーンショットでも、ゲームアプリとして快適といえる画面に
なっていない。具体的には:

1. **メッセージログがHUD(階数・HP)に覆いかぶさる。** ログは
   行数が増えると上へ伸び、左上のHUDパネルを完全に隠す。
2. **ログが画面の1/3近くを占有し、盤面が見えない。** デスクトップの
   「左側に縦長のログ」をそのまま持ち込んでいるのが原因。
3. **チュートリアル文がキーボード前提。**「矢印かWASDで歩けるよ」
   「Xキーで攻撃できる」という文言が、キーボードの無い端末で
   そのまま出る。
4. **ミニマップが大きく、始めたばかりの階では中身がほぼ空。**
5. 終了オーバーレイ等の文言も「R キーで」「Space:」とキーボード
   前提(タップ可能なボタンの追加は
   `plan/game/gameover-touch-return.md` で別途扱う)。

## 方針: スマホ用は「重ねる」のではなく「別レイアウトを組む」

これまでの「デスクトップのパネル配置を基本にして、タッチ端末では
予約マージンでずらす」やり方(`--zone-tr-reserve` 等)は限界なので、
`@media (pointer: coarse)` ではパネルの寸法・位置・挙動そのものを
モバイル向けに切り替える。

### ゾーン割り(横持ち)

```
+--------------------------------------------------+
| [HUDバー]                       [ミニマップ(小)] |
|                                                  |
|                 (盤面 = 最優先)                  |
|                                                  |
| [仮想パッド]  [メッセージ帯(中央下)] [ボタン群] |
+--------------------------------------------------+
```

- **HUDバー(左上)**: 現在の縦積みパネルをやめ、
  「B1F・Lv1・HPバー」を1行に収めた**細長い横バー**にする。
  高さの目安は40px前後。満腹度などの追加情報はバー内にアイコン+
  数値で詰める。
- **ミニマップ(右上)**: 現在より一回り小さくし(目安: 短辺の
  1/4以下)、背景の透過を強める。タップで拡大/縮小をトグル
  できるとなおよい(未決事項)。
- **メッセージ(中央下の帯)**: 縦長ログパネルを廃止し、
  **最新2〜3行だけを表示する半透明の帯**を画面下部中央
  (パッドとボタン群の間)に置く。新しい行が来たら古い行を
  押し出し、**数秒操作が無ければ帯ごとフェードアウト**する。
  過去ログ全文は「≡」メニューの「ログ」から全画面で読める
  ようにする(スクロール可能)。
- **仮想パッド(左下)・アクションボタン(右下)**: 現状の配置を
  維持。メッセージ帯とはゾーンが分かれているため重ならない。

### 文言のタッチ対応

キー名を含むテキストを、タッチUI有効時はボタン名に差し替える。

- チュートリアルtip(`src/game.ts`の`tutorialTip`系)と
  ゲーム内メッセージのうち、「矢印/WASD」「Xキー」「Spaceキー」等の
  キー名を含むものを対象に、**入力方式(タッチ/キーボード)ごとの
  2パターンの文面**を持てる仕組みにする。例:
  - キーボード:「Xキーで、向いている方向へ攻撃できる。」
  - タッチ:「攻撃ボタンで、向いている方向へ攻撃できる。」
- 判定は既存のタッチUI表示条件(`pointer: coarse`)と同じで良い。
- 操作説明一覧(`src/entities/settings.ts`の`KEY_REFERENCE`)にも
  タッチ版一覧を用意し、タッチ端末の「≡」メニュー・拠点設定画面
  ではそちらを表示する。

### セーフエリア対応

PWA化(`plan/game/pwa-support.md`)で全画面表示になると、iPhoneの
ノッチ・ホームインジケータ領域にUIが食い込む。各ゾーンの端の
オフセットに `env(safe-area-inset-*)` を加算しておく
(`viewport-fit=cover` をviewport metaに追加する)。

## 受け入れ基準

1. スマホ横持ちで、HUD・ミニマップ・メッセージ・パッド・ボタンの
   **どの2つも重ならない**(ログが何行たまっても)。
2. 盤面(3Dビュー)を遮るのは半透明の帯・小パネルのみで、
   プレイヤーと周囲8マスが常に見える。
3. キーボードのキー名がタッチ端末の画面に一切出ない。
4. メッセージ帯は放置でフェードアウトし、全文ログは「≡」→ログで
   読める。
5. デスクトップ(pointer: fine)の表示・挙動は変わらない。

## 対象外

- 縦持ちレイアウト(引き続き「横向きにしてください」案内で対応)
- 終了オーバーレイへのタップボタン追加
  (`plan/game/gameover-touch-return.md`)
- 文字選択・ズーム誤発動の防止(`plan/game/touch-gesture-guard.md`)
