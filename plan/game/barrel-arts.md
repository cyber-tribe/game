# タルわざ ― タルの種類拡張と、投げる/置く/あける/持つの戦略化

## 経緯

タルは現在3種(空・爆発・モンスター入り)で、使い方も「投げる」が
ほぼすべて。タルというこのゲームの看板ギミックを、**仲間の特技で
タルを作り変え、投げる・置く・あける・頭上に持つの4通りで使い分ける**
戦略の核へ拡張する。あわせて敵側もタルに干渉させ、盤面のタルを
めぐる駆け引きを作る。

## 1. 新しいタルの種類(元素タル)

空のタルに仲間の「タルわざ」(後述)を注いで作る。初期5種:

| タル | 投げる | あける(足元/正面へ) | 頭上に持つ(パッシブ) |
|---|---|---|---|
| 水タル | 命中した敵に水ダメージ。火系の敵に大ダメージ | 周囲3×3を水びたしの床にする。**炎の床・火柱を消火**して道をひらく | 火ダメージを半減 |
| 風タル | 直線上の敵をまとめて2マス吹き飛ばす | 周囲の敵全員を1マス押し出す | 罠を踏んでも発動しにくくなる(足取りが軽い) |
| 光タル | 命中した敵を数ターン目つぶし | 部屋全体を明るくする(暗闇ギミック対策) | 視界+2 |
| 石タル | 単体に大ダメージ(重い) | **その場に岩の壁(1マス)を作る**。通せんぼ・退路封鎖に | 被弾ノックバック無効 |
| ねむタル | 命中した敵を眠らせる | 周囲1マスの敵に眠りをばらまく | 敵に気づかれにくくなる |

- **あけると中身は失われ、空のタルに戻る**(捕獲道具として再利用
  できる)。「強い効果を今使うか、空タルとして温存するか」の
  損得がタル1個ごとに生まれる。
- 置く(既存の下ろす)はどのタルでも従来どおり可能で、1マスの
  遮蔽物になる。石タルの壁と合わせて「地形を作る」選択肢になる。

## 2. タルわざ(仲間の特技でタルを作る)

- **ゆめわざ(`plan/game/companion-leveling-and-arts.md`)の
  一分類**として「タルわざ」を追加する。習得の枠組み(種族の習得表・
  レベルで覚える)はゆめわざと共通。
- 使い方: プレイヤーが**空のタルを抱えて「仲間へ指示」(T)を開く**と
  「タルわざを頼む」が現れ、タルわざ持ちの仲間を選ぶと抱えたタルが
  変化する(1ターン消費)。新しいキーは増やさない。
- どの種族がどのタルわざを覚えるかは、種族の系統で割り当てる
  (水辺系→水タル、風系→風タル、発光系→光タル、岩・骨系→石タル、
  まどろみ系→ねむタル)。ゆめわざ習得表(`dreamArts`)に
  タルわざも並べる。
- **なじみ(`plan/game/archive/companion-bond-growth.md`)の段階が
  上がると、同じタルわざが強力版になる**(例: 水タル→大水タル:
  あけた範囲が5×5に、消火に加えて味方の火傷も治す)。
  「育てるほど・懐くほどタルの選択肢が増える」が育成の報酬になる。

## 3. あける(新しい操作)

- タルを抱えているとき、**「あける」で中身を正面(塞がっていれば
  足元)に放つ**。効果は上の表のとおり。1ターン消費。
- 操作: キーボードは `V`。タッチはタルを抱えている間だけ
  「あける」ボタンを表示する(文脈ボタン。`plan/game/archive/
  mobile-layout-redesign.md` のゾーン内に収める)。
- 爆発タルをあけるとその場で爆発する(自爆。できるが推奨されない
  ことは説明文で伝える)。モンスター入りタルはあける=既存の
  「解放」と同じ扱い。

## 4. 敵もタルに干渉する

一部の敵種族に「盤面に置かれたタル(空・元素とも)を作り変える」
行動を持たせる:

- 火系の敵: 空のタル・置かれたタルに火をつけ**爆発タル**に変える
  (数ターン後に自然爆発。プレイヤーへの時限の脅威)。
- 水系の敵: タルを**水タル**に変えてしまう(捕獲用の空タルを
  潰される妨害。ただし水タルとして使えば得もする)。
- 対象は各地方2種程度に留め、行動頻度も低くする(タル管理が
  煩雑になりすぎない範囲)。敵がタルに干渉したターンはログと
  専用エフェクトで必ず知らせる。

これにより「置いたタルを守る/わざと変えさせる」「敵の近くに空タルを
置かない」という盤面の駆け引きが生まれる。

## 5. 必須にしない(最重要の制約)

**元素タルが無いと絶対に進めない状況は作らない。** 消火・暗闇・
通せんぼ等、タルわざで楽になるギミックには必ず代替手段(回り道、
既存のアイテム、時間経過)を残す。タルわざは「攻略が速く・楽しく
なる選択肢」であり、特定の仲間の連行を強制しない
(仲間編成の自由=育成の幅を狭めないという方針)。

## 受け入れ基準

1. 空のタル+タルわざ持ちの仲間で元素タル5種を作れる。
2. 各元素タルを投げる/あける/持つで表の効果が出て、あけた後は
   空のタルに戻る。
3. なじみ段階の高い仲間のタルわざは強力版になる。
4. 火系・水系の敵が置かれたタルを作り変え、ログで通知される。
5. 元素タル無しでも全ダンジョンを踏破できる。

## 対象外

- タルわざの全種族割り当て表(`companion-leveling-and-arts.md` の
  `dreamArts` 割り当てと同時に実装側で決める)
- 元素タルの追加(6種目以降)。まず5種の手触りを見る
