# 村の画面構成の再設計(建物考証の反映)

## 経緯

村なか歩き(`plan/game/archive/town-3d-exploration.md`)と建物内部
(`plan/game/village-interiors.md`)は機能としては仕様化済みだが、
見た目は「緑の平面に色つきの箱」の仮置きのまま。建物考証
(`design/village-buildings.md`)と祠木・タルの考証
(`design/yorishiro-and-barrels.md`)が固まったので、**村の屋外
シーンと内装の画面構成を、考証を出典に作り直す**。

モデル(建物・小道具)の造形仕様は `plan/models/model-village-
structures.md`(別PR)が担い、本書は**配置・カメラ・光・導線**を扱う。

## 屋外シーンの再設計

### レイアウトの原則(考証の反映)

1. **山を背景に置く。** シーンの奥(北)に、ヨリシロの稜線を模した
   遠景シルエット(霧がかった大きな山影)を常に見せる。
   「山に背を向けて建てない」の考証どおり、**主要な建物の入口は
   すべて山側(奥)を向く**=プレイヤーからは建物の正面が見える。
2. **洞窟の入口は村の最奥・山裾に置く。** 門柱の祠木一対+たが縄が
   村で一番目を引くランドマークになる。出発への導線が画面の構図
   としても「山へ向かう」動きになる。
3. **広場の囲炉裏火を村の中心に置く。** 常時ゆらめく炎(既存の
   焚き火表現の流用)+タルの腰掛け。ポチ・おたま(章進行後)は
   この火の周りに立つ。夜も明るい「現実側の錨」として、村の
   ライティングの光源中心にする。
4. **祠木をまばらに植える。** 村は祠木の林の中、という考証の表現。
   通行の邪魔にならない密度で5〜8本。渦を巻いた年輪の切り株を
   1〜2箇所に置く(座れる必要はない、景色として)。
5. 建物の配置は現行の `VILLAGE_BUILDINGS` の座標を土台に、
   上記1〜3を満たすよう調整する(倉庫・工房は広場を挟んで左右、
   ねむり小屋は静かな村はずれ、依頼板と看板は村の入口側)。

### ライティング・色

- 時間帯は**常に夕暮れ〜宵**(帰ってくる時間の村)。囲炉裏火の
  暖色を中心に、山側は青い霧の寒色。タルと同じ飴色の木肌が
  映える配色にする(トゥーンシェーディングの階調と相性の良い
  2トーン構成)。
- 各建物の窓・入口から暖色の明かりを漏らす(生活の気配)。

### 導線・ヒント

- 建物ヒント(「決定: ◯◯へ」)に役割の一言を添える既存方針は
  そのまま。加えて、**建物の外観自体が役割を語る**(工房の煙突の
  煙、ねむり小屋の掛け布、依頼板の札 等。造形は models 側)ため、
  文字に頼る度合いを下げられる。

## 内装の再設計(village-interiors.md への上書き指定)

`plan/game/village-interiors.md` の内装要素表を、考証に基づき
次のとおり具体化する(構造・遷移・メニュー配置は同仕様のまま):

| 建物 | 内装の必須要素(考証出典) |
|---|---|
| モグラ婆の倉庫 | **伏せた古タルを転用した棚**に道具が並ぶ。帳場の机。屋根裏へ続くはしご(ガルドが育った屋根裏) |
| ゲンドの工房 | 炉(広場の火の株分け=同じ暖色)、金床、壁の工具、**寝かせて乾かす祠木の材**、作りかけのタル |
| ねむり小屋 | **名札と掛け布つきのタルの寝床**が並ぶ。宿めいた落ち着いた薄明かり。フクが寝床の間を回る |
| おキヨの図鑑小屋 | 本と標本瓶の棚、**タルの側板の木札の束**(図鑑の実体)、大机 |
| 記録の間 | 巻物棚(芯棒はタルのたが)、**年代記「ねむりのしおり」を広げた文机**、掲示された記録 |
| 村の発展の受付 | 村の模型(現在の発展段階を反映できるとよい)、図面 |
| ガルドの家 | 土間の支度タル、**壁の歴代樽守りの手形**、衣装掛け、寝床 |

- 内装のカメラは「入口から見た斜め俯瞰」の既存方針のまま。
- 内装内でも、窓の外に山側の霧(寒色)か広場の火(暖色)のどちらが
  見えるかを建物の向きと一致させる(細部だが世界の一体感に効く)。
